# sitting-posture-corrector

LSTM 기반 자세 붕괴 주기 분석 및 교정 보조 시스템.

이 저장소의 `frontend/`는 **발표용 UI 데모**입니다. 카메라도 모델도 붙지 않았고,
미리 정해둔 시나리오를 재생하면서 화면과 판정 규칙만 실제로 동작시킵니다.

## 실행

```bash
cd frontend
npm install
npm run dev
```

`http://localhost:5173` 에서 열립니다. 로그인 화면에서 아무 값이나 넣고 들어가면 됩니다.

## 화면

| 경로 | 내용 |
| --- | --- |
| 로그인 | 계정별 기록 분리 안내 (인증 동작 없음) |
| 홈 | 최근 7일 요약, 최근 측정 목록, 측정 시작. 기록 없는 상태도 전환 가능 |
| 측정 준비 | 카메라 권한 확인, 카메라 선택, 촬영 안내, 기준 자세 보정 |
| 실시간 측정 | 키포인트 오버레이, 판정 상태, 붕괴 확정 카운터, 교정 알림, 이벤트 목록 |
| 대시보드 | 일별 기록, 주간 비교, 초기·최근 구간 전후 비교 |
| 설정 | 판정 파라미터, 알림 설정, 운영 정보 |

## 구현된 판정 규칙

계획서의 이벤트 규칙을 `src/lib/engine.ts`에 그대로 넣었습니다. 화면 연출이 아니라
실제로 돌아가는 상태 기계입니다.

- 붕괴 확률이 임계값(기본 0.70) 이상으로 **3초 지속**될 때만 이벤트로 확정
- 같은 이벤트의 반복 경고는 **재알림 간격 60초**만큼 억제
- **정상 복귀 유지 시간 2초**를 둬서 상태가 반복 전환되는 것을 방지
- 판정 불가 구간에서는 자세 판정을 멈추고 조명·위치 안내만 표시
- 이벤트에 시작·종료 시각, 지속시간, 알림 횟수, 회복 여부를 기록하고
  측정 종료로 끊긴 이벤트는 따로 구분

통계 정의도 계획서를 따릅니다.

- 유효 측정 시간 = 전체 − 일시정지 − 판정 불가
- 바른 자세 유지율 = 바른 자세 시간 / **유효** 측정 시간
- 붕괴 발생 간격은 같은 세션 안의 연속 이벤트 시작 시각 차이로만 계산
- 회복 시간은 최초 알림부터 정상 복귀까지. 알림을 꺼둔 구간의 이벤트는 집계에서 제외 표시
- 평균과 함께 **중앙값·표본 수**를 같이 표기
- 유효 측정 시간이 0이면 `0%`가 아니라 **계산 불가**로 표기

파라미터는 설정 화면에서 바꿀 수 있고, 바꾸면 측정 화면에 바로 반영됩니다.

## 발표용 조작

실시간 측정 화면에 시연을 돕는 조작이 있습니다.

- **시연 배속** 1x / 2x / 4x / 8x — 재알림 60초 같은 긴 규칙을 짧은 시간에 보여줄 때 사용
- **다음 구간으로** — 붕괴 구간이 올 때까지 기다리지 않고 바로 건너뜀
- **키포인트 표시** 토글
- 설정 화면의 **홈에 기록 표시** — 신규 사용자(기록 없음) 화면으로 전환

시나리오 한 바퀴는 385초이며 바른 자세 → 거북목 → 기울어짐 → 자리 비움(판정 불가) →
긴 거북목(재알림 발생) 순으로 반복됩니다.

## 구조

```
frontend/src/
  data/posture.ts    자세 정의, 관절 좌표, 시연 시나리오, 판정 파라미터
  data/history.ts    대시보드용 14일치 가짜 기록
  lib/engine.ts      판정·이벤트 상태 기계 (순수 함수)
  lib/stats.ts       유지율·평균·중앙값 등 통계 정의
  hooks/useSession.ts  requestAnimationFrame으로 engine을 구동
  components/        PoseStage(가짜 웹캠), 공용 UI
  pages/             화면 6종
```
