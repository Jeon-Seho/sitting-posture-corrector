# 관측 전체 및 ML 후보 특징 내보내기

`/dev`에서 명시적으로 내려받는다. 실제 영상·오디오와 카메라 장치 ID는 포함하거나 저장하지 않고, 이름이나 참가자 식별자 전용 필드도 두지 않는다. 출력은 현재 탭 메모리에만 머무르며 서버로 전송하거나 자동 저장하지 않는다. 메모에 개인 정보를 입력하지 않도록 안내한다. **안내 과제는 수행을 검증한 정답이 아니다.** 참여자별 분리와 라벨 검토는 별도다.

## 전체 데이터

`observation-keypoint-replay-v5` JSON은 Pose 원래 인덱스 0..32의 image/world x·y·z·visibility를 33개 순서로 기록한다. 프레임마다 관측 시각·검증 전 원시 시각·영상 시각·수집 경과 시각·크기·추출기 ID·추론 시간·실행 delegate·어깨 추적 상태·이용 가능한 기존 특징을 포함한다. `phase`, `task`, `round`, `trial`, `attempt`, `segment`, `measurement`는 안내 맥락이고, 최상위 plan·수동/자동 모드·스트레칭 메모·중단 표식과 누락 수를 보존한다. 유효하지 않거나 없는 값은 null이며 0으로 보완하지 않는다. 시간 역전의 좌표 원본은 보존하되 유효 관측으로 해석하지 않는다.

화면 측정 경로에서 약 10Hz로 채택한 추론 관측을 기록한다. 카메라의 모든 영상 프레임이나 실측 전신 좌표를 보장하지 않으며 화면 밖 좌표는 모델 추정이다. 메모리 한도 6,000프레임 도달 시 측정을 자동 종료하고 보존된 자료를 내보내도록 알린다. 이전 v1(13점)·v2~v4(23점) 파일도 리플레이로 읽는다. 파일 불러오기는 64MiB 이하만 허용한다.

## ML 후보 특징

`observation-ml-candidates-v1` JSON은 같은 기록에서 현재 연구의 후보 5개(기준 대비 머리–어깨 간격·얼굴 세로 길이·어깨 높이·어깨폭·코–어깨 상대 z)와 팔 13..22 image/world 좌표·visibility를 별도로 내보낸다. 기준은 녹화된 기준 등록에서 기존 관측 엔진으로 재구성하며 실패·결측은 null로 남는다. 프레임 시간·단계·시도·유효성·추출기·중단 표식·누락 수를 포함하고 영상·전체 좌표는 포함하지 않는다. 팔 좌표는 추정값이며 낮은 visibility도 그대로 남는다. 특징 목록은 연구 후보이고 학습 입력 형식이나 모델 성능을 확정하지 않는다.
