# 서비스 자료 처리 안내 service-v2

2026-10-13 현재 구현과 가입 화면에 대응하는 동의 문서 버전이다. 연구·학습용 이용 동의는 포함하지 않는다.
비의료용 자세 변화 안내 서비스이며 진단·치료 효과를 제공하지 않는다.

| 종류 | 선택 | 목적·자료·보관 |
| --- | --- | --- |
| TERMS | 필수 | 서비스 이용 조건과 비의료용 자세 변화 안내 범위에 동의 |
| ACCOUNT_INFO | 필수 | 이메일·이름·비밀번호 해시를 로그인과 계정 관리에 사용 |
| POSE_COORDINATES | 필수 | 기준 등록 시 9개 관절 평균 좌표를 전송·보관하고, 측정 중에는 기준 대비 특징 변화량과 품질을 서버 판정에 사용. 영상은 전송·보관하지 않음 |
| MEASUREMENT_RECORD | 필수 | 설정·기준·세션 요약·사건·알림 시도·일별 통계를 계정 기록 제공에 사용 |
| AGE_14_OVER | 필수 | 만 14세 이상임을 본인이 확인. 생년월일은 수집하지 않으며 입력한 나이가 14세 미만이면 가입 거부 |
| OPTIONAL_PROFILE | 선택 | 나이·직업의 선택 입력과 보관. 거부해도 서비스 이용 가능, 프로필에서 철회 시 두 값을 즉시 비움 |

필수 사항에 동의하지 않으면 가입할 수 없다. 필수 동의 철회는 회원 탈퇴로 처리한다.
탈퇴 시 즉시 계정 사용을 중지하고 30일 뒤 삭제하며, 유예 기간 안에는 로그인 화면에서 철회할 수 있다.
유예 중에는 동의와 기록을 보관하고, 계정 최종 삭제 시 동의 행도 지운다.
직접 내려받은 파일은 사용자가 관리한다. 기존 백업의 만료 정책·개정 약관 재동의는 별도 운영 결정이다.

각 동의는 종류·문서 버전·서버 동의 시각을 저장한다. 선택 정보 재동의는 새 행으로 남긴다.
문서 내용을 바꾸면 버전을 갱신하고 새 동의를 받는다. 과거 이용자의 동의를 자동 생성하지 않는다.
