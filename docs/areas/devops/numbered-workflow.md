## 요청과 완료 기준

작업 번호, 팀 배정, AI 소유자 기록, 분야별 문서, 선행 관계, 원격 변경 알림과 공용 스킬을 한 작업 흐름으로 연결한다.

## 구현과 운영

- 아르케의 AGENT.md와 tools/project-board/work.py에서 카드 등록 → 착수 → 기록 → 접수함 → 검증 루프와 실제 변경 이력을 확인했다. 바른자세는 담당 배정이나 별도 사용자 승인 없이도 완료 근거가 확인되면 완료 처리하는 사용자 요청을 적용했다.
- GP 번호는 변경·삭제 후 재사용하지 않는다. 별은 선행 영향, 점은 규모, 10·20·30은 배치 간격이다. 의존 순환·누락과 오래된 버전 저장을 거부한다.
- AI 작성자는 team.json에서 확인된 계정에 GPT/CL 접미사를 붙인다. 우진 예외는 Lellon_GPT/CL이다. 메모와 카드 이력은 다음 작업의 접수함으로 연결한다.
- 프론트·백엔드·데브옵스·서버·머신러닝·논문·DB별 생성 규칙과 프로젝트 단계를 연결한다. .agents/skills가 공용 정본, .claude/skills가 같은 정본의 진입점이다. docs.py는 최신 파일에서 제한된 목록·목차를 제공한다.
- 신규 MD의 분야·작업 번호, 카드 단계·근거, 계획 등록 누락을 work.py check로 검사한다. Windows 공통 tools/dev.py check 및 CI의 make check에도 포함했다.
- 5분 간격 원격 fetch와 최근 브랜치 SHA 변경·내 미커밋 파일 겹침 알림을 제공한다. 타 PC의 미푸시 작업은 알 수 없다.
- develop 9533234의 저장 검증·비교·카메라/탈퇴 개선을 병합했다. 충돌한 카메라 동작은 사용자가 허용한 개선 버전의 직접 켜기 동작으로 통합했다. 기존 변경은 선행 커밋 6bfc350에 보존되어 있다.
- GP-0011~0039에 후속 작업 29개와 선행 관계를 등록했다. GP-0040~0042에는 동욱의 이미 완료한 develop 구현을 배정 여부와 무관하게 근거와 함께 반영했다. 실제 카메라 검증은 GP-0033에 남긴다.

## 공유와 한계

팀원은 goodpose-mdweb을 받은 뒤 루트 바른자세_관리판.bat을 실행한다. 카드·메모 변경도 커밋·푸시하고 다른 PC에서는 pull한다.
공개 웹 호스팅이나 중앙 동시 편집 서버가 아니다. 원격 알림은 중복 작업 예방 보조이며 독점 잠금이 아니다.
실제 카메라·소리·장시간·다른 PC·실제 모바일 검증은 수행하지 않았다. 해당 제품 검증은 후속 카드로 추적한다.
