# 단계별 프로젝트 여정

- 분야: 프론트
- 작업: GP-0043

## 문제와 완료 기준

평면 문서 목록만으로는 프로젝트가 어느 단계인지 알기 어렵다. 단계별 현재 작업·완료 기준·선행 대기·근거 문서를 함께 보여준다.

## 구현

stages.json의 7개 제품 단계와 상시 운영을 사용한다. 카드의 stage를 기준으로 완료·진행·대기를 계산하고, 가능한 다음 작업은 선행 관계와 배치 순서를 따른다.
단계 선택 시 관련 카드와 MD를 모아서 보여준다. 전체 문서 탐색·본문 검색·분야 필터·원문 읽기도 유지한다.
제품 작업 완료 집계에서 상시 운영을 제외한다. 카드 개수는 제품 품질이나 연구 성과 달성률이 아니다.
카드 생성 시 단계 선택이 필요하고 CLI의 add/create-doc/sync-plans도 --stage를 받는다. 새 단계 누락은 공통 검사에서 잡는다.
