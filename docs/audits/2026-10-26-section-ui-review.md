# 화면 구간별 UI 검수

2026-10-26 실제 앱 첨부 피드백 이후 로컬 프론트를 구간별로 검수했다. 기준은 현재 읽기 크기 유지, 단색 아이콘 유지, 중립 면과 선명한 기록/선택 대비다. 검수는 합성 프로필과 영상으로 수행하며 사용자의 실제 저장 자료를 변경하지 않는다.

| 구간 | 확인한 문제 / 판단 | 적용 |
| --- | --- | --- |
| 로그인·회원가입 | 긴 약관 목록이 왼쪽 소개/그림까지 세로로 늘림 | 넓은 화면의 소개는 창 높이 안에 고정, 그림 높이 제한. 좁은 웹은 일반 흐름 유지 |
| 측정 준비 | 기존 단계/카메라 행동은 명확함 | 현재 구조와 단일 카메라 시작 버튼 유지 |
| 측정 중 | 280px 보조 열에서 원+설명을 가로 배치해 한글 설명이 수직으로 끊김 | 원 위/설명 아래 배치, 설명14px/넉넉한 행간 |
| 잠시 쉬기·측정 불가 | 영상 위 옅은 배지에 짙은 화면의 밝은 글자가 상속돼 대비가 매우 약함 | unknown 배지의 밝은 바탕/어두운 글자를 명시. 정상·이탈·측정 불가 의미 유지 |
| 카메라 조작 | 재개/일시정지의 옅은 버튼에서 아이콘도 밝아 흐릿함 | 주 조작은 옅은 면+어두운 글자/아이콘, 나머지 어두운 영상 조작은 밝은 아이콘 유지 |
| 종료 결과 | 기록 화면용 통계 배치가 종료 카드에 상속돼 한쪽으로 치우침, 무거운 갈색 그림자 | 중앙 통계 정렬, 가벼운 중립 그림자, 행동 위 간격 |
| 기록 없음 | 그림만 중앙이고 설명/버튼은 왼쪽 | 앞선 보정 유지: 가운데 한 그룹 |
| 기록 목록·잔디 | 무기록과 짧은 기록 차이가 약함 | 앞선 보정 유지: 밝은 무기록/분명한 4단계 초록. 데이터 구간은 그대로 |
| 달력 | 이번 주 전체와 선택 셀 채움이 과함 | 앞선 보정 유지: 날짜 원만 표시 |
| 설정·프로필 | 입력값까지 이름 라벨의 굵기를 상속, 초점은 이전 주황색. 비활성 조작은 과한 투명도 | 입력400, 초점 초록, 읽을 수 있는 비활성 바탕/글자. 상세 펼침 제목14px |
| 삭제·오류 | 삭제 버튼 hover가 이전 주황색 | 오류 역할에 맞는 붉은 계열 유지. 실패/동의/저장 설명은 삭제하지 않음 |
| 데스크톱 작은 창·제목줄 | 제목줄이 이전 바탕색에 남음 | 본문과 동일한 제목줄. 작은 창 기존 단색 아이콘·드래그/접기/닫기 유지 |

색상/배치 변경이며 카메라 판정·기록 저장·서버 계약은 변경하지 않는다. 프론트 테스트/타입/빌드와 실제 브라우저 상태별 캡처, 좁은 화면, native 작은 창을 검증한다. 전체 DB 통합과 실제 장치/장시간 사용은 별도다.

## 실행 결과

- `python tools/dev.py check-frontend`: 55파일364개 통과, TypeScript/생산 빌드 통과. 마지막 CSS 추가 이후 빌드도 재확인. 기존500KB 번들 경고는 남음.
- Chrome 독립 합성 프로필: 로그인/회원가입/약관 모달/프로필/측정 준비/정상 측정/측정 불가/일시중단/종료/연결 오류 캡처와 시각 검수. 회원가입·프로필·측정·종료·오류는1360/1180/690/390px에서 가로 넘침/이미지 누락 없음. 기록·달력·설정도 기존 합성 검수 스크립트로 확인.
- 원형 지표0/80/100%×네 너비에서 안쪽 여백 유지. 달력 주 전체 배경/선택 셀 채움이 없음과 잔디5단계 색상 확인.
- 실제 개발 Electron 합성 작은 창 열기/같은 스트림/단일 창/외부 팝업 차단/닫기·재열기/카메라 종료 정리 통과.
- `python tools/dev.py check-browser`: 생산 번들에 합성 진입점이 없는 검사는 통과. Docker daemon 연결 실패로 임시 MySQL 생성에서 중단. 전체 서버 통합 성공이 아님.
- 문서 검사와 diff 공백 검사 통과. 실제 카메라 장시간/서버·DB 통합/모든 운영체제는 미검증. 현재 실행 중 앱은 보존했으며 이번 구간 검수 수정의 EXE 재패키징은 미실행.

브라우저 캡처는 Git 제외 `.cache/design-review/audit-*.png`와 `records.png`, `calendar.png`, `settings.png`다. 검수는 실제 저장 기록에 접근하지 않았다.
