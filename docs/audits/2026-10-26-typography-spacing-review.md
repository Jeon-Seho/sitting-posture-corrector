# 글자와 여백 검토 — 2026-10-26

## 문제

사용자가 원형 지표의 글씨가 꽉 차 보인다고 지적했다. 오늘 원 지름은 136px로 줄어든 상태에서 내부 숫자는 54px로 남아 있었다. 수치와 제목에 반복되는 800 굵기, 음수 자간, 서로 다른 보조 글자 크기도 화면의 밀도를 높였다.

## 공식 제품 가이드 조사

개별 앱 화면의 CSS나 사용량을 추정하지 않고 공개된 공식 제품 디자인 시스템을 확인했다.

| 근거 | 공개 기준 | 적용 판단 |
| --- | --- | --- |
| [Microsoft Fluent 2 Typography](https://fluent2.microsoft.design/typography) | 웹 본문 14/20px, 캡션 12/16px, 부제 16/22px, 제목 24/32px. 굵기별 역할 분리 | 데스크톱 조작 화면의 기본 크기·제목 계층에 참고 |
| [Atlassian Typography](https://atlassian.design/foundations/typography) | 앱 본문 14/20px, 긴 본문 16/24px, 보조 12/16px. 본문 굵게 표시는 제한적으로 사용. rem 기반 | 한글 설명은 13/20px로 조정하고 입력은 16/24px. 숫자/단위 굵기 구분 |
| [Atlassian Spacing](https://atlassian.design/foundations/spacing) | 8px 기반이며 4·8·12·16·20·24·32px 등 제한된 간격 사용 | 카드 24px, 조작 이름과 입력 8px, 항목 간 16px, 큰 그룹 24/32px |

원 지름 대비 숫자 크기는 위 가이드의 규정이 아니라 이 제품의 실제 한글·숫자 조합에 맞춘 판단이다. 모든 작은 캡션을 본문 크기로 키우거나 전체 글씨를 일괄 축소하지 않는다.

## 최초 적용과 후속 수정

- `typography.css`를 테마/반응형 배치 뒤에 로드해 텍스트 역할을 한 곳에서 결정한다.
- 기본 14px/약21px, 설명 13/20px, 짧은 캡션 12/16px, 카드 제목 16/24px, 화면 제목 24/32px. rem 사용.
- 본문 자간 0, 제목 -0.01~-0.02em. 역할별 굵기 400/500/600/700. 공유 Amount의 800 굵기도 700으로 조정.
- 오늘 지표: 원 136→156px, 선 12→10px, 숫자 54→36px, % 22→16px, 숫자와 캡션 간 8px. 0·80·100%에서 원 안쪽 안전 영역 확인.
- 측정 중 점수는 40→32px, 로컬 종료 화면은 오늘 지표와 같은 156px 원/36px 수치로 조정. 서버 종료 화면도 %를 작은 단위로 분리하고 점수 크기를 맞춤.
- 카드 패딩 24px/모바일20px. 제목 아래20px, 설명 위6px, 필드 이름과 입력8px, 지표 항목16px. 기록 행과 부가 문구도 행간을 확보.
- 로그인·측정 준비·기록·달력·설정에 공유 스타일 적용. 조건부 오류/동의/개인정보 문구는 보존. 색상과 날짜별 저장 로직은 이번 수정에서 변경하지 않음.

## 검증

프론트 단위 테스트·타입·빌드, 실제 Chrome 합성 화면 시각 검수와 원 안쪽 여백/반응형 검사를 실행한다. 결과는 [실행 계획](../plans/active/0058-forest-theme-and-kst-day-records.md)에 기록한다. 사용자 대상 가독성 실험을 수행한 결과는 아니다.

## 사용자 가독성 피드백에 따른 최종값

전체 글자가 작아져 가독성이 낮아졌다는 피드백을 반영했다. 위 최초 적용 수치는 이력이며 현재 기준은 아래와 DESIGN.md다. 일반 UI 가이드 수치를 이 앱의 적정 크기로 단정하지 않는다.

- 본문 15px, 주요 설정 이름 16px, 기록 행 제목/버튼/메뉴 15px, 설명 14/22px, 화면 제목 26/34px로 확대.
- 오늘·로컬 종료 지표는 원 176px/선10px, 숫자44px/행52px. 오늘 지표의 단위18px·설명14px. 측정 중 점수는 기존40px로 복원.
- 원 안 여백과 카드/항목 간격은 유지한다. 답답함을 글자 전체 축소로 해결하지 않는다.
- 네 화면 너비와 0/80/100%에서 확대된 글자와 원형 지표의 여백을 다시 검사한다.

후속 원 두께 요청: 현재 오늘/로컬 종료 원은 지름188px·선16px다. 수치44px는 유지하며 내부 여백을 확보한다.
