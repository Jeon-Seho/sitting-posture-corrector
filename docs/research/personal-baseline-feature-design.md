# 개인 기준 대비 변화량을 위한 ML 특징 설계 초안

- 상태: 비교 방향 합의, 상세 특징·임계값은 제안. [최종 점검표](personal-baseline-final-review.md)와 [ADR 0023](../decisions/0023-baseline-feature-comparison.md)를 따른다. 서비스 구현·계약·판정 임계값은 변경하지 않는다.
- 작성일: 2026-10-12
- 사용자 확정 범위: 등록한 개인 기준에서 얼마나 벗어났는가. 공통 바른 자세를 정의하지 않는다.
- 촬영: 정면 고정. 모니터 위의 높은 카메라와 노트북의 낮은 카메라를 모두 고려한다.
- 입력 추적기: 현재 Heavy. 어깨 포함 얼굴의 원래 Pose index 0~12를 사용한다.
- 2026-10-12 후속 사용자 결정: 현재는 Pose의 얼굴 11개와 어깨 2개를 활용한다. Face Landmarker는 후속 비교 실험으로만 기록한다.
- 라벨 부담: 데이터 수집과 정답 검토의 시간이 큰 제약이다. 아래 기준 중심 설계를 우선 검토하며 다단계 수동 라벨은 필수로 확정하지 않는다.

## 현재 구현과 한계

`lee_app1` 반영 후 `model/prototype/pose.ts`는 코·양쪽 귀·양쪽 어깨를 사용한다.
headGap은 코 높이, offset은 귀 중점의 좌우 위치, tilt는 어깨선 높이 차이다. turn은 코와 귀 중점의 좌우 차이로 고개 회전을 제외하는 보조 특징이다.
네 값은 매 프레임의 어깨 간 영상 거리로 나눈다. `calibration.ts`는 평균을 기준으로 보관하며 `serverFeatures.ts`는 headGap/offset/tilt의 현재−기준 변화량을 만든다.
현재 서비스 판정 기준에는 13개 키포인트별 대표 좌표가 없다. 완료된 기준 등록의 13점 원본 시계열은 별도 IndexedDB에 저장하고 JSON으로 내려받는다.
과제 CSV에는 기준 시계열이 없으며 같은 calibration_id의 기준 JSON과 연결해 대표값을 산출해야 한다. [보존 결정](../decisions/0022-local-baseline-archive.md).

headGap은 영상에 투영된 코 높이이며 머리 전방 이동을 직접 측정한 값이 아니다.
과거 코 기반 offset은 고개 회전과 머리/몸 이동을 혼동할 수 있었다. 현재 귀 중점 기반 offset과 turn 제외 규칙은 이 혼동을 줄이려는 보완이며 실제 각도 측정이나 검증된 정확도를 뜻하지 않는다.
tilt는 어깨선 높이 차이의 비율이며 실제 목/척추 각도가 아니다.
현재 가시성·화면 경계 품질은 코와 양쪽 어깨만 확인한다. 양쪽 귀는 유한 좌표만 필수이고 가시성 검사는 하지 않는다. 눈·귀·입을 새 입력으로 쓰려면 포인트별 품질도 필요하다.

## 좌표와 기준 변화량의 제안

좌표를 수집하는 것은 타당하다. 다만 화면 절대 좌표만 학습하거나 변환 정의 없이 현재−기준을 계산하면
영상 해상도·위치·카메라 구도에 의존한다. 원본 추정값은 연구용 자료로 보존하고 모델 입력은 재현 가능한 공통 변환으로 만든다.
서버 특징 전송은 기존 입력 v2와 다른 데이터 범위이므로 구현 전 새 계약 버전·개인정보 경계를 정의해야 한다.

### 기준 좌표 수집

기준 등록의 유효 프레임에서 13개 포인트의 대표 좌표와 변동, 포인트별 유효 표본 정보를 계산한다.
대표값을 평균으로 할지 중앙값으로 할지는 학습/검증 실험으로 선택한다.
불충분한 포인트를 0 좌표로 대신하지 않는다. 기준 등록의 모든 포인트가 유효해야 한다는 임계값도 추측으로 정하지 않는다.
눈·귀의 가림이 모든 측정을 중단시키는 구조 대신 특징별 마스크와 전체 측정 불가 기준을 별도로 설계한다.

### 정규화 후보: 기준 크기로 정규화하고 위치 변화도 보존

영상 정규화 좌표를 먼저 픽셀 좌표 p=(W*x,H*y)로 변환한다. 두 축의 영상 비율을 반영하기 위해서다.
기준 프레임에서 어깨 중점 c0, 어깨 간 거리 s0를 구한다. 현재 어깨 중점은 ct, 거리는 st다.
모든 값은 같은 카메라·해상도에서 얻고 s0가 유효할 때만 계산한다.

```text
q_i(t)  = (p_i(t) - c(t)) / s0
q_i(0)  = (p_i(0) - c0) / s0
dq_i(t) = q_i(t) - q_i(0)
dc(t)   = (c(t) - c0) / s0
scale_ratio(t) = st / s0
```

q는 어깨 중심에 대한 얼굴·어깨 배열, dq는 개인 기준 대비 배열 변화다.
dc는 어깨 중심 자체가 움직인 양이다. 이를 빼면 머리와 어깨가 함께 이동하는 변화가 사라질 수 있다.
기준 s0를 고정하면 영상 크기 변화가 보존된다. 현재 실험에서는 카메라 위치·줌을 고정한다.
고정 조건이 바뀌면 기준을 재등록한다. 높고 낮은 카메라 구도는 각각 같은 조건의 기준으로 비교한다.

### 정규화 비교 항목: 현재 어깨 크기로 정규화

현재 q_i(t)의 분모를 st로 바꾼다. 카메라 거리의 영향을 더 제거할 수 있지만, 자세와 관련된 크기 변화도 지울 수 있다.
이 경우에도 dc와 st/s0를 따로 남긴다. 기준 폭/현재 폭 정규화는 같은 참여자 분할·모델·라벨에서 비교한다.
어깨선을 매 프레임 수평으로 회전 정렬하면 기울임 정보가 사라질 수 있으므로 초기 제안에서는 하지 않는다.

## ML 입력 후보

| 묶음 | 후보 정보 | 이유 |
| --- | --- | --- |
| 좌표 | 13개 q_i의 x/y | 코 하나로 요약하지 않고 얼굴·어깨 배열을 유지 |
| 개인 변화 | 13개 dq_i의 x/y | 각 사람의 기준을 직접 반영 |
| 위치·크기 | dc의 x/y, st/s0 | 중심 정렬·크기 정규화로 사라질 수 있는 정보 보존 |
| 품질 | 현재·기준 포인트별 visibility/유효 마스크 | 가림·실패를 실제 자세 변화와 분리 |
| 보조 기하 | 눈선·귀선·입선 방향, 각 중점의 어깨 대비 위치, 좌우 거리 비대칭 | 머리 회전과 위치 변화를 구분하는 후보 단서 |
| 시간 | 실제 시각·관측 간격·최근 시계열 | 일시 움직임과 지속 변화를 비교 |

좌표 26개와 좌표 변화 26개가 첫 비교 후보이며, 위치·크기·품질을 추가한다.
원본 x/y와 정규화 x/y를 혼동하지 않도록 이름·단위·순서·좌우 반전 정책을 계약에 명시한다.
코는 유지하되 다른 얼굴 포인트와 함께 사용한다. 눈/귀/입의 각도·비대칭은 영상상의 단서이지 검증된 yaw/pitch/roll 측정값이 아니다.
z/world 좌표 추가는 별도 소거실험으로 검증한다. Pose의 깊이·3D는 단안 추정값이며 실측 깊이로 취급하지 않는다.
[BlazePose GHUM 연구](https://arxiv.org/abs/2206.11678).

## 라벨 예시와 모델 출력

목표는 해부학적 자세 종류의 정답이 아니라 개인 기준 대비 변화다. 다음 이름은 예시이며 단계 수·경계는 미정이다.

| 자세 변화 정도 라벨 | 수집 예시 |
| --- | --- |
| baseline_like | 기준을 유지하되 호흡·작은 자연 움직임을 포함 |
| small_change | 기준에서 의도적으로 조금 이동하거나 기울임 |
| medium_change | 위보다 더 큰 변화 |
| large_change | 수집 범위에서 큰 변화 |

변화 방향은 별도 태그로 기록한다: 좌/우 이동, 위/아래 이동, 머리 회전, 어깨선 기울임, 복합 변화.
정면 영상에서 직접 관찰하기 어려운 전방 깊이 변화를 곧바로 forward_head 정답으로 확정하지 않는다.
degree 라벨은 촬영 지시를 수행했다는 이유만으로 자동 확정하지 않고 수집 후 자기 보고/검토로 확인한다.
측정 불가·전환·자리 비움·가림은 변화 정도의 최상위 단계로 넣지 않는다.

다단계 라벨 분류는 라벨 비용 때문에 우선순위를 낮춘다. 향후 필요하면 단계 간 순서를 사용하는 ordinal 모델 또는 기준과 현재를 비교하는 pairwise 모델을 비교한다.
연속 점수 회귀는 연속 정답 점수의 정의와 평가 근거가 마련된 뒤 비교한다.
좌표 거리로 만든 점수를 그대로 정답으로 삼으면 그 거리 공식을 복제하는 학습이 될 수 있다.
기하 거리로 정의한 변화량만 필요하다면 먼저 학습 없이 계산한 기준 모델을 평가한다.
서비스 출력 후보는 변화 점수·방향 단서·측정 품질이다. 현재 우선 개발 경로의 시간 정책은 로컬 엔진이 담당하며 선택형 서버 경로는 CEP가 담당한다.

## 라벨 부담을 줄이는 우선 제안

사용자가 정의한 목표는 공통 정답 자세가 아니라 개인 기준에서 관측된 변화량이다.
초기에는 baseline_like/small/medium/large 전체를 사람이 붙이는 분류기보다 기준 중심의 연속 변화 점수를 먼저 비교한다.
이는 제안이며 서비스 구현이나 알림 정책이 확정됐다는 의미가 아니다.

### 1. 학습 없는 기하 변화 점수

정규화 좌표의 개인 변화량, 머리의 어깨 대비 위치, 눈·귀·입 선의 영상상 방향 변화,
어깨 중심 이동·어깨선 변화·크기 변화를 따로 계산한다. 방향 성분을 유지하면서 연속 크기를 출력한다.
코 한 점의 이동을 전체 점수로 대신하지 않고 얼굴 위치·방향과 어깨 변화의 묶음별 출력을 비교한다.
눈 주변 6개가 귀/입/어깨보다 많은 이유만으로 전체 점수를 지배하지 않도록 묶음 집계와 가중치를 검토한다.
가림 마스크·유효 포인트 수가 바뀌었을 때 점수 분모도 처리하며, 정보가 부족하면 unmeasurable이다.

이 점수는 정의한 영상상 변화량이며 해부학적 자세의 심각도나 이탈 확률이 아니다.
별도 감독학습의 정답 라벨은 필요하지 않지만, 어떤 변화에 알림을 원하는지와 카메라 잡음의 허용 범위는 평가가 필요하다.

### 2. 기준 범위를 이용한 novelty detection

기준으로 받아들일 수 있는 촬영만 확인해 수집하고 그 분포에서 벗어난 관측을 찾는 방식을 비교한다.
기준 중심·변동량을 이용한 통계 점수부터 시작하고 필요하면 One-Class SVM 등의 모델을 검토한다.
모든 이탈 종류의 라벨을 요구하지는 않지만 기준 자료 선정, 검증 표본 검토, 임계값 선택은 필요하다.
현재 3초·최소 15개 기준 프레임은 서로 상관된 짧은 관측이며 고차원 분포 학습에 충분하다고 간주하지 않는다.
특징별 변동이 너무 작으면 점수가 폭증할 수 있으므로 잡음 하한·안정화·차원 축소를 학습/검증에서 검토한다.
임계값·가중치·차원 축소를 시험 참여자의 이탈 자료로 튜닝하지 않는다.
[공식 novelty detection 설명](https://scikit-learn.org/stable/modules/outlier_detection.html).

### 검토 시간 줄이기

- 기준 등록 구간은 사용자 의도상 기준 자료다. 표본 품질·실제 기준 유지 확인을 거친 후 촬영 단위 태그를 사용할 수 있다.
- 촬영 과제와 시작/종료 시각은 자동 메타데이터로 기록한다. 과제를 요청했다는 이유만으로 실제 이탈 정도를 정답으로 확정하지 않는다.
- 학습용 대규모 프레임별 라벨 대신 일부 독립 촬영·짧은 구간을 기준 유지/의도적 변화/확인 불가로 검토해 초기 평가를 구성한다.
- 모델 점수로 추린 애매한 학습/검증 구간만 추가 검토하는 방식은 후속 후보다. 시험 자료를 이 과정에 섞지 않는다.
- 평가용 정답은 모델 출력으로 만들지 않는다. 모델이 선택한 구간만 평가하면 편향될 수 있으므로 연속/대표 평가 구간도 별도로 확보한다.

자연스러운 고개 회전까지 기준 이탈에 포함할지, 작업 중 허용할 움직임으로 볼지는 서비스 의미를 별도로 정해야 한다.
관측된 기준 차이와 사용자에게 알릴 필요성은 같은 목표라고 가정하지 않는다.

## 카메라 높이·관측 범위

개인 기준으로 카메라 높이에 따른 고정 오프셋을 줄일 수 있지만 투영 차이가 모두 사라지지는 않는다.
높은/낮은 정면 카메라 조건을 수집 메타데이터로 기록하고 조건별 성능·새 참여자 성능을 확인한다.
상체가 함께 앞으로 이동한 상황과 머리만 이동한 상황, 고개 숙임과 회전 등 서로 혼동될 후보를 포함한다.
카메라가 실제 움직이거나 해상도/줌이 바뀌면 기존 기준 비교의 유효성을 확인하고 필요 시 재등록한다.
어깨 위 영상으로 허리·골반·척추 상태까지 판정하지 않는다.

## 비교와 완료 조건

참여자 분할을 먼저 적용하고 같은 기준 등록 자료·라벨·시계열 구간으로 비교한다.
시험 참여자는 본인의 기준 등록 자료만 개인 보정에 쓰며 그 외 시험 자료로 특징·임계값을 선택하지 않는다.

1. 과거 코·어깨 세 특징 규칙과 현재 귀 기반 offset·turn 제외 규칙을 대조군으로 구분한다.
2. A: 13개 점의 절대 변화 (현재−기준)/기준 어깨 폭.
3. B: 현재 어깨 중점 기준 13개 상대 좌표의 기준 대비 변화.
4. C: B+어깨 중점 자체의 변화+현재/기준 어깨 폭 비율. 우선 실험 후보이며 최적안은 아니다.
5. 위 입력에 얼굴 관계 특징 추가, 기준 폭/현재 폭 정규화를 별도 비교한다.
6. 필요할 때 Face Landmarker 방향 특징 또는 z/world 추가.

같은 유효 좌표·기준 폭이면 A_i=dq_i+dc이므로 A와 C는 좌표 정보를 재구성할 수 있는 표현이다.
결합 입력은 새로운 센서 정보를 추가하지 않는다. 품질 조건·모델·분할을 맞추고 성분 분리의 효과를 비교한다.

카메라 높이별 혼동, 기준 유지 구간의 오알림, 변화 단계 순서 오류, 판정 불가 비율, 지연·FPS를 측정한다.
코를 제외하거나 코만 사용한 비교도 실시해 의존성을 확인한다. 품질·누락 경계를 넘어 보간하거나 학습 창을 연결하지 않는다.
이 문서는 제안이며 검증된 최적 입력이나 모델 정확도를 주장하지 않는다.
