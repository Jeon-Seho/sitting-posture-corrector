# v8 자세 자료: 학습 전용 수학적 증강 파일럿

2026-11-08에 [기존 트리 파일럿](replay-v8-trees.md)과 같은 20개 v8 원본을 사용했다.
원본 JSON은 수정하지 않았다. 학습에 사용하는 1초 창의 6개 특징을 메모리에서 증강하고,
한 번도 변형하지 않은 실제 참여자의 창으로 시험했다. 안내 과제는 확인된 정답이 아니며,
이름별 참여자가 실제로 서로 다른 사람인지 아직 확인되지 않았다.

## 증강 방법

기존 등록 기준·품질 판정·1초 중앙값을 그대로 사용한다. 각 **학습 창**마다 아래 네 개의
특징 벡터를 추가해 원본 포함 총 5개로 만든다. 원본 좌표 JSON이나 라벨 파일은 생성·변경하지 않는다.

1. 좌우 반전: 좌우 치우침·어깨 기울기의 부호를 바꾸고 다른 네 특징은 그대로 둔다.
2. 원본 특징에 작은 난수 오차를 더한 두 복사본.
3. 좌우 반전한 특징에 작은 난수 오차를 더한 복사본.

오차는 6개 특징별 표준편차 `[0.005, 0.005, 0.002, 0.004, 0.004, 0.005]`의 정규분포에서
뽑아 각각 ±2표준편차로 제한했다. 기존 특징은 기준 어깨폭에 대한 비율 또는 정규화 비율이다.
seed는 `20261108`이다. 원본과 네 복사본의 가중치 합을 원본 한 개의 가중치와 같게 해,
증강만으로 특정 참여자·시도의 비중이 늘지 않게 했다. 난수 크기와 좌우 반전 시 라벨 보존은
아직 실제 촬영으로 검증하지 않은 가정이다. 좌우 반전은 비대칭 환경과 행동을 완전히 재현하지 못한다.

전체 자료로 후보를 학습할 때의 1,968개 원본 창에서 7,872개 합성 특징 창을 만들어 총 9,840개를
사용했다. 이 합성 창은 원본과 상관되어 있고, 새 사람이나 실제 새 촬영 7,872개가 아니다.

## 실제 원본 테스트 결과

각 평가에서 한 사람을 빼고 나머지 사람의 학습 창만 증강했다. 모델 설정과 임계값도 남은
사람들의 내부 참여자 분할에서만 고른 뒤, 제외한 사람의 **증강하지 않은 실제 창**으로 시험했다.
이 과정을 사람별로 6회 반복했다. 수치는 참여자별 결과의 평균이다.

| 모델 | 증강 전 창 balanced accuracy | 증강 후 창 balanced accuracy | 증강 전 시도 기준 | 증강 후 시도 기준 |
| --- | ---: | ---: | ---: | ---: |
| 랜덤 포레스트 | 91.1% | 91.6% | 93.2% | 93.1% |
| LightGBM | 88.5% | 89.0% | 90.3% | 91.3% |

독립적으로 시작하는 안내 측정 구간에 3초 연속 판정을 재생한 탐색 결과:

| 모델 | 이탈 시도·재시도 감지 | 기준 구간에서 이탈 감지 |
| --- | ---: | ---: |
| 랜덤 포레스트 증강 전 | 56 / 71 | 7 / 56 |
| 랜덤 포레스트 증강 후 | 55 / 71 | 5 / 56 |
| LightGBM 증강 전 | 52 / 71 | 7 / 56 |
| LightGBM 증강 후 | 51 / 71 | 4 / 56 |

기준 구간 오감지는 줄었지만 이탈 감지도 각각 1개 줄었다. 한 시도·재시도에는 유효한 창이 없어
재생 분모에서 빠진다. 연속적인 일상 작업과 실제 이탈 시작 시점이 원본에 없어 위 결과는
실생활 시간당 오알림률이나 감지 지연이 아니다. 6명과 약한 라벨에서 0.5%p 차이는 안정적인
개선으로 확정할 수 없다.

## 실행과 산출물

Python 환경에 `model/analysis/requirements-training.txt`와 `requirements-trees.txt`가 필요하다.
기존 파일럿의 비공개 카탈로그에서 참여자 소유 관계를 확인한 뒤 저장소 루트에서 실행한다.

```powershell
python -m model.analysis.replay_pilot.augment --catalog "<private>/catalog.json" --output "<private>/augmentation-run-01"
```

신원 확인 전의 탐색 실행에만 `--allow-unverified-identities`를 추가한다. 입력 해시는 실행 전후로
재확인하며, 기존 출력은 덮어쓰지 않는다. 산출물은 Git 밖의 접근 제한 폴더에 보관한다.
`report.json`에는 분할·설정·집계·해시가, `all-data-augmented-random-forest.joblib`과
`all-data-augmented-lightgbm.txt`에는 전체 참여자로 학습한 후보가 들어 있다. 각 fold 모델은
파일명의 참여자를 학습과 증강에서 뺀 모델이다. 전체 참여자로 다시 학습한 후보는 **별도의 독립
시험을 받지 않았으며** 서비스에 연결하지 않았다. `joblib`은 신뢰할 수 있는 파일만 불러온다.

현재 실행 환경은 Python 3.14, NumPy 2.4.4, scikit-learn 1.8.0, LightGBM 4.6.0이다.
새 참여자와 연속적 일상 작업 자료를 확보해 의자·몸·카메라 이동, 일시 동작과 실제 알림을
별도로 검증한다. 이번 수학적 증강은 의자 이동 보정을 구현하거나 검증한 결과가 아니다.
