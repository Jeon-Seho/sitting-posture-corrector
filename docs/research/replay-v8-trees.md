# v8 자세 리플레이: 랜덤 포레스트와 LightGBM

2026-11-08에 기존 [v8 파일럿](replay-v8-pilot.md)과 같은 원본·기준·6개 2D 특징·1초 창으로
참여자별 교차 검증을 실행했다. 안내 과제는 수행 검증을 거친 정답이 아니다. 이름 표기의 동일인
확인도 하지 않았으므로 참가자 분리의 정확성을 보증할 수 없다. 이 결과는 탐색용이다.

## 결과

| 모델 | 참여자별 창 balanced accuracy 평균 | 참여자별 시도 중앙값 balanced accuracy 평균 |
| --- | ---: | ---: |
| 기존 규칙, 임계값 0.7 | 0.852 | 0.864 |
| 기존 규칙, 내부 검증 임계값 | 0.846 | 0.858 |
| 로지스틱 회귀, 3특징 | 0.851 | 0.848 |
| 로지스틱 회귀, 6특징 | 0.842 | 0.843 |
| 랜덤 포레스트, 6특징 | **0.911** | **0.932** |
| LightGBM, 6특징 | 0.885 | 0.903 |

창 점수의 참여자별 범위는 랜덤 포레스트 0.802~0.989, LightGBM 0.720~0.991이었다.
측정 구간을 각각 독립적으로 시작하는 3초 연속 이탈의 탐색적 재생에서, 이탈 시도·재시도
71개 중 감지는 기존 규칙 41개, 랜덤 포레스트 56개, LightGBM 52개였다. 기준 구간 56개 중
이탈이 감지된 수는 세 모델 모두 7개였다. 유효 창이 없는 1개 시도·재시도는 이 분모에 없다.
이 재생은 끊겨 있는 안내 구간만 쓰므로 실생활 오알림률이나 실제 발생 시점 기준 지연이 아니다.
윈도우는 같은 사람과 시도 안에서 상관되며, 사람 6명의 결과로 신뢰성 있는 일반화나 모델 우위를
확정할 수 없다. 비교 모델을 같은 시험 결과로 선택하면 선택 편향도 생긴다.

## 방법

- 참가자 한 명을 시험에 빼는 바깥쪽 6회 평가, 남은 사람만의 안쪽 참가자 분할로 설정·임계값을
  선택한다. 각 사람의 모든 촬영은 같은 역할이며 시험 참가자의 이탈 데이터는 학습에 넣지 않는다.
- 랜덤 포레스트는 트리 120개와 `(깊이 4, 최소 잎 10)` 또는 `(깊이 8, 최소 잎 5)`를 비교한다.
  LightGBM은 트리 100개·학습률 0.05와 `(깊이 3, 잎 7, 최소 표본 40)` 또는
  `(깊이 4, 잎 15, 최소 표본 20)`을 비교한다. 두 모델 모두 seed 7·CPU 1스레드다.
- 임계값 0.10~0.90을 0.05 간격으로 검증하고, 사람·클래스·시도별 가중치를 쓴다.
  모델 점수는 확률 보정을 검증하지 않았다. 피처 구성과 품질 기준은 기존 파일럿과 같다.
- 이후 6명 전체로 학습한 두 후보도 별도로 저장한다. 각각의 설정·임계값은 전체 참여자 대상
  내부 교차 검증으로 정한다. **이 최종 학습본에는 별도의 독립 시험 집합이 없다.**

## 실행

Python 3.12 환경에서 `model/analysis/requirements-training.txt`와
`model/analysis/requirements-trees.txt`를 설치한다. 기존 파일럿 설명에 따라 Git 밖의 비공개
카탈로그를 만들고 신원을 확인한 뒤 저장소 루트에서 실행한다.

```powershell
python -m model.analysis.replay_pilot.trees --catalog "<private>/catalog.json" --output "<private>/tree-run-01"
```

신원 검토 전의 탐색 실행에만 `--allow-unverified-identities`를 추가한다. 기존 출력 폴더는
덮어쓰지 않는다. `report.json`에 코드·데이터 해시, 버전, 각 fold 결과와 후보 설정을 기록한다.
`all-data-random-forest.joblib`, `all-data-lightgbm.txt`는 전체 자료로 학습한 후보이며
그 외 모델은 각 시험 참가자를 뺀 fold 모델이다. 모델·카탈로그·원본 좌표는 Git 밖의
접근 제한 폴더에 둔다. `joblib` 파일은 신뢰할 수 있는 출처의 파일만 불러온다.

이번 실행은 Python 3.14, scikit-learn 1.8.0, LightGBM 4.6.0이다. 고정 의존성과 버전이 다르므로
실행별 보고서를 확인한다. 현재 서비스와 계약에는 연결하지 않았으며, 신원을 검토한 독립 참여자와
연속적인 평소 작업 자료로 오알림·감지 지연을 다시 평가한 뒤 연동을 결정한다.
