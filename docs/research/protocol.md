# 연구 프로토콜 초안

상태: 가설과 설계. 실험 결과 없음. [제공된 논문 구상](../references/posture_ai_paper_one_page.md)을 개발 기준으로 정리했다.

추가 자료: [현재 기업연계 계획서](../references/current-proposal-review.md)는 LSTM과 에피소드 중심 평가,
팀원 6명의 초기 270분 수집 목표, 3주 A/B/A′ 파일럿을 제안한다.
아래 M0~M4는 **초기 논문 구상의 비교군**이며 최신 LSTM 계획과 통합하기 전이다.
새 사용자 평가의 참여자 분할은 유지하며, 사용자/세션 분할과 판정 불가 학습 클래스의 차이는 참고 요약에 보류 사항으로 기록한다.
에피소드 평가와 개입 파일럿은 별개의 검증 단계이며, 개입 효과는 아직 확인되지 않았다.

## 연구 질문과 비교군

RQ1: 개인 기준 변화량이 처음 보는 사용자의 Macro-F1과 시간당 오알림을 개선하는가?
RQ2: 시계열 모델이 일시적인 움직임과 지속적 자세 이탈을 더 잘 구분하는가?

| ID | 비교군 |
| --- | --- |
| M0 | 고정 각도 규칙 |
| M1 | 정규화한 단일 프레임 KNN |
| M2 | 정규화한 단일 프레임 MLP |
| M3 | 개인 보정 없는 GRU |
| M4 | 개인 기준 변화량을 사용하는 GRU |

동일한 랜드마크·라벨·분할에서 비교한다. 포즈 추정기를 새로 학습하는 연구로 기술하지 않는다.

## 수집 전 동결할 내용

- 동의·익명화·삭제 절차, 보관 위치, 접근 권한, 보존 기간
- 단일 촬영 시점, 해상도, 카메라 거리, 실제 구분 가능한 자세 유형
- 시퀀스 길이, 기준 등록 구간, 품질·알림 임계값 및 재등록 규칙
- 라벨 지침, 촬영 구간, 2인 검토 및 불일치 해결 규칙
- 오알림 이벤트 정의, 정상 관찰 시간의 분모, 감지 지연의 시작/종료 기준
- 신뢰구간 추정 방식과 리샘플링 단위 (참여자별 상관을 반영)

프로토타입 6명, 본 실험 최소 20명은 모집 목표다. 확보한 참여자 수로 오인하지 않는다.
각도 규칙의 출력을 정답 라벨로 재사용하지 않는다.

## 누수 방지

참여자 단위 GroupKFold 또는 LOSO를 사용하며 프레임 무작위 분할을 금지한다.
참여자 분할 후 시퀀스 창을 만들고, 세션 경계나 분할 경계를 넘는 창을 만들지 않는다.
스케일러·특징 선택·임계값·하이퍼파라미터는 학습/검증 참여자만으로 맞춘다.
시험 참여자의 20~30초 기준 등록 구간만 개인 보정에 사용하고 그 구간은 평가 대상에서 분리한다.
시험 참여자의 이탈 데이터는 학습·튜닝에 사용하지 않는다.

## 보고와 재현

Macro-F1, balanced accuracy, 클래스별 recall, 시간당 false alarm, 감지 지연, p95 추론 지연/FPS,
95% 신뢰구간을 보고한다. 개인 보정과 시간 모델링을 각각 제거하는 소거실험을 포함한다.
결과마다 코드 commit, 설정, seed, 데이터 버전/해시, 익명화된 분할 manifest, 환경·장치 정보를 남긴다.
실제 데이터와 manifest는 접근 통제된 외부 위치에 두고 저장소에는 합성 예제·집계 결과만 둔다.
유의하지 않은 결과, 소규모 모집, 카메라 가림·깊이 불확실성, 기준 등록 오류도 기록한다.
