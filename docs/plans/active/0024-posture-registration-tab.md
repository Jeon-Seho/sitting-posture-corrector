## 배경

지금은 「측정하기」에 들어가면 얼굴과 어깨가 보일 때 3초 보정이 저절로 시작되고, 끝나면 바로 측정이 시작된다.
기준 자세는 앱 메모리에만 있고 카메라를 끄면 사라져서, 측정할 때마다 다시 등록한다.
DB `baseline_posture`는 사용자당 1행이라 "한 번 등록하고 계속 쓰는" 구조다(2026-10-12 결정).

## 목표

| 사이드바 | 기준 자세가 없을 때 | 있을 때 |
|---|---|---|
| **측정하기** (맨 위) | "아직 등록한 자세가 없어요" 안내만(버튼 없음, 등록은 사이드바 탭에서) | 카메라 미리보기·구도 확인 뒤 「측정 시작」. 보정 없이 바로 측정 |
| **자세 등록** (새 탭) | 얼굴·어깨가 보이면 3·2·1 → 측정 중 3초 → 스스로 끝남. 「측정 종료」로 멈춤 | 등록 완료 표시, 「다시 등록」을 누르면 같은 흐름. 측정 중이면 막음 |
| 기록 · 설정 | 그대로 | 설정의 「다시 등록」은 자세 등록 탭으로 이동 |

보정은 「자세 등록」 탭에서만 한다. 등록한 자세가 없으면 얼굴·어깨가 보일 때 3·2·1 뒤 저절로 시작하고, 있으면 「다시 등록」을 누를 때만 한다(10/12 피드백).

## 완료 기준

1. 사이드바 순서가 측정하기 → 자세 등록 → 기록 → 설정이다.
2. 측정하기 화면에서 보정이 시작되지 않는다. 기준이 없으면 측정 시작이 막히고 자세 등록으로 안내한다.
3. 자세 등록에서 보정이 끝나도 측정이 저절로 시작되지 않는다.
4. 등록한 기준은 카메라를 끄거나 다시 켜도 앱이 켜져 있는 동안 유지된다(4a).
5. 측정 중에는 다시 등록할 수 없다.
6. 프론트 시험·타입·빌드, 브라우저 시험이 통과한다.

- [x] 2. 자세 등록 화면(`PosturePage`): 보정 시작·취소·진행 표시, 등록 완료 표시, 다시 등록, 측정 중 막기.
- [x] 3. 측정하기 화면(`SetupPage`): 보정 부분 제거, 기준 없음 안내, 구도 확인 뒤 측정 시작.
  자동 보정·보정 직후 자동 측정(`useAutoBaseline`) 제거. 설정의 「다시 등록」과 첫 사용 흐름은 자세 등록 탭으로.
  `registration` 상태(측정 시작 버튼을 "등록 완료"로 바꾸던 흐름)는 필요 없어져 없앤다.
- [x] 4a. 기준 보관: 카메라를 끄거나 다시 연결해도 기준을 지우지 않는다(앱이 켜져 있는 동안).
- [ ] 4b. 서버 저장·조회: 등록 흐름(제안서 3.3, 10/13 정해짐)을 붙인다. 이 계획 범위 밖, 계획 0023 3단계에서 한다.
- [x] 5. 시험: 탭 순서, 기준 없을 때 막힘, 등록 뒤 보정 없이 시작, 측정 중 재등록 막힘, 카메라 재연결 뒤 기준 유지. 브라우저 시나리오 수정.

## 범위 밖

- 카메라·의자 위치가 바뀌었을 때 재등록 안내. 측정 중 평소보다 지나치게 나쁜 값이 이어지면 재등록을 제안하는 방식으로 나중에 한다([다음 작업](../backlog.md) 9번).
- 설정 안의 자세 데이터 수집 화면(BE·ML 요구를 받은 뒤 다시 만든다).
- 서버 기준 자세 저장(4b).

## 결정과 진행 기록

- 2026-10-12: 탭 이름은 「자세 등록」(정자세는 의학적 기준처럼 들려서 쓰지 않음). 화면 흐름은 위 목표 표대로.
- 2026-10-12(피드백): 자세 등록은 버튼 없이 얼굴·어깨가 보이면 "3초 뒤 측정이 시작돼요" 3·2·1 → "측정 중" 3초 → 스스로 끝남. 「측정 종료」 버튼으로 멈춘다.
  "안 끝난다"는 원인 후보: 3초 중 판정 불가 프레임 하나로 처음부터 다시 시작하거나, 초당 5장 미만이면 15표본을 기다린다. 15초 안에 끝나지 않으면 멈추고 "자세를 인식하기 어려워요"를 띄운다(`usePostureRegistration.ts`).
- 2026-10-12: 측정하기의 안내 우선순위 — ① 등록한 자세가 없음(카메라 상태와 관계없이 이 안내만, 「자세 등록으로 가기」 버튼은 어색해서 없앰) → ② 카메라 연결 → ③ 얼굴·어깨 확인. 시험 `shows the registration notice before the camera notice`.
