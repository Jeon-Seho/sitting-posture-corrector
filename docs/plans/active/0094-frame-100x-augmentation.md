## 문제와 완료 기준

기존 25배 특징 증강을 같은 방식·잡음 범위로 100배까지 늘려 기준/이탈 RF를 재학습하고, 같은 참여자 분할과 동일한 0.5 탐색 기준에서 25배 결과와 비교한다. 모델 가중치와 보고서는 새 비공개 폴더에 보관한다.

## 범위와 제외

- 100배는 원본을 포함한 100개 특징 벡터다. 기존 25개를 그대로 포함하고 같은 종류의 잡음을 추가하며, 새 사람이나 촬영이 아니다.
- 시험 참여자는 보정기·분류기 학습 및 모든 증강에서 제외한다. 시험 프레임은 원본만 사용하고 개인 기준 등록만 허용한다.
- 25배 평가의 데이터·그룹·모델 설정·품질 기준·0.5 비교 기준을 해시와 분할 기록으로 확인한다. 임계값을 시험 결과로 튜닝하지 않는다.
- 입력 9점·6특징, 보정 RF 및 3초 판정 서버 역할은 그대로 둔다. 33점 모델·FE·BE 계약과 기존 사용자 파일은 바꾸지 않는다.
- 이름 미확인 그룹은 탐색 결과로 표시하고, 단일 라벨 그룹은 클래스별 지표에는 포함하되 두 클래스 그룹 평균에서 제외한다.

## 결정과 진행 기록

- 사용자 요청: 100배 증강으로 다시 학습·평가하고 0.5의 의미를 설명한다.
- 0.5는 RF 이탈 점수를 기준/이탈로 나누는 실험용 기준이며 0.5초가 아니다. 서비스 운영 임계값은 아직 결정·검증되지 않았다.
- 평가에 사용했던 27개 촬영·9개 이름 기준 그룹을 유지하며, 신원 확인 전이라 독립 참여자 성능으로 확정하지 않는다.
- 사용자 요청으로 실행을 중단했다. 참가자별·조합별 보정 모델 45개는 체크포인트에 저장했고, 100배 분류기의 평가 결과와 전체 자료 후보는 아직 없다. 중단 당시 진행 중이던 분류기 학습은 재개할 때 다시 시작한다.
- 다른 컴퓨터에서 기존 보정 모델을 재사용할 수 있도록 비공개 자료를 해시 검증해 옮기고 카탈로그 경로·체크포인트 식별자를 갱신하는 재개 도구를 추가했다. 실행법은 [프레임 RF](../../../model/analysis/frame_pilot/README.md)를 따른다.
