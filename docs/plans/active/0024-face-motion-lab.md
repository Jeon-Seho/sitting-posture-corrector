## 문제와 완료 기준

0.1.0은 실제 사용에서 고개 회전·스트레칭·화면 이동과 어깨 미검출에 대응하지 못했다.
얼굴 추적을 독립시키고, 관측 가능한 특징으로 초기 모델을 학습하고 실험 실행 파일에 연결한다.
실제 사용자 오차 감소는 별도 검수이며 합성 시험 성능으로 완료를 선언하지 않는다.

## 범위

- 얼굴 추적, 선택적 어깨·손목, 누락 mask와 기준 상대 회전.
- 자세/행동 두 출력의 시간 CNN, 학습/검증/시험 분리와 가중치 내보내기.
- 검토한 로컬 기록의 개인 분할 입력; 자동 pseudo-label 학습은 제외.
- 서비스 API/CEP 계약과 일반 서비스 판정 교체는 제외. 별도 실험 앱이다.
