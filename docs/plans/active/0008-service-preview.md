# V2 서비스 흐름 미리보기

- 상태: in_progress
- 담당: FE
- 관련 요구사항: docs/team-requirements.md

## 문제와 완료 기준

연구용 카메라 기반을 유지하며 사용자 흐름을 검토할 수 있는 서비스 미리보기를 만든다. 내부 이동 시 측정 보존, 수동 재개, 로컬 저장 결과 공유, 소리와 화면 알림 분리, 개인 정보 편집을 확인한다.

## 범위와 제외

실제 인증·서버 저장·학습용 탈퇴 데이터 처리는 API 미연결 상태로 표시한다. 개인화 예시 학습을 구현했다고 주장하지 않는다. 연구용 화면은 별도 진입으로 유지한다. 로컬 저장 실패는 결과 보존 및 재시도로 처리한다.

- [x] 서비스 화면·저장·측정 수명 연결
- [x] 테스트·타입·빌드·문서 검증 (브라우저 흐름 미검증)

## 검증 및 남은 사항

Python10개, 프론트29개, 타입/빌드 통과. UI 도구는 sandbox 경로 오류로 연결 실패. 실제 카메라·외부 탭·음성·장시간 및 서버 연동 완료는 별도 검증이 필요하다. 상세 범위는 docs/team-requirements.md §10에 기록했다.
