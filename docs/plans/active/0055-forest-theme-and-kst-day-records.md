## 문제와 완료 기준

왼쪽 핵심 메뉴·넓은 본문 구조를 유지하며 전체 화면을 포레스트 테마로 통일한다. 반복 설명을 줄이고 상태/행동은 아이콘과 짧은 문구로 표현한다. 로그인 대표 그림과 필요한 빈 상태 자산을 실제 화면에 연결한다.

측정 세션과 판정은 자정에도 연속으로 유지한다. 일별 측정분을 KST 00시 경계로 나눠 중간 기록/종료 기록에 저장하고 오늘·지난 날짜·달력·기간 통계에서 같은 기준을 사용한다. 원 서버 snapshot은 변조하지 않는다.

## 범위와 제외

프론트 스타일·화면·자산·로컬 일별 저장/집계·검증. 카메라·판정 임계값·서버 계약·DB 스키마는 변경하지 않는다. 과거 합계만 있는 기록의 날짜별 정상/이탈 시간을 임의 비율로 복원하지 않는다.

## 결정과 진행 기록

아이콘은 작은 크기·접근성을 위해 벡터를 사용한다. 이미지 생성은 대표 일러스트에 사용하고, 생성 프롬프트·최종 자산은 저장소에서 관리한다. 원본 측정 세션 안에 날짜별 측정분을 저장해 자정마다 세션·알림 기준을 초기화하지 않는다.

- 사용자 피드백: 사실적인 남성 표현은 폐기. 기존 `login-posture-45.webp`를 편집 대상으로 삼아 단순한 인물/책상 스타일을 유지했다.
- 사용자 피드백: 화면이 너무 초록색이므로 정보 영역을 밝게 수정. 최종은 초록 사이드바·로그인 소개, 회백색 본문, 흰 카드, 주황 강조다. [Material 색상 역할](https://m3.material.io/styles/color/the-color-system), [Atlassian 면 계층](https://atlassian.design/foundations/elevation)을 참고했다.
- 추가 피드백: 색이 많아 보인다는 의견에 따라 주황 UI 강조를 제거했다. 중립적인 흰/회색 본문에 초록 버튼·그래프·선택 표시만 사용하고 로고 SVG·PNG·ICO와 상태 그림도 맞췄다.
- 글자/여백 피드백: [공식 가이드 조사](../../audits/2026-10-26-typography-spacing-review.md)를 바탕으로 공통 글자 크기·행간·굵기·자간과 카드/항목 간격을 정리했다. 오늘 원형 지표는 156px/선10px, 숫자36px로 수정했다.
- 자산: 생성 일러스트 1개(WebP, PNG 원본/프롬프트), 코드 기반 상태 그림 SVG 3개. 실제 조작은 Phosphor 벡터 아이콘과 접근성 이름을 유지한다.
- 구현 규칙은 [KST 날짜별 보관](../../decisions/0025-kst-daily-measurement-parts.md)을 따른다. API/DB 계약은 변경하지 않았다.

- 글자/여백 후속 수정: `check-frontend` 55파일·364개, 타입·빌드 통과. 실제 Chrome 로그인·준비·기록·달력·설정 시각 검수. 오늘 지표 0/80/100% × 1360/1180/690/390px의 12조합에서 원 안쪽 선과 내용 경계 간 최소 8px 여유 확인. 같은 네 너비의 측정·기록·설정 가로 넘침 없음. `check-repo`·`git diff --check` 통과. 전체 Docker 게이트의 기존 미검증 상태는 유지한다.

### 글자 축소에 대한 후속 피드백

사용자가 전체 축소로 가독성이 낮아졌다고 지적했다. 본문15px·주요 항목16px·설명14px·제목26px로 조정하고, 오늘/종료 지표는 원176px·숫자44px로 확대했다. 카드/항목 여백을 유지하고 측정 중 점수는40px로 복원했다. 현재 기준은 DESIGN.md와 글자/여백 조사 문서의 최종값이다.

기록 행의 측정시간/경고 횟수는 이전 선택자의 우선순위를 보완해 실제14px로 적용했고 작은 비율 원은46→56px로 확대했다. 최종 Chrome 0/80/100% × 네 너비의12조합과 화면 검수 통과. 프론트55파일·364개·타입·빌드 통과, 저장소 문서 검사와 diff 공백 검사 통과. 전체 Docker 통합 게이트와 EXE 재패키징은 이번에 실행하지 않았다.

### 자체 이미지 아이콘과 원 두께

기본 아이콘을 직접 설계한 SVG 이미지43종으로 교체했다. 원본 JSON/개별SVG/공용sprite/React 연결부를 저장하고 메뉴·설정·카메라·기록·재생·알림창에 적용했다. 라이브러리 import와 의존성을 제거했다. 선택 색상과 버튼 접근성 이름은 유지한다.

오늘·종료 지표는 선10→16px, 지름188px로 바꾸어 두께와 안쪽 공간을 함께 확보했다. 작은 비율 원은 크기의1/7로 선 두께를 확대했다. 글자 크기는 유지했다.

### 이미지 모델과 평면 이모티콘 스타일로 수정

사용자 정정에 따라 SVG 제작안과 개별 입체 클레이 생성은 폐기했다. 내장 image_gen으로 같은 팔레트·외곽선·형태를 공유하는 평면 이모티콘 시트1장을 생성하고 PNG43종을 추출했다. 원본/프롬프트/분리 좌표/재추출 스크립트를 보관했다. 실제 화면과 native 작은 창은 PNG를 사용한다. 추가 요청에 따라 선택 메뉴 왼쪽의 반달처럼 보이는 inset 그림자를 제거하고 배경/굵기로 선택을 표시한다.

최종 검증: 프론트55파일·364개·타입·빌드 통과. 실제 Chrome에서 PNG 디코딩/선택 inset 제거, 원형 지표12조합 여백, 로그인·측정 준비·기록·달력·설정 확인. 실제 Electron 합성 영상 작은 창 검사 통과. 저장소 문서·diff 공백 검사 통과. 전체 Docker 통합 검증/EXE 재패키징은 실행하지 않음.

### 형광 느낌 제거

밝은 초록 채움이 화면과 이질적이라는 피드백에 따라 이미지 모델로 동일 시트를 단색 선형 기본 아이콘으로 편집했다. PNG43종을 재추출하고 밝은 면은 회색·짙은 면은 옅은 회색으로 표시한다. 레이아웃·글자 크기·원 두께·선택 배경은 유지한다. 현재 원본과 편집 프롬프트를 자산 폴더에 보관했다.

단색 아이콘 최종 검증: 프론트55파일·364개, 타입·빌드 통과. 실제 Chrome PNG 표시/선택선 제거/원 여백12조합·주요 화면 검수, 실제 Electron 합성 카메라 작은 창 검사 통과. check-repo와 diff 공백 검사 통과. 전체 Docker 게이트/EXE 재패키징은 실행하지 않았다.

### 실제 앱의 빈 기록·잔디·달력 검수

사용자 실앱 첨부를 기준으로 빈 상태의 그림/문구/버튼 정렬 불일치를 수정했다. 기본 면/글자를 중립 회색 계층으로 바꾸고 행동/정상 초록은 명료하게 보정했다. 잔디의 빈 칸과1단계가 구별되도록 별도5단계 팔레트를 지정했다. 기존 측정시간 구간은 유지한다. 이번 주 전체에 퍼지는 달력 배경과 선택 셀 전체 채움을 제거하고 숫자 원만 강조한다. 글자 크기와 원 두께·아이콘은 유지한다.

이번 보정 검증: 프론트55파일364개·타입/빌드 통과. Chrome 빈 기록/합성 기록 화면, 달력 선택 범위와5단계 활동 색 확인. 네 너비에서 측정/기록/설정 가로 넘침 없음. check-repo/diff 공백 검사 통과. 실행 중 EXE는 교체하지 않았으며 이번 EXE 재패키징은 미실행.

### 구간별 전체 화면 검수

[구간별 결과](../../audits/2026-10-26-section-ui-review.md)에 문제/적용/검증을 정리했다. 점수카드 줄바꿈, 중단/측정불가 배지 대비, 영상 조작/안내 아이콘, 긴 회원가입 소개, 프로필 입력 굵기/초점, 비활성 조작, 종료 통계/그림자, 상세 펼침 제목, 삭제hover, 차트 초점, 앱 제목줄을 보정했다. 프론트364개·타입·빌드, Chrome 상태별/네 너비, native 작은 창 검증 통과. 전체check-browser는 Docker daemon 부재로 MySQL 생성에서 중단. 실행 중인 사용자 앱은 변경하지 않았으며 이번 EXE는 재생성하지 않았다.

### UTC 잔존 확인과 표시 보정

API 응답/실시간 produced_at/로컬 ISO 저장은 UTC(`Z`)가 현재 계약이다. DB는 KST DATETIME, JDBC connectionTimeZone=Asia/Seoul, 일별 집계는 KST 경계다. 이 저장/전송 계약은 변경하지 않았다. 기준 자세 등록 시각과 중단 복구 시각에 Asia/Seoul을 명시했고, 기록 행의 월/일/요일도 한국 날짜로 계산해 KST 시계와 일치시켰다.

검증: check-frontend56파일366개·타입/빌드 통과. UTC 자정이 아닌 한국 자정 경계/기록 월일요일시계 일치 회귀2개를 TZ=UTC에서도 통과. 백엔드/DB는 코드·설정 조회이며 실제 DB 실행 검증은 아니다. 과거 EXE는 재패키징하지 않았다. 예시 데이터 생성은 기기 로컬 시각을 사용하지만 실제 기록 경로와 구별되며 이번 수정 대상은 실제 표시 경로다.

### 렌즈 광택과 오늘 잔디 칸 보정

사용자는 카메라 그림 전체가 아니라 렌즈 반사광이 과하다고 정정했다. 이미지 모델 편집으로 기존 형태/크기를 유지하고 렌즈 광택·흰 반사점·밝은 상태점만 무광으로 보정했다. `ready-camera-matte.webp`를 적용하고 원본/편집 프롬프트를 보관했다. 잔디 오른쪽 오늘칸의 바깥outline이 scroll 경계에서 잘리므로 inset 테두리로 바꿨다. 달력 링은 이전 스타일 선호에 따라 형태/두께/색을 변경하지 않았다.

렌즈/잔디 후속 검증: 실제 Chrome에서 today칸 outline 없음/inset 확인, 카메라 대기 그림과 달력 시각 검수. 타입/빌드·check-repo·diff 공백 검사 통과. 로직 변경이 없어 단위테스트는 이번에 재실행하지 않았다. 이번 수정은 아직 EXE에 재패키징하지 않았다.

### EXE·바탕화면 전달 방식

사용자는 이후 수정도 계속EXE에 반영하고 바탕화면에서 실행하기를 요청했다. `desktop:pack` 후 실행기를 만드는 단계에서 Windows 바탕화면 경로를 조회해 `PoseGood.lnk`를 생성/갱신하도록 연결했다. 실행기/폴더를 복제하지 않고 동일 최신 경로를 참조한다. 이번 패키지에는 무광 카메라/잔디 오늘 테두리 수정도 포함한다.

이번desktop:pack·타입/빌드 통과. 실제 패키지 UI smoke에서 최신 로그인/무광 카메라 이미지, 메일 준비중 안내/링크 진입 확인. 바탕화면PoseGood.lnk의 대상/작업폴더/대상존재를 읽어 검증했다. check-repo/diff 공백 검사 통과. 최근 프론트376개 통과 이후 이미지/테두리/패키징 전달 변경만 있어 단위테스트는 재실행하지 않았다.

### 사용자 선택 클리어 레드

팔레트 비교에서 사용자가 클리어 레드 #E5484D를 선택하고 적용/EXE 갱신을 요청했다. --alert-soft만 변경해 기록의 큰/작은 링·타임라인·달력 링에 공통 반영한다. 다른 색/링 형상·두께는 유지한다. 실행 중 앱은 정상 닫기 요청으로 종료한 뒤 최신 EXE와 바탕화면 바로가기를 갱신한다.

클리어 레드 검증: desktop:pack·타입/빌드·check-repo·diff 공백 검사 통과. 실제 EXE UI smoke에서 --alert-soft=#E5484D 확인. 바탕화면 바로가기 대상을 검증하고 새 앱을 실행했다. 색 토큰만 바꿔 최근376개 단위테스트는 재실행하지 않았다.

### 날짜 탐색·초점 안내·전환 모션

메뉴의 `오늘`은 당일 측정, `기록`은 날짜별 기록/달력/최근 흐름이다. 잔디는 hover/키보드 초점에서 1.4배 확대하며 클릭/Enter로 해당 날짜를 선택한다. 방향키·Home·End로 이동하고 미래 날짜는 비활성화한다. 연간 잔디는 한 번의 Tab 진입점을 사용한다.

카메라 대기 면을 #294638로 밝히고 계정 팝업은 흰 면/짙은 글자/명료한 로그아웃 빨강으로 구분했다. 잔디/최근 흐름은 120ms opacity 전환을 사용하고 차트 툴팁/강조 띠의 위치가 쓸려 이동하는 전환은 제거했다. 준비 단계의 활성 표시는 340ms 이동과 짧은 물방울 변형을 사용하며 시스템 움직임 줄이기를 따른다. 키보드 초점 시 항목 설명 툴팁을 연결하고 메뉴에는 목적을 명시한다.

검증: 프론트57파일376개·타입/빌드, 실제 Chrome 네 너비(1360/1180/690/390) 화면/원 여백/이미지, 키보드 설명과 aria-describedby, 대기 면/계정 메뉴 대비, 준비 표시 정렬, 잔디 확대/날짜 연결/방향키, 차트 전환, 개발 Electron native 작은 창 검사 통과. 전체 서버/DB 브라우저 게이트는 Docker daemon 부재로 미통과 상태다. 최신 EXE와 바탕화면 바로가기를 재생성하고 develop PR로 전달한다.

최종 전달 검증: 2026-10-26 `desktop:pack` 성공. 실제 패키지 UI smoke에서 밝은 자산/클리어 레드/메일 준비 안내/토큰 URL 제거 통과. 바탕화면 바로가기 대상은 `C:\GoodPose\develop\frontend\PoseGood.exe`이며 대상 존재를 확인했다. 후속 초점 툴팁은 창 경계에서 잘리지 않도록 위치를 보정했다. 최종 check-frontend57파일376개·타입/빌드 및 check-repo/diff 공백 검사 통과. check-browser 재시도는 Docker pipe 부재로 임시 MySQL 생성 실패(전체 게이트 미통과). develop 대상으로 PR을 생성하며 병합은 하지 않는다.
