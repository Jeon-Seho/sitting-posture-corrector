# 작업 제목

- 상태: planned / in_progress / completed / blocked
- 담당:
- 시작일:
- 관련 요구사항/ADR:

## 문제와 완료 기준

관찰 가능한 결과와 검증 방법을 적는다.

## 범위와 제외

변경할 컴포넌트, 계약, 데이터 경계를 적는다.

## 작업 단계

- [ ] 관련 문서와 현재 구현 확인
- [ ] 구현 및 필요한 실패 경로 검증
- [ ] 문서·계약 동기화
- [ ] `make check`와 컴포넌트 검증

## 결정과 진행 기록

확정한 내용, 근거, 남은 질문을 기록한다.

## 검증 결과와 남은 한계

실제로 실행한 명령과 결과를 적는다. 계획한 검증과 실행한 검증을 구분한다.
