## 문제와 완료 기준

도구가 접혀 있고 카드가 한 줄로 쌓이며 주요 제어가 분산되어 있다.
다섯 지표와 상대 z 해석 카드를 같은 2열 그리드에 놓는다. 도구 탭을 기본 노출·가운데 정렬하고
중복 CSV·재등록·접기 버튼을 없앤다. 종료는 카메라 하단 중앙 진행 제어와 함께 빨간색으로 표시하고
도움말은 테마 아이콘 왼쪽으로 옮긴다. 동작 선택과 수동 진행 모드의 의미를 구분한다.

## 범위와 제외

ObservationLab/Guide/Tools, 관측 CSS·관련 테스트·설계 문서.
영상 해상도, 관측·안내 프로토콜, 수집 및 내보내기 형식은 바꾸지 않는다.
기존 메모리의 측정·리플레이 자료를 보존한다.

## 결정과 진행 기록

- 상대 z는 원시 추정 m, 다섯 지표는 기준 대비 %다. 단위를 보존하고 시각적 카드 배치만 합친다.
- 종료는 시작/일시정지/다음과 같은 카메라 하단 중앙 그룹에서 찾을 수 있게 한다.
- 수동 동작 탭은 진행 모드와 다르므로 동작 선택으로 바꾼다.
- Git 상태 조회는 기존 메타데이터 경로 누락으로 실패했다. 파일 범위를 한정해 기존 변경을 보존한다.

## 검증 결과와 남은 한계

- `make check-frontend`: 98개 파일·836개 테스트 통과, TypeScript·Vite 빌드 통과. 기존 큰 청크 경고 유지.
- `make check-repo`: 기존 Git 메타데이터 경로 누락으로 실패. 수정 문서·필수 경로·공백을 별도 부분 검사했다.
- 1384×774에서 카드 559px씩 2열·3행, 동일 행 높이 일치와 중앙 탭을 확인했다. 카메라는 832×624를 유지한다.
  402×874에서 1열 전환·가로 넘침 없음·라이트 모드를 확인했다. 상단 도움말 펼침/Escape 닫힘도 확인했다.
- 실제 탭을 새로고침하거나 촬영하지 않고 기존 리플레이 2,037프레임과 비교표 CSV 55행 접근을 확인했다.
  실제 자료 다운로드·수정은 하지 않았다. 실제 `/dev` 콘솔 오류 0건.
- 실제 Guide 컴포넌트의 임시 합성 UI에서 1384px 진행/320px 일시정지의 빨간 종료 버튼을 확인했다.
  종료 클릭 후 시작 버튼으로 복귀했다. 임시 HTML/TSX와 검수 탭은 제거했다.
- 실제 카메라 종료는 합성 카메라를 이용한 기존 라우트 통합 테스트로 확인했다. 실제 장치 촬영·서버/DB
  브라우저 게이트·전체 `make check`는 실행하지 않았다.
