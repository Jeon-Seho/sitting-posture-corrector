# 관측 안내 카드와 분석 도구 정리

- 관련 요구사항/ADR: 사용자 브라우저 주석 3·4·5 및 통합안 승인 / ADR 0039

## 문제와 완료 기준

현재 동작·남은 초·다음 안내를 영상 왼쪽 위 카드 하나로 합친다. 다음 안내는 전환 직전에만
보이게 축약하지 않고 계속 표시한다. 도움말은 상단 정보 아이콘에서 열고, 하단 네 막대 대신
분석 도구 버튼 하나와 수치·그래프 / 수동 동작 / 비교표 탭을 제공한다.

## 범위와 제외

ObservationGuide·ObservationLab·전용 분석 도구 컴포넌트·CSS·UI 검증·문서를 변경한다.
기존 미커밋 삭제 변경을 보존한다. 시간 정책·카메라·등록·정지/재개·CSV·자료 보존은 유지한다.
모델·계약·데이터 경계를 바꾸지 않는다. 실제 영상과 좌표를 저장하지 않는다.

- [x] 카드 통합과 도움말·분석 도구 구현, 키보드 조작·기존 생명주기 확인
- [x] 모듈 문서 동기화
- [x] 프론트·저장소 검증과 브라우저 화면 확인

## 결정과 진행 기록

- 사용자가 앞서 제안한 두 통합안을 승인했다. 다음 안내는 상시 표시한다.
- 분석 도구를 접거나 탭을 바꾸어도 기존 측정 상태·자료를 초기화하지 않는다.
- 도움말은 native details, 분석 탭은 방향키/Home/End 및 roving tabindex를 제공한다.
- 검토에서 찾은 등록 완료 후 재등록을 요구하던 카드 문구를 수정하고, 준비 상태에 따른 시작 안내를 검증했다.

## 검증 결과와 남은 한계

- `python tools/dev.py check-frontend`: 94개 파일·788개 테스트, TypeScript 검사·Vite 빌드 통과.
- 분석 도구 새 합성 테스트 2개는 방향키/Home/End·포커스, 탭 전환과 접기 후 상태 보존을 확인했다.
- 실제 브라우저에서 통합 카드·상시 다음 안내·세 탭 내용·방향키/End 전환과 도움말 Escape 닫기를 확인했다.
- `python tools/dev.py check-repo` 통과. `git diff --check`도 통과했다.
- 실제 카메라·사람 동작·Electron·서버/DB 통합 및 전체 `make check`는 실행하지 않았다.
  빌드의 기존 500kB 청크 경고는 남는다. 카메라 권한은 자동 허용하지 않았다.
