# 실시간 자세 시나리오 기록과 로컬 JSON 저장

- 상태: completed
- 담당: 모델 연구 화면
- 시작일: 2026-11-10
- 관련 요구사항/ADR: ADR 0005, ADR 0020, 연구 프로토콜

## 문제와 완료 기준

사용자가 웹캠 화면에서 정해진 자세 시나리오를 확인하고, 각 자세마다 현재 규칙·모델 점수를 기록하거나 직접 입력한 뒤 요청한 폴더에 JSON을 저장한다.

## 범위와 제외

독립 로컬 연구 화면, 로컬 저장 API, 실행 설명 및 합성 시험만 변경한다. 저장 데이터는 선택한 시나리오, 점수, 명시적으로 캡처한 판정·알림·특징 설명으로 제한한다. 원본 영상과 랜드마크, 참여자 식별 정보는 저장하지 않고 운영 서비스 계약이나 학습에 연결하지 않는다.

## 결정과 진행 기록

- 사용자가 데이터를 넣은 바탕화면 프로젝트의 `model/test/senario/`에 저장하도록 로컬 서버에 경로를 지정한다. 기본 실행 경로도 프로젝트의 같은 상대 경로다.
- 자동 기록에는 표시 점수와 원점수 판정의 차이를 보존하고, 수동으로 수정한 행에서는 자동 판정 정보를 지워 혼동을 피한다.
- 카메라 중단·측정 불가·오래된 관측은 자동 기록하지 않는다. 수동 점수는 카메라 없이 입력할 수 있다.
- 저장마다 임의 식별자가 있는 새 파일을 생성하며 폴더와 파일의 접근 권한을 제한한다. 허용한 점수·특징 설명 외의 입력은 거절한다.

## 검증 결과와 남은 한계

- `make check`: Python 181개 중 170개 통과, PySpark 미설치로 11개 건너뜀. 메인 프런트 Vitest 945개와 Node 시험 5개, TypeScript·Vite 빌드는 통과했다. 마지막 백엔드 빌드는 이 컴퓨터에 Java 런타임이 없어 실행하지 못해 전체 `make check`는 실패했다.
- `node --test tests/live_comparison_ui.test.cjs`: 합성 UI 시험 21개 통과. 자세별 자동·직접 입력, 측정 불가·오래된 관측, 기록 보존과 저장 실패를 확인했다.
- 격리 브라우저에서 입력한 합성 점수를 JSON에 저장했고, 실제 로컬 서버와 요청 폴더에서도 합성 자동·수동 기록과 파일 권한·좌표 미포함을 확인한 후 시험 파일을 지웠다.
- 실제 웹캠으로 자세를 취하면서 버튼을 누르는 과정은 확인하지 않았다. 시나리오 기록은 개인 정보가 포함될 수 있는 로컬 연구 자료이며 정확도 평가나 학습 결과가 아니다.
