## 문제와 완료 기준

현재 코·어깨 중심 세 특징과 기준 차분의 의미를 확인하고, 사용자가 확정한 개인 기준 대비 변화 목표와
높은/낮은 정면 카메라 조건에 맞는 비교 가능한 입력·라벨 초안을 제공한다. 실제 서비스 구현 변경은 이번 검토 범위가 아니다.

## 범위와 제외

현재 코드 조사, 공식 포인트/모델 자료 확인, [특징 설계 초안](../../research/personal-baseline-feature-design.md) 작성.
모델·임계값·촬영 시점·라벨 경계 확정, 코드·계약 변경, 실제 자료 수집/학습은 제외한다.

## 결정과 진행 기록

사용자: 공통 바른 자세 대신 처음 등록한 기준에서 얼마나 벗어났는지를 판정한다.
카메라는 정면 고정이며 눈보다 위/아래인 위치를 모두 고려한다.
후속 사용자 결정: Pose 얼굴 11개+어깨 2개를 활용하며 Face Landmarker는 후속 비교 실험으로만 남긴다. 라벨 비용을 고려한 기하 변화 점수·기준 자료 기반 novelty detection을 제안으로 추가했다.
현재 기준은 13개 좌표가 아닌 세 특징의 평균이다. 새 기준 좌표 수집과 서버 계약 변경은 후속 구현에 필요하다.

## 검증 결과와 남은 한계

`python tools/dev.py check-repo`와 `git diff --check` 통과. 문서만 추가했으며 Python/프론트 테스트·타입 검사·빌드·전체 check는 실행하지 않았다. 좌표 정규화·차분·라벨·모델 후보는 제안이며 성능 실험을 실행하지 않았다.
