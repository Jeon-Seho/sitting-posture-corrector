# 실제 관측 자료와 화면 예시 분리·초기화 보호

- 상태: completed
- 담당: jisung / Codex
- 시작일: 2026-10-16
- 관련 요구사항/ADR: 실제 자료 덮어쓰기 방지 사용자 요청, ADR 0039

## 문제와 완료 기준

카메라 측정 종료 후 예시 시작이 같은 버퍼를 초기화하여 실제 자료를 잃을 수 있다.
실제 화면에서 예시를 별도 탭으로 분리하고 예시는 수집·비교표 저장·CSV 내보내기를 하지 않는다.
자료가 있는 상태의 새 실제 측정·재등록·표 비우기는 명시적 확인을 거치며 취소하면 자료를 보존한다.
추출 조건이 바뀌면 현재 측정을 중단하되 이전 자료와 내보내기 기준 정보를 보존한다.

## 범위와 제외

관측 비교 화면·훅·합성 회귀·사용 정책만 수정한다. 기존 변경을 보존하고 서비스·원본 좌표 저장·
실제 카메라 자동 실행·기존 자료의 영구 저장·자동 CSV 다운로드는 추가하지 않는다.

- [x] 화면 모드 분리·예시 내보내기 차단·초기화/조건 변경 보호
- [x] 합성 회귀·타입·빌드·브라우저 확인

## 결정과 진행 기록

예시는 UI 설명용 임의 좌표였으나 카메라 자료와 같은 수집/다운로드 흐름을 공유한 것이 혼동 원인이다.
실제·예시 모드를 시작 함수와 내보내기 경계에서도 제한한다. 새로고침/이동 시 자료가 있으면 브라우저
이탈 경고를 연결하되 종료 버튼은 자료를 지우지 않는다.

## 검증 결과와 남은 한계

- 최종 `make check-frontend`: 91개 파일·762개 테스트 통과. TypeScript·Vite 생산 빌드 통과.
  보호/모드 분리/내보내기 차단/beforeunload 회귀 6개를 추가하고 기존 8개 수명 테스트를 새 정책에 맞췄다.
  기존 큰 JS 청크 경고는 남는다.
- `make check-repo`·`git diff --check` 통과.
- 실제 화면에서 예시 시작 버튼 부재와 별도 탭 도움말 링크를 확인했다. 예시 화면에서 가상 기준 등록 후
  비교표 0개·CSV 버튼 0개 및 수집하지 않는 안내를 확인했다. 실제 카메라는 실행하지 않았다.
- 브라우저 모달은 임시 명시적 합성 카메라 fixture로 검증했다. 기준 등록·새 측정 요청 시 6행을 보존한
  확인창이 뜨고 기본 포커스가 취소에 갔다. 취소 뒤 6행 유지, 명시적 계속 확인 뒤 0행을 확인했다.
  실제 사람/영상·다운로드를 사용하지 않았고 임시 HTML fixture와 시험 탭은 제거했다.
- 전체/서버 통합 게이트는 이번 프론트 내부 변경에서 재실행하지 않았다. 0053의 Python 패키지 환경
  제약과 실제 카메라/장치 성능 미검증은 그대로다. 브라우저 강제 종료 시 영구 보존은 보장하지 않는다.
- 이미 초기화된 과거 메모리 자료를 복구한 작업이 아니다. 이번 변경은 이후 덮어쓰기를 방지한다.
