# 관측 준비 확인과 기준 재등록

- 상태: completed
- 담당: Codex
- 시작일: 2026-10-28
- 관련 요구사항/ADR: 사용자 화면 피드백, ADR 0040

## 문제와 완료 기준

측정 전 준비 상태와 다음 행동을 명확하게 표시하고 수동 진행을 기본 선택한다. 대기 중에는 중앙 버튼으로 다음 단계를 시작한다. 기준 재등록은 기존 자료 삭제를 명확히 알리는 확인 후에만 시작한다. 종료 버튼은 오른쪽에 배치하고 키보드·터치로도 접근할 수 있다.

## 범위와 제외

/dev 관측 안내·제어·확인 화면과 관련 문서, 합성 테스트. 관측 시간·자료 수집 경계·CSV 계약은 변경하지 않는다.

## 작업 단계

- [x] 관련 문서와 현재 구현 확인
- [x] 구현 및 필요한 실패 경로 검증
- [x] 문서 동기화
- [x] 범위별 검증과 결과 기록

## 결정과 진행 기록

자동 모드는 선택지로 유지하고 수동 모드를 기본 선택한다. 수동 각 단계의 시간과 품질 검사 및 측정 구간은 유지한다. 재등록 전에 기존 자료 다운로드 기회를 제공한다.

## 검증 결과와 남은 한계

`make check-frontend`: 테스트 870개, TypeScript 검사·빌드 통과. `make check-repo`: 통과.
합성 UI에서 대기 화면의 버튼, 측정 화면 배치와 종료 확인창을 확인했다.
전체 브라우저 회귀는 이 환경의 Python 가상환경에 `pymysql`이 없어 실행하지 못했다.
실제 카메라·Windows 환경의 화면과 조작은 별도로 확인해야 한다.
