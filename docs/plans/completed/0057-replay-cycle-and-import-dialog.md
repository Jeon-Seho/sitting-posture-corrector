## 문제와 완료 기준

측정 한 번(기준 등록부터 종료까지)의 메모리 JSON 기록을 별도 파일 선택 없이 리플레이에 자동 연결한다.
파일 불러오기/저장은 유지하고, 불러오기는 버튼으로 연 모달의 드래그앤드롭 또는 파일 선택으로 처리한다.
지정한 빈 상태 안내 문구는 삭제한다. 자동 재생·자동 파일 저장은 하지 않는다.

## 범위와 제외

리플레이 패널·공통 확인창을 사용하는 파일 모달·관련 합성 검증·문서만 변경한다.
수집/CSV·JSON 형식·학습·서비스·실측 입력은 변경하지 않는다.

## 결정과 진행 기록

측정 종료 후 재생 위치는 처음에 둔다. 파일 재생 중에도 측정 사이클 버튼으로 현재 측정으로 돌아간다.
새 측정이 시작되면 이전 플레이어를 비우며, 종료 후 새 사이클로 자동 연결한다.

## 검증 결과와 남은 한계

- `make check-frontend`: 98파일·834테스트 통과. TypeScript·Vite 빌드 통과, 기존 번들 크기 경고 유지.
- 전체 한 사이클(기준10초+안내144초)의 합성 카메라 입력을 실제 ObservationLab에 넣고 종료 후 파일/불러오기 버튼 없이 자동 재생 준비됨을 통합 컴포넌트 테스트로 확인.
- 드롭·파일 선택·형식/크기/개수 거부·확인 전 미적용·취소·언마운트 뒤 응답 무시·파일에서 사이클 복귀 검증.
- 인앱 브라우저에서 모달/초기 초점·파일 선택 후 활성화·확인 후 합성 JSON 재생·삭제한 문구 부재 확인. 브라우저 콘솔 오류 없음.
- `make check-repo`, `git diff --check`: 통과.
- 실제 OS 파일 드롭 동작은 브라우저에서 직접 실행하지 않았고 합성 이벤트 테스트로 확인했다.
- 서버 JAR을 준비하지 않아 `make check-browser` 및 전체 `make check`는 미실행. 실제 카메라 입력의 성능·ML 분리도 검증은 범위 밖이다.
