# 자동·수동 정상 자료 수집과 실제 예측 방향 표시

- 상태: completed (개발 구현 완료, 통합 환경 제약 기록)
- 담당: Codex
- 시작일: 2026-10-14
- 관련 요구사항/ADR: 기준 오차 0.5% 이하 자동 라벨, 수동 30초 촬영, LSTM 13점 예측 가시화 / ADR 0029

## 문제와 완료 기준

`/dev` 실측에서 등록 기준 거리 0.5% 이하인 새 관측을 자동 행으로 모으고 `정상자세(자동)`을 표시한다.
수동 모드는 `30초 측정하기`로 정상 구간을 직접 촬영·확인하며 자동 임시 라벨과 구분한다.
LSTM이 얼굴·귀·어깨 13점의 좌표를 예측한다는 사실과 실제 예측 방향을 현재 관측·등록 기준과 구분해 보여준다.

## 범위와 제외

개발자 UI·수집 메모리·모델의 표시용 예측 출력·별도 수집 계약·현재 ML 문서/HTML.
기존 미커밋 변경을 유지한다. 일반 서비스·서버·실제 자료의 Git 추가·자동 업로드는 제외한다.
자동 라벨은 초기 실험용 규칙 가정이며 평가 정답이나 자동 개인 프로파일 학습으로 사용하지 않는다.

## 결정과 진행 기록

- 0.5%는 사용자가 지정한 실험 조건이다. 화면과 동일한 어깨폭 정규화 기준 거리 `deviation <= 0.005`이며 예측 잔차/정상 확률이 아니다.
- 자동 모드는 기본 켜짐이다. 실제 카메라 측정 시작과 기준 등록 뒤 새 유효 영상 관측만 최대 10Hz로 추가한다.
  합성 데모·등록 전·저품질·누락은 제외한다. 한도 도달 시 기존 행을 삭제하지 않고 멈춘다.
- 자동 자료는 필터를 통과한 시각만 남으므로 이탈·품질·시간 단절을 구간 경계로 보존한다. 이를 압축한 연속 시계열로 취급하지 않는다.
- 수동은 기존 유효 30초 촬영과 자기 보고 확인을 유지한다. 양쪽 라벨의 출처를 명시한다.
- world 모델 좌표를 카메라 영상 좌표로 정확히 투영할 보정 정보가 없으므로 미래 좌표는 독립적인 정규화 좌표 도식으로 표시한다.
  실제 LSTM/비교군 출력과 원래 입력의 방향 화살표를 쓰며 기준→현재 화살표와 구분한다.

## 검증 결과와 남은 한계

- `make check`: 저장소·문서 검사, Python **163개**, 프론트 **63파일 520개** 테스트, TypeScript·Vite 빌드 통과. Java 21/Maven 부재로 백엔드 단계에서 중단했다. 전체 게이트 통과가 아니다.
- 마지막 수집 종료 처리·익명 코드 기본값 연결·표시 문구 수정 뒤 `npx vitest run src/features/developer/useDeveloperSession.test.tsx src/features/developer/DeveloperLab.test.tsx src/features/developer/DeveloperNormalCollection.test.tsx`: **3파일 50개** 통과. `npm run build` 타입·빌드 재통과. 기존 주 번들의 500kB 초과 경고는 남아 있다.
- 자동 수집 회귀: 0.5% 포함 경계, 새 영상 프레임·최대 10Hz, 품질/시간/참조 단절과 세그먼트, 6,000행 보존 상한, 합성 제외, 원본 좌표/참조/출처 내보내기, 중지/백그라운드 처리.
- 예측 표시 회귀: 실제 모델 39개 출력, 방어적 복사, 입력·목표 시각, 누락/품질/종료/예측 시각 만료, 정면·깊이 좌표계와 13점 표시.
- `make check-browser`: 생산 번들의 합성 진입점 제외 검사는 통과. Java Runtime 부재로 서버가 준비되지 않아 통합 시나리오를 실행하지 못했다. 임시 테스트 서버 종료 확인.
- `make check-compose`: Docker daemon 부재로 중단. DB/계정/서버 통합 결과는 미검증.
- 별도 in-app browser의 `/dev`: 자동 기본 켜짐, 자동·수동 모드 전환, 익명 코드가 채워진 `30초 측정하기`, 합성 데모에서 실제 LSTM 도식, 품질 누락 시 예측 숨김과 종료 시 제거, 합성 관측의 자동 수집 0행을 확인했다. 실제 웹캠 촬영은 실행하지 않았다.
- ML HTML은 1280px·390px에서 테마 전환과 가로 넘침 없이 표시됨을 확인했다. 문서의 자동/수동·원본/예측·평가 경계를 계약과 동기화했다.

자동 라벨의 정확도, 0.5% 조건의 실제 수집률, 실제 예측 방향/장치 지연·음향·장시간 품질은 합성 검증과 별도다. 새 의존성과 모델 재학습은 없다. 실측 자료나 가중치를 저장소에 추가하지 않았다.
