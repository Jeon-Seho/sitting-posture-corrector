## 문제와 완료 기준

문서 확인과 일반 개발 작업에 별도 관리판, 카드 등록, AI 기록과 자동 Git 훅이 요구되고 있다.
관리판 실행 코드·스킬·전용 문서를 제거하고 setup과 검증 명령이 제품 개발에 필요한 작업만 실행하도록 정리한다.
남은 문서의 링크와 개발 진입점을 확인하고 develop에 병합·공유한다.

Windows 실행기·바로가기 생성, 관련 작업 지침과 문서 연결을 정리한다.

## 검증 결과와 남은 한계

- `python tools/dev.py check-repo`: 저장소 구조·Markdown 링크·산출물 검사 통과.
- `python tools/dev.py check`: Python 140개 실행, 136개 통과·1개 건너뜀·3개 오류. 배포 백업 실패 정리 테스트 2개는 Windows 파일 잠금(WinError 32), 배포 재실행 테스트 1개는 POSIX 파일 잠금 요구 때문에 실패했다. 이 테스트와 배포 구현은 develop 기준에서 변경하지 않았다.
- 위 오류로 전체 게이트의 프론트·백엔드·브라우저·Compose 단계는 이어 실행되지 않았다.
- `python tools/dev.py check-frontend` 별도 실행: 35파일·276개 통과, TypeScript와 Vite 빌드 통과. 기존 500kB 번들 경고가 있다.
- setup을 의존성 준비만으로 호출하는지, 삭제한 CLI 명령이 종료 코드 2로 거부되는지, 전용 실행 파일·스킬·훅 부재를 확인했다.
- Windows 설치 스크립트는 실행 대신 PowerShell 구문 검사로 확인했다. 실제 설치·다른 PC·서버 배포·카메라 동작은 이번 작업에서 검증하지 않았다.
