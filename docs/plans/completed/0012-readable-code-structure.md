## 문제와 완료 기준

앱 진입점에 프로필·로컬 저장·세션 복구·화면 렌더링이 섞여 있고 React/Java/Python 일부 코드가 한 줄에 압축되어 있다.
기능을 찾고 수정할 수 있는 책임별 디렉터리와 일반적인 여러 줄 코드로 정리한다.
기존 UI·시간 정책·저장 키·HTTP 계약·실행 명령을 유지하고 전체 검증을 통과한다.
현재 기술의 유지 상태와 대안은 공식 자료에 근거해 보고하며 스택·의존성 버전은 변경하지 않는다.

## 범위와 제외

- 프론트: 앱 조립/탐색, 프로필 화면/편집, 세션 저장/복구, 저장 검증/IO, 측정 결과/이벤트 표시, 스타일 구분.
- 서버: API 웹/서비스/저장소/CEP 연결, CEP 시간 누적/Esper 연결, Java·POM 가독성.
- Python: 추론 입력/점수/API, 개발 명령/런타임/시험 프로세스 구분.
- 문서: 실제 구조 지도, 기술 스택 검토, 검증 기록.
- 제외: 화면 디자인·제품 동작·스택 변경, 외부 DB/인증·실제 영상·학습·push·배포.

## 결정과 진행 기록

기존 컴포넌트 경계 frontend/backend/model/contracts/tools를 유지한다. 코드 위치를 바꾸는 리팩터링이며
새 프레임워크나 의존성을 추가하지 않는다. 이전 계획 0009의 화면 분리 제외는 당시 통합 범위이며,
이번 사용자의 기능 분리 요청에 따라 UI 동작을 보존하는 범위에서 별도 진행한다.
사용자가 기존에 둔 `docs/references/temp.md`는 읽거나 수정하지 않는다.

## 검증 결과와 남은 한계

초기 환경에 빠진 프론트/Python 의존성은 기존 manifest와 lockfile 그대로 준비했다.
공식 체크섬을 확인한 JDK 21·Maven을 Git 제외 `.cache/toolchains`에만 준비했다.
프로젝트 스택·버전·의존성 목록은 변경하지 않았다.

- `make check` 전체 통과: Python 19개, 프론트 85개/12파일, Java 26개(CEP 16/API 10).
- TypeScript 타입 검사, Vite 빌드, Java 21 컴파일 및 실행 JAR 패키징 통과.
- FastAPI → API → 독립 Esper → 저장/조회 합성 HTTP 검증과 시험 서버 3개 종료·포트 해제 통과.
- `make check-backend` 별도 통과. JVM 테스트 연결·loopback 검증은 sandbox 밖의 승인된 실행 경로를 사용했다.
- 프론트 카메라 8개 합성 생명주기 테스트 통과. 분리한 비동기 모델 helper의 반환과 hook 재개 사이 취소 경계 회귀 1개를 추가했다.
- 기존 엔진 11개·저장 함수 18개는 TypeScript AST 기준으로 서식·괄호를 제외한 본문이 동일하다.
- 분리한 CSS는 기존 순서대로 연결한 후 Lightning CSS 컴파일 결과가 원본과 동일(26,002바이트)하다.
- 합성 추론 150가지와 health 응답은 이전 HTTP 결과와 동일하다.
- 합성 v2 CSV로 분석 stdout/DataFrame·보고서 Markdown/PNG가 이전 결과와 동일하고 입력 파일은 보존됨을 확인했다.
- 내장 브라우저에서 별도 localhost 포트의 합성 프로필로 등록·준비·기록 대시보드·설정·프로필·자세 등록 화면,
  프로필 편집 취소를 확인했다. 캡처 화면에서 기존 스타일이 표시됐고 콘솔 error는 없었다.
  카메라 연결/촬영·소리·실제 사용자 자료 삭제는 실행하지 않았다.
- `git diff --check` 통과. POM XML 구조·EPL 원문·JS/Python 의존성 파일 불변을 확인했다.

전체 검증 로그는 로컬 Git 제외 `.cache/refactor-check.log`, backend 로그는 `.cache/backend-check.log`다.
구조는 [코드 지도](../../code-structure.md), 기술 유지 상태와 대안은 [스택 조사](../../audits/2026-10-01-technology-stack.md)에 있다.
스택 조사는 보고만 수행했고 테스트 렌더러·지원 종료 런타임을 교체하지 않았다.
실제 카메라·음성·기기별 지연·모델 정확도·외부 DB/인증·원격 CI·배포는 미검증이다.
