## 문제와 완료 기준

사용자가 Spring Boot API의 입력·저장·조회, 별도 Esper CEP의 붕괴·회복 시간 사건 판정,
FastAPI 추론 경계를 승인했다. 시간 판정을 API에 중복하지 않는다. 합성 관측으로 세 서비스를 연결하고
3초·60초·커스텀 회복시간 경계, 중단·누락·중복·역순·세션 격리와 휴식 제외 통계를 검증한다.

## 범위와 제외

루프백 전용 개발 서버, 메모리 저장, 버전 있는 관측·이벤트 계약, 결정적 회귀 테스트를 구현한다.
외부 DB·계정·비밀값·배포·실제 영상 전송·카메라 권한·모델 학습은 포함하지 않는다.
Kafka/Redis/HDFS/Spark는 이 흐름 검증 이후의 의존성으로 남긴다. 기존 프론트는 로컬 모드를 유지한다.
