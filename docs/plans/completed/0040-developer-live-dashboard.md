## 문제와 완료 기준

측정 중 560px 영상과 긴 설명이 첫 화면을 차지한다. 1381×774 화면에서 카메라와 현재 상태·이탈
정도·알림 상태를 동시에 확인할 수 있게 한다. 구도 안내는 큰 영상으로 유지하고 영상 확대는 선택한다.
작은 화면·다크/라이트·키보드 조작 및 측정 불가 표시를 확인한다.

## 범위와 제외

`frontend/src/features/developer/`의 화면 구성·표시·CSS와 관련 문서만 변경한다.
연구 코어·등록 조건·출력 계약·일반 사용자 화면은 변경하지 않는다. 기존 미커밋 수정은 보존한다.

- [x] 단계별 카메라 크기와 상태 요약, 펼쳐 보는 상세 정보 구현
- [x] 표시 의미·카메라 생명주기·접근성 회귀 검증
- [x] 문서 동기화와 프런트·브라우저 검증

## 결정과 진행 기록

현재 상태 카드는 기존 출력과 선택한 알림 판단 기준만 소비한다. 측정 불가를 정상 상태로 표시하지 않는다.
기술 수치는 접기 항목으로 이동한다. 종횡비와 영상/관측점의 좌표 정합, 스트림 인스턴스를 유지한다.

## 검증 결과와 남은 한계

- `make check-frontend`: 55파일 447개 테스트, TypeScript 검사와 Vite 빌드 통과.
- `make check-repo`, `git diff --check`: 통과.
- 실제 개발 화면의 측정 중 병렬 배치 확인. 별도 합성 데모에서 자동 전환, 확대/축소,
  모델 비교 접기와 Enter 조작, 예측 오차 표시 전환, 390px 라이트 화면의 가로 넘침 없음 확인.
  검증 탭의 브라우저 오류 0개. 사용자 카메라 영상 대신 합성 화면을 작업 증거로 저장했다.
- `make check-browser`: 생산 번들의 합성 입력 제외 검사 통과. 서버 통합 부분은 현재 호스트에
  Java Runtime이 없어 서비스 준비 실패로 중단. 임시 테스트 서버 정리 확인.
- 이번 범위는 프런트 화면만 변경하며 `make check` 전체는 재실행하지 않았다.
