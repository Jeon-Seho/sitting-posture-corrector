## 문제와 완료 기준

사용자가 규칙과 모델의 점수를 각각 가장 높게 받은 실제 관측 자세를 현재 자세와 실시간으로 비교한다. 모델은 목표 관절 좌표를 생성하지 않으므로 관찰한 최고점과 절대적인 100점 자세를 구분한다.

## 범위와 제외

로컬 연구 화면과 합성 UI 시험·실행 안내를 변경한다. 두 방식은 같은 현재 관측을 사용하되 각각의 원점수로 최고점을 고른다. 선택한 9개 점은 브라우저 메모리에만 두고 세션 종료나 재등록 시 지운다. 모델·서버 계약·판정·학습은 변경하지 않는다.

## 결정과 진행 기록

- 100점 목표 자세는 모델 출력에서 복원할 수 없다. 사용자에게 확인한 대로 각 방식에서 실제 관측된 최고점 자세를 표시한다.
- 화면에 나타내는 점은 점수가 관측된 시점의 랜드마크이며, 점수 자체는 최근 1초 관측 창에서 계산된다. 실제 영상은 보관하지 않는다.
- 카메라 영상에는 현재 자세를 연두색, 규칙 최고점 자세를 노란색, 모델 최고점 자세를 보라색으로 표시한다. 측정이 불가능하면 최고점 오버레이를 그리지 않고 관측 끊김에는 영상의 관절 표시를 지운다.

## 검증 결과와 남은 한계

- `make test`: Python 171개 중 160개 성공, PySpark 미설치로 11개 건너뜀. 연구 화면의 합성 JavaScript 시험 14개가 포함되어 있다.
- 브라우저에서 새 비교 창과 카메라 영역의 배치, 초기 상태와 콘솔 오류 없음을 확인했다. `node --check`와 `git diff --check`도 통과했다.
- 실제 웹캠으로 자세를 바꿔 가며 비교하는 과정은 사용자 장치에서 확인해야 한다. 메인 프런트 TypeScript 빌드와 전체 `make check`는 이 독립 연구 화면 변경에 실행하지 않았다.
