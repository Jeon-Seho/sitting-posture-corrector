## 문제와 완료 기준

현재 결정의 유지 여부를 점검하고 합의·가정·실험·구현 상태를 간결하게 구분한다.
절대/상대/결합 좌표의 정보 관계, 측정 품질과 기준 자료 연결의 미완료 항목을 기록한다.

## 범위와 제외

연구 문서·결정·문서 지도만 갱신한다. 런타임·학습·임계값·출력 계약은 변경하지 않는다.

- [x] 결정과 보완 항목 정리

## 결정과 진행 기록

13점·개인 기준·정면 고정·로컬 우선을 유지한다. 결합 입력은 우선 실험 후보로 두고 최적 입력으로 확정하지 않는다.

## 검증 결과와 남은 한계

`python tools/dev.py check-repo` 통과: 저장소 구조·로컬 문서 링크·산출물 경로.
문서만 변경해 런타임 테스트·타입 검사·빌드는 재실행하지 않았다.
실제 데이터 성능은 이번 점검에서 검증하지 않는다.
