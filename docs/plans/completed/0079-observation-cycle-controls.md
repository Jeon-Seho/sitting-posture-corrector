# 관측 사이클 입력과 스트레칭 안내

- 상태: completed
- 담당: Codex
- 시작일: 2026-10-30
- 관련 요구사항/ADR: 사용자 브라우저 주석 1~5, ADR 0044

## 문제와 완료 기준

사이클 수를 1~5 직접 입력하고 수동 선택을 위에 둔다. 각 스트레칭 직전에 메모를 받고 입력 중 시간은 멈춘다. 메모는 회차와 함께 보존한다. 시작 창에는 공통 스크롤 표시를 적용하고 카메라 안내 오버레이를 밝힌다.

## 범위와 제외

/dev 프론트와 로컬 리플레이 계약. 실제 사용자 영상·서비스 판정은 변경하지 않는다.

## 작업 단계

- [x] 현재 구현과 기존 변경 확인
- [x] UI·안내 상태와 리플레이 구현
- [x] 테스트·문서 갱신과 검증

## 결정과 진행 기록

스트레칭 메모는 각 사이클에서 별도로 기록한다.

## 검증 결과와 남은 한계

`make check`: 저장소 검사·Python 203개·프론트 891개 테스트와 TypeScript·Vite 빌드 통과 후 Java 런타임 부재로 백엔드 단계 실패. 이후 추가한 UI 시나리오는 해당 테스트 파일 38개 전체 통과. `make check-browser`: 생산 번들 내 합성 진입 제외 통과 후 Docker daemon 부재로 실패. 브라우저에서 카메라를 켜지 않고 시작 선택 창을 확인했다. 실제 카메라 전체 측정과 오버레이 밝기는 실기기에서 확인하지 않았다. 번들 크기 경고가 남는다.
