## 문제와 완료 기준

타임라인과 설정을 중앙 재생 제어와 같은 활동 상태로 표시/숨긴다. 타임라인은 아래에서 올라온다.
설정이 열리거나 키보드 초점이 있으면 조작을 유지한다. 테두리 없는 선명한 블루 탐색 막대를 쓰고
출처 배지는 기록 정보로 옮긴다. 자세 라벨 제목을 지우고 종료 화면의 두 버튼 높이를 맞춘다.

## 범위와 제외

UI 표시·스타일만 변경한다. 실제 메모리 기록·측정·JSON 형식은 유지한다.
