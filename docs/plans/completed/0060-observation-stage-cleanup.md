# 관측 화면 문구와 영상 높이 정리

- 상태: completed
- 담당: Codex
- 시작일: 2026-10-21
- 관련 요구사항/ADR: 브라우저 주석 1~6 / ADR 0039

## 문제와 완료 기준

측정 툴바의 기술 표기·초기 안내·영상 아래 기본 순서 안내·하단 연구 설명을 제거한다.
진행 구간은 영상 오른쪽 아래에 표시하고, 영상 영역 높이는 기존 계산값의 1.3배로 늘린다.
실제 안내 컴포넌트에 명시적인 합성 상태를 넣어 준비·네 동작·이동/복귀·중단/완료 화면을 캡처한다.

## 범위와 제외

관측 UI·기본 notice·전용 CSS·합성 UI 검증·관련 문서만 변경한다. 기존 미커밋 변경을 보존한다.
오류·일시 정지·CSV 보존 메시지와 접근성 안내는 유지한다. 카메라·등록·시간·CSV 정책은 바꾸지 않는다.
실제 카메라 영상·참여자 좌표는 사용하지 않는다. 캡처용 임시 진입 파일은 검수 후 제거한다.

## 결정과 진행 기록

- 삭제 요청은 중복 상시 안내에 적용한다. 오류/중단 메시지와 연구 한계는 상태 표시 및 상단 도움말에서 확인한다.
- 합성 예시는 실제 촬영·모델 정확도 검증과 구분하여 표시한다.

## 검증 결과와 남은 한계

- `python tools/dev.py check-frontend`: 94개 파일·788개 테스트 통과. TypeScript 검사·Vite 빌드 통과.
- 관련 기존 합성 UI/생명주기 테스트 30개도 통과했다. 기존 500kB 청크 경고는 남는다.
- 실제 페이지(뷰포트 높이 884px)의 대기 영상 높이는 기존 602px 대비 782.59px로 확인했다.
  기술 표기·초기 안내·하단 중복 문구가 사라지고 진행 구간이 영상 오른쪽 아래에 놓인 것을 확인했다.
- 별도 browser-smoke 서버의 임시 진입에서 실제 ObservationGuide와 ObservationProtocol,
  명시적인 comparisonDemo 합성 점을 사용해 준비·이동·네 동작 유지·복귀·추적 끊김/일시정지·완료·종료 10장을 캡처했다.
  1280×720에서 진행 표시와 버튼, 중단 메시지가 겹치지 않는 것을 확인하고 2장 모음 이미지도 만들었다.
- 이는 컴포넌트의 고정 합성 상태 시각 검수다. 실제 카메라·모델 정확도나 앱 전체의 연속 수행 결과가 아니다.
- 검수용 HTML/TSX 파일·브라우저 탭·서버를 정리했다. 캡처 산출물은 저장소 밖 작업 아티팩트에 두었다.
- 최종 문서 이동 후 `python tools/dev.py check-repo`와 `git diff --check`도 통과했다.
- 전체 `make check`, 서버/DB 통합 `check-browser`, 실제 카메라·Electron은 실행하지 않았다.
