## 문제와 완료 기준

잘못된 프로젝트에 둔 새 CSV를 현재 프로젝트의 Git 제외 경로로 이동한다.
본인 1명의 검토된 촬영을 회차별로 먼저 분리하고, 학습 자료에만 작은 변형을 적용해 실제 분류 모델을 학습한다.
원본 해시·실험 설정·학습/검증/확인용 촬영·재현 정보·한계를 로컬 결과에 남긴다.

## 범위와 제외

연구 도구만 추가한다. 서비스의 규칙 추론·CEP·API·UI는 바꾸지 않는다.
사용자가 선택한 본인 실험은 같은 사람의 다른 촬영 간 확인이며 새 참여자 성능 평가가 아니다.
기존 참여자 분할 연구 도구는 유지한다. 실제 데이터·분할 manifest·가중치는 Git 제외 경로에만 둔다.
3초 관측 창의 평균·표준편차·기울기를 이용한 softmax 분류를 첫 기준선으로 사용한다. LSTM 학습이라고 주장하지 않는다.

## 결정과 진행 기록

사용자는 본인 자세를 목표로 첫 실험을 선택했다. 여러 사람 성능은 참여자 분할 연구 경로에서 별도로 평가한다.
1회차 학습·2회차 검증·3회차 확인용 촬영을 고정하며 프레임 무작위 분할을 하지 않는다.
확인용 자료는 스케일러·증강 통계·모델 선택에 사용하지 않는다. 카메라와 개인 기준이 같은 짧은 촬영의 결과다.
작은 jitter/scaling은 라벨 보존이 검증되지 않은 탐색 가정이다. 원본과 증강 모델을 검증 자료로 비교하고 선택 뒤 확인용 자료를 평가한다.
