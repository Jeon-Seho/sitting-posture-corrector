## 문제와 완료 기준

개발자 도구가 모든 종류를 세로로 늘어놓아 오류 재현을 찾기 어렵다. 종류별 탭 하나만 표시하고 오류 선택·재현, /dev 진입을 제공한다. /dev는 Electron 제목 표시줄 높이를 빼서 기본·최소 창에 맞추며 시작 대화상자와 내부 스크롤을 유지한다. 최신 develop 통합 후 프론트 검증·패키징·바탕화면 바로가기를 확인한다.

## 범위와 제외

frontend의 개발자 도구, /dev의 CSS와 앱 진입·복귀 링크, 관련 테스트·문서. 서버 계약·연구 판정·실제 영상/좌표 수집 방식은 바꾸지 않는다. 실제 카메라는 검수에서 시작하지 않는다.

## 결정과 진행 기록

- PR #109는 확인 시 이미 develop에 병합돼 있었다. CI 타입·린트 성공, 변경 파일·페이지 오류 분류·표시 위치·복구 경로를 검토하고 현재 작업을 해당 develop 위로 재배치했다.
- 오류 선택은 400번대·500번대·인터넷 끊김·앱 오류·연결 중이다. 연결 중은 실제 offline.html을 미리 보며, 앱 오류는 실제 렌더링 예외도 재현한다.
- /dev 진입은 웹 새 탭, Electron 현재 창이다. 기존 /dev 관측·JSON 다운로드와 CSV 수집은 구별한다.
- 앱의 /dev 본문·영상·도움말·대화상자는 창 높이에서 제목 표시줄 40px을 뺀 공간을 사용한다.

## 검증 결과와 남은 한계

- 최종 `python tools/dev.py check-frontend`: Vitest 981개 + Node 5개, 타입·Vite 빌드 통과. `npm run lint` 오류 0·기존 경고 28개, `git diff --check` 통과.
- 통합 후 관련 4개 테스트 파일의 63개 테스트와 TypeScript 검사 통과.
- 브라우저에서 탭 단일 표시·키보드 탐색·다섯 오류/연결 상황 재현과 /dev 새 탭을 확인했다.
- 실제 개발 Electron 창에서 개발자 로그인 → 기록·수집 → /dev 현재 창 이동, 기본·최소 창의 제목 표시줄/영상/탭/시작 대화상자 배치를 확인했다. 카메라·실측은 시작하지 않았다.
- `npm run desktop:pack` 성공. 패키지 안의 오류 이미지 28종이 최신 dist와 일치하고 /dev 높이 보정 CSS가 포함되는지 검사했다. 숨긴 창·독립 임시 프로필의 EXE 연결 실패 화면·그림 표시 검사 및 시험 프로세스 종료를 확인했다. 바탕화면 PoseGood.lnk가 최신 frontend/PoseGood.exe를 가리킨다.
- 운영 앱은 운영 웹을 불러오므로 소스 병합·로컬 재패키징과 운영 웹 배포를 구분한다.
