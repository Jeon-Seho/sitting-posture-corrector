## 문제와 완료 기준

동일한 입력과 참여자 분할에서 규칙·로지스틱 회귀와 트리 모델을 비교하고, 학습 후보와 결과를
Git 밖에 남긴다. 서비스 성능이나 의학적 판단을 주장하지 않는다.

## 범위와 제외

오프라인 학습·참여자 분할 검증·모델 산출물·합성 테스트와 연구 기록. 서비스 연동과 배포는 제외한다.

## 작업 단계

- [x] 동일한 기준·품질·창·가중치의 트리 학습 및 중첩 참여자 검증 구현
- [x] 합성 데이터의 분할·결과·모델 저장과 복원 확인

## 결정과 진행 기록

각 모델의 설정·임계값은 시험 참가자를 뺀 자료의 참가자별 내부 검증으로 선택한다.
전체 자료 학습 후보는 독립 시험이 없음을 기록한다. 세부 설정과 결과는
[트리 파일럿](../../research/replay-v8-trees.md)에 있다.

## 검증 결과와 남은 한계

- `python -m unittest discover -s tests -p 'test_replay_pilot*.py' -v`에 해당하는 합성 테스트
  15개가 통과했다. 저장한 두 유형의 합성 모델을 다시 읽어 예측 일치도 확인했다.
- 기존 프로젝트 `.venv`가 없어 `python tools/dev.py test` 전체 게이트는 실행하지 못했다.
- 신원·실제 수행 라벨, 연속적인 일상 작업, 독립 사용자 시험은 확인되지 않았다.
