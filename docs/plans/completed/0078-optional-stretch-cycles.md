## 문제와 완료 기준

기본은 이탈·기준 복귀를 반복하고, 스트레칭 포함은 이탈 뒤 기준 복귀와 스트레칭·복귀를 안내한다. 선택한 스트레칭 설명은 로컬 리플레이 기록에 보존한다. 기존 리플레이를 읽을 수 있고 측정 불가 처리와 자료 보존을 유지한다.

## 범위와 제외

/dev 안내·시작 선택·리플레이 계약과 문서. 서비스 판정과 실제 성능 검증은 제외한다.

## 결정과 진행 기록

두 동작을 한 바퀴로 유지해 기본은 이탈 두 번, 선택형은 이탈과 스트레칭을 순서대로 수행한다. 각 동작 뒤 기준 복귀를 안내한다.

## 검증 결과와 남은 한계

`make check`: 저장소 검사, Python 203개, 프론트 886개 테스트와 TypeScript·Vite 빌드 통과 후 Java 런타임 부재로 백엔드 단계 실패. `make check-browser`: 프로덕션 합성 진입 제외 확인 후 Docker daemon 부재로 통합 검증 실패. 브라우저에서 시작 창과 두 선택·메모 입력을 확인했으며 실제 카메라 측정은 하지 않았다. 기존 번들 크기 경고가 남는다.
