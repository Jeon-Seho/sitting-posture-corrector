# 0003: 프론트 상태·알림 프로토타입

- 상태: completed
- 시작일: 2026-09-18

## 범위

기존 frontend 폴더에 React/TypeScript 로컬 프로토타입을 만든다.
합성 상태로 정상/이탈/측정 불가, 지속시간 알림, 휴식, 세션 통계를 체험한다.
사용자 추가 요청에 따라 실제 웹캠 MediaPipe 추출과 개인 기준 비교 규칙도 포함한다.
LSTM 학습·서버·인증·영구 저장은 제외한다.

- [x] 3초 지속·60초 재알림 기본값과 사용자 설정
- [x] 측정 불가·휴식 제외 및 중단 이벤트 구분
- [x] 타이머 상태 전이 테스트, 타입 검사, 빌드, 기존 하네스 검증

## 검증 결과

- `make check`: Python 10개 + 프론트 9개 테스트, TypeScript, 프로덕션 빌드 통과.
- `git diff --check`: 통과. 모델·WASM·빌드 출력이 Git에서 제외되는 것 확인.
- 브라우저 데모: 시작, 3초 이탈 알림, 휴식 중 유효 시간 고정, 세션 기록의 `휴식으로 중단` 확인.
- 합성 영상 스트림에 실제 MediaPipe를 로드하여 프레임 추론·사람 없는 품질 처리·종료 시 트랙 해제를 확인.
- 별도의 합성 랜드마크 대역으로 5초 기준 등록 → 정상 → 이탈 → 측정 불가 연결 확인.
- 권한 거부 대역으로 안내 및 재시도 UI 확인. 물리 카메라 영상은 테스트에서 사용하지 않았다.
- 390px 모바일 화면에서 가로 넘침 없음, 주요 화면 배치 확인. 테스트용 임시 페이지는 삭제했다.
- 브라우저 미리보기와 로컬 개발 서버를 유지한다. GitHub Actions 원격 실행·배포는 수행하지 않았다.
