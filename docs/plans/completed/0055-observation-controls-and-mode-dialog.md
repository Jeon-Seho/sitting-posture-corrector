## 문제와 완료 기준

상단 브랜드/LIVE 행을 제거한다. 카메라 안 시작 버튼을 카메라 켜기로 바꾸고 자동/수동
선택 모달에서 확인한 뒤 연결한다. 취소는 카메라를 연결하지 않는다. 꺼진 카메라의 안내는
영상 중앙에 표시한다. 등록·종료·CSV·도움말은 관측 도구 오른쪽에 두고 수집 설명은 도움말로
옮긴다. 단계와 바퀴/동작 위치는 한 행의 양끝에 표시한다.

## 범위와 제외

관측 화면·가이드·도구 UI와 모달. 2초 안내/8초 등록·2/5/5 진행·측정 구간 수집·CSV 계약은 유지한다.

## 결정과 진행 기록

- 공통 native dialog를 재사용해 Escape·Tab·배경 차단·초점 복귀를 유지한다.
- 모드를 명시적으로 고르고 시작을 확인하기 전에는 카메라를 연결하지 않는다.

## 검증 결과와 남은 한계

- `make check-frontend`: 95개 파일·794개 테스트 통과, TypeScript·Vite 빌드 통과.
- `git diff --check`: 통과. 저장소·문서 링크는 `make check-repo`로 별도 확인한다.
- 브라우저: 중앙 안내/시작 버튼과 하단 도구/도움말 배치, 명시적 모드 선택 전 시작 비활성,
  선택 후 활성화, Tab 순환·Escape 취소·시작 버튼 초점 복귀, 도움말 표시/닫기를 확인했다.
  콘솔 오류·경고는 없었다. 실제 카메라 연결 버튼은 실행하지 않았다.
- 등록·수동 진행·기존 자료 보존 확인 연결은 명시적 합성 관측으로 검증했다.
- 기존 Python 가상환경·백엔드 빌드/JAR가 없어 전체 `make check-browser`는 실행하지 않았다.
  실제 카메라 실측은 미검증이다. Vite의 500kB 초과 청크 경고는 남아 있다.
