- 관련 요구사항/ADR: 사용자 제공 Apple 건강 다크 화면, [개발자 화면](../../design/developer-lab.md)

## 문제와 완료 기준

`/dev`의 수치·그래프 위계와 아이콘 구분이 약하다. 제공 이미지의 검정 바탕, 둥근 차콜 카드,
항목별 색상과 아이콘, 큰 숫자·작은 단위를 기존 화면에 적용한다. 모바일과 데스크톱, 다크·라이트에서
읽기와 기존 도구 조작을 확인한다.

## 범위와 제외

ObservationLab, ObservationTools, 리플레이 가져오기 아이콘과 관측 CSS만 변경한다.
기존 로컬 Pretendard와 Phosphor를 사용한다. 카메라 해상도·판정·수집·내보내기·안내 시간은 바꾸지 않는다.
참고 이미지의 OS 크롬·개인 아바타·건강 점수는 추가하지 않는다.

## 결정과 진행 기록

- 검정 캔버스/차콜 카드와 의미별 청록·주황·민트·파랑·핑크를 사용한다.
- 그래프는 기존 실제 관측값과 누락 구간을 그대로 표시하며 예시 수치를 실제 화면에 채우지 않는다.
- 시작 시 Git 메타데이터 참조 경로가 없어 git status가 실패했다. 기존 파일을 읽고 범위를 한정해 수정한다.

## 검증 결과와 남은 한계

- `make check-frontend`: 98개 파일·836개 테스트 통과, TypeScript·Vite 빌드 통과. 기존 큰 청크 경고는 남는다.
- 실제 브라우저에서 402/1384px 관측 화면, 320px 합성 예시, 다크/라이트, 도구 탭과 키보드 이동,
  모드 선택/취소·리플레이 파일 창/취소를 확인했다. 실제 `/dev` 콘솔 오류 0건.
- 참고 이미지와 전체/확대 비교 후 카드 높이와 그래프 축 레이블을 수정하고 재검수했다.
  자세한 시각 증거는 프로젝트 루트 `design-qa.md`에 기록했다.
- `make check-repo`는 기존 Git 메타데이터 참조 경로 누락 때문에 실패했다. 수정 문서 링크·필수 경로·공백
  부분 검사는 별도로 실행한다. 실제 카메라·서버/DB 통합과 전체 `make check`는 실행하지 않았다.
