## 문제와 완료 기준

원본 JSON을 보존하면서 학습 특징을 수학적으로 증강하고, 시험 참여자의 변형하지 않은
실제 자료로 증강 전후 랜덤 포레스트·LightGBM을 비교한다.

## 범위와 제외

학습 전용 반전·제한 잡음, 참여자 분할과 내부 검증, 비공개 모델·집계 보고서, 합성 시험.
서비스 연결, 의자 이동 보정, 실제 정확도·의료 효과 주장은 제외한다.

## 작업 단계

- [x] 학습 전용 증강과 검증·시험 참여자 차단, 모델·보고서 생성

- [x] 실제 자료에 대한 참여자별 탐색 평가와 결과 기록

## 결정과 진행 기록

반전·잡음이 라벨을 유지한다는 것은 미검증 가정이다. 원본과 증강 특징 5개의 총 가중치를
원본 한 창의 기존 가중치와 같게 둔다. 설정·결과·산출물은
[증강 파일럿](../../research/replay-v8-augmentation.md)에 기록한다.

## 검증 결과와 남은 한계

- `python -m unittest discover -s tests -p 'test_replay_pilot*.py'`의 합성 테스트 18개가 통과했다.
  증강 개수·반전·잡음 범위·가중치·시드·데이터 누수와 모델 저장·복원을 확인했다.
- 실제 원본 20개는 실행 전후 SHA-256이 같았다. 참여자 이름 동일성·실제 수행 라벨은 미검증이다.
- 6개 평가 fold의 모델은 시험 참여자를 제외했으며, 전체 자료로 다시 학습한 모델은 독립 시험이 없다.
- 기존 `.venv`와 일부 의존성이 없는 환경이므로 저장소 전체 게이트 결과와 구분한다.
