## 문제와 완료 기준

카메라 연결 후 2초 안내하고 유효한 8초 기준을 자동 등록한다. 이후 준비 2초 → 측정 5초 →
복귀 준비 5초를 네 동작·세 바퀴 진행한다. 자동은 시간이 끝나면 전환하고 수동은 시간이
끝난 뒤에만 다음 버튼으로 전환한다. 측정 5초 안에서만 수치 자료를 모은다.
안내 카드 배경을 더 투명하게 한다. 합성 시간·프레임으로 조기 전환, 대기 중 수집,
누락·숨김·재등록·자료 보존을 검증한다.

## 범위와 제외

관측 비교 UI·프로토콜·훅·CSV와 순수 기준 등록 시간 옵션. 서비스·다른 /dev 흐름·
모델 학습·원본 데이터 저장·서버 API는 제외한다. CSV 의미 변경은 v3로 구분한다.

## 결정과 진행 기록

- 사용자가 동작 시간은 기존 2/5/5초로 유지하도록 선택했다.
- 기준 등록은 관측 비교에서만 8초로 지정한다. 다른 소비자의 기본 2초는 유지한다.
- 측정 외 단계의 수치 표본은 내보내지 않고 안내 사건은 값 없는 경계로 남긴다.

## 검증 결과와 남은 한계

- `make check-frontend`: 94개 파일·790개 테스트 통과, TypeScript·Vite 빌드 통과.
- 브라우저: 별도 탭에서 자동/수동 전환과 카드 background alpha 0.55·blur 8px,
  콘솔 경고/오류 없음 확인. 실제 카메라 권한은 사용하지 않았다.
- `make check`: 저장소 구조·문서 링크 검사 통과 후 Python 가상환경 부재로 중단.
  Python·백엔드·MySQL·Compose 및 전체 합성 브라우저 게이트는 실행하지 못했다.
- `git diff --check`: 통과. 빌드의 500kB 초과 청크 경고는 남아 있다.
- 기준/측정 시간·자동/수동 36단계·수집 구간·중단/숨김/재시도·카메라 재연결·자료 보존은
  명시적인 합성 관측으로 확인했다. 실제 카메라 정확도·실제 수행 일치·장시간 장치 검증은 남아 있다.
