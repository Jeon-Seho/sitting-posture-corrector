## 문제와 완료 기준

사용자가 기존 동작인 최초 알림 3초, 정상 복귀 2초, 같은 사건 재알림 60초,
휴식 후 새 사건, 측정 불가·누락 시 연속 판정 중단과 유효 통계 제외,
설정의 다음 세션 적용을 재확인했다. 구현은 보존하고 현행 문서의 미결정 표시를 정리한다.
기존 프론트·CEP·API 구현과 합성 검증이 이 정책에 일치함을 확인한다.

## 범위와 제외

- 포함: 결정 기록, 제품·팀 요구·계약 설명·인계·백로그 및 관련 코드 주석과 안내 문구.
- 제외: 시간 판정 알고리즘·기본값·전송 계약·기술 스택 변경, 실제 특징 어댑터 연결,
  품질/점수 임계값·카메라 시점·입력 공백 인식 기준의 확정, 실제 카메라 사용·데이터 전송.
- 기존 구조 정리 변경과 사용자 자료를 보존한다. 과거 완료 기록에는 후속 결정 링크를 추가한다.

## 결정과 진행 기록

- 2026-10-01: 사용자 재확인으로 기존 시간 정책을 확정한다. 결정 근거는 사용자 선택이며
  실제 환경에서의 탐지 성능이나 의료 효과를 입증한 결과가 아니다.
- `legacy-interrupt-v1`은 기존 API 식별자를 유지한다. 정책 승인 상태만 갱신하므로 계약 버전을 바꾸지 않는다.
- 현행 제품·팀 요구·인계·백로그·서비스/계약 안내와 SettingsPage의 미결정 표시를 갱신했다.
  ADR 0011과 완료 계획 0011에는 날짜를 구분한 후속 결정 링크를 남겼다.
- 기존 새 기록의 사건 간격은 같은 세션의 유효 시간 축을 사용한다. 과거 유효 발생 시각 없는 기록만
  같은 연속 구간에 제한하는 실제 구현에 맞춰 README와 SessionResult 설명도 갱신했다.
- 기존 시간 판정·누락 제외·세션별 설정 고정·복구 테스트를 확인했다. 이번 변경은 설명·주석만 바꾸므로
  판정 코드와 테스트, 기본값, 스키마, 의존성을 수정하지 않았다.
