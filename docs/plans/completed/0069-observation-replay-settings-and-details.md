# 관측 디테일과 리플레이 영상 내부 설정

## 문제와 완료 기준

버튼과 바깥 배경의 중첩 곡률을 맞추고 스크롤 바 배경 제거·길이 2배, 탭 사이 짧은 구분선을 넣는다.
리플레이에는 기록이 없어도 동일한 정보 카드를 표시한다. 파일/속도/좌표/기록 설정을 영상 내부 톱니바퀴로
옮기고 플레이어 제어는 필요한 폭의 반투명 박스로 표시한다. 빈 플레이어에 파일 가져오기 버튼을 둔다.
현재 프레임의 기록된 자세 라벨을 위에 명시하며 없는 기록에 라벨이나 수치를 만들지 않는다.

## 범위와 제외

관측 UI만 변경한다. 추론·기준·시간·수집·JSON 형식은 유지한다. 라벨은 기존 안내 메타데이터이며
자세 판정/정답으로 취급하지 않는다. 활성 측정에서는 경쟁 파일/재생 조작을 허용하지 않는다.

## 결정과 진행 기록

- 설정은 Escape/바깥 클릭/작업 선택으로 닫고 트리거에 초점을 복원한다. 가져오기 모달과 기존 파일 경로는 유지한다.
- 기준 없는 리플레이는 카드와 빈 trace만 표시한다. 실제 좌표는 저장소에 추가하지 않는다.
- Git status는 기존 메타데이터 경로 오류로 실패한다.

## 검증 결과와 남은 한계

- `make check-frontend`: 102개 파일·851개 테스트, 타입·빌드 통과. 빈 카드/라벨 없음·재생 위치의 기록 라벨 변경·설정 닫기/초점/정리 3개 회귀를 추가했다. 기존 경로 회귀는 UI와 분리해 종료 후 기록 보존을 확인한다.
- 브라우저 1624×924: 버튼 14px·여백 9px·외곽 23px, 스크롤 바 투명/그림자 없음·길이 56px, 탭 구분선 16px 확인. 리플레이 카드 6개가 빈/기록 상태에서 동일하게 표시된다.
- 명시적 합성 프레임으로 기준 등록 후 기록을 만들고 자세 라벨·지표 갱신과 360px 제어 박스, 설정의 속도/좌표 변경을 확인했다. 설정에서 모달 열기/취소 후 톱니바퀴 초점 복원, Escape 닫기도 확인했다. 최종 합성 탭 console warn/error 0건.
- 320×774에서 기록 있는 메뉴와 빈 메뉴의 가로 넘침 없음. 빈 모바일 플레이어 높이 부족으로 메뉴가 잘리는 문제를 발견해 최소 높이와 버튼 위치를 보완하고 메뉴 전체가 플레이어 안에 들어오는 것을 재확인했다.
- 임시 합성 HTML/TSX/탭은 제거하고 뷰포트 override를 해제했다. 실제 개인 파일 가져오기/내보내기·카메라 재촬영·전체 서버/DB 브라우저 게이트는 실행하지 않았다.
- `make check-repo`는 기존 Git 경로 오류로 실패한다. 수정 문서 링크·필수 경로·공백은 부분 검사했다.
