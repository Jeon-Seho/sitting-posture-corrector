## 문제와 완료 기준

오른쪽 목록의 기본 스크롤바를 숨기고 더 볼 정보가 있는 방향의 중앙 위/아래에 떠 있는 짧은 바를 표시한다.
처음에는 아래만, 중간에는 양쪽, 마지막에는 위만 표시하고 넘침이 없으면 모두 숨긴다.

## 범위와 제외

관측 도구 패널의 표시와 스크롤 힌트. 카메라·기록·그래프 값·파일 형식은 유지한다.
트랙패드/마우스/키보드 스크롤과 패널 상태 유지, 줄어든 모션 설정을 지원한다.

## 결정과 진행 기록

- 바를 누르면 같은 목록을 화면 높이의 70%만큼 이동한다. 숨겨진 탭은 힌트를 렌더하지 않는다.
- Git status는 기존 Git 경로 오류로 실패했다.

## 검증 결과와 남은 한계

- `make check-frontend`: 101개 파일·848개 테스트, 타입·빌드 통과. 가장자리/클릭/내용·뷰포트 크기 변경/숨김 탭 복귀/관찰자 정리 2개 회귀를 추가했다.
- 브라우저: 기본 scrollbar-width none, 처음 아래만/중간 양쪽/끝 위만/스크롤 없는 비교표는 표시 없음 확인. 버튼 클릭 후 같은 목록이 이동하고 초점은 tabpanel에 유지된다. 목록 scrollTop 298에서도 페이지 scrollY는 0이다.
- 402×874 라이트 화면에서 가로 넘침 없이 목록 max-height와 힌트가 유지된다. 최종 데스크톱 화면과 시작/끝 증빙을 저장하고 뷰포트 override를 해제했다.
- CSS의 줄어든 모션 규칙을 유지했다. OS 접근성 설정 전환, 실제 카메라 재촬영·전체 서버/DB 브라우저 게이트는 실행하지 않았다.
- `make check-repo`는 기존 Git 경로 누락으로 실패한다. 수정 문서는 별도 링크·필수 경로·공백 부분 검사를 수행했다.
