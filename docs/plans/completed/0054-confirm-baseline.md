# 기준 등록 확인과 상태 아이콘 개선

- 상태: completed
- 담당: Codex
- 시작일: 2026-10-28
- 관련 요구사항/ADR: 사용자 화면 피드백, ADR 0040

## 문제와 완료 기준

카메라 연결 뒤 자동 2초 대기를 없애고 유효한 관측에서 사용자의 확인을 받은 후에만 8초 기준 등록을 시작한다. 아이콘 버튼의 정렬과 접근성을 유지하고 상태 아이콘을 실제 표시와 일치하는 범례로 설명한다.

## 범위와 제외

/dev 기준 등록 흐름, 관련 UI와 테스트·문서. 관측 데이터와 리플레이 스키마, 측정 단계 시간은 유지한다.

## 작업 단계

- [x] 관련 구현·계약 확인
- [x] 준비 확인과 아이콘 구현
- [x] 합성 상태 전이 및 화면 검증
- [x] 문서 동기화와 범위별 검증

## 결정과 진행 기록

기존 리플레이의 preparing 단계는 사용자 확인을 기다리는 기간으로 사용한다. 카메라가 꺼져 있는 동안 정지된 점을 사용하고 실제 연결 중에만 애니메이션을 재생해 카메라를 찾는 중이라고 잘못 표시하지 않는다.

## 검증 결과와 남은 한계

`make check-frontend` 테스트 872개와 TypeScript·빌드 통과. 합성 데이터로 장시간 대기,
최신 관측 없는 확인 거부, 확인 후 8초 등록과 재등록·숨김 경로를 확인했다. 합성 화면에서
확인 전·후 UI와 아이콘 정렬을 확인했다. 브라우저 전체 회귀는 Python 가상환경의 `pymysql`
누락으로 기존에 실행하지 못했으며 실제 카메라·Windows 검증은 별도다.
