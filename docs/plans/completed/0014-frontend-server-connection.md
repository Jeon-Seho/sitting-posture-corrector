## 문제와 완료 기준

사용자가 남은 작업을 요청했고 DB·인증 환경은 미정이므로 서버 연결부터 진행하기로 선택했다.
브라우저의 세 특징 변화량과 서버의 두 임시 특징을 별도 버전 계약으로 맞추고,
프론트에서 선택할 수 있는 개발 서버 모드를 FastAPI → API → CEP 흐름에 연결한다.
서버 모드에서는 로컬 시간 판정 엔진을 실행하지 않고 서버가 확인한 관측·사건·통계를 표시한다.
중복 재시도·연결 실패·중단·종료 응답 및 새로고침 복구를 합성 입력으로 검증한다.

## 범위와 제외

- 포함: 추론 입력 v2·특징 응답 v1 추가, 모델 책임의 특징 어댑터, API의 추론/CEP 조율,
  동일 출처 개발 프록시, 프론트 서버 전용 화면·순서 큐·확인 결과 저장·실패 복구, DB·인증 연결 설계.
- 기존 로컬 모드·저장 자료·v1 추론·관측 v2·시간 정책·기술 스택·의존성을 유지한다.
- 원본 영상·랜드마크는 서버에 보내지 않는다. 서버 모드는 사용자가 측정 준비에서 선택한다.
  검증에는 명시적 합성 자료만 쓴다. 실패 재시도용 변화량은 중간 기록에 일시 보관하고 종료 후 정리한다.
- 제외: DB 제품/인증 방식 확정 및 외부 계정·DB 연결, 실촬영·참여자 자료 수집·학습,
  점수/품질 임계값 최적화·카메라 시점의 연구상 최종 확정, 배포·원격 push.
- 인접한 실제 프레임 구간을 사용하는 실험용 어댑터를 정의한다. 기존 품질·프레임 유효기간을 보존하고
  단절·미확인 입력을 정상 시간으로 채우지 않는다. 실제 정확도·장시간 장치 성능은 별도 검증한다.
- 메모리 서버 재시작은 영구 복구로 표시하지 않는다. 세션 유실 시 같은 ID를 새 서버 세션으로 만들지 않는다.

## 결정과 진행 기록

- 2026-10-01: 사용자가 “정해진 환경 없음 — 서버 연결부터 진행”을 선택했다.
- 최초 3초·복귀 2초·같은 사건 60초, 중단 후 새 사건, 제외 시간, 다음 새 세션 설정을 유지한다.
- 특징 입력은 머리 높이·좌우 치우침·어깨 기울기의 어깨 너비 정규화 값에서 현재−기준 변화량을 사용한다.
  기존 점수 스케일과 품질 0.65는 검증 전 규칙으로 보존한다. 전방 굽힘을 단정하지 않는다.
- 서버 응답은 관측 v2와 조회 v1을 함께 반환한다. 서버에 없는 실시간 진행률을 프론트에서 추측하지 않는다.
- 시작 기준·장치·영상 크기와 미확인 요청 하나·고정 종료 의도를 중간 기록에 보관한다.
  종료 후 원래 서버 사건/통계와 모델/기준 ID를 남기고 임시 자료를 정리한다.
  서버 유실 시 같은 UUID를 새 세션으로 만들지 않으며 확인된 요약 보관은 종료 미확인으로 표시한다.
- 교차 검토에서 저품질 입력 후 과거 정상 ACK 표시, enum 배열/숫자 수용,
  API UUID Base64 수용과 낮은 품질의 유효 추론 출력 수용을 찾아 합성 회귀로 보완했다.
- DB·인증은 [연결 설계](../../design/server-persistence-and-auth.md)까지만 작성했다. 제품·로그인 방식 선택/연결은 하지 않았다.

## 검증 결과와 남은 한계

- 2026-10-01 Mac에서 JDK 21·Maven 3.9.16 경로를 지정한 `make check` 전체 통과.
  Python 35개, 프론트 166개(서버 모듈 70개 포함), Java 49개(API 33/CEP 16),
  TypeScript·Vite 빌드·두 실행 JAR·저장소 지도/링크 검증 통과.
- Vite 동일 출처 프록시 → API `/features` → FastAPI v2 → CEP 실제 HTTP 합성 흐름 통과.
  3초·2초 경계, 휴식 후 새 사건, 누락/저품질 제외, 고정 기준, 동일/충돌 재시도,
  종료 확인·추론/CEP 실패 후 마지막 요약 보존을 검증하고 모든 시험 서버·포트를 정리했다.
- `make dev-server`를 실행해 앱 브라우저에서 합성 프로필 진입·홈·측정 준비·서버 선택 기본 꺼짐/선택/안내를 확인했다.
  오류/경고 로그는 없었다. 카메라 버튼·권한은 사용하지 않았다. 테스트 탭과 네 개발 프로세스를 종료했다.
- 기술 스택·의존성 버전·배포를 변경하지 않았다. 원격 push/CI는 실행하지 않았다.
- 실제 카메라 정확도·소리·장시간 백그라운드·지연/FPS·학습 모델·DB·인증·동의/삭제·영구 서버 복구는 미검증 또는 미구현이다.
  개발 메모리 서버의 10,000개 관측 한도와 프레임 구간 근사는 실서비스 수용 기준을 대신하지 않는다.
