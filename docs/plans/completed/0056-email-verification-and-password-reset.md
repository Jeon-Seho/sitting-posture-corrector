## 문제와 완료 기준

서버는 BCrypt12 해시를 저장하며 원문 조회는 없다. 프론트는 로컬 미리보기다. 비밀번호 재설정/이메일 확인 페이지와 제안 API 클라이언트, 딥링크·실패/대기 표시를 준비한다. 실제 메일 발송 성공을 가장하지 않는다. 새 일러스트와 밝은 탐색 면을 적용하고 최신 EXE를 생성한다.

## 범위와 제외

프론트 UI·typed client·mock 단위 검증·연결 설계 MD·이미지·패키징. SMTP 서버·실제 이메일 발송·백엔드/DB 코드 변경·소셜 로그인은 이번 범위에서 제외한다. 기존 로컬 프로필/기록은 유지한다.

## 결정

실제 비밀번호는 BCrypt12 저장을 유지한다. 복호화 가능한 암호문으로 바꾸지 않는다. 메일 토큰 해시·재발급 제한·일회용 소비·전체 로그인 철회·SMTP는 백엔드 담당의 후속 구현이다. 초기에 작성한 백엔드 mail 의존성과 미적용 migration 초안은 사용자 정정에 따라 제거했다.

## 검증 기록

프론트57파일376개·타입/빌드 통과. Chrome에서 재설정 버튼·준비중 API 오류·새 비밀번호 화면·네 너비·reset/verify 링크 진입/URL token 제거 확인. 기본 화면/회원가입·프로필·정상·측정불가·중단·종료·오류 검수, native 작은 창 합성 검사 통과. SMTP·실제 계정 인증은 구현 범위 밖이며 호출하지 않았다. 기존 전체 Docker 게이트의 MySQL 미기동 제한은 남는다.

최종 `npm run desktop:pack` 성공. `frontend/PoseGood.exe` 실행기와 release/win-unpacked 생성. `node scripts/smoke-packaged-ui.mjs`로 실제 EXE/독립 프로필에서 밝은 소개 배경·최신 이미지 디코딩·재설정 진입·미연결 안내·token 링크/URL 정리 통과. 합성 카메라 native 창 검사도 별도 통과. 초기 검사 스크립트의 DOM 준비/숨긴 창 캡처 대기 문제를 수정한 뒤 전체 패키지 UI 검사를 재실행해 통과했다. SMTP/운영 메일/서버 인증은 구현하지 않았고 BE/DB는 MD 인계다.
