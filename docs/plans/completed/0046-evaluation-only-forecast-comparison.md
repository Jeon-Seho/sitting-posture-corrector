## 문제와 완료 기준

기존 수동 수집은 개인 기준 또는 정상 학습 후보만 표시한다. 평가 자료를 학습 후보로 표시하지 않는 명시적인 수집 경로가 필요하다.
평가용 30초를 별도 스키마로 내보내고, 학습 도구가 거부하며, 이미 학습된 모델과 스케일러를 고정한 채 같은 미래 실측에 두 예측을 비교한다.

## 범위와 제외

- `/dev` 수동 수집에 평가 전용 용도, 전용 안내 및 내보내기를 추가한다.
- 평가 자료는 정상 라벨·개인 범위를 만들거나 현재 개인 범위에 적용하지 않는다.
- Python의 평가용 읽기는 학습용 읽기와 분리하며 원본·가중치는 외부 비공개 경로에 둔다.
- 한 사람의 새 촬영 비교다. 새 참여자 일반화·자세 정확도·교정 효과 평가가 아니다.
- 재학습, 하이퍼파라미터 선택, 평가 자료로 스케일러/기준 재계산은 제외한다.

## 결정과 진행 기록

- 기존 `training_normal`을 평가용으로 재해석하지 않는다. 새 `forecast-evaluation-collection-v1`에서 `trainingAllowed:false`와 `dataRole:evaluation_only`를 명시한다.
- 미래 좌표 정답은 실제 관측이며 기존 100ms 입력 격자·명목 300ms 목표·실측 목표 ±50ms를 유지한다.
- 평가 전후 모델·체크포인트·학습 manifest·학습 보고서 해시를 비교한다.
- 평가 확인은 프로파일 fitting을 호출하지 않고 현재 개인 범위를 보존한다. Python은 별도 `evaluation_frames`로만 평가 자료를 읽으며, 평가 스키마·용도·학습 금지 표시를 학습용 읽기와 pilot manifest에서 거부한다.
- 새 촬영 1회에서 유효 30,083.8ms·278표본을 확보했다. 네 연속 구간 중 마지막 구간에서 232개 유효 평가 창과 비중첩 8창을 만들었다.
- 주 비교의 좌표 MAE는 개인 MediaPipe LSTM 0.0274931733, 마지막 위치 유지 0.0140757571이었다. 비중첩 8창에서도 마지막 위치 유지가 모두 작았다. 중첩 창 상관과 한 사람·한 회차의 한계를 유지한다.
- 네 동결 산출물 해시가 평가 전후 같았으며 재학습·스케일러 재추정·보정·모델 선택은 하지 않았다. 자세 정답·교정 효과를 검증한 결과가 아니다.
- 현재 화면 설정에서 `panoptic-lstm-v1`이 선택되어 있음을 직접 확인해, 같은 232창·목표로 기본 Panoptic을 추가 비교했다. MAE는 0.0556032469였고 마지막 위치 유지 값은 주 비교와 정확히 같았다. Panoptic 가중치도 평가 전후 같았으며 모델을 선택·교체하지 않았다. Panoptic→MediaPipe 대응은 근사·도메인 미검증이므로 현재 웹캠 입력 대응 오차로만 해석한다.
- [집계 측정 기록](../../ml/measurements/forecast-evaluation-2026-10-15.md)에 시간·표본·오차·제외 기준을 남긴다. 원본·참여자 코드·가중치·비공개 파일 경로는 저장소에 넣지 않는다.

## 검증 결과와 남은 한계

- `make check`: Python 186개, 프론트 71파일·652개 테스트, TypeScript와 Vite 빌드 통과. Java 21/Maven 부재로 백엔드 단계에서 중단되어 전체 성공이 아니다.
- `python3 -m unittest tests.test_forecast_evaluation_capture tests.test_mediapipe_lstm -v`: 신규 평가 전용 7개와 기존 자료 준비 20개, 총 27개 통과. 기존 20개는 위 186개와 중복된다.
- 프론트 개별 수집 코어 14개, UI·hook 13개 통과. 이 27개는 전체 프론트 652개에 포함되므로 별도 가산하지 않는다.
- `make check-browser`: 첫 실행은 샌드박스 로컬 서버 bind 제한으로 실패했다. 허용된 재실행에서 생산 번들의 합성 카메라·테스트 진입점 제외 검사와 임시 서버 3개 정리는 통과했다. Java runtime 부재로 서비스 준비에 실패하여 실제 브라우저 회귀 단계는 실행하지 못했다.
- 실제 내장 브라우저에서 평가 모드 선택 → 30.1초 수집 → 학습 제외 확인 → 전용 JSON 다운로드를 완료했다. 일반 서비스 회귀 전체가 통과했다는 뜻은 아니다.
- 최종 `make check-repo`와 `git diff --check`가 통과했다.

실제 비교는 같은 사람의 새 회차 1회이며 새 참여자 일반화 평가가 아니다. 232개 중첩 창을 독립 시행으로 세지 않으며 비중첩 8창도 독립 참여자를 뜻하지 않는다. 목표는 실제 관측이며 입력 격자 끝 기준 목표 간격 중앙값 301.75ms와 마지막 원본 입력 관측 기준 유효 예측 시간 중앙값 216.85ms를 함께 기록한다.
