# 큰 후방·하강 변화 감지와 작은 움직임 허용

- 상태: completed (구현·합성 검증 완료, 실제 기대기 시험 대기)
- 담당: Codex
- 시작일: 2026-10-15
- 관련 요구사항/ADR: 뒤로 기대거나 거의 누웠을 때도 이탈 판정, 작은 움직임 과민 방지, 무음 유지. ADR 0033의 정규화 공백 후속.

## 문제와 완료 기준

어깨 중심·현재 폭 정규화만으로는 동일한 상대 모양의 전체 이동·축소를 구분할 수 없다.
등록 때의 영상 위치·어깨폭을 고정한 별도 관측 경로로 큰 공통 이동/축소를 판정에 반영한다.
작은 움직임·고개만 움직임·짧은 이탈에는 알림이 발생하지 않고, 유효한 큰 변화가 지속되면 무음 시각 알림이 발생한다.
상대 자세·전체 몸 변화·최종 판정 수치를 구분하고 새 이탈을 정상 자동 수집에 넣지 않는다.

## 범위와 제외

`/dev` 관측 판정·표시·진단 계약·자동 선별 제외만 변경한다. 13점과 기존 LSTM/정상 학습 입력은 유지한다.
일반 서비스·SDK·33점 보관·재학습·의학적 자세 분류는 변경하지 않는다.

## 결정과 진행 기록

카메라를 고정하고 정면 기준을 등록한다는 실험 조건이다. 큰 영상 변화는 등록 구도 대비 이탈이며 실제 후방 각도나 의도를 측정하지 않는다.
개발 시작 허용폭은 공통 이동 0.45 등록 어깨폭, 어깨폭 축소 20%이며 등록 흔들림 q95×1.5가 더 크면 넓힌다.
특징 평활화 200ms, 기존 진입 점수 >1·복귀 2/3 및 지속/복귀 3초를 사용한다. 실제 정확도가 검증된 임계값으로 주장하지 않는다.

## 검증 결과와 남은 한계

- `make check`: 저장소 검사, Python **193개**, 프론트 **677개**, TypeScript·생산 빌드 통과. Java 21·Maven 부재로 백엔드부터 중단되어 전체 성공이 아니다. Compose 검사는 도달하지 않았다.
- 마지막 표시 보완 후 `make check-frontend`: **73개 파일·679개 테스트**, TypeScript·생산 빌드 통과. 새 본 작업의 회귀는 총 19개이며 기존 테스트 수와 합산 결과를 구분한다.
- `make check-browser`: 생산 번들의 합성 카메라 제외 검사와 시험 서버 정리 통과. Java 런타임 부재로 서버 준비에 실패하여 통합 브라우저 회귀를 실행하지 못했다.
- 수동 브라우저 확인: 기존 `/dev` 탭을 새로 로드하고 44초 합성 데모를 실행. 종합/상대/몸 전체 점수와 45% 이동·20% 축소 하한, 기본 실측 룰, 소리 꺼짐을 확인했다. 큰 상대 변화의 3.1초 지속에서 시각 알림 1회, 짧은 이탈 후 복귀 1회와 최종 범위 안을 확인했다. 합성 데모의 몸 전체 점수는 0이므로 실제 기대기 성능의 근거로 쓰지 않는다.
- 별도 합성 회귀는 상대 3D 거리 0인 영상 축소에서도 실제 hook→엔진→무음 알림과 export를 검증하고, 작은 흔들림·고개만 이동·짧은 축소·복귀·품질 누락·종횡비 변경·자동 정상 제외를 확인한다.
- 실제 카메라 기대기/누움·오탐률·임계값 적합성은 미검증이다. 사용자에게 작은 움직임→뒤로 기대기 5초→복귀 시험 가능 여부를 요청했고 아직 실제 관측 시험은 하지 않았다. 실제 자료·가중치의 수집/재학습은 이 작업에 포함하지 않았다.

카메라 자체 이동·회전과 사람 이동의 구분, 13점 밖 몸통/골반과 해부학적 각도는 관측하지 않는다. 얼굴/어깨가 가려지면 측정 불가다. 카메라를 고정하고 올바른 자세를 새로 등록해야 한다.
