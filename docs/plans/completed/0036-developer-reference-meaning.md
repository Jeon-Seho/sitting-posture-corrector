# 화면 기준 위치와 자세 판정 기준의 의미 분리

- 상태: completed
- 담당: jisung / Codex
- 시작일: 2026-10-13
- 관련 요구사항/ADR: 화면 기준선에서 벗어나도 기준 근처로 표시되는 사용자 피드백, ADR 0025·0026

## 문제와 완료 기준

등록 당시의 2D 화면 윤곽과 어깨 중심·폭으로 정규화한 3D 판정 기준을 같은 이름으로 표시했다.
몸 전체의 화면 이동은 3D 자세 거리에서 제거되므로 두 화면이 모순처럼 보인다.
영상에 화면 상하 이동과 실제 판정 거리를 함께 표시하고 점선·상태의 의미를 명확히 한다.

## 범위와 제외

개발자 표시용 상하 좌표 변화, 카메라 및 결과 설명, 합성 회귀, 관련 문서를 변경한다.
모델 입력·기준·임계값·판정 정책은 바꾸지 않는다. 실제 사용자의 자세가 올바르게 측정되었는지
스크린샷만으로 확정하지 않는다. 영상과 현재/기준 좌표는 기록·export에 추가하지 않는다.

- [x] 화면 상하 이동·3D 판정 거리·설명 구현
- [x] 평행 이동 불변성 및 머리/어깨 상대 변화 회귀·UI 검증
- [x] 문서 동기화 및 `make check` 결과 기록

## 결정과 진행 기록

점선은 등록 당시 화면 위치로 유지한다. 화면 위치 변화의 단위는 화면폭/높이,
자세 차이의 단위는 현재 3D 어깨폭으로 표시한다. `near_reference`는 자세 차이가 기준 범위 안이라는
뜻이며 점선과의 픽셀 거리나 정확히 동일한 자세를 의미하지 않는다.
브라우저 확인 중 Fast Refresh가 카메라/세션을 정리한 뒤 React의 이전 측정 상태만 보존하는
경우도 발견했다. 활성 실행이 없는 갱신 후에는 시작 대기로 초기화하여 현재 결과처럼 표시하지 않는다.

## 검증 결과와 남은 한계

- `make check`: 저장소 검사, Python 163개, 프론트 51파일 388개 및 타입·빌드 통과.
  Java 21/Maven 부재로 백엔드 단계에서 종료되어 전체 성공은 아니다.
- Fast Refresh 상태 정리 추가 후 `make check-frontend`: 388개 테스트 및 타입·빌드 통과.
- 합성 기하 회귀에서 화면 상하 15% 이동과 3D 전체 평행 이동·일정한 크기 변화는 분리되며,
  머리의 어깨 대비 상대 이동은 룰 이탈 대기로 전환함을 확인했다.
- 카메라 표시 회귀에서 화면 이동 15%와 별도의 판정 거리 4%를 동시에 표시한다.
  누락·영상 비율 변경 시 변화값은 숨기고 warming에 기준 범위 상태를 표시하지 않는다.
- 브라우저에서 코드 갱신 뒤 오래된 활성 상태가 시작 대기로 정리되고, 합성 측정 중 네 수치와
  설명·결과 카드가 표시됨을 확인했다. 실제 웹캠의 3D 추정과 모델 구분 성능은 미검증이다.
- 375px와 1280px에서 화면 수평 넘침이 없음을 확인하고 좁은 화면의 수치를 2열로 배치했다.
