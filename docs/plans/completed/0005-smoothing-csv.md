# 0005: 스켈레톤 표시 개선과 CSV 파일럿 수집

- 상태: completed
- 시작일: 2026-09-19

## 범위

Docker/DB 도입 전 CSV로 특징·품질·수동 라벨을 살펴보는 파일럿을 제공한다.
GPU 우선/CPU 폴백, 최대 30 Hz 추적과 화면 전용 시간 기반 평활화, 실제 FPS/추론 시간 표시를 추가한다.
판정·CSV에는 평활화하지 않은 특징을 사용한다. 영상/원본 좌표 업로드는 없다.

## 완료 기준

- [x] 카메라 생명주기 보존, 추적과 화면 평활화 구분, 측정 품질 유실 시 잔상 제거
- [x] 명시적 수집 시작/중지/다운로드, 품질·시간·수동 라벨·개인 기준·설정 메타데이터 CSV
- [x] 휴식/탭 숨김/종료/카메라 해제 처리, 중복 프레임 배제, 메모리 상한
- [x] pandas 탐색 예제와 파일럿 데이터 한계 문서
- [x] 순수 로직 회귀, 빌드·하네스 및 합성 브라우저 QA

## 제외

Docker, DB, 로그인/서버, 모델 학습, 실사용자 촬영, 성능 수치 보증.
추론은 아직 메인 스레드다. GPU/주기 조정 후에도 느리면 Worker 분리를 후속으로 진행한다.

## 검증 기록

- Python 계약/하네스 10개, 프론트 16개 테스트 및 타입/빌드 통과.
- 합성 랜드마크: 최대 30Hz 스케줄, 기준 등록, 수집 290행/CSV 헤더·결측값을 확인했다.
- 휴식 시 145행으로 수가 고정되고 재개 후 다시 증가함을 확인했다. 화면 이동 후 버퍼 유지·영상 트랙 종료 확인.
- 실제 MediaPipe + 사람 없는 합성 영상: GPU 초기화 실패를 주입하면 CPU로 자동 연결되고 품질 불충족으로 등록을 차단한다.
- JS CSV 직렬화로 만든 합성 10행을 pandas 2.2.3 분석 스크립트로 읽어 라벨·결측·간격·특징 집계 확인.
- 실제 사람의 FPS/정확도, 발열, 장시간 수집은 미검증이다. 합성 추론 대체 경로의 FPS를 실제 성능으로 보고하지 않는다.
- 실제 MediaPipe GPU 초기화/추론도 확인했다. 사람 없는 합성 영상의 순간 표시값 GPU 28 FPS·16ms / CPU 19 FPS·20ms는 스모크 확인이며 사람 추적 벤치마크가 아니다.
- 최종 패널 배치에서 수집 중 다운로드가 수집을 중지하고, 측정 종료 후에도 67행 버퍼가 유지됨을 확인했다. 임시 QA 파일을 제거했다.
