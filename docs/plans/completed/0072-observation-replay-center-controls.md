## 문제와 완료 기준

중앙에는 5초 뒤로 / 재생·정지 / 5초 앞으로 아이콘을 두고 포인터 활동 시 표시·유휴 시 숨긴다.
키보드 초점/터치로도 접근한다. 하단에는 여백 있는 타임라인과 가운데 시간을 두며 파일 가져오기는
설정으로 옮긴다. 측정 후 기록이 있으면 다시 측정/JSON 다운로드를 제공한다. 최근 측정 보기의 의미를
분명히 하고 공통 SelectMenu로 좌표/속도 드롭다운을 직접 스타일링한다.

## 범위와 제외

관측 UI·재생 탐색만 변경한다. 5초 탐색은 양 끝에 clamp하고 기존 누락/기준 정책을 유지한다.
재측정은 기존 자료 보호 확인을 유지한다. 개인 기록은 저장소에 넣지 않는다.

## 결정과 진행 기록

- 기존 공통 SelectMenu가 있어 새 Radix/Tailwind 의존성을 추가하지 않고 재사용한다. shadcn 공식 Select 문서도 확인했다.
- 실제 현재 기록은 UI 다운로드로 저장소 밖 Downloads의 JSON으로 백업했다. 코드 갱신 시 부모 기록 훅 순서를 유지한다.
- Git status는 기존 Git 경로 오류로 실패했다.

  해당 장시간 케이스만 제한을 15초로 설정했고 최종 전체 게이트를 다시 통과했다. 판정/프로토콜 시간은 바꾸지 않았다.
