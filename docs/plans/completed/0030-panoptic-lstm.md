## 문제와 완료 기준

Panoptic 시계열로 실제 LSTM을 학습하고 재현 가능한 가중치·집계 결과를 Git 제외 경로에 저장한다.
자세 정답 라벨이 없으므로 과거 얼굴·어깨 좌표에서 0.3초 뒤 좌표를 예측하는 회귀 과제다.
실제 참여자 대응이 검증되지 않아 이번 시퀀스 전체를 학습 전용으로 배정한다.
시험/검증 참여자를 임의 track ID로 만들지 않고 일반화 성능은 보고하지 않는다.

## 범위와 제외

연구 도구·합성 테스트·ML 기록. 서비스, 프론트, 영상, 개인 기준 등록 제외.
Panoptic의 얼굴/몸 포인트 정의는 MediaPipe 13점과 동일하지 않다.

## 결정과 진행 기록

참여자 일반화 평가는 실제 참여자 대응이 있는 별도 자료 확보 후 시행한다.
학습 집합에서 위치 유지·등속 예측 비교는 fitting 진단만이며 정확도 검증으로 해석하지 않는다.
신뢰도·시간창 설정은 이 실험의 설정이며 서비스 임계값으로 채택하지 않는다.

## 검증 결과와 남은 한계

실제 자료 2,465창, 25epochs, 가중치 79,969bytes 저장·weights_only 재로딩 성공.
학습 집합 점 거리: LSTM0.045511, 마지막 위치 유지0.044814, 등속0.064127.
따라서 가장 단순한 위치 유지 방법을 이기지 못했으며 독립 성능은 평가하지 않았다.

신규 합성 unittest 7개 통과, 합성 CLI 2epochs 실행 성공.
`python -X utf8 tools/dev.py test` 정상 환경 실행: 154개 중150통과, 기존 배포3오류,1skip.
기존 오류는 Windows에서 열린 백업 파일 unlink 2건, Linux/POSIX deployment lock 1건이다.
샌드박스 내 전체 검사는 임시 경로 권한/API TestClient 대기 때문에 중단하고 정상 환경에서 재실행했다.
신규 저장 경로 테스트에서 확인한 Windows 경로 오류는 Python file handle을 사용해 해결했다.
`check-repo`, `git diff --check` 통과. 타입/프론트 빌드·전체 make check·실제 서버/GPU 검증 미실행.

실제 참여자 대응·독립 시험·MediaPipe 좌표 입력·자세 라벨은 후속 과제다.
