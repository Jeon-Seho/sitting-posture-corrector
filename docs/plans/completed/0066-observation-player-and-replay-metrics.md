## 문제와 완료 기준

작은 프리뷰와 분리된 재생 옵션은 보기 어렵고, 동작 선택 탭과 비교표 설명은 불필요하게 복잡하다.
동작 선택 탭을 제거한다. 좌측 그래프 1열과 우측 큰 카메라/리플레이, 영상 내부의 재생 제어로 정리한다.
상대 z 좌표는 맨 아래로 옮긴다. 비교표는 프리뷰를 숨기고 중앙의 간결한 카드 스타일로 표시한다.
리플레이에서는 기록 시점의 지표와 최근 10초 그래프를 재생바에 맞춰 보여준다.

## 범위와 제외

관측 UI/표시용 리플레이 지표 계산·검증·문서. 기존 안내·추론·자료 수집·CSV/JSON 형식은 유지한다.
기록의 등록 단계로만 기준을 재구성하고 수행 구간이나 미래 프레임을 기준으로 쓰지 않는다.
미등록/누락/추출기·해상도 불일치는 빈 값이다. 실제 데이터는 저장소에 넣지 않는다.
비교표에서 영상은 숨겨도 스트림/세션을 종료하지 않으며 활성 측정 종료 제어는 남긴다.

## 결정과 진행 기록

- 사용자의 선택지 중 얼굴/안내를 덮지 않는 그래프 좌측 분리안을 먼저 적용한다.
- 비교표 설명은 도움말로 옮기고 주요 동작/다운로드·빈 값 의미만 남긴다.
- v1 JSON은 기준 좌표를 따로 저장하지 않는다. 등록 구간과 완료 경계 프레임을 기존 8초 엔진에 순서대로
  전달해 재구성하며 등록이 성립하지 않으면 %를 만들지 않는다. 미래 프레임 값은 현재/과거 화면에 노출하지 않는다.
- Git 메타데이터 경로 누락으로 status 조회가 실패했다. 기존 변경과 메모리 기록을 보존한다.

## 검증 결과와 남은 한계

- `make check-frontend`: 100개 파일·846개 테스트, 타입 검사와 빌드 통과. 기준 재구성/미등록/등록 중단/world 누락/시점·누락 그래프 5개 합성 테스트와 비교표 전환 중 세션 보존 통합 회귀를 포함한다.
- 브라우저: 1624×924에서 좌측 340px 그래프 1열·우측 752×564px 플레이어, 제어의 플레이어 내부 배치와 비교표 영상 숨김을 확인했다. 402×874 라이트·320×774에서도 문서 가로 넘침이 없다. 재생/정지·키보드 시점 이동·탭 방향키·위치 보존을 확인했다.
- 명시적 합성 프레임을 실제 안내/기록 UI에 전달해 등록 전 빈 값과 등록 후 변화율, 과거 시점의 값 전환을 확인했다. 최종 합성 검수 탭 console warn/error 0건이며 임시 소스와 탭은 제거했다. 중간 HMR 단계에서 일시적 함수 자식 경고가 있었고 최종 소스에서는 재현되지 않았다.
- 기존 실제 2,037프레임 로컬 백업을 최신 UI로 불러와 시점 변경과 기준 -0.183m 복원을 확인했다. 원래 메모리 기록 탭도 보존했다. 개인 좌표는 저장소/외부에 추가하지 않았다.
- 실제 카메라 재촬영, 전체 서버/DB 브라우저 검증은 실행하지 않았다. `make check-repo`는 기존 Git 메타데이터 경로 누락으로 실패한다. 수정 문서 링크·필수 경로·공백은 별도 부분 검사한다.
