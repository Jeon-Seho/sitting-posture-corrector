## 문제와 완료 기준

`/dev`에서 명시적으로 정상 자세 좌표를 수집하고 구간 확인 뒤 개인 정상 변동 모델을 맞추고 적용한다.
기준 등록은 개인 보정이며 의학적 정상성 검증이 아니다. 기준 이탈·지속시간은 예측 모델 준비와 독립적으로 동작한다.
11 FPS의 샘플 건너뛰기/170ms 초기화 충돌을 제거하고 실제 품질 누락은 계속 측정 불가로 처리한다.
표시 좌표만 평활화하며 원본 학습 자료·판정 좌표를 바꾸지 않는다. 최신 설계·구현·미검증 범위를 Markdown/HTML로 제공한다.

## 범위와 제외

`model/prototype/`, `/dev` 전용 프론트, 별도 정상 수집 계약, ML 문서. 기존 미커밋 작업은 유지한다.
사용자 요청에 따라 별도 수집 흐름에서만 원본 좌표를 명시적으로 다운로드한다. 일반 진단 export에는 원본을 추가하지 않는다.
실제 좌표·모델 자료는 Git에 넣지 않으며 서버 업로드·일반 서비스·검증되지 않은 정확도 주장은 제외한다.

## 결정과 진행 기록

- 정상 범위 모델은 검토된 목표 자세 변동을 학습하는 개인용 통계 모델이다. 전역 학습 모델의 성능을 주장하지 않는다.
- 새 관측 모드의 정상 범위/거리·시간이 기본 알림 경로이며 LSTM은 비교·예측 보조다.
- 학습 대상 원본 수집과 기존 수치 진단을 분리한다. 자료 역할·촬영 회차를 남겨 연구 분할을 준비한다.
- 등록/학습 구간 자동 갱신 및 이탈 자료 자동 학습은 하지 않는다.
