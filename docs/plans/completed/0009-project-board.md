## 문제와 완료 기준

아르케 로컬 관리판의 문서 탐색·작업 보드·메모 흐름을 바른자세 저장소에 제공한다.
더블클릭 실행, MD 원문 기반 검색과 읽기, 계획서 상태 집계, 별도 작업 카드·메모 저장을 확인한다.

## 범위와 제외

`tools/project-board/`와 실행기, 안내 문서, 하네스 검증을 추가한다. 기존 앱과 사용자 변경은 유지한다.
계획 상태와 체크리스트를 구분하며 체크리스트 100%를 실서비스 완성률로 표시하지 않는다.
외부 배포·AI 자동 실행·MD 원본 편집 기능은 이번 범위에 포함하지 않는다.

## 검증 결과와 남은 한계

Windows에 make가 없어 `make check` 자체는 실행하지 않았다. 대응 명령을 실행했다.
저장소 문서 검사 통과, 프로젝트 .venv에서 Python 20개(기존10+관리판10) 통과,
프론트 29개 테스트·TypeScript·Vite 빌드 통과, 관리판 JS 문법 검사와 diff 공백 검사 통과.
기본 Python에 jsonschema가 없어 초기 계약 테스트가 실패했고, .venv에 requirements-dev.txt 설치 후 전체 통과했다.
실브라우저에서 MD 검색·표 읽기·분야 선택 메뉴·공동 담당 카드 저장·팀 집계·메모 저장·CLI 결과 반영·작성자별 커밋 필터를 확인했다.
합성 검증 카드·메모는 확인 후 제거했다. 원격 CI·다른 PC·실제 모바일 장치·원격 동시 협업은 미검증이다.
관리판은 로컬 전용이며 커밋 작성자 분류는 Git 메타데이터 기준이다. 실제 GitHub 인증을 대신하지 않는다.
