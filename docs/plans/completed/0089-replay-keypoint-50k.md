# 키포인트 특징 약 5만 건 증강 비교

- 상태: completed
- 시작일: 2026-11-08
- 관련: [기존 증강 파일럿](0088-replay-v8-augmentation-pilot.md)

## 문제와 완료 기준

팀이 수집한 키포인트 자료를 약 5만 건의 학습 특징으로 증강하고, 시험 참여자의 미변형 실제
자료를 사용해 5배 증강과 비교한다. 원본과 프론트엔드는 변경하지 않는다.

## 범위와 제외

오프라인 25개 변형·참여자 분리 비교·모델 산출물·합성 테스트. 외부 이미지 데이터 다운로드,
프론트엔드·서비스 연동, 의자 이동 보정과 실제 환경 성능 주장은 제외한다.

## 작업 단계

- [x] 기존 자료·특징·분할·증강과 데이터셋 공개 정보를 확인
- [x] 5배·25배 증강을 같은 설정으로 비교하고 실제 미변형 참여자 창을 평가
- [x] 합성 데이터의 누수·가중치·크기·복원 검사와 원본 SHA-256 재확인
- [x] 모델 폴더에 결과·실행·외부 자료 견적 기록

## 결정과 진행 기록

각 fold에서 기존 5배 학습 참여자의 내부 검증으로 고른 설정을 5배와 25배에 동일하게 적용한다.
최종 전체 학습 모델은 독립 시험을 거치지 않은 후보이며, 결과는
[모델 폴더 안내](../../../model/analysis/replay_pilot/AUGMENT_50K.md)에 기록한다.

## 검증 결과와 남은 한계

- 합성 테스트 21개 통과. 원본 20개 파일의 SHA-256을 실험 시작과 종료 때 확인했다.
- 원본 특징 1,968개로 전체 학습용 변형 49,200개를 생성했다. 개인 구분·라벨은 미검증이다.
- 공식 Multi-view 배포처는 브라우저 보안 정책에 의해 접근이 차단되었고 사용자 결정으로 취득을 보류했다.
- `.venv`가 없어 저장소 전체 게이트는 실행하지 않았다. 새 데이터가 확보되면 독립 시험이 필요하다.
