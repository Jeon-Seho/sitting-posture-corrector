## 문제와 완료 기준

수동 동작 준비는 정해진 2초를 기다리지 않고 사용자가 준비될 때까지 대기한다. 측정 5초와 복귀 준비 5초, 사용자 확인과 품질 검사는 유지한다. /dev 관측 모델을 Heavy로 바꾼다.

## 범위와 제외

관측 안내 상태기계, 리플레이·CSV의 프로토콜 식별과 UI, MediaPipe 설정·문서·합성 검증. 기존 리플레이는 읽을 수 있게 보존한다. 모델 정확도·장치 성능은 측정하지 않는다.

## 결정과 진행 기록

자동 모드의 2초는 유지한다. 수동 모드의 move 단계는 즉시 대기로 들어가고 진행은 사용자 확인으로만 한다. 새 프로토콜 식별자를 사용하되 기존 v2 리플레이를 읽고 원래 식별자를 보존한다.

## 검증 결과와 남은 한계

`make check-frontend`: 테스트 875개와 TypeScript·빌드 통과. `make check-repo` 및
`git diff --check` 통과. 합성 프레임 테스트에서 수동 즉시 대기·5초 측정·중복 입력 차단,
Heavy 경로와 이전 v2 리플레이 호환을 검증했다. 실제 카메라·Windows 성능과 전체 브라우저
회귀는 확인하지 않았다. 전체 브라우저 회귀는 이전에 가상환경의 `pymysql` 누락으로 중단됐다.
