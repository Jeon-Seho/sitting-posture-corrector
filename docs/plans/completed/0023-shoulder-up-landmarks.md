# 어깨 포함 머리 좌표 선택과 Heavy 전환

- 상태: completed
- 담당: Codex
- 시작일: 2026-10-12
- 관련 요구사항/ADR: 사용자 요청, [ADR 0020](../../decisions/0020-shoulder-up-landmarks.md)

## 문제와 완료 기준

어깨 위만 촬영하는 사용 범위에 맞게 MediaPipe 출력 중 0~12번만 실시간 관측과 수집 CSV에 남긴다.
화면 숨김만으로는 충분하지 않다. 영상/world 좌표에서 13~32번을 제거하고 기존 특징과 품질 판정은 유지한다.

## 범위와 제외

프론트 공통 관측·CSV 내보내기·관련 합성 테스트·문서. 사용자 후속 요청으로 Heavy 모델 전환·공식 자산 검증을 포함한다. 영상 crop, 학습 모델 구현과 기존 실제 CSV 변경은 제외한다.
v2 CSV는 이미 최대 33개의 가변 길이 배열이므로 13개 부분집합도 허용한다. 열·인덱스·특징 의미는 유지한다.

## 결정과 진행 기록

공통 추론 직후 어깨 포함 머리 13개를 선택하며 두 소비 경로에 동일하게 전달한다. CSV도 전체 배열을 받더라도 같은 범위만 내보낸다. 사용자 후속 요청으로 [ADR 0021](../../decisions/0021-heavy-pose-tracker.md)에 따라 Heavy를 사용한다.

## 검증 결과와 남은 한계

- `python tools/dev.py check-repo`: 통과. `git diff --check`, 데스크톱 smoke 스크립트 구문 검사도 통과.
- `python tools/dev.py check-frontend`: 37개 파일·285개 테스트, TypeScript 검사·Vite 빌드 통과.
- Heavy 공식 자산 다운로드와 고정 SHA-256 검증 완료. 자산은 Git 제외 경로에만 있다.
- 원격 develop 의존성과 로컬 설치가 달라 폰트가 누락돼 있던 빌드 실패는 잠금 파일 기반 `npm ci --prefix frontend` 후 해소했다.
- `python tools/dev.py check` 실행: Python 140개 중 136개 통과, 오류 3개, 건너뜀 1개. 기존 Windows 배포 도구의 파일 잠금·POSIX 호스트 요구 오류로 중단됐다. 서버·브라우저·Compose 게이트는 이 실행에서 도달하지 못했다.
- 실제 카메라 FPS·어깨 위 프레이밍 품질·ML 성능과 데스크톱 EXE 재패키징은 미검증이다.
