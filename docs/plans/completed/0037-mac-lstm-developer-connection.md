# Mac LSTM 실제 학습 및 개발자 룰 비교 연결

## 문제와 완료 기준

현재 Mac 체크아웃에는 이전 Windows 학습의 데이터·가중치가 없어 LSTM이 비활성화되어 있다.
기존 공개 Panoptic 입력과 연구 학습 코드를 재현하고 실제 가중치를 브라우저에 연결한다.
학습 모델+룰과 룰만의 동작을 확인하며 모델이 위치 예측을 맡고 판정은 기준 거리·시간을
조합한다는 의미를 설명한다. 독립 자세 분류 정확도를 학습 진단으로 대체하지 않는다.

## 범위와 제외

공개 좌표 데이터·가중치·보고서는 Git 제외 data/runs/public research-model 경로에 보관한다.
현재 실험은 참여자 대응 미확인의 단일 시퀀스 전부를 학습 전용으로 배정한다.
참여자 분리 일반화 평가·서비스 승격·새 사용자의 자세 분류 효과는 이 실험으로 주장하지 않는다.
기존 서비스·룰 임계값·LSTM 구조는 유지한다.

## 결정과 진행 기록

기존 30시점×39차원, hidden48, 300ms 미래 좌표 예측 구조와 25epoch/seed42를 사용한다.
모델은 정상/비정상 분류기가 아니며 Panoptic→MediaPipe 13점의 근사 대응은 미검증이다.
사용자가 선택한 실행 중 예측 방식을 자동으로 변경하지 않는다.

## 검증 결과와 남은 한계

- 공개 파일 233,472,000bytes의 두 SHA-256이 기존 검토 값과 일치했다.
- 실제 유효 관측25,176개·학습 창2,465개, CPU 25epoch/seed42 학습 완료.
  학습 MSE0.789041→0.353409, 학습·학습 집합 예측4.760초.
- LSTM 학습 자료 점거리0.045511, 위치 유지0.044814로 LSTM의 추가 이득은 확인되지 않았다.
  참여자 대응 미검증의 train-only 실험이며 독립 시험·자세 정확도는 null이다.
- 실제 checkpoint→391,009bytes browser JSON 생성. hash:
  `c8f86019340450bf7ea50b02822962c6a258d167ecfaf142e09dde17e9121687`.
  Python/브라우저 최대 차이2.045e-7로 허용치1e-5 통과. Git 제외 확인.
- 실제 모델로 오프라인 합성10사례 실행, 브라우저에서 자동 LSTM 선택·실행·룰 비교·종료 확인.
  탭의 콘솔 오류 없음. 브라우저 입력은 명시적 합성으로 실제 사람 성능이 아니다.
- `make check`: 저장소·Python163개·프론트391개·타입·빌드 통과 후 Java21/Maven 부재로 중단.
  종료된 비교군 결과를 LSTM으로 잘못 표시하지 않는 마지막 회귀 포함 `make check-frontend`:
  51파일·392개·타입·빌드 통과.
- 실제 카메라 정확도/FPS, 독립 참여자 검증, 서버/Compose·운영 배포는 미검증.
