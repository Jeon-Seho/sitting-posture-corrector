- 관련 요구사항/ADR: 사용자 주석 1~2, [관측 UI](../../design/developer-lab.md)

## 문제와 완료 기준

도움말/설정에도 스크롤바 대신 부유 막대 규칙을 적용하고 개발 규칙에 남긴다.
탭 폭·여백을 줄이고 hover는 배경 유지·아이콘/글자 강조와 소폭 확대만 한다.
선택 배경은 가속 이동 중 얇아졌다 도착 시 부풀고 제자리로 돌아온다.

## 범위와 제외

관측 UI·공통 스크롤 표시·탭 모션만 변경한다. 좌표/기록/재생 상태/파일 형식을 바꾸지 않는다.
감소된 모션과 키보드 전환, 빠른 재선택 시 애니메이션 정리/취소를 지원한다.

## 결정과 진행 기록

- 기존 스크롤 패널을 region에도 쓸 수 있도록 확장한다. 설정 안의 부유 바는 메뉴를 닫지 않는다.
- 이동은 기존 한 배경의 translate, 변형은 안쪽 면의 독립 모션으로 처리한다. 관측값은 보간하지 않는다.
- Git status는 기존 메타데이터 경로 누락으로 실패했다.

## 검증 결과와 남은 한계

- `make check-frontend`: 103개 파일·853개 테스트, 타입·빌드 통과. 물방울 모션의 시작 변형/도착 부풀기/복구·빠른 재선택 취소·감소된 모션과 구독 정리 2개 회귀를 추가했다. 기존 스크롤 경계·리사이즈·탭 보존 회귀도 통과했다.
- 실제 브라우저: 탭 폭 384px, 이동 0.42s, 이동 중 내부 면의 변형 행렬과 translate 변화를 확인했다. hover 배경 rgba(0,0,0,0), weight 600과 scale 1.045를 확인했다.
- 도움말은 600px 중 내용 536px와 막대 여백을 사용한다. 막대로 끝까지 내리면 위 막대만 남고 페이지 scrollY는 0이다. 설정 막대 클릭도 메뉴를 닫지 않는다.
- 320×774 도움말의 가로 넘침 없음, 320×480 설정 팝업 상단이 화면 밖으로 나가던 문제는 짧은 화면 최대 높이를 38svh로 줄여 보완했다. 최종 팝업 top 18.6px, height 182.4px이며 같은 막대로 내용을 접근한다.
- 최종 실제 탭 console warn/error 0건. 뷰포트 override를 해제하고 도움말 열린 /dev를 남겼다. 실제 카메라/개인 파일 조작·전체 서버/DB 게이트·OS 설정 직접 변경은 실행하지 않았다. 감소된 모션은 테스트의 preference 전환으로 검증했다.
- `make check-repo`는 기존 Git 경로 오류로 실패한다. 수정 문서와 작업 규칙의 링크·필수 경로·공백은 부분 검사했다.
