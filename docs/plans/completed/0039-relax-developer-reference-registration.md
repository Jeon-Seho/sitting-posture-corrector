# 개발자 기준 등록 반복 초기화 완화

- 상태: completed
- 담당: jisung / Codex
- 시작일: 2026-10-13
- 관련 요구사항/ADR: 실제 구도·기준 등록이 지나치게 빡빡하다는 사용자 피드백, ADR 0025·0026

## 문제와 완료 기준

`/dev`에서 구도 확인 뒤 8초 기준 등록이 자연스러운 자세 변화·간헐적 추적 지연으로 처음부터
반복되는 현상을 줄인다. 진입 구도는 실제 관측 가능성을 확인하고, 등록 도중에는 미세한 화면
위치 변화를 금지하지 않는다. 누락 관측을 기준 표본이나 정상 자세로 계산하지 않는다.

## 범위와 제외

연구용 가이드, 기준 등록의 표본 연속성 및 개발자 화면의 상태 안내만 변경한다.
등록 목표 8초·65개 유효 표본과 추적 중 측정 불가 규칙, 일반 서비스는 유지한다.
느린 카메라에서 대응 예측 오차가 20개 미만이면 최소 한계 0.02로 완료한다.

## 결정과 진행 기록

구도 준비는 연구용 안내일 뿐 정상 자세의 정답을 판정하지 않는다. 기준 등록 중에는
프레임·3D 특징이 유효한지 확인하고, 짧은 누락은 표본을 추가하지 않고 기다린다.
코어 추적의 170ms 규칙은 유지하며 등록에서만 별도의 허용 간격을 둔다.

## 검증 결과와 남은 한계

`make check`: Python 163개, 프런트엔드 54파일 434개 테스트, TypeScript 검사와 Vite 빌드 통과.
백엔드 단계는 현재 호스트에 Java 21/Maven이 없어 실행하지 못했다.
합성 데모 브라우저에서 구도 확인→8초 기준 등록→자동 측정 전환 및 콘솔 오류 0개를 확인했다.
실제 웹캠의 다양한 프레임 속도·조명·추적 품질에서 성공률은 측정하지 못했다.
