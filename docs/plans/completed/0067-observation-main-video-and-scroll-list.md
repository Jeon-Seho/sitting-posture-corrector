## 문제와 완료 기준

영상을 더 크게 왼쪽에 두고 그래프 목록을 오른쪽에서 독립 스크롤한다. 제목 문구와 확대 토글을
제거하고 탭은 수치·그래프 / 리플레이 / 비교표 순서로 바꾼다. 시작 버튼의 반투명 배경을 복원한다.
비교표 중앙 배치·리플레이 동기화·기준과 기록을 보존한다.

## 범위와 제외

관측 프론트 배치·탭 순서·표시. 해상도·추론·품질·시간·파일 형식은 바꾸지 않는다.
데스크톱에서는 페이지 대신 오른쪽 패널을 스크롤한다. 좁거나 짧은 화면에서는 화면을 가리지 않는
세로 배치와 목록 스크롤을 제공하며 모든 제어를 키보드로 접근할 수 있게 한다.

## 결정과 진행 기록

- 큰 영상에서는 안내와 제어를 영상 안의 반투명 패널로 배치해 영상 아래 공간을 줄인다.
- Git status는 기존 Git 메타데이터 경로 오류로 실패했다. 저장소를 초기화하지 않는다.

## 검증 결과와 남은 한계

- `make check-frontend`: 100개 파일·846개 테스트, 타입 검사와 빌드 통과. 탭 순서 변경에 맞춰 기존 키보드·측정 보존·리플레이 위치·비교표 전환 회귀를 갱신했다.
- 브라우저 1624×924: 영상 1018.7×764px, 오른쪽 패널 360×764px. 목록 scrollTop 298인 상태에서도 page scrollY=0, stage top=136px를 확인했다. 원시 z는 마지막에 있고 제목/확대 토글은 없다.
- 1384×774: 영상 818.7×614px, 문서 높이 774px와 가로 넘침 없음. 키보드 End로 목록 스크롤, 탭 방향키 이동, 리플레이 끝 위치 보존을 확인했다.
- 실제 안내/수집 훅에 명시적인 합성 프레임을 전달해 기준 등록·수동 다음 대기·버튼 배경과 빨간 종료·리플레이 지표를 확인했다. 최종 합성 탭 console warn/error 0건. 임시 소스와 탭은 제거했다.
- 402×874 라이트·320×774 리플레이에서 내부 제어·1열 목록과 가로 넘침 없음을 확인했다. 실제 카메라 재촬영·전체 서버/DB 브라우저 게이트는 실행하지 않았다.
- `make check-repo`는 기존 Git 경로 누락으로 실패한다. 수정 문서 링크·필수 경로·공백은 부분 검사했다.
