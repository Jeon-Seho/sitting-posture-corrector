# 테마별 앱 아이콘·네이티브 팝업과 Windows 재패키징

- 상태: completed
- 담당: FE
- 시작일: 2026-10-29

## 완료 기준

- 선택한 색의 자세 심볼을 창 아이콘에 적용하고 기기 캐시에서 재실행 시 복원한다.
- 이 패키지를 가리키는 기존 PoseGood 바탕화면 바로가기만 아이콘을 갱신한다.
- 별도 자세 알림 팝업과 앱 내부 스낵바도 테마의 표면·강조색을 따른다.
- Windows 패키징과 독립 프로필의 실제 EXE 검증을 실행한다.

## 구현 경계

EXE에 내장된 파일 아이콘은 차콜로 고정된다. 실행 창과 바로가기의 사용자별 아이콘을 변경한다.
렌더러는 경로를 넘기지 않으며 main은 검증된 색·256px PNG만 받는다. 아이콘은 userData에 보관한다.
숨긴 smoke 창은 바탕화면 바로가기를 변경하지 않는다. 팝업은 main 창이 보낸 고정 키의 HEX 값만 적용한다.

## 검증

실제 카메라·Windows 재부팅·다른 PC와 고정된 작업표시줄 캐시 표시는 별도 확인 대상이다.


## 최종 결과

- 프론트 300개 검사·타입·생산 빌드 통과. 네이티브 아이콘 Node 검사 2개 통과, npm test에 연결.
- Windows desktop:pack 성공, 빠른 실행기와 기존 바탕화면 바로가기 갱신.
- 독립 프로필의 실제 패키지 smoke 성공: PNG/ICO 캐시·잘못된 요청 거부·팝업 테마 전달,
  합성 카메라 640px·모델 초기화·WASM/모델 200·secure context·Web Locks. 화면/IPC 준비 828ms(한 번의 로컬 측정).
- 브라우저 테마 회귀·check-repo·git diff --check 통과.
- 첫 EXE smoke는 로그인 후 수집 화면으로 나가는 시험 순서 때문에 모델 준비 검사가 실패했다.
  로그아웃 후 수집 화면 진입으로 수정한 최종 실행은 통과했다. 실패 시에도 시험 창을 닫도록 정리 경로를 보완했다.
- 전체 check/Docker 회귀, 실제 카메라, 재부팅, portable 단일 EXE 재생성은 수행하지 않았다.
