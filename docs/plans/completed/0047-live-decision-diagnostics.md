## 문제와 완료 기준

어깨 중심·폭 정규화는 전체 평행 이동·균일 크기 변화를 제거한다. 이를 유지한 채 누운 자세가 검출된다고 주장할 수 없다.
현재 판정, 일시 이탈 후 복귀 횟수, 지속 이탈, 실제 알림과 원시 화면 기하를 한 화면에서 확인한다.
일시 움직임은 복귀를 관측한 뒤에만 집계하고 측정 불가를 0/정상으로 표시하지 않는다.

## 범위와 제외

`/dev` 표시, 선택한 룰의 시간·횟수 진단, 기본 음소거 및 계약의 선택 필드만 변경한다.
판정 임계값·정상 프로파일·LSTM 입력·일반 서비스는 변경하지 않는다. 화면 기하는 진단 전용이며 새 알림 기준이 아니다.

## 결정과 진행 기록

- 현재 코드는 13점 각각에서 어깨 중점을 빼고 현재 3D 어깨폭으로 나눈다. 전체 이동·균일 크기는 입력에서 사라진다.
- 기존 `returnedExcursions`/`durationMs`는 예측 조합 정책의 수치다. 룰 선택 시 해당 정책의 별도 수치를 사용한다.
- 최근 알림 0/1은 현재 관측 시각 기준 최근 1초에 실제 발생한 알림의 표시이며 판단 임계값이 아니다. 종료 시에는 마지막 관측으로 명시한다.
- 알림음은 기본 꺼짐. 시각 알림·집계는 계속하며 실제 테스트에서 소리를 켜지 않는다.

## 검증 결과와 남은 한계

- `make check` 실행: 저장소 검사, Python 193개, 당시 프론트 659개와 타입/빌드 통과. Java 21/Maven 준비가 없어 백엔드에서 중단했다. 전체 게이트 성공이 아니다.
- 최종 `make check-frontend`: 72파일·660개 테스트와 TypeScript/Vite 빌드 통과. 새 판정 패널 7개, 룰/예측 복귀 집계 차이 1개를 포함한다. 개별 126개 검증은 전체와 겹치므로 합산하지 않는다.
- `make check-browser`: 생산 번들 합성 카메라/진입점 제외 검사 통과. Java runtime 부재로 서비스 준비에 실패해 자동 브라우저 회귀는 미완료. 테스트 서버 3개 정리 통과.
- 실제 내장 브라우저의 명시적 합성 데모: 기본 음소거, 짧은 이탈 후 복귀 1회, 시각 알림 1회, 종료 뒤 최근 알림 0과 누적 1회 분리 표시를 확인했다. 실제 카메라 동작 성능 검증이 아니다.
- 작은 화면에서 숫자 3열, 관측 전/누락 값 `—`, 종료 상태와 합성 출처를 확인했다. 표시 해석은 접을 수 있다.
- React 검토: 새 데이터 요청·효과·타이머 없이 기존 상태에서 표시를 유도한다. 원본 영상/좌표를 저장하지 않고 CSS를 `.dev-lab`로 제한한다. 0/1을 색상과 별개로 읽을 수 있다.
- 최종 `git diff --check`·`make check-repo` 결과는 완료 응답에 기록한다.

화면 이동·크기 변화를 점수에 추가하거나 눕기 검출이 해결됐다고 표시하지 않는다. 실제 누운 자세의 놓침은 추가 관측/특징 연구가 남아 있다.
