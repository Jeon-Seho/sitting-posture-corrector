# 두 단계 자세 모델 합성 이동 파일럿

- 상태: completed
- 시작일: 2026-11-08
- 범위: 개인 기준과 자세 판정의 오프라인 연구. 서비스·프론트엔드·원본 데이터는 변경하지 않는다.

## 문제와 완료 기준

기준에서의 작은 영상 위치 변화와 자세 이탈을 별도 모델로 다루는 접근을 시험한다. 현재 v8에는
실제 의자 이동량이나 기준 보정의 정답이 없으므로 합성 세로 이동 제거를 탐색적 대리 과제로만 둔다.
사람을 먼저 분리하고 두 모델을 따로 학습해 기존 분류 결과의 재현과 합성 이동 전후의 결과·측정
불가 범위를 함께 기록한다. 임상 효과나 실제 의자 보정 성능은 주장하지 않는다.

## 작업 단계

- [x] 기존 평가 코드·등록 기준과 라벨 출처 확인
- [x] 학습 참가자 기준 구간에서만 합성 보정 표본을 만들고 모델 학습
- [x] 기존 내부 검증으로 선택된 설정을 사용해 자세 분류기를 별도 재학습
- [x] 동일 시험 구간에 보정 전·학습 보정·합성 정답 보정을 비교
- [x] 합성 시험, 출력 및 연구 문서 검증

## 범위와 제한

정답은 주입한 합성 세로 이동량이며, 원본에 이미 있던 이동량이나 움직임의 물리적 원인은 알 수
없다. 시험 대상은 사람 단위로 제외한다. 보정은 윈도우 특징에서만 수행하며 등록 기준을 자동으로
변경하지 않는다. 3초 재생은 서비스 전체 타임라인의 알림 시험이 아니다. 산출물은 Git 밖에 둔다.

## 검증 결과

합성 단위 시험과 기존 오프라인 파일럿 시험을 실행한다. 실제 v8 시험에서는 사람별 6회 분할을
사용하고 원본 SHA와 이전 분류 결과를 재확인했다. 두 단계 모델은 미이동에서 92.1%로 보정 전과
같았지만 아래 14.4px 합성 이동에서 89.1%→88.3%로 하락했다. 측정 불가 및 3초 탐색 재생과
범위·라벨 한계는 [실험 문서](../../../model/analysis/replay_pilot/TWO_STAGE.md)에 기록했다.
이 연구 결과는 서비스 교체, 실제 의자 이동 보정, 재등록 알림을 검증하지 않는다.
