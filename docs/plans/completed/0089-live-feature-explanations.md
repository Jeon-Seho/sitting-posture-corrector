# 웹캠 비교 화면의 특징별 점수 설명

- 상태: completed
- 담당: 모델 연구 화면
- 시작일: 2026-11-10
- 관련 요구사항/ADR: ADR 0005, ADR 0020, 연구 프로토콜

## 문제와 완료 기준

사용자가 규칙과 모델 점수의 변화를 이해할 수 있도록 카메라에서 두 방식의 특징 설명을 선택하고 해당 위치와 수치를 확인한다. 차이 장면 캡처는 제거하고 현재 판정과 알림 비교는 유지한다.

## 범위와 제외

로컬 연구 서버·화면과 합성 시험만 변경한다. 규칙의 기존 점수 계산과 모델의 학습·판정·운영 API는 변경하지 않는다. 측정 불가와 설명 실패를 정상으로 표시하지 않는다.

## 결정과 진행 기록

- 규칙은 세 특징 중 최대 성분으로 점수를 정한다. 등록 구간 범위와 기존 이탈 임계값을 표시용 분류에 사용한다.
- 모델은 각 입력 특징을 개인 기준 값 0으로 하나씩 바꾸고 보정기와 분류기를 다시 실행한 차이를 표시한다. 이는 조건부 비교이며 관절의 인과적 기여도나 의학적 정상 판정이 아니다.
- 설명과 표시용 색은 점수·알림에 영향을 주지 않으며 영상과 좌표를 저장하지 않는다.
- 특정 특징이 의존하는 점의 관측 창 내 가시성이 부족하면 해당 설명을 회색으로 표시한다. 캐시된 결과에도 현재 창의 품질을 적용한다.

## 검증 결과와 남은 한계

- `make test`: Python 176개 중 165개 성공, PySpark 미설치로 11개 건너뜀. 합성 UI 시험도 게이트에 포함된다.
- `node --test tests/live_comparison_ui.test.cjs`: 합성 UI 시험 16개 성공. 모드 전환, 색상·글자, 숨김, 측정 불가·설명 실패, 점수·알림 기존 동작을 확인했다.
- 실제 로컬 모델과 합성 입력으로 각 설명의 3개/6개 출력, 머리 이동의 모델 이탈, 어깨 기울기의 규칙 이탈, 측정 불가를 HTTP로 확인했다. 기준 대체 비교가 보정기를 다시 호출하는 합성 단위 시험도 통과했다.
- 브라우저의 카메라 꺼짐 화면에서 버튼, 목록, 차이 장면 제거와 콘솔 오류 없음을 확인했다. 실제 카메라·장시간 동작은 확인하지 않았다.
- 독립 연구 화면의 Python 변경이라 메인 프런트 TypeScript·빌드 및 전체 `make check`는 실행하지 않았다. 모델 성능이나 의학적 정상성은 검증하지 않았다.
