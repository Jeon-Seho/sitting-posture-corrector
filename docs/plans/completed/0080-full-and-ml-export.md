# 관측 전체 및 ML 후보 특징 내보내기

- 상태: completed
- 담당: Codex
- 시작일: 2026-10-30
- 관련 요구사항/ADR: 사용자 요청, ADR 0041·0044

## 문제와 완료 기준

원본 영상 없이 가용 포즈 관측과 수집 맥락을 전체 JSON으로 보존한다. 별도로 현재 연구 후보 특징과 결측·시간·단계 메타데이터만 내보내며 과제 지시를 정답으로 취급하지 않는다. 기존 리플레이를 계속 읽는다.

## 범위와 제외

/dev 관측 추출·리플레이·다운로드·문서. 서버·모델 학습이나 자동 업로드는 제외한다.

## 작업 단계

- [x] 기존 계약·ML 후보·원격 상태 확인
- [x] 추출 및 버전별 다운로드 구현과 합성 검증
- [x] 문서·계약·UI 갱신과 범위별 검증
- [x] 원격 작업 브랜치 및 develop 병합 가능성 확인

## 결정과 진행 기록

사용자가 원본 영상 제외를 선택했다. 낮은 품질과 누락을 보존하고 실제 데이터는 저장소에 넣지 않는다.

## 검증 결과와 남은 한계

`make check`: 저장소 검사, Python 203개·프론트 895개 테스트와 TypeScript·Vite 빌드 통과 후 Java 런타임 부재로 백엔드 단계 실패. 이후 v4 호환 테스트를 추가하고 관련 파일 37개 테스트 통과. `make check-browser`는 생산 번들 합성 진입 제외를 확인했으나 Docker daemon 부재로 실패. 실제 웹캠 측정·내보내기는 미검증이다. 원격 develop 기준 merge-tree는 다수 충돌이며 실제 병합하지 않았다. push는 이 커밋 생성 후 수행한다.
