## 문제와 완료 기준

실제 장치에서 관측 간격을 모델 추론 시간과 구분하여 측정한다. 현재 Heavy 설정을 기준으로
좌표 추출·후속 LSTM/룰·화면 상태 예약·타이머 대기를 분리하고 측정 후 지연을 줄인다.
Lite/Full/Heavy와 명시적 GPU/CPU를 같은 메모리 프레임으로 비교하며 초기화 실패와 유효 추적률을 함께 보고한다.

## 범위와 제외

/dev 측정 도구·개발 전용 카메라 선택과 실행 정책, 공유 어댑터의 후방 호환 선택 옵션, 합성 테스트·문서.
일반 서비스의 기본 모델·시간/알림 정책은 유지한다. 영상과 실제 좌표는 비교 중 메모리에만 두며 업로드/저장소 저장하지 않는다.
모델 가중치는 공식 자산을 다운로드해 Git 제외 경로에 둔다. 수동 내보내기는 좌표 없는 집계 결과만 포함한다.

## 결정과 진행 기록

- 비교는 동일한 웹캠 프레임 묶음을 메모리에 잠시 보관해 순차 실행한다. 다른 사람/움직임을 모델별로 새로 촬영한 값을 같은 입력 비교로 쓰지 않는다.
- 실제 추적 성공률·좌표 변동은 정확도 정답이 아니다. 움직임 구간의 변화량을 정지 상태 떨림으로 해석하지 않는다.
- 명시적 GPU 비교가 초기화에 실패하면 CPU 결과로 바꿔 보고하지 않는다.
- 초기화/워밍업과 정상 상태 추론을 구분하고 p50/p95·반복 간 변동·환경을 기록한다.
- M1 Metal GPU 경로 성공, 소프트웨어 renderer 아님, fallback 없음. GPU 사용률은 측정하지 않았다.
- 동일 24프레임 2회차의 Full GPU p50 11.9/12.0ms, Heavy GPU 34.4/33.0ms.
  실제 앱은 기존 12.7 FPS에서 Full+responsive 27.2 FPS, 재확인 23.5 FPS였다. [실측·집계 근거](../../ml/camera-performance.md).
- `/dev`만 Full+responsive 기본으로 변경. 일반 서비스는 Heavy+legacy. 실제 `poseModelId`를 수집·프로파일에 보존하고 다른/미상 추출기 프로파일 적용을 막는다.
- 실제 촬영 중 고개 회전·상체 기울임 알림 2회와 복귀를 관찰했다. 자동 0.5% 자료는 약 6분간 0행.
  등록 정상성 검증·깊이 품질·학습 어댑터·독립 평가 공백을 [감사](../../ml/live-keypoint-audit.md)에 분리 기록한다. 이 추가 기능들은 구현 완료로 표시하지 않는다.
- 영상·실제 좌표·개인 식별자는 저장소에 추가하지 않았다. 공식 모델은 무시 경로에만 저장하며 npm 의존성 추가 없음.
- 최종 독립 검토에서 20초 분석 중 탭 숨김/카메라 종료를 완료로 잘못 표시하는 문제 1건을 발견해 수정했다.
  숨김 시 즉시 부분 결과로 동결하고 완료 경계에서도 연결·표시 상태를 먼저 검사한다. 관련 회귀 16개·타입 검사를 통과했다.

## 검증 결과와 남은 한계

2026-10-14 최종 검증:

- `make check-frontend` 초기 전체 검증은 **68파일 583테스트**, TypeScript, Vite 생산 빌드 통과. 이후 마지막 회귀는 아래 `make check`로 확인했다.
- `make check`: 저장소·문서 검사, **Python 163테스트**, 최종 프론트 **68파일 589테스트**·타입·빌드 통과.
  이후 **Java 21/Maven 부재**로 백엔드 단계에서 중단. 전체 게이트 성공이 아니다.
- `make check-browser`: 기본 sandbox에서는 임시 포트 권한에 막혔다. 승인된 로컬 실행으로 재시도 후
  합성 카메라/테스트 진입점의 생산 번들 제외와 임시 서버 정리를 확인했다. Java 런타임 부재로
  통합 서버 준비에 실패하여 실제 합성 브라우저 흐름은 완료하지 못했다.
- `make check-compose`: Docker daemon unavailable로 시작 조건에서 중단. DB/계정/Compose 통합 미검증.
- 공식 Heavy/Full/Lite 모델 자산은 SHA-256 검증 통과. 모델 가중치와 실제 프레임·좌표는 Git에 넣지 않았다.
- 실제 브라우저에서 Full 기본값·GPU renderer·측정/종료·20초 집계·동일 입력 모델 비교·예측 표시를 확인했다.
  사용자 고개/상체 동작과 복귀·알림 2회를 관찰했으나 정확도 시험으로 해석하지 않는다.
- 빌드의 기존 큰 chunk 경고는 남는다. 원격 CI·다른 장치·장시간·깊이 정확도·독립 LSTM 평가는 수행하지 않았다.

후속 연구·관측 기능은 [감사](../../ml/live-keypoint-audit.md)에 남겼다. 이번 완료 범위는 실제 병목 계측·
개발 경로 최적화·모델 비교 및 추가 요청한 빈 부분 조사다. 정상 등록 검증이나 새 LSTM 학습의 완료가 아니다.
