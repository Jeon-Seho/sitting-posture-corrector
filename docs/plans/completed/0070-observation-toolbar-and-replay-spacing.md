## 문제와 완료 기준

탭 구분선을 제거하고 도움말·테마를 같은 탭 줄에 배치해 별도 상단 행을 없앤다.
리플레이 설정은 영상 오른쪽, 재생 조작만 가운데에 두며 설정의 중복 파일 가져오기를 제거한다.
파일 기능은 영상의 별도 버튼으로 유지한다. 선택 상자와 자세 라벨 배지/빈 안내의 여백을 늘린다.

## 범위와 제외

관측 프론트 배치와 표시만 바꾼다. 기록·재생 상태·라벨 의미·추론·JSON 형식은 유지한다.
좁은 화면에서는 재생 조작 아래 별도 설정/파일 행을 사용해 겹침과 잘림을 막는다.

## 결정과 진행 기록

- 기록이 있는 플레이어의 파일 가져오기는 왼쪽, 설정은 오른쪽, 재생 조작은 가운데다.
- Git status는 기존 메타데이터 경로 오류로 실패했다.

## 검증 결과와 남은 한계

- `make check-frontend`: 102개 파일·851개 테스트, 타입·빌드 통과. 기존 빈/기록 회귀에 중앙 제어 안에 설정이 없고 중복 파일 버튼이 없는 조건을 보완했다.
- 실제 `/dev` 1624×924: 탭 top 16px와 보조 아이콘 중심이 같은 줄, 기존 상단 40px 여백 제거. 설정은 영상 오른쪽 아래, 빈 파일 버튼은 중앙, 선택 상자는 높이 42px·패딩 10/32/10/12px, 라벨 배지는 12/16px 여백으로 확인했다.
- 명시적 합성 프레임으로 기록을 만들고 1280×720에서 파일 왼쪽·재생 360px 중앙·설정 오른쪽 배치를 확인했다. 파일 모달 열기/취소 후 버튼 초점 복원도 유지된다. 최종 합성 탭 console warn/error 0건.
- 320×774에서 상단 탭 x12~224와 아이콘 x232~308이 겹치지 않고 중심 높이도 맞는다. 빈/기록 설정 메뉴가 가로 넘침 없이 플레이어 안에 표시된다. 기록 플레이어는 조작 아래 별도 행을 쓴다. 도움말도 뷰포트 안에 열린다.
- 임시 합성 소스/탭 제거와 뷰포트 해제 완료. 실제 카메라 재촬영·개인 JSON 가져오기/내보내기·전체 서버/DB 브라우저 게이트는 실행하지 않았다.
- `make check-repo`는 기존 Git 경로 누락으로 실패한다. 수정 문서는 링크·필수 경로·공백 부분 검사했다.
