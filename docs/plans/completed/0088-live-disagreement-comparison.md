## 문제와 완료 기준

최고점 자세는 두 방식에서 같은 프레임이 될 수 있어 차이를 이해하기 어렵다. 같은 유효 관측에서 규칙과 모델의 순간 판정을 나란히 보여주고, 한쪽만 이탈인 두 경우의 실제 관측 장면을 각각 일시 보관해 비교한다. 기존 방식별 실제 화면 알림 횟수와 측정 불가 처리를 유지한다.

## 범위와 제외

독립 로컬 연구 화면·합성 UI 시험·설명만 변경한다. 불일치는 원래 판정으로 판단하며 표시 평활화 점수를 판정에 쓰지 않는다. 캡처한 9개 관절점은 브라우저 메모리에만 두고 종료·재등록·페이지 종료 때 지운다. 모델, 학습, 서버 계약, 운영 판정 엔진은 바꾸지 않는다.

## 결정과 진행 기록

- 차이는 두 이탈 점수의 숫자 차이가 아니라 각 방식의 기준에 따른 `deviation` 불일치로 정의한다. 두 점수는 같은 척도로 보정된 확률이 아니다.
- 차이가 시작될 때 해당 관절점을 저장하고 같은 차이가 이어지는 동안 고정한다. 일치·측정 불가·관측 누락 뒤 같은 차이가 다시 시작되면 최신 사례로 바꾼다.
- 차이 장면은 최근 1초 점수가 관측된 시점의 점이며 영상은 저장하지 않는다. 화면 알림은 기존의 각 방식별 3초 지속 규칙을 별도로 따른다.

## 검증 결과와 남은 한계

- `node --test tests/live_comparison_ui.test.cjs`: 합성 UI 시험 15개 성공. 판정 일치와 양방향 차이, 각자의 임계값, 일시 중단·관측 공백·재등록 및 알림을 확인했다.
- `make test`: Python 171개 중 160개 성공, PySpark 미설치로 11개 건너뜀. 위 UI 시험이 게이트에 포함된다.
- 실행 중인 로컬 모델에 합성 기준·머리 이동·어깨 기울기·빈 프레임을 전송해 양방향 판정 차이와 `unmeasurable`을 확인했다. 브라우저에서 초기 화면과 콘솔 오류 없음을 확인했다.
- 실제 웹캠으로 전 과정을 확인하지는 못했다. 메인 프런트 TypeScript 빌드와 전체 `make check`는 독립 연구 화면 변경에 실행하지 않았다.
