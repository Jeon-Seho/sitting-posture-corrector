## 문제와 완료 기준

사용자가 확인한 정상 자료의 중심으로 새 등록 후보를 검증한다. 범위 밖 후보를 새 정상 중심으로 덮어쓰지 않는다.
자동 수집은 실제 자료가 쌓이도록 개발 기본 선별값을 완화하고, 각 행의 선별 정책·출처와 연속 창 수를 보존한다.
MediaPipe 수집 JSON을 검증·참여자 분할·연속 창으로 변환하여 LSTM을 학습하고 `/dev`에 결과를 불러온다.
실제 수집 자료는 아직 없다는 사용자 답변을 확인했다. 합성 학습 실행은 실제 자세 정확도 검증과 구분한다.

## 범위와 제외

`/dev`, 연구 모델/학습 CLI, 출력 계약, 합성 테스트, ML 문서와 HTML 계획.
일반 서비스·서버/DB·배포는 변경하지 않는다. 실제 영상·좌표·참여자 코드·모델 가중치는 Git에 넣지 않는다.
정상은 사용자 확인 구간이며 의료적 정상·동작 의도 분류를 뜻하지 않는다.

## 결정과 진행 기록

- 등록 검증은 기존 개인 허용 폭의 점수 1 경계를 재사용한다. 카메라 추출 모델이 같고 유효한 후보만 비교한다.
  프로파일 미등록 상태는 명시적으로 미검증이며 기존 개인 기준 룰 실험은 허용한다.
- 초기 안내는 기존 500ms 구도의 중앙값으로 비교해 한 프레임 튐으로 구도 유예를 초기화하지 않는다. 최종 등록 중앙값 검증은 8초·65개 원본 표본을 유지한다.
- MediaPipe v2 모델은 실제 추출기 ID가 다르면 종료한다. 기존 #forecast는 v1만 받도록 경계를 보존한다.
- 정상 점수는 학습한 center를 고정한다. 매 세션 등록값으로 중심을 바꾸던 처리는 제거한다.
- 자동 6%는 직전 정면 관찰의 1.8~5.2%와 0.5% 자동 0행에 근거한 개발 선별값이다. 검증된 정상 임계값이 아니다.
  새 선별 의미는 auto collection v2로 구분하며 이전 v1 0.5% 자료를 소급 변경하지 않는다.
- LSTM 입력은 같은 MediaPipe의 39D·100ms 격자 30개, 입력 끝 300ms 뒤 좌표. 33격자/3.2초 연속 구간이 필요하다.
  품질 실패·250ms 초과 간격·참여자/세션/기준/추출기/선별 정책 경계를 잇지 않는다.
- 참여자 분할 뒤 창을 만든다. train만으로 scaler를 맞추고 validation만으로 선택한다. test 자료로 학습/튜닝하지 않는다.
  한 사람의 초기 연결 확인은 train-only pilot로만 허용하고 독립 평가 성능으로 표시하지 않는다.
- 수집 자료가 없으므로 실제 사용자 모델 재학습은 이번 완료 조건이 아니다. 합성 CLI 학습·브라우저 호환 검증으로 실행 경로를 확인한다.

## 검증 결과와 남은 한계

- `make check-repo`: 저장소 구조·문서 링크·민감 산출물 경로 검사 통과.
- `make check`: Python 186개, 프론트 71파일·645개 테스트, TypeScript와 Vite build 통과 후 Java 21/Maven 부재로 백엔드 단계 실패. 전체 성공으로 보고하지 않는다.
- Python 신규 자료 검증 20개 + 실제 Torch fitting 3개는 위 186개에 포함된다. 마지막 입력 형식/실효 horizon 검증 보강 후 해당 준비 20개 재실행 통과.
- 최초 프론트 검사에서는 두 기존 프로파일 fixture가 실제 합성 카메라와 다른 0 중심을 써 거부됐다. 같은 합성 관측에서 학습한 fixture로 바꾼 뒤 실제 route 통합과 전체 프론트가 통과했다.
- 합성 CLI: manifest 생성 → validate → 2 epoch 학습 → model.json/report.json 생성 성공. train/validation/test는 명시적 합성 참여자별 28창. 실제 사용자 데이터 없음.
- 생성된 v2를 실제 TypeScript loader/predictLstm으로 검증: PyTorch 대비 39축 최대 절대차 3.0685962448817605e-7 (허용 1e-6). 합성 모델의 브라우저 파일 불러오기 UI도 성공.
- UI에서 기본 6%·3% 변경·6% 복원, 수집 진단, 학습 안내/설정 이동을 확인했다. 카메라는 켜지 않았고 새 실제 좌표를 수집하지 않았다. 콘솔 error 없음. 테스트로 불러온 모델은 새로고침으로 해제했다.
- `make check-browser`: 처음 샌드박스 로컬 서버 제한으로 실패, 허용된 재실행에서는 생산 번들의 합성 카메라 제외 검사 통과 후 Java runtime 부재로 서비스 기동 실패. 임시 서버 3개 정리 통과. 서비스 E2E는 미검증.
- `make check-compose`: Docker daemon 부재로 실패. DB/Compose 경로 미검증.
- 문서·HTML·ADR·계약을 갱신했다. `git diff --check` 통과. NumPy 1.26.4를 기존 LSTM 선택 의존성 파일에 명시했으며 새 프론트 라이브러리는 추가하지 않았다.

실제 자료 확보 뒤 동일 추출기의 정상 분포와 등록 거부율, 자동 선별 통과율/연속 창 수, 미래 좌표 오차,
이탈 놓침·오알림·감지 지연을 별도로 평가해야 한다. 13점의 가림/깊이 정확도, 허리 관측 부재, 정규화로 제거되는
전체 이동과 크기, 스트레칭 의도 구분은 해결된 것으로 표시하지 않는다. 사용자 모델을 이번에 학습했다는 주장은 하지 않는다.
