- 상태: completed
- 시작일: 2026-11-08
- 관련: [ADR 0045](../../decisions/0045-base-deviation-first.md), [연구 프로토콜](../../research/protocol.md)

## 문제와 완료 기준

v8 안내 구간으로 개인 기준과 이탈의 규칙·단순 학습 모델을 누수 없이 비교한다.
안내 라벨의 한계를 밝히고 서비스 모델을 변경하지 않는다.

## 범위와 제외

- v8 검사·익명 매핑·기준 재현·참여자 분할·중첩 검증·합성 시험과 비공개 보고서.
- 서비스 연결, 실생활 성능 주장, 라벨 정답 확인 및 LSTM 학습은 제외한다.

## 작업 단계

- [x] 실제 파일 형식과 서비스 입력·기준·규칙 확인
- [x] 로더·특징·규칙 및 로지스틱 회귀 참여자 분할 평가 구현
- [x] 합성 경계 사례 및 CLI 시험, 연구 문서 작성
- [x] 신원 미검토 표시를 단 탐색 평가

## 결정과 진행 기록

- 실제 파일과 이름은 비공개 위치에 남기며 저장소에는 집계 결과만 기록한다.
- 확장 특징은 현행 추론 계약의 입력이 아니며 서비스 연동은 별도 설계가 필요하다.
- 상세 사용법과 제한은 [v8 파일럿](../../research/replay-v8-pilot.md)에 기록한다.

## 검증 결과와 남은 한계

- `python -m unittest discover -s tests -p test_replay_pilot.py -v`: 합성 테스트 14개 통과.
- `python tools/dev.py test`: 프로젝트 `.venv`가 없어 실행되지 않았다. 시스템 Python으로 기존
  테스트 98개를 실행한 별도 확인은 의존성 누락으로 오류 8개, 건너뜀 14개였다.
- 실제 자료의 신원 미검토 탐색 결과는 파일럿 문서에 기록했다. 서비스 연결·전체 게이트는 검증하지 않았다.
- 사용자별 신원 대조와 안내 수행 여부는 확인되지 않았다. 누수 없는 참여자 수와 실제 정답을 확정하지 못한다.
- 데이터가 이동·복귀·평소 작업을 담지 않아 실생활 오알림과 실제 발생 시점은 평가하지 못한다.
