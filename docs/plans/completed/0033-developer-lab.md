## 문제와 완료 기준

기존 사용자 화면을 그대로 유지하면서 `/dev`에서 한 번의 명시적 시작으로 카메라 연결,
8초 연속 유효 기준 등록, 실시간 실험을 이어간다. 모델 파일 없이 단순 예측·거리/시간 비교를
실행할 수 있고 LSTM은 유효한 실제 모델이 있을 때만 활성화한다. 결과·추이·품질·실험 기록을
건강 앱을 참고한 독립 시각 체계로 읽기 쉽게 제공한다.

## 범위와 제외

프론트 전용 `/dev` 라우트, 개발자 UI/수명 관리, 연구 코어의 모델 없는 단순 예측,
명시적 합성 데모, 수치 진단 다운로드와 메모리 내 실험 기록. 기존 사용자·수집·forecast 화면,
서비스 계약·CEP·서버·DB는 유지한다. 원본 영상/좌표/가중치 자동 저장·서버 전송은 하지 않는다.
실제 장치 정확도·의료 효과·새 모델 학습은 범위에 포함하지 않는다.

## 결정과 진행 기록

- UI는 `.dev-lab` 아래 독립 스타일과 지연 로딩으로 기존 서비스 화면에 영향이 없게 한다.
- 기본은 마지막 위치 유지 예측. 모델 없음을 정상적인 사용 가능 상태로 표시한다.
- 카메라 시작은 사용자가 누른 경우만 실행하고 진입만으로 권한을 요청하지 않는다.
- 낮은 품질·누락은 `unmeasurable`이며 유효 시간/기준 유지 비율에서 제외한다.
- 합성 데모는 입력과 기록에 명시적으로 표시하며 실제 측정과 합산하지 않는다.
- 기록은 탭 메모리에만 보관하고 다운로드에는 설정·출처·수치 진단만 포함한다.
- 독립 리뷰 후 170ms 관측 중단의 그래프 연결, 장시간 실행의 시간축,
  복귀 확인 중 재이탈 중복 집계, 중도 종료의 완료 표시를 수정했다.
- 데모 종료 뒤 바로 재실행할 수 있고 기록 상세·설정은 키보드로도 접근할 수 있다.

## 검증 결과와 남은 한계

- `make check` 실행: 저장소 구조·문서 링크 통과, Python **163개** 통과,
  당시 프론트 **355개** 통과, TypeScript·Vite 빌드 통과. Java 21/Maven 미설치로
  백엔드 단계에서 중단되었으며 전체 명령 성공으로 기록하지 않는다.
- 마지막 UI 회귀 수정 후 `make check-frontend`: **49개 파일, 359개 테스트** 통과,
  TypeScript·Vite 빌드 통과. 기존 메인 번들의 500kB 경고가 남아 있다.
- 브라우저: `/dev`의 합성 40초 자동 등록→이탈→복귀→품질 저하→종료,
  기록 상세·설정·결과 다운로드를 확인했다. 내려받은 JSON의 합성 출처와 수치 전용 내용을 확인했다.
- 375px 모바일과 1440px 데스크톱에서 가로 넘침이 없고, 기존 `/` 사용자 화면이 유지됨을 확인했다.
- 실제 웹캠·장치 권한·실제 학습 가중치·자세 판정 정확도는 미검증이다.
  백엔드·Compose 통합 검증은 실행 환경 미비로 수행하지 않았다.
