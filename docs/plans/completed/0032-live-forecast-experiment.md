## 문제와 완료 기준

학습한 LSTM을 브라우저에서 실제 실행하고 실험 기준 거리·예측 오차·시간 및 모델 없는 대조군을 확인한다.
카메라·기준8초·실험·결과 파일 다운로드 흐름을 제공한다.
실제 학습 가중치는 Git 제외 asset으로 export하며 Python↔TypeScript 결과의 수치 일치를 확인한다.
Panoptic→MediaPipe 근사 대응과 좌표계 분포 차이는 명시한다. 정확도 검증/서비스 판정으로 표현하지 않는다.

## 범위와 제외

model/prototype 실험 코어, 프론트 별도 #forecast 화면, 내부 출력 명세, 합성 테스트, 재현 문서.
기존 서비스/CEP 판정·수집 라벨·서버 API는 변경하지 않는다. 서버 없이 로컬에서 실행한다.

## 결정과 진행 기록

MediaPipe world 좌표의 어깨 중심/너비 정규화 입력을 사용한다.
Panoptic 얼굴9+몸4의 순서로 MediaPipe 원래13점을 근사 재배열한다.
눈 중심·입 정의와 카메라/월드 축의 분포 차이는 미검증이다. 실험용 입력 호환을 성능 호환으로 주장하지 않는다.
기준 대표값과 예측 오차 한계는 같은 기기에서 별도8초 실험 등록으로 산출한다.
원본 좌표·영상은 자동 저장/전송하지 않고 수동 export에는 수치 진단만 포함한다.
