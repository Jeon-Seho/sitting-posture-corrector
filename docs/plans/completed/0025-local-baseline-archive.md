## 문제와 완료 기준

기준 등록은 세 특징 요약만 남겼다. 완료된 등록의 13점 시계열을 별도로 로컬에 저장하고
기준 자세 라벨을 검증되지 않은 정상 가정으로 내보낸다. 취소·품질 초기화·저장 실패를 검증한다.

## 범위와 제외

프론트 카메라 등록·로컬 IndexedDB·JSON 내보내기·문서. 서버 확장은 후순위로 기록한다.
서버 계약·DB·모델 분류·기존 CSV 라벨은 변경하지 않는다.

## 결정과 진행 기록

실제 카메라 기준 등록 완료에 적용하며 수집 화면에서 전체 자료를 내려받는다.
실패한 쓰기는 메모리에 보존하고 영구 저장 실패를 표시한다. 정상 가정은 정답 검증과 구분한다.

## 검증 결과와 남은 한계

- `python tools/dev.py check-frontend`: 38파일·288테스트 통과, TypeScript·Vite 빌드 통과. 기존 500kB 청크 경고가 남는다.
- `python tools/dev.py check-repo`: 저장소·문서 링크·산출물 경로 검사 통과.
- `python tools/dev.py check-browser`: production 합성 진입 제외 확인 통과 후 API·CEP JAR 누락으로 서비스 시작 실패. 전체 브라우저 게이트는 통과하지 않았다.
- 서버 없는 별도 임시 실행기에서 기존 `verifyCollectionPreview`를 실행: 분리된 Chrome 프로필로 15개 로컬 브라우저 검사 통과. 기준 저장·새로고침·JSON 내보내기 3개와 기존 미리보기 검사 12개 포함. 브라우저 오류 없이 Chrome/Vite 종료.
- 초기 테스트 타입 오류와 브라우저 검증의 새로고침 대기 경쟁을 수정한 후 위 결과를 얻었다.
- 전체 `make check`는 이 프론트 내부 변경에 대해 재실행하지 않았다. 실제 장치 성능·실제 참여자 정답·데스크톱 EXE 재패키징은 검증하지 않았다.
