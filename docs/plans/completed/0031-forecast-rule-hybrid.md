## 문제와 완료 기준

LSTM 미래 예측 오차와 기준 좌표 거리·지속시간을 조합해 일시 동작/지속 이탈 가설을 실험한다.
저장한 LSTM을 실제 실행하고 마지막 위치 유지·등속 예측·거리/시간만 사용하는 대조군과 비교한다.
합성 기준 유지·급변 복귀·점진 이탈·급변 유지·예측 쉬운 일시 동작·저품질 사례의 결과를 저장한다.
예측이 빗나간 행동을 즉시 일시 동작으로 확정하지 않고 복귀/지속 관측으로 확인한다.

## 범위와 제외

연구용 도구·합성 테스트·집계 기록. 프론트/CEP/서버 계약과 실제 서비스 판정은 변경하지 않는다.
기준 대표값은 합성 기준 구간에서 계산하며 Panoptic 기준을 실제 정상 자세로 가정하지 않는다.
기존 Panoptic LSTM은 독립 평가가 없는 모델이다. 이번 합성 실험은 서비스 정확도 결과가 아니다.

## 결정과 진행 기록

미래 t+0.3 예측은 t 시점에 보관하고 실제 t+0.3이 도착한 뒤 비교한다.
예측 오차는 뜻밖의 움직임 표시이며 자세의 정상/이탈 정답이 아니다.
기준 이탈이 지속되면 예측 오차와 무관하게 지속 이탈 후보가 된다.
높은 예측 오차가 지속 이탈을 무기한 억제하지 않도록 모델 기반 대조군의 제한을 확인한다.
실험 임계값은 합성 개발 구간에서만 정하고 실제 서비스에 채택하지 않는다.
