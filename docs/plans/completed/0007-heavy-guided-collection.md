# Heavy 추적기와 안내형 라벨 수집

- 상태: completed
- 담당: Codex
- 시작일: 2026-09-21
- 관련 요구사항/ADR: 사용자 요청 — Heavy로 전환하고 정면 자세·작업 상황·자리 비움을 라벨링해 수집

## 문제와 완료 기준

기존 세 파일은 대부분 라벨 미지정이며 특징 3개만 남아 새 특징을 재계산할 수 없다.
Heavy 모델을 검증된 로컬 자산으로 로드하고, 명시적으로 시작한 안내 과제의 준비·촬영·검토 구간을 구분한다.
자세 정답과 과제 지시, 재석 상태, 관측 품질을 분리하며 추적 실패를 자리 비움으로 단정하지 않는다.
새 스키마에 원본 추정 랜드마크와 메타데이터를 기록하고 기존 CSV는 보존한다.

## 범위와 제외

- 프론트 추적기, 자산 준비, 수집 UI/시간 상태, 버전 있는 파일 내보내기, 합성 테스트와 문서.
- 사용자 답변에 따라 좌표와 라벨만 수집한다. 영상 저장·녹음·서버 업로드·실제 참여자 자동 촬영·모델 학습은 제외.
- 기존 실제 파일은 수정하거나 Git에 추가하지 않는다. Heavy의 실제 M1 Air FPS는 측정 없이 주장하지 않는다.

## 결정과 진행 기록

자세 라벨과 작업 상황을 분리한다. 안내된 동작은 자동 확정 정답이 아니며 사용자 검토 전에는 학습 확정 자료로 표시하지 않는다.

## 검증 결과와 남은 한계

- make check 성공: 저장소/문서/산출물 경로 게이트, Python 10개, 프론트 26개 테스트, TypeScript 및 Vite 빌드.
- 모델 SHA-256 검증 성공. 브라우저 GPU에서 공식 Heavy를 실제 로드하고 합성 빈 캔버스 3프레임 추론 성공(포즈 0개). 실제 카메라는 사용하지 않았다.
- 실제 useCollection/CollectionPanel에 명시적인 합성 관측을 연결해 준비 시간 0행, 자동 종료, 확인 전 다운로드 차단, 확인 후 CSV 내보내기를 확인했다.
- 브라우저 내보내기 검사: v2 56열, image/world 각각 33점, accepted/upright/seated 및 시간 범위 확인.
- 미검출 과제: 행을 유지하고 poor + 빈 좌표 + reviewed away + 자세 학습 제외로 내보냄을 확인했다.
- 카메라 끊김: 확정 차단, excluded 및 camera_disconnected 보존 확인. 화면 이동 중단도 확인했다.
- v2 합성 CSV로 pandas 요약 및 Markdown/PNG 분석 도구 실행 성공. 원본 실제 파일과 모델 자산은 Git 제외 확인.
- 미검증: 실제 M1 Air 웹캠 FPS/정확도, 실제 참여자의 라벨 일치도, 장시간/브라우저별 테스트, 원격 CI. 탭 숨김 중단은 구현했으나 별도 브라우저 자동화로 재현하지 않았다.
- 개발 서버는 127.0.0.1:5173에서 실행한다. 영상 저장 및 이미지/영상 분류기 학습은 사용자 선택에 따라 포함하지 않았다.
