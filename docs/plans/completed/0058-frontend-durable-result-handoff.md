## 문제와 완료 기준

최신 서버 통신을 시도하고 성공한 경우에만 연결 방식을 전환한다. 앱 종료 뒤에도 계정별 미저장 결과를 보관하며,
서버의 같은 결과 저장 확인 후 로컬 재시도 자료를 삭제한다. 서버 정본을 오래된 표시용 사본으로 덮어쓰지 않는다.
진행 중 로그아웃으로 측정·저장 절차가 생략되지 않게 한다.

## 범위와 제외

현재 프론트 작업본의 저장·기록 병합·로그아웃과 합성 검사를 변경한다. 운영 서버·DB·배포·원격 브랜치 병합은 하지 않는다.
공개 API 연결 실패 시 JWT 전환을 완료했다고 보고하지 않는다. PR은 설계 문제와 최신 기반 통합 해결 전 보류한다.

## 결정과 진행 기록

- 최신 origin/develop은 6e768a4로 FE JWT 전환도 합쳐졌다. 현재 작업본은 2e1fd2b 기반이라 중복 구현을 무조건 병합하지 않는다.
- 공개 /health·/api/v2/auth/me 통신은 모두 HTTP 530, error code 1033. SSH 우회는 실제 호스트·계정 정보가 문서에 없어 사용자에게 요청했다.
- 사용자 제공 정보로 `bdp@192.168.0.104` SSH 인증 성공. 원격 8088 전달은 connection refused.
  원격 리스너·컨테이너 조회에서 web/io-api(8088/8090)는 없고 처리 서비스 8080·추론 서비스 8000만 확인했다.
  서버는 변경하지 않았으며 점검 터널을 종료했다. 최신 API 연결 성공 조건이 충족되지 않아 인증 방식 전환은 보류한다.
- 측정 중 또는 결과 저장 중 로그아웃을 막고 종료·저장으로 안내한다. 비밀번호 변경도 같은 보호를 적용한다.
- 저장 요청은 같은 ID뿐 아니라 같은 본문으로만 재시도한다. 서버 응답의 ID·통계 등 일치를 확인하고 서버가 정한 시각을 채택한다.
- startedAt/endedAt는 측정 시각이며 수정 버전이 아니다. 시각의 크기만으로 충돌 자료를 덮어쓰지 않고 서버 확인 자료를 우선한다.
