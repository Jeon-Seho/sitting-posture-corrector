## 문제와 완료 기준

기존 실험실 분기를 제거하고 `/dev`에서 동작 관측·리플레이가 바로 열린다.
명시적 예시는 `/dev?demo=1`, 이전 주소는 같은 화면으로 호환하며 내부 링크를 갱신한다.

## 범위와 제외

경로 조립·관련 링크·경로 통합 테스트·현재 문서만 변경한다.
기존 연구 모듈 전체 삭제·일반 서비스·관측 엔진·CSV/JSON 규격·학습은 제외한다.

- [x] 프론트/문서·브라우저 검증과 완료 기록

## 결정과 진행 기록

실측과 합성 예시의 key 분리, 카메라 연결 전 모드 선택, 자료 보존 정책은 유지한다.
현재 체크아웃의 .git이 가리키는 외부 Git 메타데이터를 읽을 수 없어 git status는 실패했다.
Git 연결 복구나 브랜치/커밋 작업은 하지 않고 읽은 파일의 경로 변경만 적용한다.

## 검증 결과와 남은 한계

- 대상 경로/앱 진입 12개 합성 테스트 통과.
- `make check-frontend`: 98파일·836테스트, TypeScript·Vite 빌드 통과. 기존 500kB 번들 경고 유지.
- 인앱 브라우저의 `/dev`에서 관측 화면과 카메라 시작 버튼 확인, 콘솔 오류 없음. 촬영은 시작하지 않음.
- `make check-repo`: 기존 .git이 가리키는 외부 경로가 없어 `git ls-files` 단계에서 실패. 수정한 Markdown 링크·필수 경로는 검사기 함수를 별도로 호출해 부분 검사함.
- Git 상태/차이 조회도 같은 이유로 불가. Git 메타데이터는 변경하지 않았으며 커밋·푸시는 하지 않음.
- 서버 통합 브라우저 게이트·전체 make check·실카메라 검증은 미실행.
