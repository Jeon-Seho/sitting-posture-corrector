# 관측 비교 CSV 다운로드

- 상태: completed
- 담당: jisung / Codex
- 시작일: 2026-10-16
- 관련 요구사항/ADR: 사용자 CSV 요청, ADR 0039

## 문제와 완료 기준

동작별 비교표와 직접 선택한 동작·시간·품질이 붙은 시계열을 수동 CSV로 내보낸다.
화면 숫자의 반올림 전 값과 단위·실제/합성 출처·기준 정보를 보존하고 누락을 0으로 바꾸지 않는다.

## 범위와 제외

관측 비교 화면의 파생 수치·수동 다운로드만 추가한다. 원본 랜드마크·영상·자동 저장·업로드·학습은 제외한다.
기존 변경을 보존한다. 이 요청으로 종전 메모리 전용 정책에 파생 수치 수동 CSV 예외를 추가한다.

## 결정과 진행 기록

시계열은 최대 12,000행의 최근 관측만 메모리에 두고 잘린 행 수를 화면·CSV에 명시한다.
재등록·추출 조건 변경·새 실행은 표와 시계열을 함께 비운다. 동작은 사용자 표식이며 분류 정답이 아니다.

## 검증 결과와 남은 한계

- `make check-frontend`: 91개 파일·756개 테스트 통과. TypeScript 검사·생산 Vite 빌드 통과.
  CSV 4개 및 시계열/출처/중단/재등록/12,000행 잘림 회귀 3개를 추가했다. 기존 청크 크기 경고는 남는다.
- `make check-repo`·`git diff --check` 통과.
- 합성 브라우저에서 기준 등록·동작 선택·표 담기 후 두 버튼으로 실제 파일을 내려받아 Python CSV
  파서로 확인했다. 요약 1행/23열, 시계열 2,135행/25열, synthetic 출처·수동 동작·단위·원본 좌표 제외 확인.
  실제 데이터는 사용하지 않았다. 샘플 파일은 사용자 다운로드 폴더에만 생성했으며 저장소에 추가하지 않았다.
- 화면 캡처로 두 버튼·행 수 안내·비교표를 확인하고 합성 측정을 종료했다. 종료 후 CSV도 사용 가능하다.
- 전체/서버 통합 게이트는 재실행하지 않았다. 앞선 0053의 numpy·joblib·pymysql 환경 제약이 남아 있으며
  이번 변경은 프론트 내부 파생 수치 다운로드 범위다. 실제 카메라·실제 동작의 분리도·장치 성능은 미검증이다.
