# V2 서비스 흐름 미리보기

- 상태: completed
- 담당: FE
- 관련 요구사항: docs/team-requirements.md, [ADR 0008](../../decisions/0008-single-app-entry.md)

## 문제와 완료 기준

연구용 카메라 기반을 유지하며 사용자 흐름을 검토할 수 있는 서비스 미리보기를 만든다. 내부 이동 시 측정 보존, 수동 재개, 로컬 저장 결과 공유, 소리와 화면 알림 분리, 개인 정보 편집을 확인한다.

## 범위와 제외

실제 인증·서버 저장·학습용 탈퇴 데이터 처리는 API 미연결 상태로 표시한다. 개인화 예시 학습을 구현했다고 주장하지 않는다. 로컬 저장 실패는 결과 보존 및 재시도로 처리한다.
처음에는 연구용 화면을 별도 진입(`?research=1`)으로 유지했으나, 두 화면이 섞여 혼란스럽다는 피드백으로 단일 앱에 통합했다(ADR 0008).

## 검증 및 남은 사항

최초 구현: Python 10개, 프론트 29개, 타입/빌드 통과. 당시 UI 도구 연결 실패로 브라우저 흐름은 미검증이었다.
통합 이후(jin_dev3): 프론트 29개 테스트·타입·빌드 통과, 앱 내장 브라우저에서 주요 화면 이동을 확인했다. Python 테스트와 `make check` 전체는 다시 실행하지 않았다.
실제 카메라 촬영·측정, 외부 탭, 소리, 장시간 사용, 서버 연동은 별도 검증이 필요하다. 상세 범위는 docs/team-requirements.md §10에 기록했다.
