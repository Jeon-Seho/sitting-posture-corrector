## 사용자 추가 지시

초록·이전 살구·블랙·디스코드 느낌 네 프리셋을 중심으로 적용한다. 임의 색은 접힌 추가 옵션이다.
이미지는 기존 login-light / ready-camera-matte / baseline-seat-light / empty-records-light를 편집 대상으로 사용한다.
원본의 평면 그림체·구도·인물과 물체를 유지하고 색만 변형한다. 새 3D 스타일의 초기 생성물은 채택하지 않는다.
초록은 기존 WebP 그대로, 나머지 세 테마는 네 그림씩 변형하여 테마 변경 때 함께 교체한다.


## 검증 결과와 한계

- FE 299개 테스트·TypeScript·Vite 생산 빌드 통과. 번들 크기 경고는 기존과 같이 남는다.
- 독립 Chrome에서 네 프리셋 이미지 로드·선택, 카메라 그림 교체, HEX/잘못된 입력,
  밝은 노랑 버튼 대비, 시스템 테마 변경, 새로고침 후 유지, 390px 가로 넘침 없음, 기본값 복원 통과.
- 테마별 화면 스크린샷 및 12개 변형 이미지 연락판을 직접 확인했다. 녹색 기존 4개 포함 총 16개 자산이다.
- Electron IPC는 신뢰한 main 창만 제목줄 밝기를 바꾸게 제한했다. 문법 검사 통과, 패키지 실행·재패키징은 미수행.
- check-browser는 Docker 엔진 부재로 임시 MySQL 시작 실패. 전체 check·실제 카메라·운영 배포는 미수행.
- 명칭은 사용자 요청에 따라 화면에서 ‘블러플 / 차콜 바탕에 청보라 포인트’로 표시한다.


## 후속 검수: 그레이 모드·차콜·차트 대비

- 화면 모드에 중간 밝기의 그레이를 추가하고 오션(파랑)·틸(청록)·차콜 프리셋을 추가했다.
- 살구 설명을 ‘포근한 살구빛과 크림 톤’으로 변경했다.
- 선택한 차콜 심볼을 SVG·PNG·멀티 해상도 ICO에 반영했다. 현재 설치된 EXE와 바로가기는 재패키징 후 갱신 대상이다.
- 차콜·오션·틸은 기존 중립 회색 일러스트를 함께 사용한다.
- 블랙 카드와 유사한 원색을 차트에 직접 쓰던 문제를 고쳤다. 막대는 카드 배경 대비 최소 3:1,
  선은 최소 4.5:1을 만족하도록 전용 색상을 계산하며 차트 범례도 같은 색상을 사용한다.

- 후속 최종 검사: FE 300개·타입·생산 빌드 통과. 브라우저에서 7종 선택·이미지 로드, 실제 블랙 차트 막대/선 대비,
  그레이 전환, 새로고침·모바일 폭 검사 통과. 전체 Docker 회귀와 설치 앱 재패키징은 앞서 적은 미검증 범위로 남는다.

- 추가 검수: 앱 내부 심볼을 적응형 SVG로 바꿨다. 로고 전용 배경/전경 토큰을 사용해 사이드바의 로컬 색상 재정의와 무관하게 선택한 강조색을 따라간다. 브라우저에서 7종 로고 적용색과 최소 4.5:1 심볼 대비를 검사한다.
