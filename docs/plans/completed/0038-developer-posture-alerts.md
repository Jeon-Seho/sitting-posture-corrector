## 문제와 완료 기준

지속 이탈 후보를 소리와 화면으로 확인하고 현재 거리·지속시간·예측 오차·판정 기준을 읽는다.
같은 사건의 매 프레임 중복 알림은 막고, 측정 불가·예측 준비·종료 중에는 잘못 울리지 않는다.
스트레칭의 의도는 판별하지 못하며 복귀 후 짧은 이탈이 확인되는 현재 모델의 한계를 표시한다.

## 범위와 제외

개발자 화면의 알림 전달·메모리 기록·진단 내보내기 및 설명만 변경한다.
기존 연구 판정·서비스 알림·개인 저장·OS 알림 권한·행동 분류 학습은 변경하지 않는다.
영상·원본 좌표·가중치를 알림 기록에 넣지 않는다.

## 결정과 진행 기록

알림 기준은 기본 예측+룰, 별도로 룰만 선택 가능하며 실행 중에는 고정한다.
상태는 코어의 `persistent_deviation_candidate`만 소비한다. 알림부가 새 자세 분류를 만들지 않는다.
같은 후보 사건은 최초 한 번과 60초마다 재알림, 복귀 확인 중 반등은 같은 사건으로 유지한다.
관측 중단은 복귀가 아니며 이후 새 코어 사건을 기다린다. 소리는 브라우저 내장 Web Audio를 사용한다.

## 완료 구현과 검증

- 알림 전달: 선택한 코어 상태가 지속 후보일 때 최초 1회·60초 재알림. 복귀 반등과
  관측이 이어지는 예측 매칭 누락(`warming`)에서 최초 알림을 중복하지 않는다.
- 화면: 카메라 안내 영역의 알림·현재 거리/시간, 별도 근거 패널·음소거·소리 테스트·
  고정 스냅샷 알림과 종료 후 마지막 관측 표시. 알림 JSON은 선택적 필드와 명시적 복사만 사용한다.
- `make check`: 실행. 저장소 검사·Python **163개**·프론트 **428개**·TypeScript·Vite 빌드 통과 후
  **Java 21/Maven 부재로 백엔드 단계에서 중단**. 전체 체크 성공은 아니다.
- 이후 카메라 표시 및 미지원 상태 회귀를 포함한 최종 `cd frontend && npm run check`:
  프론트 **54개 파일 / 430개 테스트**, TypeScript와 Vite 빌드 통과.
- 최종 `python3 -X utf8 tools/dev.py check-repo` 및 `git diff --check` 통과.
- 실제 `panoptic-lstm-v1`을 불러온 IAB `/dev` 합성 시연: 00:28에 거리 **16.7%**, 연속 **5.1초**로
  알림 **1회** 생성, 종료 후 기록/스냅샷 유지. 소리 테스트와 시작에서 재생 가능 상태 확인,
  음소거 시 테스트 버튼 비활성화·기록 유지·소리 켜기에서 재준비 확인. 새 QA 탭 콘솔 오류 없음.
- Web Audio 생성/예약/취소/경쟁은 fake AudioContext **10개** 테스트로 확인.
  물리 스피커의 실제 청취, 실제 사용자 웹캠 정확도, 의도적인 스트레칭 분류는 미검증이다.
- 백엔드·Compose·공식 브라우저 게이트는 실행 완료하지 못했다. 기존 서비스 번들 크기 경고는 남아 있다.
