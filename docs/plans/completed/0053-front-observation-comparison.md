## 문제와 완료 기준

머리 내밀기·숙임·몸통 접근·어깨 올리기의 관측 차이를 직접 확인한다. 같은 Pose의 영상 좌표와
world 상대 z를 별도로 표시하고 고정 기준 대비 변화·최근 추이·수동 동작별 비교표를 제공한다.
동작 선택은 사용자 수행 표식이며 자동 분류·학습 정답이 아니다.

## 범위와 제외

`/dev?view=observation` 연구 화면과 순수 기하 모듈만 추가한다. 서비스·기존 예측·알림·DB·수집 계약은
변경하지 않는다. 좌표·영상·관측표는 탭 메모리만 사용하며 저장·다운로드·전송하지 않는다.

## 결정과 진행 기록

2D의 세로 좌표는 영상 높이/너비를 반영한다. 변화 분모는 등록 시 어깨폭에 고정한다.
z는 같은 Pose world의 코 z−양어깨 평균 z이며 추정 미터와 등록 world 어깨폭 대비 변화로 표시한다.
Face z와 혼합하지 않는다. 품질 기준과 2초 기준 창은 연구 UI 정책이며 판정 정확도 근거가 아니다.
카메라는 명시적 클릭으로만 시작하고 숨김·중단·누락에 현재값/수집 창을 비운다.

## 검증 결과와 남은 한계

- 합성 특징·등록·품질·누락·시각 역전·고정 분모·원점 상쇄·동작 경계·재등록·숨김·종료 회귀 15개 추가.
- 최종 `make check-frontend`: 90개 파일, 749개 테스트 통과. TypeScript 검사·Vite 생산 빌드 통과.
  처음 추가한 경로의 Node 테스트 전역(window) 접근과 테스트 act 반환 타입 오류를 수정했다.
  자산 준비는 sandbox DNS 차단 후 공식 모델을 SHA-256 검증해 준비했으며 최종 게이트는 통과했다.
  기존 생산 JS 청크 500 kB 경고는 남는다.
- `make check-repo`, `git diff --check` 통과.
- `make check`: Python 183개 실행 중 import 오류 3개·skip 3개로 중단. 현재 `.venv`의
  `numpy`·`joblib` 부재로 기존 학습 테스트를 import하지 못했다. 이후 전체 게이트는 미실행이다.
- 별도 `make check-browser`: 생산 번들의 합성 카메라 제외 검사 통과. 임시 MySQL을 실행했으나
  `.venv`의 `pymysql` 부재로 연결 검증 실패. 임시 컨테이너 제거 확인. 통합 성공으로 보고하지 않는다.
- 로컬 브라우저에서 실제 카메라 대신 합성 예시를 사용해 기준 자동 등록·네 동작 선택·각 1초 표 담기·
  기준 복귀 행·최근 추이·종료 후 현재값 해제와 표 보존을 확인했다. 1,280px에서 가로 넘침 없음.
  관측 화면은 서비스 세션·개인 정상 수집·알림을 만들지 않는다.
- 실제 카메라·실제 네 동작·장치별 성능·동작 구분 가능성은 미검증이다. 계획 0052의 L0/G0는 미완료다.
  이번 완료는 관측 도구 구현이며 실제 연구 결과를 의미하지 않는다.
