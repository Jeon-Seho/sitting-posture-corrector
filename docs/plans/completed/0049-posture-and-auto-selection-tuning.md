# 자세 이탈과 자동 정상 선별의 허용폭 조정

- 상태: completed (구현·합성/실제 동작 확인, 정확도·오탐률 미검증)
- 담당: Codex
- 시작일: 2026-10-15
- 관련 요구사항/ADR: 큰 변화가 0.46배에 머문다는 사용자 관찰, 자동 수집 기준 조정, 기존 613행 보존·재검토 표시. ADR 0034 후속.

## 문제와 완료 기준

기존 개발 공통 이동 하한 45%는 관측된 20.9% 이동을 0.46배로 표시한다. 하한을 18%, 축소를 12%로 조정하고 작은 흔들림·짧은 이탈의 허용은 유지한다.
자동 정상 선별은 알림 경계보다 좁은 종합 0.5배와 1초 연속 적합·실측 룰 범위 안을 요구해 과도 구간을 제외한다.
기존 약라벨은 보존하면서 재검토 표시와 학습 입력 차단을 적용한다. 실제 정확도 검증으로 주장하지 않는다.

## 범위와 제외

`/dev` 몸 전체 보완, 자동 수집·출처·학습 입력 검증, 관련 계약과 문서. 서비스 `/`, 학습 가중치, 평가 전용 자료는 변경하지 않는다.

## 결정과 진행 기록

사용자 제공 화면의 실측 숫자는 개발 조정 근거이며 독립 시험 결과가 아니다. 반복 측정·오탐 검증은 후속이다.
기존 자료는 저장소 밖에 원래 행을 유지하며 reviewGate/학습 차단 메타데이터를 추가해 보존했다. 실제 좌표·개인 식별 정보·가중치를 저장소에 넣지 않는다.

## 검증 결과와 남은 한계

- `make check`: Python **195개**, 프론트 **687개(73개 파일)**, TypeScript·생산 빌드 통과. Java 21·Maven 부재로 백엔드부터 중단했다. 전체 게이트 성공이 아니며 Compose 단계에 도달하지 않았다.
- 마지막 합성 점수 일관성 보완 후 `make check-frontend`: **687개**, TypeScript·생산 빌드 통과.
- `make check-browser`: 생산 번들의 합성 입력 제외와 시험 서버 정리는 통과했으나 Java 런타임 부재로 통합 브라우저 회귀는 실행하지 못했다.
- 합성 회귀: 작은 5% 이동 무알림/21% 이동 지속 이탈, 종합 반 경계 포함·초과 제외, 1초 연속 확인·누락/기준/선택 변경 초기화, 이탈·복귀 중 선별 제외, 이전 행 보존/학습 차단, Python 선별 출처·점수/시간·manifest 거부 검증.
- 사용자의 기존 613행은 저장소 밖에 재검토 표시로 보존했다. 원래 행 직렬화 SHA-256 동일성을 확인했고 실제 보존 파일이 학습 창 생성 전 차단되는 것을 읽기 전용으로 확인했다. 재학습은 하지 않았다.
- 브라우저 새 로드에서 새 하한 18%/12%, 무음·기본 실측 룰, 자동 상대 6%+종합0.5배+1초 조건을 확인했다.
- 실제 카메라 시험: 기본 Panoptic LSTM 보조·개인 정상 자료 미등록·실측 룰 상태에서 실행했다. 알림 스냅샷의 몸 전체 1.55배/3초 지속과 후속 재알림 몸 전체 2.50배를 확인했다. 3분46초에 종료했고 총 알림 5회(재알림 포함)다. 별도 움직임 라벨이 없어 각 알림을 정탐/오탐으로 분류하지 않는다. 상대 모양 단독 알림도 있어 작은 움직임 오탐률과 실제 복귀 완료는 추가 시험이 필요하다.
- 새 자동 후보는 118행, 최장 저장 구간 14.1초였고 이탈/복귀 검사 구간에서 행 수가 증가하지 않는 것을 확인했다. 별도 내보낸 실제 118행의 출처·원본 좌표/39차원 일치·시간·새 선별 조건을 Python 준비기로 검사했다. 최소 확인 시간은 1012.8ms, 최대 종합 점수는 0.397이었다. 이 자료는 여전히 미검토 약라벨이며 별도 보존했고 모델에 학습/적용하지 않았다.
- `make check-repo`와 `git diff --check` 통과. 실제 영상·랜드마크·개인 식별 정보·가중치를 저장소에 추가하지 않았다.

새 기준은 고정 카메라·정면 등록을 전제로 하며 실제 기대는 각도나 스트레칭 의도를 판정하지 않는다. 개별 화면의 개발 조정과 독립 정확도/오탐률 평가는 구분한다.
