# 영상 중심 관측 화면과 두꺼운 단계 게이지

- 상태: completed
- 담당: jisung / Codex

- 관련 요구사항/ADR: 사용자 선택 1번 시안과 게이지 내부 글자 요청 / ADR 0039

## 문제와 완료 기준

검정 바탕과 선 없는 색상 면으로 구분하는 앱 화면에 카메라·타이머·현재 및 다음 안내를 함께 표시한다.
영상 중앙의 얼굴·양어깨를 피하여 모서리 HUD를 배치하고, 영상 아래 두꺼운 이동/유지/복귀 게이지
안에 단계명과 남은 초를 표시한다. 선택 시안의 가상 영상은 실제 카메라 영상으로 대체한다.

## 범위와 제외

ObservationLab·ObservationGuide·관측 전용 CSS와 UI 회귀·사용 문서를 변경한다. 기존 변경을 보존하고
2/5/5초·3바퀴·36구간, 추적/중단/재개, CSV와 초기화 확인창은 유지한다. 모델·기하·계약은 변경하지 않는다.
실제 영상·참여자 자료를 저장하지 않으며 브라우저 검증에는 명시적인 합성 fixture만 사용한다.

## 결정과 진행 기록

- 기존 Pretendard/Outfit·Phosphor 아이콘을 재사용하고 관측 화면에만 검정/라임/핑크/하늘색/보라를 적용한다.
- 시안의 OS 창 버튼은 그리지 않는다. Electron의 기존 titlebar와 플랫폼 버튼이 소유한다.
- 단계 게이지는 GuideSnapshot의 elapsedMs/remainingMs에서 파생하며 별도 시계를 만들지 않는다.
- 선택 1번처럼 안내 중 준비 툴바를 접고 영상 모서리에 현재·다음 지시를 표시한다. 게이지 높이는 56px이며
  단계명·남은 초·멈춤 글자를 안에 둔다. 키보드 포커스 외에는 카드 외곽선과 구분선을 사용하지 않는다.
- 작은 화면에서 관측점을 가리지 않도록 안내 폭을 제한했다. 저감 모션·timer의 aria-live=off와
  완료 구간 progress 36/36 의미를 유지했다.

## 검증 결과와 남은 한계

- 최종 `make check-frontend`: **93개 파일·786개 테스트 통과**, TypeScript·Vite 생산 빌드 통과.
  게이지의 5→4초, 정지 시 고정/멈춤·재개 시 5초 재시작·복귀와 완료 표식을 검증하는 회귀 2개를 추가했다.
  기존 500kB 초과 JS 청크 경고는 남는다.
- `make check-repo`·`git diff --check` 통과. 임시 합성 UI HTML/TSX와 검증 탭을 최종 산출물에 포함하지 않았다.
- 선택 시안과 1440×1024의 양어깨 유지 캡처를 함께 비교하고 타이머·게이지도 확대 검수했다.
  1180×760에서 HUD 간 겹침/합성 얼굴·어깨 점 가림이 없고 게이지 하단 y=688을 확인했다.
  정지 상태의 긴 안내와 세 버튼도 겹치지 않는다. 최종 시각 검수는 루트 `design-qa.md`에 기록했다.
- 합성 관측으로 등록→시작→양어깨 유지→일시정지→중간 CSV→재개→36구간 완료를 확인했다.
  완료 CSV Blob은 1,527행 및 protocol_completed를 포함했다. 디스크 다운로드는 막았다.
  새 측정 전 자료 보호 확인창과 CSV 접근도 확인했다. 브라우저 console error 조회 결과 0건.
- 중단 후 실제 카메라용 URL을 새 탭으로 열고 1168×853에서 세 게이지 높이가 모두 56px임을 확인했다.
  카메라를 자동으로 켜지 않았고 기존 사용자 측정 탭은 새로고침하지 않았다.
- 전체 `make check`·서버/DB의 `make check-browser`·실제 Electron 창 실행은 이번 검증에서 수행하지 않았다.
  실제 사람 영상·동작·조명·구도·좁은 어깨 조건과 모델 정확도는 별도 검증 대상이다.
