# 프레임 RF 증강 학습과 참여자 분리 평가

- 상태: completed

- 관련: [프레임 RF](../../../model/analysis/frame_pilot/README.md), [기존 25배 증강](../../../model/analysis/replay_pilot/AUGMENT_50K.md), [연구 프로토콜](../../research/protocol.md)

## 문제와 완료 기준

기존 증강 방식을 현재 프레임 RF의 기준/이탈 라벨에 적용하고, 평가 참여자를 학습과 증강에서 제외한 결과를 보고한다. 같은 두 단계 보정·분류 설정에서 증강 전과 25배 증강 후를 비교한다. 프레임·시도별 혼동행렬과 클래스 재현율, 사람별 평균 balanced accuracy를 기록한다.

## 범위와 제외

- 보정 RF는 학습 참여자의 기준 프레임만 51개 합성 세로 이동으로 증강한다. 분류 RF는 교차 적합된 학습 프레임에 기존 25배 특징 증강을 적용한다. 시험 프레임은 원본 그대로 둔다.
- 매 반복에서 한 참여자 그룹을 제외하고 시험하며, 미확인 신원은 탐색 결과로 표시한다. 각 그룹의 기준 등록만 해당 시험 그룹의 개인 기준에 쓴다.
- 기존 후보와 같은 80/120개 트리와 임시 이탈 기준 0.5를 평가 전에 고정한다. 시험 결과로 모델 설정이나 임계값을 고르지 않으며, 전체 자료 후보는 별도 독립 시험을 받지 않는다.
- 입력은 기존 RF의 9점에서 만든 6개 특징이다. 33점 모델, 제품 FE·BE 계약, 실제 원본과 기존 가중치는 바꾸지 않는다.
- 27개 촬영의 이름 기준 임시 그룹 9개 중 1개는 기준 라벨만 있다. 이 그룹은 학습 및 해당 클래스 평가에 포함하되 두 클래스 balanced accuracy 평균에서는 제외한다. 충돌한 중복 촬영 3건의 파일 6개는 입력에서 제외한다.

- [x] 라벨별 평가 제외 프레임과 전부 제외된 시도 집계 및 합성 검증

## 결정과 진행 기록

- 사용자 요청: 기존 증강 코드로 자료를 늘려 학습한 뒤 이탈 라벨 기준으로 평가한다.
- 같은 프레임 배열의 중복 촬영과 이름 충돌은 이전에 제외했다. 나머지 자료에서 서로 다른 임시 그룹 간 완전히 같은 이미지 좌표 프레임은 발견하지 못했으나, 이것만으로 사람별 신원이 확인된 것은 아니다.
- 결과는 고정 기준 0.5에서 비교한다. 재현성과 속도를 위해 동일한 학습 참여자 조합의 보정기만 재사용하며, 모든 학습 함수는 제외 참여자 혼입을 거부한다.
- 라벨별 관측 범위: 기준 프레임 6,429개 중 6,404개, 이탈 프레임 6,909개 중 6,237개가 유효하다. 고개 회전 조건으로 이탈 시도 95개 중 5개는 유효 프레임이 없어 분류 점수의 분모에 들어가지 않는다. 이 제외를 정상이나 이탈 감지 실패로 임의 변환하지 않는다.

## 검증 결과와 남은 한계

- 이름 기준 임시 그룹 9개에 대해 그룹별 홀드아웃을 수행했다. 라벨 두 종류가 있는 8개 그룹의 프레임별 평균 balanced accuracy는 증강 전 89.76%, 25배 증강 후 89.98%였다. 동일 그룹 이탈 재현율 평균은 92.60%와 92.73%다. 고정 기준 0.5에서 계산했으며 신원 확인 전 탐색 결과다.
- 시도별 점수 중앙값으로 판정한 그룹 평균 balanced accuracy는 증강 전 92.69%, 증강 후 92.36%였다. 전체 유효 이탈 시도 90개 중 이탈 판정은 각각 83개·84개, 기준 시도 78개 중 이탈 오판정은 7개·10개였다. 판정 서버의 3초 알림 평가는 아니다.
- 총 12,641개 유효 프레임을 316,025개 특징 벡터로 증강해 전체 자료 후보를 재학습했다. 이름 충돌이 있는 3건의 양쪽 파일 6개는 제외했으며, 모델·분할 보고서·라벨별 관측 범위 보고서는 별도 비공개 폴더에 저장했다. 전체 자료 후보에는 별도 독립 시험이 없다.
- 같은 데이터·설정·난수 시드로 재학습한 전체 자료 후보의 보정 RF와 자세 RF 파일 해시는 이전 25배 증강 후보와 각각 정확히 같았다. 이번에 새로 얻은 것은 참여자 분리 증강 비교와 관측 제외 집계다.
- `make test`: 201개 중 190개 통과, PySpark 미설치로 11개 건너뜀. 합성 입력의 참여자 제외·증강/비증강 비교·단일 라벨 분모·CLI 및 관측 제외 집계가 포함됐다. 새 후보를 로컬 HTTP TestClient에 불러와 합성 기준 등록과 프레임 추론도 확인했다.
- 사용자 원본·기존 가중치를 수정하지 않았다. FE·BE 타입 검사·빌드, 실제 카메라·서비스 연결, 3초 알림·실생활 성능, 참여자 신원과 촬영 라벨의 일치 여부는 검증하지 않았다.
