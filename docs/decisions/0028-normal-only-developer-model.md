# ADR 0028: 정상 구간으로 만드는 개인 범위 모델과 개발자 수집

- 날짜: 2026-10-14
- 상태: `/dev` 연구 경로에 한정해 채택. 실제 자세 정확도·서비스 승격은 미검증.
- 상세: [현재 ML 계획](../ml/current-plan.md), [HTML 요약](../ml/current-plan.html)

## 배경

프레임마다 정상·이탈 유형을 표시하는 수집은 부담이 크다. 사용자는 정상 자세 구간부터 모으고,
개인 기준과 이상 탐지·예측 모델을 함께 시험하기를 요청했다. 현재 LSTM은 미래 좌표를 예측하는
회귀 모델이다. 예측 가능한 지속 이탈은 낮은 잔차를 만들 수 있으므로, 잔차만으로 정상 여부나
스트레칭 의도를 판정하지 않는다. 정상 범위 학습과 지속시간 판단을 명시적으로 분리한다.

## 결정

1. `/dev`에 정상 구간 수집을 둔다. 사용자가 수집을 시작하고, 수집 후 해당 구간이 의도한 자세였음을
   확인해야 프로파일을 맞추거나 내보낼 수 있다. 이 확인은 **참여자의 자기 보고**이며 의학적 정상
   정답이나 독립 검토자의 라벨로 승격하지 않는다. 학습 자료에는 이 출처를 함께 남긴다.
2. 첫 모델은 정상 구간의 MediaPipe 특징 중앙값과 변동 폭을 맞추는 통계적 일클래스 개인 범위다.
   신경망을 새로 학습한 것으로 표시하지 않는다. 범위 밖 점수와 지속시간으로 후보를 만들고,
   LSTM과 고정 거리 규칙은 같은 입력의 별도 비교 신호로 남긴다.
3. 개인 등록과 학습 자료 수집을 분리한다. `personal_calibration`은 본인의 세션 보정용,
   `training_normal`은 향후 학습 자료용이다. 같은 자료를 독립 평가 자료로 재사용하지 않는다.
   익명 참여자·세션 코드를 함께 내보내며 train/validation/test 배정은 후속 manifest에서 수행한다.
4. 유효한 관측의 개인 범위·룰 판단은 예측 창 준비 상태에 종속시키지 않는다. 관측 실패와
   예측 준비를 구분한다. 가림·실제 시간 단절은 계속 `unmeasurable`이며 누락 시간을 메우지 않는다.
5. 화면 키포인트 보정은 표시 계층에만 적용한다. 수집·품질·모델 입력의 원본 좌표를 바꾸거나
   가림을 보간해 정상 관측으로 만들지 않는다. 세션·추적 단절에는 표시 필터도 초기화한다.
6. 실제 수집 자료와 프로파일은 브라우저 메모리에 두고, 사용자가 요청한 별도 다운로드에만 포함한다.
   자동 업로드·일반 세션 내보내기 혼합·Git 추가는 하지 않는다. 사용자 영상은 수집하지 않는다.

## 탐색 설정과 근거

정상 구간의 유효 관측 30초·최소 100표본은 조작 부담과 자연스러운 변동 관찰을 위한 첫 개발 설정이다.
특징 축별 허용 폭은 절대 편차 q95의 1.5배와 하한 중 큰 값이다. 얼굴·귀 중심 xyz는 0.12,
어깨 방향 xyz는 0.10의 어깨폭 단위 하한을 사용한다. 조용한 구간의 작은 분산이
무한히 민감한 판정을 만드는 것을 막기 위한 장치이며, 임상·인간공학 근거로 정한 정상 임계값이 아니다.
점수 1에서 진입·2/3에서 복귀 확인, 이탈 3초·복귀 3초는 경계 반복 전환을 줄이며 기존 개발 시간 설정을 비교하기 위한 선택이다.
현재 환경의 최소 8초·실제 65표본 기준에 허용 폭을 맞추고 그 실행 동안 고정한다.
정확한 특징·상수·정지 조건은 [수집 계약](../../contracts/normal-posture-collection.v1.md)과
모델 구현에 명시하고 참여자 분리 검증 자료에서 비교한다. 시험 참여자의 이탈로 튜닝하지 않는다.

`/dev`의 새 `observed-v2` 경로는 유효 원본 관측마다 룰/범위를 판단하고, 예측만 100ms 격자에 맞춘다.
250ms를 초과하는 실제 간격과 잘못된 관측은 연속성을 끊는다. 이전 95ms 표본 건너뛰기와 170ms 초기화가
특정 FPS에서 충돌하는 경로를 분리하기 위한 선택이며, 낮은 FPS의 품질을 검증했다는 뜻은 아니다.

## 대안과 결과

- 미래 예측 잔차만 사용: 예측 가능한 지속 이탈을 놓칠 수 있어 주 판단으로 쓰지 않는다.
- 정상/이탈 지도 분류부터 시작: 학습 라벨 비용이 높아 보류한다. 평가용 구간 라벨까지 없애지는 않는다.
- 모든 관측을 계속 기준에 흡수: 서서히 변한 자세를 기준으로 받아들일 수 있어 자동 갱신하지 않는다.

정상 자료만으로 정상 상태의 오알림은 관찰할 수 있지만 지속 이탈의 놓침은 측정할 수 없다.
평가에는 별도 참여자의 `기준 유지 / 일시 움직임 후 복귀 / 지속 이탈 / 측정 불가` 구간 표시를 둔다.
실제 장치의 오알림·놓침·지연 개선을 확인하기 전에는 일반 사용자 화면·서버/CEP 경로로 승격하지 않는다.

## 과거 결정과의 관계

[ADR 0025](0025-local-forecast-experiment.md)의 좌표 예측 비교는 유지한다.
[ADR 0027](0027-developer-posture-alerts.md)의 최초·재알림 전달 구조는 유지하되,
예측 창 `warming`만으로 유효한 룰·개인 범위 후보의 알림을 막는 조건은 대체한다.
영상·저장·서버 계약은 바꾸지 않고 새 정상 수집 내보내기를 별도 계약으로 둔다.
