# ADR 0005: 자세 점수 방향과 표시 효과

- 상태: 채택
- 날짜: 2026-09-19
- 표시 범위 갱신: 2026-10-02

사용자가 100점을 좋은 상태로 읽을 수 있도록 요청했다. UI의 자세 점수는
`100 × (1 - change_score)`로 표시한다. 100은 개인 기준에 가깝고 0은 큰 변화다.
알림 설정도 UI는 5~50점 이하로 표시하며 내부 임계값 0.95~0.50으로 역변환한다.
기본 알림 경계는 30점 이하가 3초 지속되는 경우다. 알고리즘·CSV rule_score·기존 파일은 그대로 유지한다.
점수는 의료적 자세 등급이나 정확도가 아니다. 표시 반전으로 움직임 허용 범위가 달라지지 않는다.

사용자 요청에 따라 표시 범위를 Pose의 얼굴과 양쪽 어깨(인덱스 0~12, 13개 후보)로 제한한다.
화면 안이고 가시성 0.65 이상인 점과 얼굴·어깨 연결만 표시하며 어깨 아래의 점과 연결선은 제외한다.
[공식 랜드마크 목록](https://ai.google.dev/edge/api/mediapipe/python/mp/tasks/vision/PoseLandmark)에 턱 점은 없으므로 턱을 추정해 실제 추적점으로 표현하지 않는다.
별도 얼굴 모델의 추가 비용과 연구 특징 변경은 후속 결정이다.

매트릭스 모드는 얼굴·어깨 연결 사이를 장식용 파티클로 채우고 몸통 파티클은 제외한다. 최대 80개로 제한하며
1200ms에 모이고 잔잔한 이동/스캔을 표시한다. 단일 2D 캔버스 효과이며 3D 체형 복원이 아니다.
효과 끄기, 다시 모으기, 애니메이션 줄이기를 제공하고 초기 OS 동작 줄이기 설정을 따른다.
실제 입력/기준 등록/판정/CSV에는 표시 효과·파티클을 전달하지 않는다.
2026-10-12 [ADR 0020](0020-shoulder-up-landmarks.md)으로 공통 관측과 수집 CSV도 어깨 포함 머리 13개만 유지하도록 변경했다. CSV 열과 v2 형식은 유지한다.

사용자 CSV와 분석 그래프·리포트는 Git 제외 경로 database/temp 안에만 둔다.
하네스는 로컬 make check로 실행하며 루트 지침의 정식 파일명은 AGENTS.md이다.
