# 관측 비교의 자동 기준 등록과 자동·수동 진행

- 상태: accepted
- 날짜: 2026-10-21
- 근거: 사용자 요청과 동작 시간 선택 답변
- 이전 설계: [ADR 0039](0039-front-observation-comparison.md)

## 결정

카메라가 준비되면 기준 자세 등록을 안내한다. 유효한 얼굴·양어깨 추적 상태에서 준비 2초를
부여하고, 연속 유효 관측 8초의 중앙값을 기준으로 등록한다. 낮은 품질·관측 누락은 기준
수집을 초기화한다. 탭 숨김은 등록을 취소하며 사용자가 다시 시작하면 2초 안내부터 진행한다.
관측 비교 소비자만 8초를 지정한다. 다른 `ObservationComparison` 소비자는 기본 2초를 유지한다.

기준 등록 완료 후 선택한 진행 모드로 자동 시작한다. 기본은 자동이다. 기존 네 동작·세 바퀴와
준비(동작으로 이동) 2초 → 측정(유지) 5초 → 복귀 준비 5초를 유지한다. 사용자가 확인한
절차 시간이며 안정화 시간·자세 정확도를 검증한 결과가 아니다.

- 자동: 각 단계가 끝나면 다음 단계의 전체 시간을 부여한다.
- 수동: 각 단계 시간이 끝나면 대기한다. 다음 버튼은 시간이 끝나고 현재 추적이 유효한 경우만
  활성화한다. 일찍 누르거나 연속 호출해 시간을 건너뛸 수 없다. 마지막 단계는 완료 버튼으로 종료한다.
- 시작한 안내의 모드는 중간에 바꾸지 않는다. 멈춤·추적 실패 후 재개는 현재 단계를 처음부터
  다시 세며 시도 번호·구간을 분리한다. 수동 완료 대기에는 자료를 모으지 않는다.

기준 등록·준비·복귀·대기·일시정지 중에도 영상 표시와 추적 품질 확인은 필요하다. 이 관측을
측정 자료로 수집하지 않는다. 시계열 수치와 비교표 캡처는 실행 중인 측정 5초 안에서만 허용한다.
측정 구간은 시작 포함·종료 제외다. 중단·안내 시작/완료 등 사건 행에는 수치값을 넣지 않는다.
기존 자료 보존 확인·수동 다운로드·메모리 경계·예시 격리는 유지한다.

## CSV v3

수집 의미가 바뀌므로 두 내보내기를 `observation-comparison-csv-v3`로 올린다.
프로토콜 ID는 `front-observation-2-5-5x3-v2`다. 시계열과 비교표의 안내 열 끝에
`protocol_mode`(auto/manual), `measurement_scope`(hold_only)를 추가한다. 비교표도 안내 중
측정 단계에서 담은 경우 안내 메타데이터와 `guided_task_not_ground_truth`를 보존한다.
이전 v2 자료를 측정 구간 전용 자료로 해석하지 않는다. 안내 동작은 검증된 정답이 아니다.
원본 좌표·영상·참여자 식별자·학습 가중치를 추가하지 않는다.

## 표시

영상 안의 카메라 켜기에서 자동·수동 선택 모달을 연다. 방식을 고르고 시작을 확인한 뒤
카메라를 연결한다. 취소·Escape는 연결하지 않고 시작 버튼으로 초점을 돌린다. 자료가 있으면
모드 선택 뒤에도 기존 보존 확인을 거쳐야 새 실행으로 바뀐다. 현재 단계 카드에는 기준 등록/준비/
측정/다음 대기 상태와 남은 시간을 표시한다.
안내 카드 배경은 55% 불투명도와 8px blur를 적용해 카메라 화면을 더 볼 수 있게 한다.
글자·버튼 전체에 opacity를 적용하지 않는다. 타이머는 live 알림 밖에 두고 단계 안내만 알린다.

후속 사용자 주석에 따라 상단 브랜드/LIVE 행을 제거하고 등록·종료·CSV·도움말을 하단 관측 도구
오른쪽으로 옮겼다. 수집 상태 설명은 도움말로 옮기며, 꺼진 카메라 안내는 영상 중앙에 둔다.
카드의 현재 단계와 바퀴/동작 위치는 `space-between`으로 같은 행 양끝에 배치한다.

## 검증 경계

합성 프레임·가상 시계로 등록 시간, 36단계 자동/수동 전환, 조기 다음 차단, 측정 외 수집 차단,
추적 불가·숨김·재개·자료 보존을 검증한다. 실제 카메라 추적 정확도·사용자 수행 일치·
장시간 장치 동작·새 참여자 성능은 별도 검증 대상이다.
