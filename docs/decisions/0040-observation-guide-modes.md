# 관측 비교의 자동 기준 등록과 자동·수동 진행

> 2026-10-28 후속: 최초 기준 등록의 자동 2초 준비는 아래 사용자 확인 결정으로 대체됐다.

- 상태: accepted
- 날짜: 2026-10-21
- 근거: 사용자 요청과 동작 시간 선택 답변
- 이전 설계: [ADR 0039](0039-front-observation-comparison.md)

## 결정

카메라가 준비되면 기준 자세 등록을 안내한다. 유효한 얼굴·양어깨 추적 상태에서 준비 2초를
부여하고, 연속 유효 관측 8초의 중앙값을 기준으로 등록한다. 낮은 품질·관측 누락은 기준
수집을 초기화한다. 탭 숨김은 등록을 취소하며 사용자가 다시 시작하면 2초 안내부터 진행한다.
관측 비교 소비자만 8초를 지정한다. 다른 `ObservationComparison` 소비자는 기본 2초를 유지한다.

기준 등록 완료 후 선택한 진행 모드로 자동 시작한다. 기본은 자동이다. 기존 네 동작·세 바퀴와
준비(동작으로 이동) 2초 → 측정(유지) 5초 → 복귀 준비 5초를 유지한다. 사용자가 확인한
절차 시간이며 안정화 시간·자세 정확도를 검증한 결과가 아니다.

- 자동: 각 단계가 끝나면 다음 단계의 전체 시간을 부여한다.
- 수동: 각 단계 시간이 끝나면 대기한다. 다음 버튼은 시간이 끝나고 현재 추적이 유효한 경우만
  활성화한다. 일찍 누르거나 연속 호출해 시간을 건너뛸 수 없다. 마지막 단계는 완료 버튼으로 종료한다.
- 시작한 안내의 모드는 중간에 바꾸지 않는다. 멈춤·추적 실패 후 재개는 현재 단계를 처음부터
  다시 세며 시도 번호·구간을 분리한다. 수동 완료 대기에는 자료를 모으지 않는다.

기준 등록·준비·복귀·대기·일시정지 중에도 영상 표시와 추적 품질 확인은 필요하다. 이 관측을
측정 자료로 수집하지 않는다. 시계열 수치와 비교표 캡처는 실행 중인 측정 5초 안에서만 허용한다.
측정 구간은 시작 포함·종료 제외다. 중단·안내 시작/완료 등 사건 행에는 수치값을 넣지 않는다.
기존 자료 보존 확인·수동 다운로드·메모리 경계·예시 격리는 유지한다.

## CSV v3

수집 의미가 바뀌므로 두 내보내기를 `observation-comparison-csv-v3`로 올린다.
프로토콜 ID는 `front-observation-2-5-5x3-v2`다. 시계열과 비교표의 안내 열 끝에
`protocol_mode`(auto/manual), `measurement_scope`(hold_only)를 추가한다. 비교표도 안내 중
측정 단계에서 담은 경우 안내 메타데이터와 `guided_task_not_ground_truth`를 보존한다.
이전 v2 자료를 측정 구간 전용 자료로 해석하지 않는다. 안내 동작은 검증된 정답이 아니다.
원본 좌표·영상·참여자 식별자·학습 가중치를 추가하지 않는다.

## 표시

영상 안의 카메라 켜기에서 자동·수동 선택 모달을 연다. 방식을 고르고 시작을 확인한 뒤
카메라를 연결한다. 취소·Escape는 연결하지 않고 시작 버튼으로 초점을 돌린다. 자료가 있으면
모드 선택 뒤에도 기존 보존 확인을 거쳐야 새 실행으로 바뀐다. 현재 단계 카드에는 기준 등록/준비/
측정/다음 대기 상태와 남은 시간을 표시한다.
안내 카드 배경은 55% 불투명도와 8px blur를 적용해 카메라 화면을 더 볼 수 있게 한다.
글자·버튼 전체에 opacity를 적용하지 않는다. 타이머는 live 알림 밖에 두고 단계 안내만 알린다.

후속 사용자 주석에 따라 상단 브랜드/LIVE 행을 제거하고 등록·종료·CSV·도움말을 하단 관측 도구
오른쪽으로 옮겼다. 수집 상태 설명은 도움말로 옮기며, 꺼진 카메라 안내는 영상 중앙에 둔다.
카드의 현재 단계와 바퀴/동작 위치는 `space-between`으로 같은 행 양끝에 배치한다.

## 검증 경계

합성 프레임·가상 시계로 등록 시간, 36단계 자동/수동 전환, 조기 다음 차단, 측정 외 수집 차단,
추적 불가·숨김·재개·자료 보존을 검증한다. 실제 카메라 추적 정확도·사용자 수행 일치·
장시간 장치 동작·새 참여자 성능은 별도 검증 대상이다.

## 2026-10-28 후속: 준비 확인과 기준 재측정

모드 선택은 수동을 기본 선택하고 자동은 선택지로 유지한다. 수동 단계가 끝나면 00초 대신
완료 상태와 다음 동작을 안내하고 영상 중앙의 버튼을 눌러 진행한다. 추적 유효성 검사는
유지하며 대기 중 자료는 수집하지 않는다. 카메라 준비와 기준 등록 뒤 첫 준비 단계는 기존과
같이 시작하지만 실제 측정 단계는 수동 확인을 기다린다.

진행 중 기준 자세를 다시 측정할 수 있다. 확인창을 여는 것과 취소는 카메라·기존 자료를
지우지 않으며 측정은 계속된다. 확인하면 진행을 종료하고 기존 비교표·시계열·리플레이를
비운 뒤 새 기준 등록을 시작한다. 확인 전 명시적 다운로드를 제공한다. 종료는 오른쪽의
아이콘 버튼과 기존 확인창을 이용하고, 키보드 초점에서도 버튼 이름을 표시한다.

후속 화면 피드백에 따라 동작과 기준 자세를 강조하고 중앙 안내에는 반투명 배경을 둔다.
수동 대기 버튼은 하단 제어 모음에 두고, 안내 영역 또는 페이지 배경에 초점이 있을 때
Enter로 진행한다. 입력 컨트롤·확인창에서는 단축키가 동작하지 않는다. 왼쪽 위에는 상태
아이콘과 완료 구간을 표시한다. 회색 점은 카메라 꺼짐/연결 실패 또는 연결 중, 초록은 유효 관측이 있는
측정 구간, 노랑은 그 밖의 대기·비측정 상태이며 상태색은 자세 판정이 아니다.

## 2026-10-28 후속: 기준 자세 등록 전 사용자 확인

카메라 연결 후 기준 등록을 자동으로 시작하지 않는다. 사용자가 편안한 자세를 잡고 버튼 또는
Enter로 확인하며, 얼굴·양어깨의 유효한 최신 관측이 있을 때만 8초 등록을 시작한다. 기다리는
시간은 정해 두지 않는다. 리플레이의 기존 `preparing`은 이 대기 기간을 기록한다. 카메라가
꺼졌거나 연결되지 않았을 때와 연결 중에 회색 점의 파동 애니메이션을 표시한다. 연결 중 여부와
오류는 별도 메시지로 구분한다. 범례에는 동일한 아이콘과 색을 함께 보여 준다.

## 2026-10-28 후속: 수동 준비와 관측 모델

수동 모드의 동작 준비는 2초를 세지 않고 즉시 대기한다. 사용자가 준비되었을 때 시작을
확인하면 측정 5초가 시작된다. 측정 완료와 복귀 준비 5초 뒤에도 사용자의 확인을 기다린다.
자동 모드의 준비 2초는 유지한다. 사용자 확인 전에는 측정값을 수집하지 않는다.

프로토콜 ID를 `front-observation-manual-ready-5-5x3-v3`으로 변경하고, 수동 준비 단계의
지속시간을 0으로 기록한다. 기존 v2 리플레이는 불러오며 원래 식별자를 유지한다. `/dev`
관측은 MediaPipe Pose Heavy, GPU 우선·CPU 대체, responsive 실행 경로를 사용한다. 이전 Full
성능 결과는 Heavy의 실측이나 정확도 검증이 아니다.

## 2026-10-27 후속: 완료 측정 비교표와 종료 확인

사용자 요청에 따라 비교표의 별도 ‘현재 동작 담기’ 조작을 제거한다. 같은 protocol_run_id·단계·시도의
hold 관측과 protocol_phase_completed 사건을 연결해 완료한 5초 구간의 중앙값을 표시한다.
같은 동작은 최근 완료 회차로 갱신한다. 기존 COMPARISON_POLICY의 최소 표본 수·500ms 공백 기준을
재사용하고 구간 시작/끝에도 같은 공백 범위를 요구한다. 중단/누락/잘린 구간과 서로 다른 시도·segment를
합치지 않는다. 2D가 불충분하면 행을 만들지 않고 depth 누락은 빈 값으로 유지한다.

이전 수동 저장분은 그대로 보존하고 우선한다. 기준 자세는 변화율 기준이며 별도 hold가 없어 행은 비운다.
표 비우기는 자동 집계도 숨기되 시계열과 리플레이는 유지한다. 새 측정으로 초기화하면 새 집계를 시작한다.
과거 CSV를 다시 쓰지 않는다. v3의 window_start/window_end/sample_count·안내 메타데이터로 실제
집계 범위를 표시하므로 열과 버전은 유지한다. 이전 1초 수동 요약을 새 5초 요약으로 해석하지 않는다.

영상과 표의 수동 종료는 확인창에서 확인한 뒤 실행한다. 취소 시 측정은 유지하며 확인 전까지 계속된다.
일시정지/재개는 활성 측정 동안 고정 슬롯에 표시해 동작 버튼이 사라지며 종료 버튼이 이동하지 않게 한다.
이는 종료 UX와 관측 요약의 변경이며 수행 정답·학습 라벨·자세 판정이 아니다.
