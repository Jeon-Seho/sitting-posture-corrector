# ADR 0008: 연구 화면과 서비스 미리보기를 단일 앱으로 통합

- 분야: 프론트
- 작업: GP-0008

- 상태: 채택
- 날짜: 2026-09-28

## 근거

V2 서비스 미리보기(`ServiceApp`)를 추가하면서 기존 연구 앱(`App`)을 `?research=1`로 따로 남겨 두었다.
그 결과 사용자는 로그인 화면 두 개, 서로 다른 사이드바, 상태를 공유하지 않는 홈·대시보드를 오가게 되었고
"왜 두 개로 나뉘어 있는지" 혼란을 겪었다. 발표에는 연구 앱의 예시 기록 홈·대시보드가 더 적합하다는 의견도 있었다.

## 결정

- 진입점은 `frontend/src/ServiceApp.tsx` 하나다. `src/App.tsx`와 `?research=1` 분기를 삭제했다.
- 로그인은 연구 앱의 주황 표지 디자인(`LoginPage`)을 재사용하고 서비스의 이름·나이·직업 입력을 넣는다.
- 사이드바는 아이콘 메뉴로 통일한다: 홈 / 측정 준비(하위: 실시간 측정) / 자세 등록 / 대시보드 / 설정(하위: 프로필 설정).
  하위 탭은 관련 화면에 있을 때만 연하게 표시한다.
- 연구 앱의 `라벨 수집`은 같은 앱의 `자세 등록` 화면으로 옮기고 사용자용 문구로 바꾼다. 수집기·CSV 규격(수집 v2)은 바꾸지 않는다.
- 홈·대시보드는 설정의 `발표용 예시 기록 표시`(기본 켜짐, `posegood.v2.demo`)로 예시 데이터와 로컬 저장 기록을 전환한다.
- 카메라는 측정 준비에서만 켜고, 카메라 화면(준비·측정·자세 등록) 밖으로 나가면 해제한다. 측정이 진행 중이면 유지한다.
  로그인 시 자동 연결과 상시 카메라 상태 표시줄, 우측 하단 프로필 버튼은 제거했다.

## 결과와 한계

- 연구용 수집과 서비스 측정이 같은 카메라 스트림을 쓰므로 측정 진행 중에는 자세 등록으로 이동할 수 없다.
- 예시 데이터는 가짜이며 화면에 발표용 예시임을 표시한다. 실제 기록과 합산하지 않는다.
- `자세 등록`이라는 이름과 달리 현재 등록 자료는 판정에 반영되지 않는다(개인화 학습 미연결). 화면 안내에 이를 밝힌다.
