# ADR 0003: 기존 PoseGood 프론트에 통합

- 상태: 프로토타입 범위 채택
- 날짜: 2026-09-18

사용자가 프론트 작업 브랜치를 정정했다. `origin/feature/retro-redesign` (60ec460)을 기반으로
`codex/retro-webcam`에서 기존 React 18·화면 6개·폰트·디자인을 보존해 웹캠을 연결한다.
독립 프로토타입은 stash에 보존하고 하네스와 재사용 가능한 카메라/특징만 옮겼다.

ADR 0002의 UI·시간 정책 배치는 이 결정으로 대체한다. 특징·점수 계산은 `model/prototype/pose.ts`가 담당한다.
프론트 어댑터가 기존 Sample 형식에 연결하며, 기존 순수 `frontend/src/lib/engine.ts`가 웹캠과 시연의 공통 시간 정책을 담당한다.
이 위치는 기존 UI의 상태 기계를 보존하기 위한 임시 예외다. 생산용 AI 경계로 분리할 때 이벤트 계약을 정의해야 한다.
현재 실시간 UI는 기존 내부 Sample을 소비하며 v1 상태 계약으로 통신하는 서버 연결은 구현하지 않았다.

기본 지속 3초·재알림 60초와 기존 복귀 유지시간 2초를 적용한다. 휴식·측정 불가에서는 후보를 초기화하고
활성 이벤트를 중단 사유와 함께 닫는다. 이 공백을 가로지른 발생 간격·회복 시간은 집계하지 않는다.
알림 횟수는 실제 표시한 횟수이며 알림 없는 이벤트의 회복 시간은 null이다.

기존 개발 도구 설치에서 취약점이 보고되어 Vite 8.3.0·Vitest 5.0.1·React 플러그인 6.1.1로 함께 갱신했다.
React 18과 TypeScript 5를 유지한다. 새 잠금 파일 설치 audit는 0건이다.

실제 기록의 영속 저장·인증·기간 통계는 범위 밖이다. 홈/대시보드 예시와 현재 세션 결과를 명시적으로 구분한다.
