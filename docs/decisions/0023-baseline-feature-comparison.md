# ADR 0023: 개인 기준 좌표 특징의 비교 방향

- 상태: accepted (비교 방향. 최적 입력·임계값은 미확정)
- 날짜: 2026-10-12
- 근거: 사용자가 어깨 중심 특징과 좌표 변화를 교차 비교하는 방향에 동의하고 최종 점검을 요청했다.

## 결정

개인 기준 대비 관측 변화가 목표다. 정면 카메라·높이/거리/줌 고정을 실험 가정으로 둔다.
높은 모니터 카메라와 낮은 노트북 카메라는 각각 같은 구도로 기준을 등록하고 조건별로 비교한다.
MediaPipe Pose Heavy의 얼굴 11점·어깨 2점과 로컬 개발 우선을 유지한다.
기준 자세를 개발상 정상으로 가정하지만 검증된 정답으로 취급하지 않는다.

원본 좌표를 보존하고 픽셀 좌표 p=(W*x,H*y)에서 특징을 산출한다.
현재 어깨 중점 ct, 기준 중점 c0, 기준 어깨 폭 s0를 사용한다.
상대 변화 dq_i=((p_i(t)-ct)-(p_i(0)-c0))/s0,
중점 변화 dc=(ct-c0)/s0, 크기 비율 st/s0를 결합하는 입력을 우선 실험 후보로 둔다.
어깨선을 매 프레임 수평으로 회전 정렬하지 않는다.

같은 자료·분할·품질 조건에서 세 입력을 비교한다.

| 입력 | 내용 |
| --- | --- |
| A 절대 변화 | (p_i(t)-p_i(0))/s0 |
| B 상대 변화 | dq_i |
| C 결합 | dq_i + dc + st/s0 |

A_i=dq_i+dc다. 같은 유효 좌표와 기준 폭을 사용하면 A와 C의 좌표 표현은 서로 재구성할 수 있다.
C는 새로운 관측을 추가하는 것이 아니라 움직임 성분을 나누어 제공한다. 크기 비율도 같은 좌표에서 계산한 보조 특징이다.
비교 목적은 정보량 증가 주장보다 표현·잡음·모델 학습 반응의 차이를 확인하는 것이다.
기존 코·어깨 세 특징은 동일 자료의 대조군으로 둔다. 현재 폭 정규화와 얼굴선 방향 추가는 별도 비교 항목이다.

## 품질·라벨·평가

화면 밖·가림·필수 특징 부족은 자세 판정에서 제외하고 unmeasurable로 처리한다.
13점의 일부 가림을 전부 정상/이탈로 바꾸거나 결측 좌표를 0으로 채우지 않는다.
현재 서비스의 가시성·화면 경계 품질은 코·양 어깨를 확인하고 귀는 유한 좌표만 필수로 요구한다. 새 특징의 그룹별 품질·유효 포인트 마스크는 별도 구현해야 한다.
눈 6점의 수가 전체 점수를 지배하지 않도록 얼굴 위치·방향·어깨 변화를 나누어 비교한다. 가중치는 미확정이다.

정답 라벨 부담을 줄이기 위해 기하 변화량부터 비교한다. 자연 변동 분포 학습은 더 긴 기준 자료 검토 후 진행한다.
학습·검증·시험 참여자를 분리하며 시험 참여자의 기준만 개인 보정에 쓰고 이탈 자료로 튜닝하지 않는다.
기준 UUID와 참여자·카메라 높이·거리/해상도·촬영 회차를 연결해야 한다. 현재 기준 archive의 participant_code는 null이다.

## 구현 상태와 제한

13점 원본 및 완료된 기준 시계열 저장은 구현됐다. lee_app1 반영 후 현재 로컬 규칙은 headGap/offset/tilt와 turn 기반 회전 제외를 사용한다.
offset은 과거 코 위치에서 귀 중점으로 바뀌었다. 과거 코·어깨 대조군과 현재 규칙의 결과는 구분해 기록한다.
13점 기준 대표값, 그룹별 품질, A/B/C 특징 비교, 새 통합 점수는 아직 구현·검증되지 않았다.
3초 등록은 시작점이며 자연 변동 전체의 학습 자료로 충분하다고 확정하지 않는다.
단안 깊이·실제 해부학적 각도를 직접 측정한 것으로 표현하지 않는다. Face Landmarker·서버 확장은 후순위다.
