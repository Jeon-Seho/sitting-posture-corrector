# 동작 뒤 기준 측정과 8~15초 랜덤 측정 시간

- 상태: accepted
- 날짜: 2026-10-31
- 근거: 사용자가 복귀를 기준 자세 측정으로 바꾸고, 측정 시간을 매번 8~15초 중 1초 단위로 정하기로 함
- 이전: [ADR 0044](0044-optional-stretch-cycles.md)의 동작·복귀 시간, [ADR 0045](0045-base-deviation-first.md) 4번("수집은 바꾸지 않는다")

## 결정

1. **각 동작 뒤에 기준 자세 측정 구간을 둔다.** 한 동작은 준비 2초 → 동작 측정 → 복귀 준비 3초 → 기준 측정이다.
   복귀 준비는 측정하지 않고, 기준 측정은 `phase=hold`, `task=neutral`, `measurement=true`로 기록한다.
2. **기준 등록은 처음 8초 한 번 그대로 둔다.** 기준점은 하나다. 기준 측정은 "기준 근처에서 흔들리는 범위"를 모으기 위한 것이며 기준점을 다시 만들지 않는다.
3. **측정 시간은 동작마다 8~15초 중 1초 단위로 뽑는다.** 같은 동작의 동작 측정과 그 뒤 기준 측정은 같은 길이다. 스트레칭 측정도 같은 규칙이다.
   사용자가 정해진 길이를 외워 끝 무렵 자세를 미리 푸는 것을 줄이고, 기준·이탈 자료의 양을 같게 맞춘다.
4. **이탈 강도는 기록하지 않는다.** 작게 벗어나든 크게 벗어나든 이탈이다. 안내 문구의 "종류와 크기를 바꿔"는 유지한다.
5. **프로토콜 `front-observation-base-hold-v7`, 기록 `observation-keypoint-replay-v7`.** v7은 실제로 뽑은 단계별 길이를 `schedule`에 남긴다.
   ML 후보 특징 JSON도 같은 `schedule`을 담는다. v1~v6 파일은 원래 프로토콜로 계속 읽는다.

## 영향

- 기본 1사이클은 기준 등록 뒤 약 30~60초다(동작 2개 × 준비 2초·측정·복귀 3초·기준 측정). 5사이클 최장 약 6분, 약 3,500프레임으로 6,000프레임 한도 안이다.
- 비교표의 기준 자세 행은 이제 기준 측정 구간의 중앙값으로 채워진다.
- ADR 0045의 기준·이탈 2클래스 목표는 그대로다. 4번 중 "수집을 바꾸지 않는다"만 이 결정으로 대체한다.

## 한계

- 화면 시계는 측정 남은 초를 계속 보여준다. 남은 시간을 보고 끝을 예측하는 효과는 남는다.
- 8~15초 범위와 복귀 준비 3초는 팀이 정한 수집 설정이며 데이터로 검증하지 않았다.
- 안내 라벨은 수행 정답이 아니다. 복귀 준비 3초 뒤에도 기준 자세로 완전히 돌아오지 않았을 수 있다.
