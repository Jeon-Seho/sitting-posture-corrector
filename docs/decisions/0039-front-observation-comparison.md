# ADR 0039: 정면 2D와 Pose 상대 z의 관측 비교

- 날짜: 2026-10-16
- 상태: 채택 — 연구용 표시·수동 비교·수행 과제 안내에 한정
- 배경: [어제 논의](../ml/jisung/2026-10-15-desktop-ml-scope-and-depth-review.md), [관측 한계](../ml/measurement-limits.md)

## 결정

사용자 요청으로 `/dev?view=observation`에 카메라/명시적 합성 예시를 사용하는 독립 화면을 둔다.
서비스 FE·BE, 기존 `/dev` 예측·알림, 개인 정상 수집과 분리한다. 동작 자동 분류·건강 점수는 만들지 않는다.

기준은 직접 누른 뒤 연속 2초·최소 10표본의 중앙값이다. 표시를 최대 약 10Hz로 샘플링한다.
원 영상의 코(0)·양눈(2,5)·양입꼬리(9,10)·양어깨(11,12)에 유한 좌표·화면 내 x/y·가시성 0.5 이상을
요구한다. world는 코·양어깨에 같은 유한성·가시성을 요구한다. 0폭과 1e-6 이하 분모는 거부한다.
이는 기존 MediaPipe 가시성 하한을 사용한 진단 화면의 수치 유효성 정책이며 검증된 추적 정확도 임계값이 아니다.
500ms 초과 누락·시각 역전·중복은 관측을 끊는다. 창은 보간하거나 정상으로 채우지 않는다.
기준 수집 중 누락은 창을 초기화하며 탭 숨김은 진행 중 기준 수집을 취소한다.

2D 길이는 `(x, y × height/width)`에서 계산하고 등록 당시 영상 어깨폭 `W0`를 분모로 고정한다.
`S`는 양어깨 중점, `N`은 코, `E`는 눈 중점, `M`은 입 중점이다. 아래 y는 비율 보정 후 값이다.

| 화면 항목 | 기준 대비 표시값 |
| --- | --- |
| 머리–어깨 간격 | `100 × ((Sy−Ny) − (S0y−N0y)) / W0` |
| 얼굴 세로 길이 | `100 × ((My−Ey) − (M0y−E0y)) / W0` |
| 어깨 높이 | `100 × (S0y−Sy) / W0` |
| 어깨폭 | `100 × (W/W0−1)` |
| 상대 z | `100 × ((Nz−(Lz+Rz)/2) − baselineRelativeZ) / worldW0` |

worldW0는 등록 당시 world 어깨 간 유클리드 거리다. 상대 z는 같은 Pose world 출력만 사용하며
화면에 현재/기준의 추정 미터도 표시한다. Face z를 섞지 않는다. 실제 목의 전방 거리가 아니다.
world가 없거나 기준 창에 하나라도 누락됐다면 z 비교는 비워 두고 2D는 계속 제공한다.
추출 모델·영상 크기가 바뀌면 현재 비교를 중단하고 카메라를 해제한다. 기존 자료와 CSV에 사용하는 이전
기준 정보는 보존한다. 사용자가 카메라를 옮긴 경우 재등록한다.

선택 동작 이후 최근 약 1초의 연속 자료(최소 5표본·최소 시간 범위 800ms) 중앙값을 탭 메모리의 표에
담는다. 품질 누락을 제외해 짜깁기하지 않으며 z 누락 시 그 셀을 비운다. 동작은 사용자가 선택한 수행
표식이지 실제 수행 확인·학습 정답이 아니다. 같은 동작 재확인은 해당 행을 교체하고 재등록·새 실행은 표를 비운다.
최근 추이는 10초·최대 120점이며 항목별 자동 대칭 축을 명시한다. 다른 그래프의 기울기를 같은 물리 단위로 읽지 않는다.

## 결과와 한계

영상·원본 좌표는 메모리 전용이다. 표·차트도 기본 탭 메모리만 사용한다. 2026-10-16 후속 사용자 요청으로
아래 파생 수치의 명시적 CSV 다운로드를 추가했다. 자동 저장·업로드·학습·자동 fitting은 하지 않는다.
MediaPipe 런타임·모델 자산의 로컬 로드는 기존 카메라 경로를 사용한다. 카메라는 직접 시작할 때만 켜고
종료·화면 이탈에 해제한다. 카메라 연결 실패/추적 정지/숨김에서는 현재 값을 비운다.
합성 예시는 독립적인 좌표 변형을 설명할 뿐 네 동작의 실제 패턴이나 분류 가능성을 증명하지 않는다.
실제 관측의 안정성·반례·개인 간 차이는 앞으로 확인할 연구 과제다.

## 후속: 파생 수치 CSV

`동작별 비교표 CSV`는 담은 동작만 한 행씩 내보낸다. 동일 동작을 다시 담으면 최신 행으로 교체하며
담지 않은 동작을 0이나 빈 관측으로 만들어 넣지 않는다. `관측 시계열 CSV`는 기준 등록 완료 후의
각 표본과 중단 경계를 내보낸다. 약 10Hz, 최근 최대 12,000행을 보관하며 잘린 앞부분 행 수를 화면과
`trace_rows_dropped` 열에 명시한다. 종료 후에도 내려받을 수 있다. 새 실행·재등록·추출 조건 변경은
표와 시계열을 함께 비우던 초기 동작은 아래 후속 보호 정책으로 대체한다.
`비교표 비우기`는 확인 후 요약 행만 비우며 시계열은 유지한다.

초기 CSV는 UTF-8 BOM·CRLF의 `observation-comparison-csv-v1`을 사용했다. 아래 자동 안내 후속은 v2다.
문자열은 CSV 인용·따옴표 이스케이프와
수식 시작 문자 무력화를 적용하고 숫자는 반올림 없이 내보낸다. 결측은 빈 칸, 유효한 0은 숫자 0이다.
실제/합성은 `source=camera/synthetic`, 동작 표식은 `label_kind=user_selected_not_ground_truth`로 구분한다.
`action`은 neutral/head/bow/body/shoulders, `action_label`은 해당 한글 안내다. 같은 동작을 다시 누르는 것도
새 `segment_id`로 구분한다. 선택과 실제 수행 시각이 일치하거나 동작이 완료됐다는 뜻은 아니다.

공통 열에는 `schema_version,run_id,started_at_utc,source,label_kind,reference_context`와 기준의
영상 어깨폭(프레임 너비 단위), 추정 world 어깨폭(m), 기준 상대 z(추정 m), 잘린 행 수를 둔다.
`started_at_utc`와 경과시간 원점은 새 실행 또는 수동 재등록 시작이다. 자동 합성 등록은 새 실행 원점을 쓴다.
`reference_context`는 추출 모델과 영상 크기이며 개인 식별자가 아니다.

| 종류 | 추가 메타데이터 |
| --- | --- |
| 비교표 | action·action_label·segment_id·captured_elapsed_ms·window_start_observation_ms·window_end_observation_ms·sample_count |
| 시계열 | action·action_label·segment_id·elapsed_ms·observation_time_ms·event·status·image_valid·world_valid |

경과시간은 원점부터의 단조 시계 ms이며, observation 시각은 추출 입력 시계 ms다. 서로 다른 시계나
다른 실행의 원점을 같은 것으로 취급하지 않는다. 요약 window는 원 관측 시각의 범위다.
event는 observation/interrupted/hidden/stopped이며 중단 행의 관측 시각과 측정값은 빈 칸이다.
status는 measured/depth_unavailable/unmeasurable로 제공한다. `image_valid`·`world_valid`는 해당 원
관측의 수치 품질이며 기준 z가 없는 경우 world가 유효해도 z 변화는 빈 칸이다.

두 CSV의 수치 열은 다음과 같다. 아래 pct는 0~1 비율이 아니라 화면과 같은 % 값이다.

- `head_gap_delta_pct_ref_image_shoulder_width`: 등록 영상 어깨폭 대비 코–어깨 간격 변화 %.
- `eye_mouth_gap_delta_pct_ref_image_shoulder_width`: 등록 영상 어깨폭 대비 눈–입 간격 변화 %.
- `shoulder_lift_pct_ref_image_shoulder_width`: 등록 영상 어깨폭 대비 어깨 중점 상승 %.
- `shoulder_width_change_pct`: 등록 영상 어깨폭 대비 확대/축소 %.
- `relative_z_delta_pct_ref_world_shoulder_width`: 등록 world 어깨폭 대비 상대 z 변화 %.
- `relative_z_estimated_m`: 같은 Pose의 현재 상대 z 추정 m. 요약은 창 중앙값이다.

원본 랜드마크·영상·Face 좌표·참여자 식별자·가중치는 CSV에 포함하지 않는다.

## 후속: 실제 자료 보호와 예시 격리

사용자가 카메라 측정 뒤 예시를 눌렀을 때 자료가 바뀐 것으로 보고했다. 구현에서 예시 시작이
같은 초기화 함수를 사용해 이전 실행의 버퍼를 지우는 경로를 확인했다. 예시는 조작 확인용으로
넣었으나 측정과 같은 수집·내보내기를 제공한 것은 혼동과 자료 손실을 유발했다.

- 실제 화면에는 카메라 시작·종료만 둔다. 예시는 접힌 도움말의 별도 탭 링크
  `/dev?view=observation&demo=1`로만 진입한다. 원래 탭·메모리·카메라 상태와 공유하지 않는다.
- 예시 화면은 큰 경고와 별도 제목을 표시한다. 가상 점과 짧은 표시 추이만 사용하고 시계열 버퍼·
  비교표 캡처·CSV 내보내기는 훅 경계에서 차단한다. 실제 모드에서 예시 start 요청도 거부한다.
- 실제 자료가 있으면 새 측정·재등록·표 비우기는 즉시 실행하지 않는다. 먼저 카메라를 멈춰 자료를
  보존하고 기존 확인창을 표시한다. 취소는 자료를 유지한다. 창 안에서 요약/시계열 CSV를 받을 수 있고
  `자료를 비우고 계속하기`를 명시적으로 눌러야 새 실행 또는 재등록으로 초기화한다.
- 표 비우기 확인은 요약 표만 지우며 시계열은 남긴다. 이미 실행 중인 카메라 start 중복 호출은 무시한다.
- 추출 조건 변경은 기존 표/시계열을 지우지 않는다. CSV는 이전 등록 기준에 고정하며 새 조건과 섞지 않는다.
- 실제 자료가 남아 있는 동안 beforeunload를 연결하여 새로고침·탭 닫기·이동의 브라우저 경고를 요청한다.
  브라우저의 사용자 상호작용 정책에 따라 경고가 표시되지 않을 수 있으며 강제 종료나 자료 복구를 보장하지 않는다.

자동 파일 저장·원본 좌표 보관·영구 복구는 추가하지 않았다. 이전에 초기화된 메모리 자료를 되살린다는
주장이 아니며, 이미 다운로드한 CSV는 별도 파일로 남는다. 보호 작업 당시에는 CSV v1을 유지했다.

## 후속: 3바퀴 자동 안내와 CSV v2

사용자가 기준 등록 후 `3바퀴 자동 안내 시작`을 누르면 머리 앞으로 내밀기 → 고개 숙이기 →
몸통 전체 접근 → 어깨 올리기를 3바퀴 안내한다. 각 동작은 이동 2초 → 유지 5초 → 기준 복귀·유지 5초다.
12회·36구간·명목상 144초이며 별도 준비 카운트는 없다. 복귀 5초에는 돌아가는 움직임도 포함된다.
이 시간은 사용자 지정 수행 절차이며 검증된 안정화 시간·판정 임계값이 아니다.

등록 기준·유효한 2D·최근 500ms 이내 수신·화면 표시·카메라 연결이 있어야 시작/재개한다.
단조 시계로 현재 단계가 시작한 시각부터 센다. 콜백 지연이 500ms 이내면 다음 단계의 전체 시간을
새로 부여하며 여러 단계를 몰아서 건너뛰지 않는다. 실제 총 시간은 표시 지연·중단만큼 길어질 수 있다.
2D 불가·관측/안내 시계 500ms 초과 누락·시계 역전·탭 숨김·사용자 멈춤은 일시 정지다.
z만 없으면 기존 정책대로 결측으로 기록하며 2D 안내를 계속한다.

추적 회복만으로 자동 재개하지 않는다. 사용자가 현재 단계에 맞는 자세/준비를 확인하고 재개하면
그 단계를 처음부터 세며 `protocol_phase_attempt`와 `segment_id`를 증가시킨다. 유지 중이었다면
화면에 목표 동작 이름과 그 자세를 다시 잡으라는 안내를 표시한다. 이전 시도와 멈춘 동안의 관측도
보존하되 `paused`로 분리한다. 추출 조건 변경은 안내를 취소하고 이전 기준의 자료를 보존한다.
안내 중 수동 동작 선택·표 캡처·기준 재등록은 잠근다. 종료/완료는 카메라를 해제하고 CSV는 남긴다.
예시 탭에는 자동 안내·수집·CSV를 추가하지 않는다.

두 CSV의 버전은 `observation-comparison-csv-v2`다. 수동 비교표의 열과 동작당 최신 중앙값 의미는
유지한다. 자동 안내의 전체 세 바퀴는 **관측 시계열 CSV**에서 받는다. 시계열의 기존 수치 열 뒤에
다음 열을 추가한다. 시작 전 수동 관측의 안내 열은 빈 칸이며 `label_kind=user_selected_not_ground_truth`다.
안내가 시작된 행은 `guided_task_not_ground_truth`이며 실제 수행 검증·학습 정답이 아니다.

| 열 | 의미 |
| --- | --- |
| protocol_id | `front-observation-2-5-5x3-v1`, 지정한 순서·시간의 버전 |
| protocol_run_id | 탭 실행 안의 안내 실행 ID |
| protocol_state | running / paused / completed / cancelled |
| protocol_round / protocol_trial | 1~3바퀴 / 전체 1~12번째 수행 과제 |
| protocol_task_action | head / bow / body / shoulders, 복귀 단계에도 원래 목표 동작 유지 |
| protocol_phase | move / hold / return |
| protocol_phase_index | 전체 1~36번째 단계, 재개 시 동일 번호 |
| protocol_phase_attempt | 각 단계의 시도 번호, 최초 1·재개 시 증가 |
| protocol_phase_elapsed_ms / protocol_phase_duration_ms | 현재 시도의 유효 진행 시간 / 지정 단계 시간 |
| protocol_pause_reason | user / hidden / tracking_lost / clock_gap, 해당되는 경우만 |

`action`은 move/hold에서 목표 동작, return에서 neutral이다. `protocol_phase_started`,
`protocol_phase_completed`, `protocol_paused`, `protocol_cancelled`, `protocol_completed` 사건을
추가한다. 제어 사건에는 관측 시각·측정값을 채우지 않는다. 기존 observation/interrupted/hidden/stopped는 유지한다.

유지 자료 분석 시 `event=observation`, `protocol_state=running`, `protocol_phase=hold`를 고르고,
같은 `protocol_run_id + protocol_phase_index + protocol_phase_attempt + segment_id`의
`protocol_phase_completed` 사건이 있는지 확인한다. 중단된 부분 시도를 5초 완료 구간으로 읽지 않는다.
2D/z 품질·결측과 잘린 행 수도 별도로 확인한다. 자동 안내는 사용자가 실제로 그 동작을 했는지,
카메라를 움직였는지, 목표 자세에 도달했는지 확인하지 않는다. 실제 사람이 수행한 검증은 별도다.

## 후속: 카메라와 안내를 함께 보는 UX

사용자가 카메라와 지시를 동시에 보기 어렵다고 확인했다. 화면 캡처에서도 전체 너비의 고정 안내가
카메라 윗부분을 덮는 것을 확인했다. 실제 측정은 왼쪽 카메라·오른쪽 현재 동작/타이머/다음 안내를
같은 영역에 배치하고 고정 겹침을 제거한다. 시작 시 그 영역으로 스크롤/포커스를 이동하며 표본 갱신이나
일시 정지/재개 때는 다시 이동하지 않는다. 좁은 화면에서는 작은 미리보기와 안내를 세로로 배치한다.

수치·그래프·상대 z 설명과 수동 비교표는 접어 두고 필요할 때 펼친다. 완료 CSV는 안내 영역에 유지하며
일시 정지 상태에서도 현재까지의 시계열 CSV를 받을 수 있다. 측정 시간·품질·구간 정책과 CSV v2 열은 같다.

`shoulders`는 **양쪽 어깨를 동시에 올리는 과제**다. 이전 안내도 양쪽을 지시했으나 제목과 유지 문구에서
놓칠 수 있어 `양쪽 어깨 함께 올리기`로 명확히 한다. 앞으로의 CSV `action_label`도 같은 명칭을 쓰되
기계용 ID·수행 의미는 유지한다. 이미 다운로드한 CSV는 바꾸지 않는다. 어깨 높이 수치는 양어깨 중점이므로
한쪽씩 올리기나 좌우 수행 성공을 별도로 판정한 값으로 읽지 않는다.

## 후속: 자동 기준 등록과 진행 모드, CSV v3

현재 실행 정책은 [ADR 0040](0040-observation-guide-modes.md)이 위 2초 수동 등록·전체 관측 수집·
자동 안내 전용 정책을 대체한다. 카메라 연결 후 2초 안내·8초 기준 등록, 자동/수동 진행,
측정 5초 안에서만 수치 수집을 적용한다. 과거 v2 자료에 새 정책을 소급하지 않는다.
