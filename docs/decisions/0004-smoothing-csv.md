# ADR 0004: 화면 평활화와 CSV 파일럿

- 상태: 프로토타입 범위 채택
- 날짜: 2026-09-19

사용자는 M1 Air에서 약 10 FPS의 스켈레톤을 관찰했고 데이터 수집 방식을 문의했다.
기존 코드는 CPU에서 100ms마다 추적했다. GPU 초기화를 우선 시도하고 실패하면 CPU로 돌아간다.
GPU 최대 30 Hz, CPU 최대 20 Hz이며 직전 추론 시간의 2배보다 짧은 간격으로 실행하지 않는다.
브라우저 렌더 주기로 스켈레톤을 시간 기반 지수 평활화(45ms 시정수)한다. 품질 유실 시 즉시 비운다.
판정·기준 등록·CSV에는 원래 추론 특징을 사용한다. 화면 표시의 추가 지연과 측정 시간은 구분한다.

실제 추론 횟수/초와 호출 시간을 화면에 표시한다. 수치는 브라우저·장치·포즈에 따라 달라진다.
추론은 여전히 메인 스레드이며 [MediaPipe 공식 가이드](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/web_js)의 동기 호출이다.
GPU/주기 개선으로 충분하지 않은 장치는 Worker 분리를 후속으로 검토한다. FPS 향상을 보증하지 않는다.

현재 수집은 DB 없이 CSV 파일럿으로 한다. 수집 시작을 명시적으로 누르고, 수동 라벨을 자동 규칙 판정과 분리한다.
원본 영상/좌표 대신 기존 3개 무단위 특징·기준·부호 있는 차이·품질·설정·시간을 최대 10Hz로 기록한다.
휴식은 제외하고 품질 불량은 빈 특징으로 기록한다. 새 데이터셋은 [CSV 지침](../research/pilot-csv.md)을 따른다.
수집 버퍼는 App 수준 메모리에 두어 화면 이동에도 다운로드할 수 있고 18,000행으로 제한한다.
이 결정은 연구용 촬영·라벨 프로토콜이나 최종 LSTM 입력을 확정하지 않는다.
