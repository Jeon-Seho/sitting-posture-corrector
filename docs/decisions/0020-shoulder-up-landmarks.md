# ADR 0020: 어깨 포함 머리 좌표만 유지

- 상태: accepted
- 날짜: 2026-10-12
- 근거: 사용자가 어깨 위만 촬영하므로 아래 부분을 제거하도록 요청했다.

## 결정

MediaPipe Pose 추론 결과에서 코·눈·귀·입·양쪽 어깨에 해당하는 원래 인덱스 0~12만 유지한다.
팔·손·골반·다리·발(13~32)은 공통 카메라 관측을 만들기 전에 영상/world 배열 모두에서 제거한다.
실시간 판정과 학습용 CSV 수집은 이 관측을 공유한다. CSV 직렬화도 최대 13개로 제한한다.
낮은 가시성의 선택 좌표는 그대로 유지하고 품질이 낮으면 특징은 null, 상태는 unmeasurable이다.

모델은 여전히 전신 33개를 내부에서 추론한다. 출력 선택은 추론 연산량을 줄이거나 영상 프레임을 crop하지 않는다.
기존 세 특징·기준 변화량과 서버 계약은 동일하다. v2 CSV의 가변 길이 배열에서 부분집합을 선택하므로 열·인덱스·버전을 유지한다.
이전 33개 CSV는 그대로 보존하고 ML 입력 준비에서 원래 index 0~12를 선택한다.

## 2026-10-29 예외

`/dev` 키포인트 리플레이만 원래 인덱스 13..22(팔꿈치·손목·손)를 별도 필드로 받는다([ADR 0043](0043-base-deviation-stretch-collection.md)).
공통 관측·서비스 판정·CSV·서버 전송은 계속 0..12만 쓴다.

## 한계

모델 종류·촬영 시점·품질 임계값의 연구 검증은 별도다. 13개 유지가 정확도나 성능 향상을 증명하지 않는다.
