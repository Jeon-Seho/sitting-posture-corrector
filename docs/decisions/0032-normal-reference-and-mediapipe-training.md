# ADR 0032: 정상 자료로 등록 검증하고 실제 MediaPipe 수집을 예측 학습으로 연결

- 날짜: 2026-10-14
- 상태: `/dev` 개발 구현. 실제 참여자 성능·서비스 승격은 미검증.
- 근거: [실제 관찰과 공백 감사](../ml/live-keypoint-audit.md), [현재 계획](../ml/current-plan.md), [학습 재현 안내](../ml/mediapipe-training.md)
- 변경 범위: ADR 0028의 새 기준 중심 덮어쓰기, ADR 0029의 자동 0.5% 단일 선별을 개발 화면에서 대체한다. 기존 파일의 의미와 일반 서비스는 유지한다.

## 문제

기존 개인 프로파일은 정상 구간에서 허용 폭을 맞췄지만, 측정 시작 때 등록한 자세로 중심을
덮어썼다. 잘못 등록한 자세도 점수 0이 될 수 있었다. 자동 0.5% 선별은 약 6분의 실제 단기
관찰에서 0행이었고, 행이 있어도 연속 창이 없으면 LSTM 학습으로 연결되지 않았다.
기존 Panoptic LSTM은 MediaPipe 좌표와 근사 대응이며 `/dev` 수집 JSON을 직접 학습하지 않았다.

## 결정

1. **학습 중심을 고정한다.** 확인한 수동 정상 자료의 9축 center/tolerance로 등록 후보와
   현재 자세를 모두 평가한다. 기존 등록 시간·품질 조건을 통과한 후보에 score ≤ 1을 허용하고
   초과는 거부한다. 가장 벗어난 얼굴/귀/어깨 축을 안내하고 범위 복귀 시 재등록한다.
   측정의 개인 범위 진입도 score > 1로 맞추며 일반 비교용 거리 룰 경계는 보존한다.
2. **추출기 출처를 검사한다.** 프로파일과 실제 관측의 알려진 ID가 같아야 정상 학습 검증을
   적용한다. 미상·불일치·손상·관측 부족은 통과가 아니다. 프로파일이 없으면 학습 검증이
   없는 기존 거리·시간 기준 등록으로 구분한다. 사용자 확인 정상은 의학적 정상 판정이 아니다.
3. **자동 선별을 v2로 확장한다.** 기본 6%, 선택 0.5%·3%·6%이며 행별 maximumDeviation을
   저장한다. 선별값 변경은 구간을 끊는다. 기존 v1의 0.5% 의미는 바꾸지 않는다. 6%는 수집
   가용성의 개발 선택이지 검증된 정상 임계값이 아니다. 자동 약라벨을 독립 정답으로 쓰지 않는다.
4. **행 수와 학습 가능성을 구분한다.** 연속 구간·후보 창·탈락 이유를 보여준다. 창은 같은
   참여자·수집·세션/실행·기준·추출기·선별값·품질 구간 안에서만 만든다. 학습 입력은 100ms
   격자 30시점이며 유효 양끝점 간격 250ms 이하만 보간한다. 미래 정답은 입력 끝 +300ms에
   가장 가까운 실제 관측 ±50ms 이내로 제한한다. 정답은 보간하지 않고 없으면 창을 제외한다.
   실제 horizon 250~350ms와 offset을 보고하고 등속 비교도 같은 타깃 시각을 사용한다.
5. **로컬 검사·학습·불러오기를 명시적으로 연결한다.** `mediapipe_lstm`의 validate/prepare는
   표준 라이브러리로 파일 hash·원본 재정규화·출처·시각·분할·창을 검사한다. train은 선택
   NumPy/PyTorch 환경에서 CPU로 실행해 비공개 새 폴더에 모델과 보고서를 만든다. 브라우저
   자동 업로드·학습·기본 모델 교체는 하지 않고 사용자가 `model.json`을 불러온다.
6. **좌표 계약을 분리한다.** 새 `forecast-weights-v2`는 `data_domain:mediapipe`, 정확한
   `pose_model_id`, `mediapipe-world13-shoulder-normalized-xyz-v1` 특징을 담는다. 점 순서는
   `[0,6,5,4,1,2,3,10,9,7,8,11,12]`, point_definition은
   `MediaPipe-13-world-shoulder-normalized-v1`이다. 어깨 중점/3D 폭 정규화는 liveForecastPoints와
   일치한다. Panoptic v1은 기존 한계를 표시한 레거시 비교 경로로 남긴다.
7. **pilot과 참여자 평가를 나눈다.** pilot은 train만 사용하는 기능/적합 점검이며 새 사용자
   성능이 아니다. 기본 participant_holdout은 세 분할을 요구하고 참여자 중복을 금지한다.
   수동 personal_calibration은 pilot에서만 학습 입력으로 허용한다. 변환기는 train 입력으로만,
   모델 선택은 validation으로 수행하며 test는 선택 뒤 평가한다. 좌표 예측 오차는 자세 정확도가 아니다.

## 검증과 한계

이번 작업은 실제 참여자 자료를 새로 수집하거나 실제 자료로 학습하지 않는다. 합성 데이터로
등록 수락/거절·중심 고정·출처 불일치·파일 변조·분할 누수·시각/창 경계·학습과 브라우저 추론
연결을 점검한다. 최종 결과는 [작업 계획 0045](../plans/completed/0045-normal-reference-and-mediapipe-training.md)에 기록한다.

자동 자료만으로 정상 변동을 충분히 대표하지 못한다. 13점으로 상체 아래쪽을 관측하지 못하고
정규화로 전체 이동/크기 정보가 제거된다. 카메라 깊이 오차와 의도적인 스트레칭 구분도 남는다.
실제 자료의 독립 평가·오알림/놓침/지연 비교를 거쳐 서비스 승격을 별도로 결정한다.
