# ADR 0002: 웹캠과 합성 입력을 갖춘 프론트 프로토타입

- 상태: 프로토타입 범위 채택
- 날짜: 2026-09-18

UI 및 시간 정책의 최신 배치는 [ADR 0003](0003-retro-integration.md)으로 대체한다. 아래는 최초 프로토타입 결정 기록이다.

## 맥락

사용자는 프론트에서 동작을 확인하는 프로토타입과 실제 웹캠 감지를 요청했다. 아직 학습된 LSTM이나 서버가 없다.

## 결정

현재 계획의 React/TypeScript에 Vite를 사용해 로컬 화면을 구성한다. MediaPipe Pose Landmarker Lite는 기기 안에서 실행한다.
머리·어깨 특징과 5초 개인 기준을 비교하는 규칙을 임시 추론기로 사용하고, LSTM/진단/검증된 성능으로 표현하지 않는다.
알고리즘과 알림 정책은 `model/prototype/`이 소유하며 프론트는 이 모듈을 호출해 결과를 표시한다.
기존 `contracts/posture-status.v1.schema.json` 형식에 맞는 상태 어댑터를 유지한다. 점수는 학습 확률이 아니다.
데모 입력도 같은 세션 상태 전이를 사용한다. 모든 관측과 기록은 메모리에서만 처리한다.

모델과 WASM은 최초 준비 때 내려받고 로컬에서 제공한다. 다운로드 모델은 SHA-256을 확인하고 Git에 포함하지 않는다.
Node 24와 npm lockfile을 사용하고 프론트 테스트·타입 검사·빌드를 루트 `make check`와 CI에 연결한다.

## 임시 정책

이탈 지속 3초/재알림 60초를 기본값으로 하고 UI에서 변경할 수 있게 한다. 품질 불량은 이탈로 추정하지 않는다.
휴식·측정 불가에서 연속 이탈을 끊고 정상 복귀와 구분해 종료한다. 탭 숨김 시 자동 일시정지한다.
긴 스케줄링 공백은 유효 시간으로 계산하지 않는다. 초기 정상 복귀는 즉시 처리하며 복귀 유지시간/히스테리시스는 후속 검증 대상이다.

## 후속 작업

촬영 시점·품질·임계값 검증, 연구용 등록 절차, LSTM 대체, Worker 추론, 생산용 이벤트 계약,
회복·주기 정의 및 서버 연동은 별도 작업이다. 브라우저 내 추론 선택은 최종 서비스 배치 확정이 아니다.
