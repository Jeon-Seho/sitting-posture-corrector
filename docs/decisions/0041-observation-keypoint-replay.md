- 상태: accepted

- 근거: 사용자가 영상 대신 키포인트로 동작을 다시 보고 ML 입력 가능성을 확인하도록 요청함
- 이전: [관측 진행과 CSV](0040-observation-guide-modes.md)

> **2026-10-30 후속:** 새 파일 v3 및 선택형 사이클은 [ADR 0044](0044-optional-stretch-cycles.md)를 따른다. 기존 v1·v2는 계속 읽는다.

> **2026-10-29 후속:** 기록 범위를 원래 인덱스 0..22로 넓힌 `observation-keypoint-replay-v2`와 기준·이탈·스트레칭 프로토콜은 [ADR 0043](0043-base-deviation-stretch-collection.md)을 따른다. 아래 v1 설명은 기존 파일을 읽을 때의 기준이다.

## 범위와 결정

`/dev`의 새 실측부터 카메라가 제공하는 원본 Pose 0..12번의 image/world xyz와
visibility를 약 10Hz로 탭 메모리에 보관한다. 영상·bitmap·Face 좌표·참여자 식별자는 기록하지 않는다.
리플레이는 기준 준비·등록·동작 준비·측정·복귀·수동 대기·일시 정지를 포함한다. 이는 움직임을
확인하는 별도 자료이며 기존 CSV v3의 측정 5초 전용 의미는 유지한다.

이 사용자 요청은 이전 원본 좌표 메모리 전용 경계에 대한 **별도 키포인트 JSON 수동 다운로드 예외**다.
일반 진단 export·서비스·서버·정상 수집·학습 경로에는 섞지 않는다. 자동 저장/업로드·학습은 없다.
실제 파일은 저장소 밖에 보관해야 한다. 기존 CSV만으로 원래 키포인트를 복원하지 않는다.

최대 6,000프레임 이후 추가 기록을 중단하고 미기록 프레임 수를 표시한다. 앞부분은 보존한다.
새 실행·재등록은 이전 재생 자료도 보존 확인하며 확인창에서 CSV와 키포인트 JSON을 받을 수 있다.
카메라 종료는 기록을 보존하고, 화면을 벗어나거나 새로고침하면 메모리는 사라질 수 있다.

## 내부 파일 v1

`observation-keypoint-replay-v1`은 프론트 개발 화면 내부 형식이다. 서비스 전송 계약이 아니다.

- `source`: camera 또는 명시적인 synthetic. 가져온 합성 파일도 실제 기록으로 바꾸지 않는다.
- `runId`, `startedAt`, `protocolId`, `pointIndices`(원래 0..12), `forecastOrder`, `mirrored=false`.
- `labelKind=guided_task_not_ground_truth`, `scope=all_phases_replay_only`.
- `frames`: 실행 시작 대비 실제 수신 `elapsedMs`, 원래 `observationTimeMs`·선택 `videoTimeMs`,
  실제 `width/height`·`poseModelId`, image/world 각각 13점, 안내 `phase/task/round/trial/attempt`,
  `segment`, 측정 구간 여부 `measurement`.
- 결측 점·visibility·시각은 null이며 0으로 보정하지 않는다. 시각 역전 프레임의 좌표도 비운다.
- `markers`: 숨김·관측 중단·종료 시각과 그 직전 프레임 번호. `droppedFrames`는 기록 한도 초과 수.

불러오기는 32MiB·프레임/마커 개수 제한, 버전·시각 순서·좌표 순서·유한 좌표·가시성·해상도·
단계 값 등을 검증하고 선택한 필드만 복사한다. 실패·취소·뒤늦은 파일 응답은 기존 재생을 덮어쓰지 않는다.

## 재생과 학습 해석

별도 리플레이 탭은 측정 종료 시 해당 사이클 JSON 구조를 자동 연결한다. 한 사이클은 기준 등록부터
종료까지의 한 번의 측정이다. 파일 선택/내보내기 없이 바로 재생할 수 있고, 자동 재생은 하지 않는다.
파일 불러오기는 버튼으로 여는 공통 확인 모달에서 파일 한 개를 드롭하거나 선택하고 확인한다.
취소·잘못된 파일·뒤늦은 읽기 응답은 현재 재생을 덮어쓰지 않는다. 파일 보기 중에도 측정 사이클
버튼으로 현재 측정에 돌아갈 수 있다. 새 측정을 시작하면 플레이어를 비우고 종료 시 새 기록을 연결한다.
현재 사이클 또는 불러온 파일에서 재생/일시정지·0.25/0.5/1/2배·
탐색·프레임 이동을 제공한다. 실제 관측/안내/CSV 함수를 호출하지 않는다. 실측 중에는
재생·파일 선택·내보내기 조작을 잠근다. 탭 숨김·도구 닫기·다른 탭 이동 시 재생을 멈춘다.

화면 좌표는 기존 미리보기와 같은 좌우 반전으로만 표시한다. 누락·중단 마커·500ms 초과 공백을
빈 구간으로 보여주고 선형 보간/이전 자세 복제/추적 평활화를 하지 않는다.
별도 ML 입력 정면(x/y)·측면(z/y) 도식은 기존 39D 변환 결과를 원래 점 번호에 대응해 표시한다.
영상으로의 실제 투영이나 측정된 신체 깊이가 아니며, 변환 불가 프레임은 도식도 비운다.

2D 유효 프레임 수와 기존 `liveForecastPoints`의 어깨 중심·폭 정규화 39D 변환 가능 개수를
입력 점검용으로 보여준다. 추출기 미상·낮은 품질을 학습 준비 완료로 표시하지 않는다.
변환 가능 수는 연속 학습 창·수행 정답·정상성·분류 가능성·모델 정확도의 검증 결과가 아니다.
JSON은 기존 학습기 형식과 다르며 라벨 검토·참여자/회차 분할·호환 변환이 필요하다.
[판정 한계](../ml/measurement-limits.md)와 본 수집/학습 보류 결정도 변경하지 않는다.
