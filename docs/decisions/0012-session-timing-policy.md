# ADR 0012: 세션 시간 정책 확정

- 분야: 백엔드
- 작업: GP-0105
- 상태: accepted (사용자 재확인)
- 날짜: 2026-10-01
- 관련 결정: [API·CEP 경계](0011-api-cep-boundary.md), [로컬 통합](0003-retro-integration.md)

## 배경과 근거

기존 프론트와 CEP는 최초 알림 3초, 정상 복귀 2초, 같은 사건 재알림 60초와
중단 후 새 사건을 구현했다. 문서에는 복귀 시간과 휴식 처리 방식이 미결정으로 남아 있었다.
사용자가 기존 결정을 재확인하여 아래 정책을 확정했다. 기존 구현과 전송 형식을 보존한다.
이 결정은 제품 요구이며 실기기 탐지 성능·최적 임계값·의료 효과를 증명하지 않는다.

## 확정 정책

| 항목 | 정책 |
| --- | --- |
| 최초 알림 | 유효한 이탈 관측이 연속 3초 지속되면 사건을 확정하고 첫 알림을 결정한다. |
| 정상 복귀 | 열린 사건에서 유효한 정상 관측이 연속 2초 지속되면 복귀를 확정한다. 그 전에 다시 이탈하면 복귀 누적을 초기화한다. |
| 재알림 | 같은 사건의 마지막 알림부터 60초 후, 이탈 관측이 계속되면 다시 알린다. 재알림은 새 사건이 아니다. |
| 휴식 후 재개 | 열린 사건은 복귀와 구분하여 중단하고 연속 이탈·복귀 누적을 초기화한다. 재개 후 이탈이 지속되면 새 사건을 만든다. |
| 자리 비움·측정 불가·누락 | 연속 판정을 끊고 열린 사건을 중단한다. 제외 시간을 정상이나 이탈 관측으로 보충하지 않는다. |
| 통계 | 휴식·자리 비움·측정 불가·누락은 유효 시간, 정상/이탈 누적, 유지율 분모 및 사건 간격의 유효 시간에서 제외한다. 전체 경과 시간과 제외 시간은 별도 표시할 수 있다. |
| 설정 적용 | 3초·2초·60초는 기본값이다. 기존 사용자 설정 기능을 유지하며, 세션 시작 시 설정을 고정한다. 이후 변경은 다음에 새로 시작하는 세션부터 적용한다. 휴식 재개·중간 저장 복구는 새 세션이 아니다. |

새 사건의 첫 알림에는 이전 사건의 60초 간격을 적용하지 않는다.
중단을 정상 복귀로 기록하거나 휴식 전후의 이탈 시간을 합쳐 최초 알림 조건을 채우지 않는다.
수동 측정 재개, 저장 실패 재시도와 알림 전달 방식은 기존 요구사항을 유지한다.

## 합성 예시

- 이탈 2초 → 휴식 → 이탈 1초: 알림 없음. 재개 후 연속 3초를 채워야 새 사건이 확정된다.
- 첫 알림 → 정상 1.5초 → 다시 이탈: 복귀 미확정, 같은 사건 유지.
- 첫 알림 → 정상 연속 2초 → 이탈 연속 3초: 이전 사건 복귀 후 새 사건의 첫 알림.
- 같은 사건의 첫 알림이 세션 3초 시점이면, 이탈이 계속될 때 63초 시점에 재알림.
- 이탈 중 측정 불가 또는 인식된 관측 공백: 연속 판정 중단. 해당 시간은 유효 통계에서 제외하고 이후 새로 누적.
- 측정 중 지속시간 설정 변경 → 휴식·재개: 기존 세션 설정 유지. 새 측정 시작 시 변경값 적용.

## 구현과 호환성

- 로컬 모드: `frontend/src/features/session/engine/`의 기존 상태 기계와 세션 설정 스냅샷을 사용한다.
- 서버 모드: CEP가 시간 조건을 판정하고 API는 설정 고정·전달·저장·조회를 담당한다.
- 기존 정책 식별자 `legacy-interrupt-v1`을 유지한다. 이름은 호환성을 위한 것으로, 미승인 정책을 뜻하지 않는다.
- 관측 v2·사건 v1·조회 v1의 구조와 기본값을 변경하지 않는다. 새 테스트용 실제 데이터도 추가하지 않는다.
- 알림 결정과 실제 화면 표시·소리 재생 성공은 구분한다.

## 남은 결정과 검증

실제 입력의 특징 정의·단위·정규화·좌우 방향·카메라 시점, 품질 게이트와 점수 임계값,
프레임의 관측 구간 및 공백 인식 기준은 이번 시간 정책 승인으로 확정하지 않는다.
현행 로컬 모드의 프레임 유효기간 1초와 입력/스케줄링 공백 1.5초 기준은 기존 구현값이며 별도 검증이 필요하다.
실제 카메라 정확도·알림 지연·백그라운드 동작·소리 전달은 기기 검증에서 확인한다.
검증 기록은 [완료 계획](../plans/completed/0013-session-timing-policy-doc-sync.md)에 남긴다.
