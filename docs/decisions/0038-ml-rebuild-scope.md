# ADR 0038 개인 파일럿 ML 재설계 범위

- 날짜: 2026-10-15
- 상태: 계획 방향 채택. 새 수집·학습·평가 구현과 실제 성능 검증은 미완료.
- 근거: 사용자 요청 — 서비스 FE·BE는 유지하고 ML만 새로 설계한다. 본인 한 명부터 시작하며 학교 장비는 i7-8700 추정·RAM 16GB·GTX 1050급이다.
- 상세: [판정 한계](../ml/measurement-limits.md), [ML 재설계](../ml/rebuild-plan.md), [실행 계획 0052](../plans/active/0052-ml-rebuild.md).

## 문제

기존 `/dev`는 정상 자료·미래 좌표 회귀를 비교하는 연구 경로다. 일반 수집의 CSV v3,
기존 CSV v2 준비 도구, 새 정상 JSON 학습이 하나의 수집·평가 경로로 이어지지 않는다.
좌표 오차만으로 서비스의 지속 이탈 검출·오알림·놓침을 판단할 수 없다.
서비스와 ML을 함께 다시 쓰기보다 ML 목표·자료·평가부터 독립적으로 정리해야 한다.
사용자는 정면 어깨 위 관측에서 기준 형태를 유지한 이동을 놓쳤다고 보고했고,
수집보다 불가능한 판정의 경계를 먼저 정하도록 방향을 수정했다. 이 보고를 정량 정확도로 취급하지 않는다.

## 결정

1. 수집·학습보다 정면 어깨 위 관측의 지원 현상·제외 상태·모호성을 먼저 정의한다.
   전신의 정상·비정상, 숨은 몸통·골반·척추 상태와 정면에서 모호한 앞뒤 자세를 보장 대상으로 삼지 않는다.
   등록 기준은 올바른 자세의 정답이 아니다. 지원하는 2D 형태 변화와 영상상 배치 변화를 구분하는 안부터 확인한다.
   미래 좌표 회귀·미래 붕괴 시각 예측·의료적 자세 판정은 제외한다.
2. 서비스 FE·BE·시간 엔진·공개 계약·인프라 설정은 변경하지 않는다.
   연구 전용 수집과 ML 파이프라인을 새 경로로 설계하며 기존 실험 코드의 이관을 강제하지 않는다.
3. 본인 한 명의 시작은 개인 파일럿이다. 촬영일 단위 학습·검증·시험을 분리하되 새 사용자 평가로 보고하지 않는다.
   참여자 평가 모드의 참여자 분리·시험 이탈 자료 fitting 금지는 유지한다.
4. CPU로 끝나는 파이프라인을 먼저 만든다. GTX 1050 가속·훈련 시간·추적 FPS는 장비 실측 후 판단한다.
   장비가 분리돼도 동급 사양임을 전제로 적재·집계와 학습의 동시 부하를 피한다.
5. 사람의 실제 수행 라벨을 룰·예측·과제 안내 시각과 분리한다.
   혼자 표시한 구간은 자기 보고이며 독립 관찰자의 정답으로 취급하지 않는다.
6. L0 한계 정의·G0 반례 확인을 통과하기 전에는 본 수집과 학습을 시작하지 않는다.
   단순 측정·규칙 B0부터 검토하고 충분하면 종료한다. B1은 구별할 라벨과 규칙의 실패가 설명될 때만 검토한다.
   LSTM M2는 기본 후보에서 보류한다. 시간 이력의 필요성과 고정 평가 이득을 확인할 경우에만 추가한다.
7. 기존 3특징 추론 계약과 목표 9점 좌표 계약을 구별한다.
   현재 요청에 없는 좌표·측정 세션 이력을 ML 서버가 추정하지 않는다. 시퀀스 모델의 서비스 연결은 후속 버전 계약과 통합 검증 대상이다.
8. 팔꿈치 필수화는 보류한다. 추가 관측이 명시한 목표의 모호성을 실제로 줄이는지 먼저 확인한다.
   어깨 위 제약과 필요한 판정이 양립하지 않으면 목표 또는 관측 조건을 바꾸며 학습으로 관측 공백을 덮지 않는다.
   낮은 품질의 `unmeasurable`과 판정 대상에서 제외한 신체 상태를 구별한다.

## 기존 결정과의 관계

ADR 0028~0037의 `/dev` 실행 동작과 과거 산출물 의미를 소급 변경하지 않는다.
새 ML 계획에는 그 실험들의 정상 선별·미래 회귀·세계 좌표 정의를 자동 승계하지 않는다.
ADR 0024의 버전 있는 경계와 ADR 0012의 시간 정책은 유지한다.
소형 LSTM 구조·CPU 예산·75분 촬영안은 한계 확인 이후 재검토할 조건부 참고안이며 검증된 최적값이나 현재 실행 지시가 아니다.

## 본 수집 전에 결정할 내용

- 실제 장비와 모델 실행 delegate, 구도·추출기·SDK·점 순서·영상 반전.
- 관측 가능한 목표 변화와 카메라 이동 처리, 품질·누락·라벨 불확실성의 경계.
- 기준 등록과 촬영일 배정, 목표 데이터 양, 후보 수와 검증 선택 규칙.
- 허용 오알림·놓침·추가 지연, 사건 대응·분모·기권의 계산 규칙.
- 자료 저장 위치와 실제 데이터 관리 절차. 기존 연구 프로토콜을 유지한다.

이 항목은 L0 명세·G0 관측 확인과 본 수집 전 명세 동결로 확정한다. 현재 실제 관측 확인은 미실행이다.
최종 시험 결과에 맞춰 소급하지 않는다.

## 결과

서비스 개발을 함께 재작성하지 않고 ML의 관측 한계를 먼저 확인한다.
단순한 기준 변화 측정만 남거나 필요한 기능을 제외하는 결과도 허용한다.
현재 서비스 입력이 제한하므로 좌표·시퀀스 모델의 연구 성공이 서비스 연결 완료를 의미하지 않는다.
한 명의 회차 평가로는 타인 일반화나 교정 효과를 주장할 수 없다.
