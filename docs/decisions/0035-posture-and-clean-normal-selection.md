# 0035: 몸 변화 허용폭 조정과 보수적인 자동 정상 선별

- 날짜: 2026-10-15
- 상태: 채택 (`/dev` 개발 조정, 실제 정확도 미검증)
- 관련: [영상 기준 v1](0034-fixed-image-posture-anchor.md), [실행·검증 계획](../plans/completed/0049-posture-and-auto-selection-tuning.md)

## 관찰과 선택

사용자 화면에서 공통 이동 20.9%가 허용폭 45%의 0.46배로 표시됐고, 사용자는 큰 이탈을 정상 범위로 보는 문제를 보고했다.
이는 개발 조정 근거이며 독립 시험 참여자 자료나 정확도 측정이 아니다. 기존 평가 전용 촬영 자료를 튜닝에 사용하지 않는다.

새 영상 정책을 `image-posture-anchor-v2`로 구분한다. 공통 이동 하한을 **0.45→0.18 등록 어깨폭**, 축소 하한을 **0.20→0.12**로 바꾼다.
예를 들어 같은 0.209 이동에 하한 0.18이 적용되면 약 1.16배다. 등록 변동 q95×1.5가 하한보다 크면 여전히 허용폭을 넓힌다.
작은 움직임 허용을 위해 기존 등록 중앙값 고정·200ms 평활화·3초 지속·3초 복귀·히스테리시스를 유지한다. 알림 소리는 계속 기본 꺼짐이다.
이전 측정에 새 임계값을 소급하지 않으며 UI에 이전 기준임을 표시하고 새 측정을 요구한다.

## 자동 정상 후보의 별도 경계

알림 경계 안에 있다고 바로 정상 자료로 쓰지 않는다. 새 실행의 `auto-normal-clean-v1` 선별은 다음을 **모두** 요구한다.

- 현재 상대 거리 ≤ 선택값 (기본 6%, 기존 0.5/3/6% 선택 유지).
- 유효한 영상 v2와 종합 점수 ≤ **0.5배**, 실측 `ruleState=near_reference`.
- 같은 실행·등록·추출기·참여자·선택값에서 이 조건을 **실측 1초 연속** 충족. 확인 전 프레임은 소급 저장하지 않는다.
- 기존 13점 품질·실제 시각·250ms 관측 간격·최대 10Hz 조건 유지.

기준 밖·품질 누락·관측 간격·일시정지·백그라운드·등록/선택 변경은 확인 시간을 끊고 저장 구간을 분리한다.
이탈 확인·지속 이탈·복귀 확인 중에는 점수가 작아도 수집하지 않는다. LSTM 준비 상태는 실측 룰이 유효한 정상 후보를 막지 않는다.
원본 좌표와 39차원 LSTM 입력을 바꾸거나 평활화하지 않는다. 선별된 약라벨은 여전히 의료적 정상/독립 평가 정답이 아니다.

## 출처와 이전 자료 보존

행에는 `selectionPolicy`, `postureScore`, `stableForMs`, `imagePosturePolicy`, `imagePostureScore`를 기록한다.
데이터셋의 선택 `cleanGate`는 적용 경계·정책을 명시한다. Python 학습 준비기는 이 확장에 맞는 행의 값과 정책을 검사한다.
새 선별 출처가 없는 보존 행이 섞인 내보내기는 `reviewGate.status=requires_review`, `trainingAllowed=false`를 포함하며 전체 파일의 학습을 차단한다.
이전 행을 새 선별을 통과한 것으로 다시 표시하거나 새 모델에 자동 적용하지 않는다. UI는 재검토 필요 행 수와 표시를 제공한다.

사용자 요청으로 기존 자동 613행은 저장소 밖에 원래 행·기준·시각·약라벨을 유지한 채 재검토/학습 차단 메타데이터를 추가해 보존했다.
원본 행의 SHA-256 동일성을 확인했으며 로컬 학습 준비기가 창 생성 전에 차단하는 것을 점검했다. 새 수집·검토가 완료된 자료로 자동 대체하지 않는다.

## 한계와 후속

이번 하한은 한 관찰을 반영한 개발 설정이며 개인·카메라별 오탐률이나 실제 기대기/눕기 정확도를 검증한 값이 아니다.
고정 카메라와 올바른 등록, 얼굴·어깨 가시성이 필요하다. 영상 이동/축소는 카메라 이동·줌·의자 이동·큰 회전과 구분할 수 없다.
실제 테스트는 새 기준 등록 후 편하게 앉기→작은 움직임→기울여 5초→복귀로 확인하며 별도 결과로 기록한다. 학습 재실행은 하지 않는다.
