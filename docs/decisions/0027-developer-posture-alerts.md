# ADR 0027: 개발자 실험의 이탈 알림 전달

- 날짜: 2026-10-13
- 상태: `/dev`에 한정해 채택

## 배경과 결정

사용자가 실제 카메라와 모델·룰을 비교하며 이탈 정도를 알림으로 확인하고, 스트레칭과 지속 변화의
구분 기준을 알고 싶다고 요청했다. [ADR 0025](0025-local-forecast-experiment.md)의 코어 판정은
유지하고 알림 전달과 근거 표시만 별도 개발자 모듈에 추가한다. 기본은 선택한 예측+룰 상태이며,
실행 전에 룰 상태만 전달하도록 선택할 수 있다. 실행 중 기준 변경으로 사건을 재해석하지 않는다.

알림은 유효한 `persistent_deviation_candidate`에서 최초 한 번 전달하고, 같은 사건이 계속되면
60초마다 재알림한다. 60초는 매 프레임 반복음과 알림 피로를 줄이기 위한 **개발 체험용 전달 간격**이다.
자세의 정상성·위험도·연구 성능을 검증한 임계값이 아니며 서비스로 자동 승격하지 않는다.
복귀 확인 중 반등은 같은 사건이다. 기준 범위 복귀 완료 또는 관측 품질·시간 연속성 단절에서
사건을 닫으며, 관측 단절을 정상 복귀라고 해석하지 않는다. 예측 대응만 빠진 `warming`에서는
전달을 억제하되 관측과 코어 룰의 사건이 유지되면 기존 알림 상태를 보존해 중복 최초 알림을 막는다.

브라우저 내장 Web Audio를 사용해 추가 패키지와 외부 오디오 파일 없이 짧은 2음을 만든다.
시작·소리 켜기·테스트 클릭에서만 컨텍스트를 준비하고, 프레임·타이머에서는 자동 재개하지 않는다.
음소거·종료·탭 숨김은 예약음을 취소하며 컴포넌트 해제는 컨텍스트를 닫는다.
오디오 미지원·차단에도 시각 표시와 기록은 유지한다. OS 알림 권한과 백그라운드 알림은 추가하지 않는다.

## 표시·기록과 한계

카메라 안내 영역에서도 현재 알림과 거리·시간을 보여주고, 아래에 거리 기준의 배수·이번 변화의
최대 거리·예측 오차·개인 한계·전체 알림 횟수·현재 기준표를 표시한다. 거리 %는 어깨폭으로
정규화한 3D 좌표 차이이며 자세가 나쁜 정도나 정확도 %가 아니다. 시각 알림의 라이브 영역에는
알림 시점의 고정 스냅샷만 넣어 매 프레임 읽기를 방지한다.

LSTM은 좌표 예측 모델이며 동작의 의도를 분류하지 않는다. 높은 오차만으로 스트레칭이라고
확정하지 않고 복귀를 관찰한다. 오래 유지한 의도적인 스트레칭도 지속 이탈 후보로 알릴 수 있다.
행동 분류에는 실제 의도 라벨·참여자 단위 검증이 별도로 필요하다.

최근 100개 스냅샷과 전체 알림 수를 탭 메모리에 보관하며 수동 진단 JSON은
[명시적 필드](../../contracts/developer-lab-export.v1.md)만 내보낸다. 영상·원본 좌표·개인 기준·
모델 가중치·오디오 객체는 기록하지 않는다. 소리 테스트는 자세 알림 횟수에 포함하지 않는다.
