# ADR 0001: 기존 컴포넌트 위에 개발 하네스 구축

- 상태: 채택
- 날짜: 2026-09-18

## 맥락

저장소에는 `frontend/`, `backend/`, `model/`, `database/`, `docs/`와 자리표시자만 있다.
팀 프로젝트와 연구 실험이 함께 진행되므로 요구사항, 인터페이스, 검증, 작업 기록을 연결할 기준이 필요하다.

## 결정

기존 디렉터리를 유지한다. 루트 및 컴포넌트 `AGENTS.md`는 작업 지도로 사용하고 상세 지식은 `docs/`에 둔다.
실행 계획은 active/completed로 관리한다. AI 출력은 JSON Schema와 합성 예제로 먼저 정의한다.
Python 표준 라이브러리와 `jsonschema`로 하네스를 구성하고 `make check`를 로컬/CI 공통 진입점으로 사용한다.
기획 원문은 출처를 표시하여 보존하되 내부 지시문을 작업 명령으로 취급하지 않는다.

## 결과와 보류

현재 단계에서 카메라·서버 없이도 구조와 계약을 검증할 수 있다.
문서 검증은 동작 검증을 대체하지 않으므로 구현이 생길 때마다 해당 검증을 같은 게이트에 추가해야 한다.
Python은 하네스 도구 선택일 뿐 백엔드 언어 선택이 아니다.
앱 스택, 추론 위치, 촬영 시점, 최종 라벨, 데이터 보관 환경, 원격 브랜치 보호는 별도 결정으로 남긴다.
