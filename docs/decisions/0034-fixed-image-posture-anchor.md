# 0034: 등록 영상에 고정한 몸 전체 변화 보완

- 날짜: 2026-10-15
- 상태: 채택 (`/dev` 실험)
- 관련: [숫자 진단의 정규화 공백](0033-live-decision-numbers.md), [정상 범위와 학습 연결](0032-normal-reference-and-mediapipe-training.md)

현재 새 실행의 하한과 자동 수집 경계는 후속 [ADR 0035 영상 v2/정상 선별](0035-posture-and-clean-normal-selection.md)을 따른다. 아래 45%/20%는 초기 v1 결정의 이력이다.

## 문제와 선택

사용자는 작은 움직임에는 덜 민감해졌으나 상대 모양을 유지하며 뒤로 기대거나 눕는 큰 변화가 감지되지 않는다고 보고했다.
현재 world 어깨 중심·폭 정규화는 전체 이동과 균일 크기를 제거한다. 13점과 39차원 학습 입력은 그대로 두고,
동일 관측의 image 좌표에서 등록 때 고정한 얼굴·어깨 위치와 어깨폭을 비교하는 별도 연구 경로를 추가한다.
SDK·공통 카메라·일반 서비스는 바꾸지 않으며 33점 또는 영상 저장을 도입하지 않는다.

## 특징과 개발 설정

- 8초·실측 65표본 등록에서 얼굴 11점 중심, 양어깨 중심, 영상 어깨폭, 종횡비의 중앙값을 고정한다.
- 두 중심의 변위 방향이 비슷할 때만 더 작은 변위 크기를 공통 이동으로 쓴다. 고개만 움직이거나 서로 반대로 움직이면 공통 이동으로 합치지 않는다.
- 변위는 **등록 당시 영상 어깨폭** 단위다. 현재 어깨폭으로 다시 나눠 큰 움직임을 제거하지 않는다.
- 축소는 `max(0, 1 − 현재 영상 어깨폭 / 등록 영상 어깨폭)`이다. 카메라와의 실제 거리나 기대는 각도가 아니다.
- 허용폭은 공통 이동 0.45 등록 어깨폭, 축소 0.20 중 각 개발 하한과 등록 변동 q95×1.5의 큰 값이다.
  이 값은 작은 움직임을 허용하기 위한 실험 시작 설정이며 실제 임계값 검증 결과가 아니다.
- 연속 관측에서만 200ms 시간상수로 두 신호를 평활화한다. 원본 수집·LSTM 입력에는 적용하지 않는다.
- 몸 전체 점수는 두 `변화/허용폭`의 최댓값이다. 종합 점수는 상대 자세 점수와 몸 전체 점수 중 큰 값이다.
  개인 프로파일이 없는 상대 점수는 기존 정규화 거리/0.12다. 기존 `normalScore`와 `deviation`의 의미를 바꾸지 않는다.
- 종합 점수 **>1** 진입, **≤2/3** 복귀와 기존 이탈 3초·복귀 3초·재알림 60초를 유지한다. 예측 비교 경로는 기존 3초+낮은 잔차/최대 5초 조건을 사용한다.

## 품질·자료·표시

매 실제 관측의 유효한 13점과 영상 크기가 필요하다. 가림·누락은 정상이나 이탈로 채우지 않고 타이머와 필터를 끊는다.
종횡비가 달라지면 측정 불가로 잠그고 새 등록을 요구한다. 같은 종횡비의 해상도 변경은 정규화 영상 좌표로 비교할 수 있다.
기준은 현재 관측으로 자동 이동시키지 않고 새 등록 때만 바꾼다. 합성 데모는 같은 보완 경로를 사용하지만 실제 관측과 구분한다.

화면은 상대 모양/몸 전체/종합 점수와 두 실측 변화·허용폭을 나눠 표시한다. 그래프·알림의 주 수치는 종합 점수다.
알림 스냅샷은 종합 점수·몸 전체 원인·최고 종합 점수를 복사한다. 기존 상대 거리 0도 그대로 보존하여 의미를 숨기지 않는다.
원본 영상 기준은 메모리 전용이고 진단 export에는 허용된 숫자만 넣는다. 자동 정상 후보는 몸 전체 점수 >1 또는 측정 불가를 제외하고,
저장 행에 적용 정책/몸 전체 점수를 선택 필드로 기록한다. 39차원 학습 특징과 정상 프로파일 형식은 그대로다.
알림 소리 기본 꺼짐과 사용자의 음소거 선택을 유지한다.

## 한계와 검증

고정 카메라와 올바른 시작 등록을 전제로 한다. 카메라 이동·줌, 의자 이동, 큰 상체 회전으로 인한 영상 축소도 영향을 줄 수 있다.
13점만으로 골반·등 전체, 실제 기대는 각도, 행동 의도나 의료적 정상성을 판정하지 않는다. 얼굴/어깨가 사라지면 측정 불가다.
이번 변경의 효과는 합성 이동·축소·고개만 움직임·누락·복귀 검증과 실제 카메라 시험을 구분해 기록한다.
