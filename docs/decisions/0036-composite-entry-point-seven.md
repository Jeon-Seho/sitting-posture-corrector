# 0036: 사용자 지정 종합 이탈 경계 0.7배

- 날짜: 2026-10-15
- 상태: 채택 (`/dev` 개발 지정, 정확도 미검증)
- 관련: [영상 v2와 자동 선별](0035-posture-and-clean-normal-selection.md), [작업·검증 기록](../plans/completed/0050-posture-entry-point-seven.md)

사용자가 기존 1배 기준이 후하므로 `배수를 0.7%`로 요청했다. 기존 화면의 배수에 맞춰 **0.7배**로 해석한다고 먼저 알리고 구현했다.
이는 0.007배·화면 픽셀 0.7%·건강 점수나 확률을 뜻하지 않는다.

새 `/dev` 종합 점수는 기존 등록 허용폭 단위를 유지하고 **>0.7배 진입**으로 변경한다.
복귀는 진입의 2/3인 **≤0.466666…배**로 낮춰 진입 바로 아래의 흔들림으로 사건이 반복되지 않게 한다.
이탈/복귀 3초·예측 보조의 3초+잔차/최대5초·60초 재알림·무음·품질 누락 차단은 유지한다.
실제 관찰 중 진입 후 중간 띠에서도 타이머가 진행되어 알림 순간 0.58배인 사건을 확인했다.
새 `/dev`에서는 알림 전 >0.7배 연속 구간만 누적하고, 이하가 되면 진입 타이머를 끊는다.
지속 이탈이 확정된 뒤에만 낮은 복귀 경계를 사용하며, 복귀 확인 중 다시 약0.467배를 초과하면 복귀 3초도 재시작한다.
기존 무옵션 정책의 히스테리시스 동작은 유지한다.
영상 보완 하한 18% 이동·12% 축소도 그대로다. 실제 하한 적용 시 이탈은 각각 12.6% 이동·8.4% 축소에 대응한다.
등록 변동으로 허용폭을 넓힌 경우는 현재 출력 허용폭으로 계산한다. 상대 거리의 12% 단위도 유지하므로 개인 프로파일 없는 상대 분기 진입은 8.4% 초과에 대응한다.

`postureEntryRatio`, `postureRecoveryRatio`를 종합 reading·알림 스냅샷·자동 후보 행에 기록한다.
세션 export에는 `composite_entry_ratio`, `composite_recovery_ratio`를 선택 설정으로 제공한다.
필드가 없는 이전 자료는 1배/2⁄3배로 표시하며 소급하지 않는다. 무옵션/기존 예측 경로는 변경하지 않는다.
숫자·게이지·그래프·비교·조건은 실제 출력 경계를 읽는다. 새 종합 판정의 상대 거리 참고값에 과거 12% 진입 게이지를 표시하지 않는다.

자동 후보의 상대 거리 선택·종합0.5배·실측 룰 범위 안·실측1초는 유지한다. 복귀 확인 전에는 후보를 모으지 않는다.
39차원 입력·가중치·개인 정상 중심·이전 수집/평가 파일을 변경하거나 재학습하지 않는다.
이 값은 사용자 지정 개발 기준이며 정탐/오탐률을 검증한 임계값이 아니다. 실제 관찰과 합성 회귀를 구분한다.
