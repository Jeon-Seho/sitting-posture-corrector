# ADR 0029: 자동 정상 후보 수집과 실제 예측 좌표 표시

- 날짜: 2026-10-14
- 상태: `/dev` 초기 실험에 한정해 채택. 실제 정상성·정확도는 미검증.
- 관련: [현재 ML 계획](../ml/current-plan.md), [HTML](../ml/current-plan.html), [ADR 0028](0028-normal-only-developer-model.md)

## 배경

사용자는 등록 자세와의 오차 0.5% 이하인 관측에 `정상자세(자동)` 라벨을 붙여 자동으로 행을 쌓고,
별도로 `30초 측정하기` 버튼에서 직접 정상 구간을 촬영하기를 요청했다. 또한 기존 카메라 점선과 화살표가
미래 예측인지 기준 대비 변화인지 구분하기 어려웠다. 현재 LSTM은 얼굴·귀·어깨를 포함한 13점의
미래 xyz를 예측하지만 화면의 기준 윤곽은 예측 좌표를 표시하지 않았다.

## 결정

1. 실제 카메라 측정의 기준 등록 이후 자동 수집을 기본 활성화한다. 원본 유효 관측의 기준 거리
   `deviation ≤ 0.005`를 만족하면 최대 10Hz로 새 행을 추가한다. 경계에 진입할 때 한 번만 저장하지 않는다.
   사용자는 수집을 일시정지하고 모은 자료를 따로 다운로드하거나 삭제할 수 있다.
2. 0.5%는 **현재 어깨폭으로 정규화한 기준 대비 3D 그룹 평균 거리**다. 얼굴 9점·귀 2점·어깨 2점의
   각 평균 거리를 구한 뒤 세 그룹을 같은 비중으로 평균한다. 화면 픽셀 오차, LSTM 잔차, 개인 정상 점수와 구분한다.
   이 값은 사용자가 정한 초기 실험 선별 기준이며 정확도나 인간공학 근거에서 산출한 허용 범위가 아니다.
3. 화면 라벨은 `정상자세(자동)`으로 표시하고 원본 파일에 규칙 기반 약라벨 출처를 기록한다.
   사용자가 촬영 뒤 확인한 `정상자세(수동)`과 분리한다. 자동 자료를 독립 평가의 정상 정답으로 쓰지 않는다.
4. 자동 자료를 개인 정상 범위 fitting·실시간 기준 갱신에 자동 사용하지 않는다. 자동 수집은 별도
   초기 연구 자료 export이며, 개인 범위는 기존의 수동 확인 경로를 유지한다.
5. 자동 수집 행은 실제 시각·구간 ID·기준 출처를 가진다. 기준 밖·품질 실패·250ms 초과 누락·중단은
   구간을 끊는다. 떨어진 정상 행을 붙이거나 보간하여 연속 미래 예측 학습 창으로 만들지 않는다.
   최대 6,000행에 도달하면 수집을 멈추고 기존 행을 유지한다.
6. 수동 수집은 준비 3초 뒤 유효 관측 30초를 모은다. 가림을 제외하므로 실제 촬영은 더 걸릴 수 있으며
   기존 최대 2분·최소 100표본 조건을 유지한다. 확인 후 개인 등록용만 적용하고 학습용은 따로 내려받는다.
7. LSTM의 실제 입력 끝 좌표와 300ms 미래 예측을 별도 도식에 표시한다. 13점×3축 출력 전체를
   사용하며 기준 대비 룰 값을 미래 위치로 변환하지 않는다. 위치 유지·등속 비교군을 선택하면 해당 이름을 표시한다.
8. 예측 도식은 어깨 중심·폭으로 정규화한 world 좌표의 정면/측면 투영이다. 카메라 영상의 픽셀 좌표가
   아니므로 영상 위의 실제 미래 위치라고 표시하지 않는다. 추적 실패·시간 단절·세션 중단·오래된 예측은 숨긴다.

## 경계와 해석

자동·수동 자료는 브라우저 메모리에만 두며 각각의 명시적 다운로드에만 좌표를 포함한다.
자동 업로드·영구 저장·영상 기록은 추가하지 않는다. 일반 진단 내보내기와 서비스 앱의 수집/라벨 계약은 유지한다.
이 결정은 [개발자 모듈](../../frontend/src/features/developer/README.md)의 자동 수집 금지 조항을
사용자가 요청한 `/dev` 초기 실험에 한해 대체한다. 일반 서비스로 자동 승격하지 않는다.

0.5% 이내 선별은 매우 좁은 기준 부근 자료만 남긴다. 이 자료만으로 자연스러운 정상 자세의 변동 폭을
학습하거나 지속 이탈의 놓침을 평가할 수 없다. 규칙을 학습 라벨과 평가 정답 양쪽에 사용하면 규칙을
재현한 결과를 모델 성능으로 오해하게 된다. 수동 구간과 독립 평가 라벨을 계속 확보하고 참여자 분할을 먼저 한다.

LSTM은 자기지도 좌표 회귀이며 정상/비정상 분류기가 아니다. 실제 13점 예측을 표시한다고 예측 성능이
개선된 것은 아니다. 기존 Panoptic와 MediaPipe의 점 정의·축 대응은 근사이며 `domainValidated=false`다.
예측이 안정적이어도 기준 밖 상태가 지속되면 룰/개인 범위의 알림 후보를 유지한다.
