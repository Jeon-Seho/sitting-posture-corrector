# ADR 0024: 로컬 개발과 서버 연결 경계

- 상태: accepted (개발 방향. 새 전송 계약·모델 도입은 후속 구현)
- 날짜: 2026-10-12
- 근거: 사용자 요청 — 로컬에서 먼저 개발하되 서버에 연결할 수 있게 개발한다.

## 결정

현재 작업은 로컬에서 기준 등록·자료 수집·특징·판정을 개발하고 검증한다.
MediaPipe Pose Heavy와 어깨 포함 머리 13점 범위를 유지한다. Face Landmarker는 후속 비교 실험이다.
서버 전환 준비를 처음부터 포함하며, 로컬 개발 우선이 서버 연결 경계를 생략한다는 뜻은 아니다.
FE의 서버 전용 배포 계획과 현재 ML 개발 경로를 구분한다. 현재 로컬 개발 경로를 서버 준비 때문에 제거하지 않는다.

카메라/MediaPipe → 원본 관측 → 품질·기준 비교·특징·추론 → 버전 있는 결과 → 시간 정책 → UI로 책임을 나눈다.
카메라·표시·자료 저장과 모델 코어를 분리한다. 로컬 어댑터는 모델 코어를 호출하고,
서버 어댑터는 계약으로 요청·결과를 전달한다. UI는 동일 의미의 결과를 소비한다.
서버 경로의 시간 정책은 CEP가 소유하며 추론 서비스에 중복 구현하지 않는다.

두 실행 경로에서 기준 ID·관측 시각·입력 범위/순서·좌우 반전·품질/누락·특징 버전·모델 버전을 맞춘다.
같은 합성 관측과 기준에서 특징·추론 출력 및 시간 정책 결과가 일치하는지 경계별로 검증한다.
다른 언어/런타임으로 옮기더라도 명세·가중치·공유 합성 사례를 기준으로 출력 차이를 확인한다.
서버가 필요로 하는 상태·순서·등록·재연결 경계까지 준비해야 전환 완료로 판단한다.

기존 입력 v2는 세 특징 변화량과 품질용이다. 새 13점 관측이나 시계열 특징을 기존 계약에 추가하지 않는다.
프론트의 13점 원본 보존과 FE 서버 제안의 9점 전송은 서로 다른 범위이며 전송 시 점 선택을 명시해야 한다.
서버 전송 자료·기준 등록 방식·새 버전은 구현 전에 합의하고 계약/예제/생산자/소비자를 함께 갱신한다.
현재 모듈 분리 및 기존 서버 모드는 연결 준비의 일부이며 새 모델을 즉시 서버에 전환하는 기능이 완성된 상태는 아니다.

## 테스트 브랜치와 서버 사양 검토

참고 브랜치는 test_0.2.3, c03ce8d다. Pose Lite + Face Landmarker와 별도 시간 CNN을 사용한다.
자체 CNN은 40×26 입력, Conv1d 26→24→24→24, kernel 3, 자세 4/행동 5 출력이다.
소스 구조로 계산한 파라미터는 5,625개, 순수 float32 가중치 환산은 22,500바이트다.
JavaScript의 40프레임 추론 구조에 대한 곱셈-누산 상한 근사는 창당 213,336회다.
이는 코드 구조 계산이며 실제 지연·메모리·처리량 측정값이 아니다. JSON·런타임·추적기의 비용은 별도다.

사용자가 제시한 서버는 i7-8700 / RAM 16GB / GTX 1050이다.
위 크기의 추론은 CPU부터 검증할 대상으로 둔다. GPU 사용·동시 사용자 용량·학습 시간은 확정하지 않는다.
클라이언트가 MediaPipe를 실행하면 서버에는 키포인트/특징 처리와 자체 모델 추론이 들어간다.
CPU 지연·동시 요청·누락/재전송을 먼저 측정한 뒤 필요한 가속과 배치를 선택한다.

Face Landmarker는 얼굴 좌표·변환 행렬을 입력 특징으로 제공할 수 있다.
이를 시간 CNN 입력으로 학습하는 것은 가능하지만 얼굴만으로 어깨·몸통 자세와 손 동작의 정답을 만들 수는 없다.
얼굴만 쓰는 비교는 개인 기준 대비 머리 방향·관측된 얼굴 변화로 목표를 제한하고 별도 검토 자료로 평가한다.
테스트 브랜치의 26개 특징은 어깨와 손목도 포함하므로 그대로 얼굴 전용 모델이라고 부르지 않는다.
랜드마크는 입력이며 정답 라벨이 아니다. 합성 자료 성능은 실제 사용자 정확도로 해석하지 않는다.
현재의 라벨 비용을 고려해 기하 변화량/기준 분포 비교를 먼저 진행하며 CNN 도입은 확정하지 않는다.

## 근거와 남은 검증

- [MediaPipe 공식 Face Landmarker 출력](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker): 얼굴 좌표·변환 행렬.
- [PyTorch Conv1d](https://docs.pytorch.org/docs/stable/generated/torch.nn.Conv1d.html): 시간축 입력과 필터 구조.
