# 로컬 우선 개발과 기준 등록 자료 보존

- 상태: accepted
- 결정일: 2026-10-12
- 근거: 사용자 요청으로 로컬을 먼저 해결하고 서버 모드 우선순위를 낮추며 기준 등록 13포인트를 별도로 모은다.

## 결정

로컬 측정·기준 대비 특징 설계를 우선한다. 기존 선택형 서버 모드는 유지하며 Kafka·서버 확장은 후순위다.
완료된 3초 기준 등록의 원본 관측(얼굴 11점·어깨 2점, world 좌표가 있으면 함께)을
IndexedDB `posegood-baseline-archive-v1`에 등록 UUID별로 저장한다. 영상은 저장하거나 전송하지 않는다.
취소·품질 저하·프레임 누락으로 초기화된 미완료 구간은 보존하지 않는다.

라벨은 `baseline_posture`(기준 자세), 출처는 `registration_assumption`이다.
`normal_assumed=true`, `ground_truth_verified=false`로 개발상의 정상 가정을 명시한다.
사용자가 등록한 자세가 객관적으로 바른 자세라는 주장은 아니다. 기존 측정 규칙과 학습 모델은 변경하지 않는다.

## 자료 사용과 한계

수집 화면의 ‘기준 자세 모음’에서 전체 JSON을 내려받는다. 새로고침·카메라 종료 후에도
같은 브라우저 프로필·origin에서 자료가 남지만 사이트 데이터 삭제·시크릿 종료로 소실될 수 있다.
저장 실패 시 현재 메모리에 남겨 내려받기를 제공하고 실패를 표시한다. 실패 자료는 새로고침하면 소실된다.
이 자료는 기존 과제 CSV 및 서버 세션 저장과 별개이며 자동 학습되지 않는다.

JSON은 `posture-baseline-v1` 배열이다. 각 항목은 calibration_id, created_at, model_id, 라벨·가정,
baseline(기존 세 특징), summary(표본 수·산포·위치), frames(Observation 원본 시계열)를 포함한다.
frames의 timeMs/videoTimeMs는 카메라 실행의 상대 시간이고 created_at은 완료 UTC다.
좌표는 원본 영상 기준, 점 인덱스는 Pose 0–12다. 얼굴 전체 메시가 아니다.
visibility가 낮은 얼굴 점도 원본대로 남으며 기존 세 특징 품질 통과가 모든 13점의 품질을 보증하지 않는다.
world 좌표 미제공 시 빈 배열이며 추정값으로 채우지 않는다. JSON의 비유한 수치는 null로 직렬화된다.

participant_code는 자동 식별하지 않아 null이다. 연구 자료 준비 시 참여자와 카메라 환경을 별도로 연결하고
참여자 단위로 분할해야 한다. 기존 CSV importer에 바로 투입하는 형식은 아니다.
3초 표본만으로 정상 분포·정답·일반화 성능을 입증할 수 없으며 독립 검증 자료가 필요하다.
