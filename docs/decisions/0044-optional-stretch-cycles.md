## 결정

`/dev` 기본 한 사이클은 기준 등록 후 이탈 → 기준 복귀 → 이탈 → 기준 복귀다. 스트레칭 포함을 선택하면 두 번째 이탈 대신 앉은 채 스트레칭을 안내한다. 각 동작에는 준비·측정·복귀 구간이 있다. 복귀는 별도의 기준 측정 구간이 아니다. 사이클 수는 1~5를 직접 입력하며 순서 섞기는 제거한다. 이탈은 5초, 스트레칭은 8초, 복귀 준비는 5초로 유지한다. 자동의 동작 준비는 2초이고 수동은 사용자가 시작한다.

스트레칭 동작 메모는 각 사이클의 스트레칭을 시작하기 직전에 선택적으로 입력하며, 입력 중 안내 시간은 멈춘다. 메모는 사이클별로 보존한다. 메모는 개인 정보를 입력하지 않도록 안내한다. 메모는 현재 탭의 리플레이 데이터에만 보관하고 사용자가 명시적으로 저장하는 JSON에 포함한다. CSV에는 포함하지 않는다. 스트레칭 결과와 입력한 메모는 비교표의 별도 행으로 보이며, 안내는 실제 수행 정답이나 스트레칭 효과의 증거가 아니다. 낮은 추적 품질은 측정 불가이며 안내는 일시 정지한다.

새 프로토콜 ID는 `front-observation-optional-stretch-v6`다. 키포인트 기록 `observation-keypoint-replay-v4`는 기존 23점과 계획을 유지하며 `stretchNotes`에 회차·시도 번호와 최대 120자 메모를 담는다. `plan.rounds`는 1~5이고 `plan.shuffle`은 false다. 메모를 건너뛰면 빈 문자열을 기록한다. v1·v2·v3 파일은 원래 프로토콜과 계획을 유지하며 계속 불러온다. 이 변경은 영상 저장, 자동 업로드 또는 학습을 추가하지 않는다.
