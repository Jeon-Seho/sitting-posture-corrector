# ADR 0025: 로컬 미래 예측 비교 실험

- 날짜: 2026-10-13
- 상태: 연구 화면에 한정해 채택

## 배경과 결정

사용자가 학습한 LSTM과 개인 기준 거리·지속시간 조합을 직접 웹캠으로 비교하도록 요청했다.
`#forecast`에서 실제 학습 가중치로 0.3초 뒤 좌표를 예측하고, 해당 시각 관측과 비교한 잔차를 사용한다.
같은 입력에서 룰만 사용하는 대조군을 함께 표시한다. 모델 코어는 `model/prototype`, UI는 프론트에 둔다.

개별 실험 기준은 8초 등록이며 기존 서비스 기준 보관과 분리한다.
거리 0.12/복귀 0.08, 3초 이탈과 1초 낮은 잔차, 5초 이탈 보완, 3초 복귀는 탐색용 설정이다.
높은 잔차는 예상 밖 움직임 후보이며 일시적 움직임의 정답 라벨로 사용하지 않는다.
낮은 측정 품질은 측정 불가로 처리한다. 서비스·CEP 계약이나 알림 정책에는 적용하지 않는다.

## 결과와 한계

모델 없는 비교를 통해 모델의 실제 추가 이득을 확인할 수 있다.
Panoptic와 MediaPipe 13점 정의·축의 근사 대응은 검증되지 않아 서비스 정확도를 주장하지 않는다.
실제 데이터·가중치는 Git 제외이며 수동 다운로드에는 수치 진단만 포함한다.
학습·실험 결과와 재현 방법은 [desktop 기록](../ml/jisung/2026-10-13-desktop-live-forecast-experiment.md)에 둔다.
