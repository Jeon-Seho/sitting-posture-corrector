# 0033: 무음 판정 숫자와 화면 기하 진단

- 날짜: 2026-10-15
- 상태: 채택 (`/dev` 실험 표시)

## 배경과 근거

사용자는 작은 움직임에는 덜 민감해졌지만 몸 전체를 같은 비율로 움직일 때 큰 자세 변화도 점수에 반영되지 않는다고 관찰했다.
`liveForecastPoints`는 매 관측에서 어깨 중점을 빼고 현재 어깨폭으로 나눈다. 유효한 전체 평행 이동·균일 크기 변환은 동일한 입력을 만든다.
이는 코드와 합성 검증으로 확인 가능한 불변성이다. 실제 눕기 중 어떤 관측 정보가 사라졌는지는 새 실제 관찰 없이 확정하지 않는다.

## 결정

- 카메라 위에 실제 판정의 숫자 패널을 항상 표시한다. 미등록·측정 불가는 `—`로 구분한다.
- 선택한 정책의 이탈 확인 0/1, 복귀를 관측한 짧은 구간 수, 지속 이탈 후보 0/1, 연속 시간, 최근 1초 실제 알림 발생 0/1, 누적 알림을 표시한다.
- 짧은 구간 수는 해당 정책이 지속 후보로 확정하기 전에 복귀한 횟수다. 스트레칭·행동 의도 정답으로 표시하지 않는다.
- 관측 룰과 예측 조합 정책의 수치가 다를 수 있으므로 룰 시간·복귀 횟수·복귀 경과 시간을 선택 필드로 추가한다.
- 최근 1초 알림은 관측 시간축에 기록된 실제 알림만 사용하며 새 타이머·새 판정을 만들지 않는다. 종료 후에는 발생 0과 마지막 알림 기록을 구분한다.
- 화면 좌우/상하(반전 화면 기준), 영상의 어깨폭 변화, 어깨선 변화는 진단 전용이다. 현재 화면과 등록 영상의 종횡비가 다르거나 유효 관측이 없으면 숨긴다.
- 알림 소리는 기본 꺼짐이며 시각 알림과 집계는 계속한다. 소리는 사용자가 명시적으로 켰을 때만 기존 준비/재생 경로를 사용한다.

## 제외와 한계

LSTM 입력·정규화·정상 프로파일·이탈 임계값은 변경하지 않는다. 화면 이동이나 확대를 바로 자세 붕괴로 해석하지 않는다.
13점의 상대 모양만으로 전체 몸통·골반 변화가 관측된다고 주장하지 않는다. 모델과 특징 보완은 이 진단을 통한 실제 관찰 후 별도로 평가한다.
일반 서비스·서버/CEP에는 적용하지 않는다.

## 검증

합성 전체 변환에서 정규화 입력 불변과 화면 어깨폭 변화를 함께 확인한다. 룰/예측 정책이 서로 다른 구간을 짧은 복귀로 집계하는 상황,
예측 준비 중 룰 숫자 유지, 품질 실패 시 표시 중단, 실제 알림만 표시, 종료 후 표시, 기본 음소거와 시각 알림 지속을 검증한다.
