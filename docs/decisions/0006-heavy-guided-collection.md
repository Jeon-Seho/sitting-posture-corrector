# ADR 0006: Heavy와 안내형 좌표 수집

- 상태: 채택 (파일럿)
- 날짜: 2026-09-21

## 근거

사용자가 MediaPipe Heavy 전환과 라벨 수집 모드 구현을 요청했고, 영상 저장 여부 질문에 **좌표와 라벨만 수집**을 선택했다.
기존 특징 3개만 저장하는 방식은 새 특징을 재계산하기 어렵다. 안내 과제와 실제 자세의 구분도 필요하다.

## 결정

- 공식 Pose Landmarker Heavy float16 v1 모델을 로컬에서 사용한다. tasks-vision 1.0.1은 유지한다.
- 다운로드한 자산의 SHA-256을 model-asset.json에 고정한다. Git에는 가중치를 넣지 않는다.
- 정면이 수집 UI 기본 시점이다. 20초 촬영·5초 준비와 수정 가능한 촬영 조건은 탐색용 초기값이며 연구 프로토콜 확정을 의미하지 않는다.
- 전용 수집 화면에서 과제를 선택하고 촬영 후 자기 보고로 라벨을 확인한다. 준비/중단/제외 구간은 정상 학습 자료로 자동 인정하지 않는다.
- 작업 상황·재석 상태·몸통 자세·추적 품질을 분리한다. 포즈 미검출로 부재를 추론하지 않는다.
- v2 CSV에 33개 영상/추정 world 좌표와 가시성을 저장한다. 원본 영상·음성은 저장하지 않는다.
- 서버 출력 계약 v1은 유지한다. 로컬 수집 파일 스키마만 v2로 올리고 기존 v1 파일을 보존한다.

## 결과와 한계

Heavy의 속도 개선이나 정확도 향상을 검증 없이 주장하지 않는다. 추론은 여전히 메인 스레드이며 실제 FPS/ms를 표시한다.
새 좌표는 후속 특징 계산에 사용할 수 있지만 단안 추정 좌표의 한계와촬영 후 영상 검수 불가는 남는다.
자세·활동 분류기, 이미지/영상 모델 학습, 세밀한 프레임별 재라벨링은 이번 범위 밖이다.
