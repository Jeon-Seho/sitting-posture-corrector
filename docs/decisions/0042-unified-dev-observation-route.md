# /dev를 동작 관측·리플레이로 통일

- 상태: accepted
- 날짜: 2026-10-26
- 근거: 사용자가 기존 /dev 화면을 제거하고 관측 화면을 /dev 기본 경로로 요청함

## 결정

`/dev`와 `/dev/`는 `ObservationLab`을 직접 렌더링한다. 기존 `ForecastDeveloperRoute`의
실험실·정상 수집·모델 비교 조립과 진입 분기를 제거하며 다른 별칭으로 옮기지 않는다.
기존 연구 모듈/단위 검증은 남겨 두되 현재 개발 경로에서는 실행하지 않는다.

합성 예시는 `/dev?demo=1`에서만 명시적으로 선택한다. 이전 `?view=observation` 쿼리는
화면 분기에 사용하지 않으므로 이전 주소도 같은 관측 화면을 연다. 내부 링크는 새 주소를 사용한다.
쿼리 제거를 위한 별도 리다이렉트나 기록 변경은 하지 않는다.

관측의 카메라 수명·자동/수동 안내·측정 구간 CSV·리플레이·저장 경계는 바꾸지 않는다.
일반 서비스 `/`와 별도 `/#forecast` 진입도 유지한다. 자동 촬영·학습·서비스 전송은 추가하지 않는다.

## 검증

기본/이전 쿼리/명시적 예시 진입, 화면 진입 시 카메라 미사용, 모드 선택 후 Full 연결·자동 등록·
안내·종료 시 해제, 권한 대기 만료를 합성 미디어와 실제 카메라 hook으로 검증한다.
프론트 게이트와 문서 검사를 실행하고 브라우저에서 `/dev` 기본 화면을 확인한다.
