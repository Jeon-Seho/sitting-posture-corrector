# Calm Soft 시안 노트

`calm-wellness/index.html`을 복사해 **색과 표면만** 고친 판이다. 레이아웃·문구·상호작용은 그대로다
(화면 구성·흐름·UX 개선점·제안 기능은 [calm-wellness/NOTES.md](../calm-wellness/NOTES.md)를 따른다).
사용자 의견 "눈이 너무 아픈 색조합"에 대한 수정이다.

위쪽 막대 오른쪽 **배색** 버튼(세이지·샌드·미스트)으로 바로 바꿔 볼 수 있다. 주소에 `?p=sand#today`처럼
붙이면 그 배색과 화면으로 시작하고, 마지막 선택은 브라우저에 기억된다(시안 전용).

## 바꾼 것

| 원인 | calm-wellness | calm-soft |
| --- | --- | --- |
| 화면 전체 배경 | 블루·라벤더 4색 135° 그라데이션 | `--bg` → `--bg-2` 거의 같은 두 색의 세로 그라데이션(사실상 단색) |
| 움직이는 배경 | 흐린 빛 덩어리 3개(blur 70px)가 38~52초 주기로 계속 떠다님 | **삭제** |
| 유리 카드 | 58% 흰 반투명 + `blur(22px) saturate(140%)` + 흰 안쪽 하이라이트 | 불투명 면 `--surface` + 1px `--line` 경계 + 약한 그림자. 흐림·채도 올림 없음 |
| 대화상자·메뉴·알림 띠·무대 칩 | 흐림 6~16px | 흐림 없이 불투명 면 |
| 강조색 | 보라 primary + 파랑 정상 + 주황 흐트러짐이 모두 고채도(LAB C* 47~61) | 강조는 배색마다 **하나**(C* 약 21~26). 상태색도 C* 19~36 |
| 버튼·글자 | 주 버튼 세로 그라데이션 + 보라 그림자, 제목 강조 글자 3색 그라데이션, 점수 링·진행 막대 그라데이션 | 모두 단색 |
| 숨쉬기 움직임 | 웰컴·가입·자세 등록·측정 구슬, 카운트다운, 알림 띠, 떠 있는 칩 모두 움직임 | **웰컴 구슬 하나만** 8초 주기로 아주 약하게(크기 ±1.3%). 나머지는 멈춤. 로딩 점·카메라 켜짐 점만 유지 |
| 큰 흰 면 | 선택 탭·입력 포커스·사이드바 현재 항목 등 `#fff` | 순백 대신 `--raise`(살짝 따뜻하거나 차가운 오프화이트). 현재 메뉴는 강조색 옅은 면 + 왼쪽 3px 선 |
| 측정 상태 구슬 | 상태별 4단 방사 그라데이션 + 숨쉬기 | 거의 단색 면 + 2px 테두리. 측정 불가는 **빗금 + 점선 바깥 테**, 연결 중은 점 테두리 |
| 카메라 무대 | 남보라 계열 어두운 면 | **어두운 면 유지**. 배색에 맞춰 아주 살짝 기울인 어두운 회색, 관절 점은 상태별 밝은 저채도 색 |

색은 모두 CSS 변수로 옮겼다(`:root[data-palette="…"]`). 하드코딩 색은 디스코드 로고 사각형 `#5865f2`와
배색 버튼의 작은 견본 동그라미(시안 전용)만 남았다.

## 대비 확인 결과

검사는 헤드리스 Chrome(1360×860, 390×844)으로 3배색 × 9화면 상태(시작·가입·로그인·첫 설정·오늘 기록·측정 정상/알림/측정 불가/연결 중)를 열어 했다.
보이는 글자 요소마다 실제 계산된 글자색과 겹친 배경을 합성해 대비를 쟀고, 토큰 쌍은 따로 계산했다.

- **본문 글자 WCAG AA 통과(세 배색 모두)**. 토큰 기준 최저값: 캡션 `--ink-3` / `--sunk` 4.55(sage)·4.81(sand)·4.75(mist).
  본문 `--ink` / 바탕 11.8~12.4, 주 버튼 글자 5.85(sage)·8.53(sand)·6.83(mist).
  상태 글자(정상·흐트러짐·측정 불가) / 옅은 면 4.80~5.89, 알림 띠 제목 4.84~5.29, 입력 오류 5.00~6.15, 무대 글자 13.6~14.0.
- 화면 전수 검사에서 걸린 것: sage 첫 설정 단계 번호가 4.42여서 `--ink-2`로 올려 고쳤다.
  남은 항목은 ① 비활성 버튼(‘연결 중’의 잠시 쉬기, 2.9 — WCAG 예외), ② 측정 알림 띠
  (배경이 `color-mix()`라 검사기가 읽지 못해 어두운 무대로 계산한 오탐. 토큰 계산 4.84~5.29·화면 확인으로 대체)뿐이다.
- 그래프 막대(비텍스트 3:1): 정상 `--good-soft` / 카드 3.40·3.05·3.14로 통과. 흐트러짐 `--drift-soft`는 2.22~2.44로
  일부러 밝게 두었다(정상과 명도 차를 두어 색약에서도 갈리게). 범례·표 보기·쌓기 간격으로 보완한다.
- 상태 구분(LAB ΔE, 정상/흐트러짐): sage 43.2(제2색약 33.8, 제1색약 24.6), sand 48.5(46.7, 37.3), mist 43.7(45.0, 38.7).
  측정 불가는 색이 아니라 **빗금·점선 테**로 구분되며, 채도 C* 2.7~5.1의 중립 회색이다.
- 채도: 강조색 C* 20.5~26.2, 상태 그래프색 18.8~35.9(이전 calm-wellness는 46.5~60.5).
- 390px 폭에서 가로 넘침 없음(시작·로그인·측정·오늘 기록). 콘솔 오류 없음. 화면 전환 후 계속 도는 애니메이션은 웰컴 구슬 두 개(halo·core)뿐임을 `document.getAnimations()`로 확인.

## 남은 한계

- 실제 모니터·부스 조명에서 눈으로 본 확인은 하지 않았다(헤드리스 스크린샷만).
- 자리표시 입력의 placeholder 대비는 3.6~3.9(AA 본문 기준 미달, 라벨이 따로 있어 필수 정보는 아님).
- 흐트러짐 그래프 막대 단독 비텍스트 대비 3:1 미달(위 설명).
- 웰컴 화면의 3단계 카드 줄이 왼쪽으로 들여 보이는 것은 원본 레이아웃 그대로다(이번 범위 밖).
