# playful-coach 시안 노트

부스 체험형 게이미피케이션 안. 단순 도형으로 그린 자세 코치 **「바로」**가 시작·가입·첫 설정·측정·기록에서 말을 걸고,
연속 바른 자세·오늘의 목표·작은 배지로 30초 체험을 "해보고 웃는" 경험으로 만든다.

- 시안: [`index.html`](index.html) (단일 파일, 외부 요청은 Pretendard CDN만, 기존 자산은 상대 경로)
- 위 전환 바 또는 ←/→ 키로 6개 화면 이동. 주소 `#/s1`~`#/s6`으로 바로 열 수 있다.
- `제안` 노란 점선 배지 = 현재 앱에 없는 새 기능.

## ① 디자인 방향과 키워드

**키워드:** 친근한 코치 · 같이 기울어지는 캐릭터 · 밝은 포도색+햇살 노랑 · 손에 잡히는 버튼(눌리는 그림자) · 작은 축하

1. **코치가 상태를 몸으로 보여 준다.** 바로의 더듬이와 몸이 사용자 자세 상태에 맞춰 기울어진다(정상=꼿꼿, 흐트러지는 중=살짝, 알림=크게 기울고 땀방울).
   측정 불가·연결 문제에서는 **회색 바로 + 물음표**로 바뀌어 정상·흐트러짐 어느 쪽으로도 읽히지 않는다.
2. **멀리서 읽히는 측정 화면.** 38px 상태 제목 + 상태 색 배너 + 카메라 테두리 색(알림은 깜빡임, 측정 불가는 회색 점선)으로 부스 모니터 2~3m 거리에서도 구분된다.
3. **30초 체험 동선.** 시작 → (제안) 30초 체험 → 3·2·1 카운트다운 → 측정 → 일부러 기울어 알림 → "고쳤어요" → 하이파이브·꽃가루. 방문자가 직접 기울였다 돌아오는 순간이 웃음 포인트.
4. **비의료 원칙 유지.** "점수는 내 기준 자세와 얼마나 비슷한지예요. 의학적 점수나 정확도가 아니에요"를 점수 바로 아래 고정.
   배지·목표·연속 기록은 "앉아 있던 시간·반응"만 세고 건강 효과를 말하지 않는다. "교정" 표현은 쓰지 않는다.

**다른 시안과의 구분:** 초록 숲(forest)·따뜻한 살구(warm)·어두운 실시간(dark)·흑백 대비(bold)와 겹치지 않도록 포도색 주색 + 햇살 노랑 보조색, 마스코트 중심, 게임형 피드백으로 방향을 잡았다(다른 시안 폴더는 열어 보지 않았다).

### 탐색 구조

사이드바 **측정하기 · 오늘 · 기록 · 설정 + 아래 계정 메뉴**는 그대로 둔다(`frontend/src/app/navigation.ts:24-30`).
현재 사이드바 아래 「오늘 바른 자세」 카드(`frontend/src/app/AppSidebar.tsx:54-68`) 자리에 **오늘의 목표(제안)** 미터를 넣었다. 바른 자세 비율은 오늘 화면에 이미 크게 있으므로 사이드바에는 "얼마나 남았나"를 보여 주는 편이 동기 부여에 낫다고 판단했다. 목표 기능을 채택하지 않으면 기존 카드로 되돌리면 된다.

## ④ `제안` 새 기능

| 기능 | 위치 | 규칙(안) | 비의료·중립 원칙 |
| --- | --- | --- | --- |

| 시간대별 누적 막대 | 오늘 기록 | 시간당 바른/흐트러짐/측정 불가 분 | 측정 불가는 "집계 제외" 회색 |
