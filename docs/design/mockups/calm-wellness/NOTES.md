# Calm Wellness 시안 노트

`index.html` 하나에 6개 화면이 들어 있다. 위쪽 짙은 막대로 화면을 바꾸고(←/→ 키도 됨), 화면 안의 **점선 상자**는 상태를 바꿔 보는 시안용 조작이다(실제 앱에는 넣지 않는다). 주소 끝에 `#signup`, `#login`, `#setup`, `#measure`, `#today`를 붙이면 그 화면에서 바로 시작한다.

## ① 디자인 방향과 키워드

**호흡 · 여백 · 유리 · 회고**

- 명상·웰니스 앱처럼 차분하게 만든다. 블루·라벤더 하늘 그라데이션 위에 흐린 빛 덩어리 3개가 38~52초 주기로 천천히 떠다니고, 반투명 유리 카드(`backdrop-filter: blur(22px)`)에 내용을 담는다.
- 상징 요소는 **숨 쉬는 구슬(orb)**이다. 8초 주기(4초 들숨·4초 날숨)로 커졌다 작아진다. 시작 화면에서는 "들이쉬고/내쉬고" 문구와 맞춰 숨 쉬고, 측정 화면에서는 상태 표시가 된다(정상=파랑, 흐트러짐=살구, 측정 불가=멈춘 회색+점선 테두리).
- 알림은 놀라게 하지 않는다. 흔들림·빨강·경고음 같은 느낌을 빼고, 카메라 위에서 살구색 유리 띠가 0.9초 동안 천천히 내려오며 "자세를 살짝 고쳐볼까요?"라고 묻는다.
- 회원가입과 로그인은 **한 카드 안의 탭**이다. 탭을 바꿀 때 썸이 미끄러지고 카드 높이가 부드럽게 바뀐다. 가입 단계도 같은 카드 안에서 옆으로 넘어간다.
- 오늘 기록은 대시보드보다 **하루 회고**에 가깝다. 큰 원 하나와 "오늘은 3번 앉아 2시간 39분 동안…" 같은 한 줄이 먼저 나오고, 시간대 흐름과 돌아보기는 그 아래에 둔다.
- 움직임은 느리고(180/420/700ms, `cubic-bezier(.33,0,.15,1)`) 시스템의 "움직임 줄이기" 설정을 지킨다.

카드 안쪽 24px(인증 카드 28×32), 열 간격 22px, 필드 사이 16px, 필드 이름과 입력 사이 8px. 버튼 높이 44px(큰 버튼 52, 작은 조작 36). 입력 높이 46px. 사이드바 208px, 측정·기록 보조 열 340px. 기본 캔버스 1360×860, 최소 760px 높이. 1100px 아래에서는 한 열로 바뀌고 사이드바가 위쪽 가로 막대가 된다. 600px 아래에서는 메뉴가 아이콘만 남는다.

## ④ `제안` 표시한 새 기능

| 기능 | 위치 | 설명 |
| --- | --- | --- |
| 오늘의 한 줄 회고 문장 | 오늘 기록 상단 | 하루 측정 시간과 가장 편안했던 시간대를 문장으로 만든다. 데이터는 기존 일별 기록으로 계산할 수 있다. |
| 오늘을 돌아보면 카드 | 오늘 기록 오른쪽 | 가장 편안했던 시간대·흐트러지기 쉬웠던 시간대·가장 긴 측정. "의자 깊숙이 앉아 보는 건 어떨까요?"처럼 부드러운 제안 문구가 들어간다. 의료적 조언으로 읽히지 않게 문구 검수가 필요하다. |
| 시간대별 쌓은 막대 | 오늘 기록 | 현재는 0–24시 세션 띠만 있다. 시간대별 바른 자세/흐트러짐/측정 불가 분은 서버 기록에서 나눠 계산해야 한다(현재 계약에 시간대별 분할 필드가 있는지 확인하지 못했다). 화면에는 `제안` 배지를 달지 않았지만 새 표시 방식이다. |

아래는 표시 방식만 바뀐 것이라 `제안`을 달지 않았다.

- 비밀번호 보기 버튼과 글자 수 막대
- 이메일 인증을 같은 화면에 펼치는 것
- 측정 종료 확인 대화상자("오늘은 여기까지 할까요?"). 현재는 바로 종료한다. 적용할지는 결정이 필요하다.

## 검사 기록

- 헤드리스 Chrome(별도 임시 프로필)으로 1360×912에서 6개 화면과 주요 상태를 캡처해 확인했다. 확인한 상태: 정상, 흐트러짐 알림, 측정 불가, 가입 2단계 입력 오류, 인증 코드 펼침, 기준 자세 저장 중.
- 390px 폭 iframe 안에서 6개 화면의 문서 가로 넘침이 없음을 확인했다(`scrollWidth == clientWidth`).
- 로그인 오류·로딩, 비밀번호 찾기 대화상자, 가입 완료, 측정 상태 7종 전환, 연결 끊김 재연결, 측정 종료 저장, 표 보기, 첫 설정 권한 거부/재시도 흐름을 자동으로 눌러 보는 동안 콘솔 오류는 없었다.
- 검사용 임시 파일은 세션 임시 폴더에만 두었고 작업 후 지웠다.
