# FE 예외 처리 모음

> 작성자: klaod-tech(FE) · 작성: 2026-11-13
> **이 문서의 역할:** 앱이 오류·예외 상황에서 띄우는 화면과 문구를 한곳에 모은다. **사용자 입장에서 할 수 있는 것**으로 크게 나누고(A~D), 그 안을 **그림 있는 오류 화면**과 **그림 없는 안내**로 다시 나눈다. 문구는 코드에서 그대로 옮겼으므로 코드를 바꾸면 여기도 고친다. 아직 정하지 않은 문제는 [FE 예외 처리 방안](fe-exception-handling-plan.md), 오류 코드별 규칙은 [연동 명세](api-ws-spec.md) 2장이다.

| 분류 | 뜻 |
|---|---|
| **A. 사용자가 해결할 수 있음** | 문구대로 하면 풀린다(다시 로그인, 카메라 권한, 자세 고치기 등) |
| **B. 기다리거나 다시 하면 됨** | 사용자 잘못이 아니고 일시적이다(서버·인터넷이 잠깐 안 됨) |
| **C. 사용자가 알 수도 고칠 수도 없음** | 앱이나 서버가 고쳐야 한다. 같은 일을 다시 해도 같을 수 있고, 일부는 사용자를 막아 버린다 |
| **D. 정해진 규칙에 따른 안내** | 오류가 아니다. 규칙대로 끝났거나 이어졌음을 알린다 |

그림은 lellon0403이 그린 오류 그림(`public/illustrations/themes/*-error-*.webp`)이고, 그림 있는 화면은 `pages/ErrorPage.tsx` `ERROR_PAGES`(데스크톱 연결 화면은 `public/offline.html`)다. 원칙: 사용자 탓을 하지 않는다, 다음에 할 일은 하나, 오류 코드는 버튼 아래 작은 글씨, 기록이 저장됐는지 같은 사실은 정확하게.

**어디에 뜨나:** 전체 화면 / 본문 자리(왼쪽 메뉴 유지, 화면이 자기 자료 R1·W1을 못 불러왔을 때만) / 측정 화면 자리 / 측정 화면 안 / 결과 화면 안 / 카메라 칸 / 자세 등록 화면 / 입력칸 아래 / 위쪽 한 줄 / 대화상자.

| 상황 | 어디 | 그림 | 제목 | 설명 | 버튼 |
|---|---|---|---|---|---|

**측정 실패 화면** (측정 화면 자리, 제목 「측정을 시작하지 못했어요」, 버튼 「다시 준비하기」)

| 상황 | 문구 |
|---|---|
| S1 401·403, 로그아웃 상태에서 측정 토큰을 못 받음 | 로그인이 필요해요. 다시 로그인한 뒤 측정해 주세요. |

## B. 기다리거나 다시 하면 됨

### B-1. 그림 있는 오류 화면

| 상황 | 어디 | 그림 | 제목 | 설명 | 버튼 |
|---|---|---|---|---|---|
| 자료(R1·W1)가 500번대·응답 없음(기기는 온라인) | 본문 자리 | 503 쉬는 서버 | 잠시 서버에 문제가 생겼어요 | 사용자 잘못이 아니에요. 잠시 뒤 다시 시도해 주세요. (R1이면 「측정한 기록은 저장돼 있어요.」 한 줄 더) | 다시 시도 |
| 측정 시작 때 서버와 연결하지 못함(아래 표) | 측정 화면 자리 | 500 수리 | 지금은 측정을 시작할 수 없어요 | 서버와 연결하지 못해 측정을 시작하지 못했어요. 인터넷 연결을 확인하고 잠시 뒤 다시 시작해 주세요. | 다시 준비하기 |
| 데스크톱 앱이 웹 화면을 여는 중 | 전체 화면 | 504 모래시계 | 연결하는 중이에요 | 잠시만 기다려 주세요. | 없음(회전 표시) |
| 데스크톱 앱이 10초 안에 웹 화면을 못 엶 | 전체 화면 | 502 뽑힌 케이블 | 서버에 연결할 수 없어요 | 사용자 잘못이 아니에요. 인터넷 연결을 확인하거나 잠시 뒤 다시 시도해 주세요. 연결되면 자동으로 다시 열어요. | 지금 다시 시도(10초마다 자동) |

「지금은 측정을 시작할 수 없어요」가 뜨는 경우. 모두 측정이 ④ `ready`까지 가지 못한 것이라 좌표를 한 장도 보내지 못했고, 결과 화면·기록이 생기지 않는다(저장할 측정이 처음부터 없음).

```
「측정 시작」 → ① S1(측정 세션 만들기) → ② WS 연결 → ③ hello → ④ ready → 좌표를 보내며 측정
```

| 상황 | 코드 |
|---|---|
| S1이 5xx | `LiveSession.start` |
| S1에 응답이 없음(네트워크) | `LiveSession.start` |
| 측정 토큰을 받다 네트워크 실패(로그인 상태) | `LiveSession.start` |
| WS를 열지 못함 | `LiveSession.start` |
| `ready` 전에 연결이 끊김 | `LiveSession.closedBySocket` |
| `ready`가 5초 안에 안 옴 | `LiveSession.start` 타이머 |
| `ready` 전에 `closed(session_lost)`(kafka 모드: 서버가 Kafka에 시작을 못 씀) | `LiveSession.handle` |

① S1이 성공했다면 서버에 데이터 없는 빈 측정 세션이 남는다. 앱은 그 세션을 다시 쓰지 않고, 서버가 그 약속을 근거로 시간이 지나면 닫는다([FE 제안서](fe-server-proposal.md) 요구 8).

| 자세 저장(B1) 503 | 자세 등록 화면 | 서버가 다른 작업을 처리하고 있어요. 잠시 뒤 다시 등록해 주세요. |
| 자세 저장(B1) 404·429·5xx | 자세 등록 화면 | 서버에 자세를 저장하지 못했어요. 잠시 뒤 다시 등록해 주세요. |
| 자세 저장(B1) 응답 없음 | 자세 등록 화면 | 서버에 연결하지 못했어요. 연결을 확인한 뒤 다시 등록해 주세요. |
| 계정 서버가 바쁨(503) | 입력칸 아래 | 계정 서버가 바빠요. 잠시 뒤 다시 시도해 주세요. |
| 계정 서버에 연결 못 함 | 입력칸 아래 | 계정 서버에 연결하지 못했어요. 잠시 뒤 다시 시도해 주세요. |
| Discord에 연결 못 함 | 입력칸 아래 | Discord에 연결하지 못했어요. 잠시 뒤 다시 시도해 주세요. |
| 서버 로그아웃 실패 | 위쪽 한 줄 | 서버 로그아웃을 확인하지 못했어요. 연결 후 다시 시도해 주세요. |
| 서버 설정을 못 불러옴(본문 오류 화면이 아닐 때) | 위쪽 한 줄 | 서버 설정을 불러오지 못했어요. 측정 전에 설정 화면을 다시 열어 주세요. |
| 설정 저장(W2) 실패 | 위쪽 한 줄 | 설정을 저장하지 못했어요. / 503: 서버가 다른 작업을 처리하고 있어요. 잠시 뒤 다시 시도해 주세요. / 5xx: 서버 설정을 처리하지 못했어요. / 응답 없음: 서버에 연결하지 못했어요. 연결을 확인해 주세요. |
| 서버 기록 확인 실패(본문 오류 화면이 아닐 때) | 위쪽 한 줄 | 서버 기록을 확인하지 못했어요. 임시 자료는 유지돼요. |
| 계정 변경 처리 중에 이동·로그아웃 | 위쪽 한 줄 | 계정 변경을 확인한 뒤 이동해 주세요. / 계정 변경을 확인한 뒤 로그아웃해 주세요. |

## C. 사용자가 알 수도 고칠 수도 없음

### C-1. 그림 있는 오류 화면

| 상황 | 어디 | 그림 | 제목 | 설명 | 버튼 | 사용자에게 생기는 일 |
|---|---|---|---|---|---|---|
| 화면을 그리다 예외가 남(오류 경계, 앱 버그) | 전체 화면 | 500 수리 | 화면을 불러오지 못했어요 | 새로 고치면 대부분 해결돼요. | 새로 고침 | 새로 고침으로 풀리지 않으면 앱을 고쳐야 함 |
| 자료(R1·W1)가 400번대(401 제외, 앱이 서버가 받지 않는 요청을 보냄) | 본문 자리 | 404 돋보기 | 요청을 처리하지 못했어요 | 화면을 새로 고친 뒤 다시 해 주세요. | 새로 고침(지금은 실제로는 자료만 다시 불러옴) | 오래된 앱이면 새로 고침으로 풀림, 아니면 앱 버그 |
| 측정 종료 뒤 S4가 404(서버 메모리에도 DB에도 없음 — 서버 고장) | 측정 화면 자리 | 500 수리 | 서버에서 이번 측정을 찾지 못했어요 | 사용자 잘못이 아니에요. 서버 문제로 이번 측정 결과를 확인하지 못했어요. 다시 측정해 주세요. | 다시 준비하기 | 이번 측정은 이 기기에 남기지 않는다(대기 기록도 지움). 서버가 받은 만큼은 열린 세션 행으로 남아 BE가 닫으면 R1에 나온다(요구 8) |

### C-2. 그림 없는 안내

| 상황 | 어디 | 문구 | 사용자에게 생기는 일 · 앞으로 |
|---|---|---|---|
| S1 409(다른 기기·탭에서 판정 기준이나 기준 자세를 바꿈) | 측정 실패 화면 | 설정이나 기준 자세가 바뀌었어요. 다시 확인한 뒤 측정해 주세요. | 「확인」할 것이 없다. FE가 W1·B2를 다시 받아 S1을 한 번 더 보내 사용자 눈에 안 보이게 바꿀 예정. 다른 기기 측정 중 알림은 [FE 제안서](fe-server-proposal.md) 요구 13 |

## D. 정해진 규칙에 따른 안내 (오류 아님)

| 상황 | 어디 | 문구 |
|---|---|---|
| 정상 종료(`closed(ended)`) | 결과 화면 안 | 서버에 저장했어요. |

| 자정에 서버가 새 세션으로 이음(`session_rollover`) | 측정 화면 안내 띠 | 자정이 지나 새 측정으로 이어졌어요. |
