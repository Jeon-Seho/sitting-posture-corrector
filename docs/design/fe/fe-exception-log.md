> 작성자: klaod-tech(FE) · 작성: 2026-11-13
> **이 문서의 역할:** 앱이 오류·예외 상황에서 띄우는 화면과 문구를 한곳에 모은다. **같은 화면을 띄우는 것끼리 한 묶음**이고, 묶음 안에서는 상황마다 문구가 다르다. 문구는 코드에서 그대로 옮겼으므로 코드를 바꾸면 여기도 고친다. 아직 정하지 않은 문제는 [FE 예외 처리 방안](fe-exception-handling-plan.md), 오류 코드별 규칙은 [연동 명세](api-ws-spec.md) 2장이다.

## 2. 데스크톱 연결 화면 (데스크톱 앱 전체 화면)

설치판이 웹 주소(`https://app.posegood.site`)를 여는 동안·못 열 때 앱에 든 화면이다([ADR 0017](../../decisions/0017-desktop-app-shell-and-redesign.md) 결정 8). 10초 안에 못 열면 실패 화면으로 바꾸고 10초마다 다시 시도한다.

| 상황 | 그림 | 제목 | 설명 | 버튼 |
|---|---|---|---|---|
| 웹 화면을 여는 중 | 504 모래시계 | 연결하는 중이에요 | 잠시만 기다려 주세요. | 없음(회전 표시) |
| 10초 안에 못 엶·연결 실패 | 502 뽑힌 케이블 | 서버에 연결할 수 없어요 | 사용자 잘못이 아니에요. 인터넷 연결을 확인하거나 잠시 뒤 다시 시도해 주세요. 연결되면 자동으로 다시 열어요. | 지금 다시 시도 |

코드: `public/offline.html`, `electron/main.cjs`.

## 3. 자료를 못 불러옴 (본문 자리, 왼쪽 메뉴 유지)

화면이 **자기 자료**를 불러오지 못했을 때만 띄운다. 기록 R1 실패 → 「오늘」·「기록」, 설정 W1 실패 → 「측정하기」·「설정」. 다른 화면에서는 위쪽 한 줄 안내만 뜬다. 다시 불러오기에 성공하거나 인터넷이 돌아오면 사라지고, 로그아웃하면 지운다.

| 상황 | 그림 | 제목 | 설명 | 버튼 |
|---|---|---|---|---|
| 400번대(401 제외) | 404 돋보기 | 요청을 처리하지 못했어요 | 화면을 새로 고친 뒤 다시 해 주세요. | 새로 고침 |
| 500번대, 응답 없음(기기는 온라인) | 503 쉬는 서버 | 잠시 서버에 문제가 생겼어요 | 사용자 잘못이 아니에요. 잠시 뒤 다시 시도해 주세요. | 다시 시도 |
| 기기가 오프라인 | 502 뽑힌 케이블 | 인터넷 연결을 확인해 주세요 | 연결되면 자동으로 다시 불러올게요. | 다시 시도 |

기록(R1)이 500번대로 실패한 화면에는 「측정한 기록은 저장돼 있어요.」 한 줄이 더 붙는다. 401은 로그인 흐름이 처리한다. 로그인·설정 저장처럼 **사용자가 누른 동작**의 실패는 이 화면이 아니라 12·13번이다. 측정 중·측정 화면, 개발자 계정에서는 띄우지 않는다.

코드: `features/connection/pageError.ts`, `ERROR_PAGES.request`·`server`·`offline`.

## 4. 측정을 시작할 수 없음 (측정 화면 자리)

측정을 시작할 때 **서버와 연결하지 못한** 경우다. 측정은 아래 순서로 시작되고, 이 경우들은 모두 ④ `ready`까지 가지 못했다.

```
「측정 시작」 → ① S1(서버에 세션 만들기) → ② WS 연결 → ③ hello → ④ ready → 좌표를 보내며 측정
```

좌표를 한 장도 보내지 못해 측정 시간이 0초다. 그래서 결과 화면도 없고 기록 목록에도 아무것도 생기지 않는다(저장에 실패해 잃는 것이 아니라 저장할 측정이 처음부터 없다). 측정하던 중에 끊긴 경우는 7번(「서버 연결이 끊겨 측정을 마쳤어요. 끊기기 전까지 저장됐어요」)이다.

① S1이 성공했다면 서버에 데이터 없는 빈 세션이 남는다. 앱은 이 세션을 다시 쓰지 않고(다시 할 때는 새 세션), 서버가 그 약속을 근거로 시간이 지나면 닫는다([FE 제안서](fe-server-proposal.md) 요구 8).

| 그림 | 제목 | 설명 | 버튼 |
|---|---|---|---|
| 500 수리 | 지금은 측정을 시작할 수 없어요 | 서버와 연결하지 못해 측정을 시작하지 못했어요. 인터넷 연결을 확인하고 잠시 뒤 다시 시작해 주세요. | 다시 준비하기 |

| 상황 | 어디서 |
|---|---|
| S1(세션 만들기)이 5xx | `LiveSession.start` |
| S1에 응답이 없음(네트워크) | `LiveSession.start` |
| `ready` 전에 `closed(session_lost)`(kafka 모드: 서버가 Kafka에 시작을 못 씀) | `LiveSession.handle` |
| 측정 토큰을 받다 네트워크 실패(로그인 상태) | `LiveSession.start` |
| WS를 열지 못함 | `LiveSession.start` |
| `ready` 전에 연결이 끊김 | `LiveSession.closedBySocket` |
| `ready`가 5초 안에 안 옴 | `LiveSession.start` 타이머 |

코드: `LiveState.serverDown`, `ERROR_PAGES.measure`.

## 5. 측정 결과를 찾지 못함 (측정 화면 자리)

| 상황 | 그림 | 제목 | 설명 | 버튼 |
|---|---|---|---|---|
| 측정 종료 뒤 S4가 404(서버 메모리에도 DB에도 없음 — 서버 고장) | 500 수리 | 서버에서 이번 측정을 찾지 못했어요 | 사용자 잘못이 아니에요. 서버 문제로 이번 측정 결과를 확인하지 못했어요. 다시 측정해 주세요. | 다시 준비하기 |

이 기기에는 결과를 남기지 않고 측정 중 남긴 대기 기록도 지운다. 서버가 받은 만큼은 열린 세션 행으로 서버에 남아, BE가 닫으면 R1에 나온다(요구 8).

코드: `LiveState.resultMissing`, `ERROR_PAGES.result`, `useSessionPersistence.finish` → `forgetResult`.

## 6. 측정 실패 화면 (측정 화면 자리, 그림 없음)

제목 「측정을 시작하지 못했어요」, 아래에 사유 문구, 버튼 「다시 준비하기」. 사용자가 고칠 수 있거나 다시 하면 되는 실패다. 기록은 없다.

| 상황 | 문구 |
|---|---|
| S1 401·403(로그인 필요) | 로그인이 필요해요. 다시 로그인한 뒤 측정해 주세요. |
| S1 400 | 측정을 시작하지 못했어요. 앱을 새로 고친 뒤 다시 시작해 주세요. |
| S1 409 `BASELINE_REQUIRED` | 기준 자세가 없어요. 자세를 먼저 등록해 주세요. |
| S1 409(설정·기준이 서버와 다름) | 설정이나 기준 자세가 바뀌었어요. 다시 확인한 뒤 측정해 주세요. |
| S1 404 | 서버에서 이 측정을 찾지 못했어요. |
| S1 429 | 지금은 측정을 시작할 수 없어요. 잠시 뒤 다시 시작해 주세요. |
| 로그아웃 상태에서 측정 토큰을 못 받음 | 로그인이 필요해요. 다시 로그인한 뒤 측정해 주세요. |
| `ready` 전 `closed(unauthorized)` | 로그인이 만료됐어요. 다시 로그인해 주세요. |
| `ready` 전 `closed(not_owner)`·`closed(bad_message)`·모르는 사유 | 측정을 이어갈 수 없어요. 다시 시작해 주세요. |
| `ready` 전 `closed(no_baseline)` | 기준 자세가 없어요. 자세를 먼저 등록해 주세요. |

코드: `LiveSession.ts` `MESSAGES`·`CLOSED`, `LiveSessionPage` `phase === 'failed'`.

## 7. 측정 결과 화면의 안내 (결과는 보여 줌)

### 7.1 결과 아래 문구

측정이 끝나 결과(서버가 보낸 값)를 보여 주면서 끝난 까닭을 한 줄로 적는다. 아무 일 없으면 「서버에 저장했어요.」.

| 상황 | 문구 |
|---|---|
| 정상 종료(`closed(ended)`) | 서버에 저장했어요. |
| 측정 중 연결이 끊김 | 서버 연결이 끊겨 측정을 마쳤어요. 끊기기 전까지 저장됐어요. |
| `closed(server_shutdown)` | 서버 연결이 끊겨 측정을 마쳤어요. 끊기기 전까지 저장됐어요. |
| 측정 중 `closed(session_lost)` | 서버에서 측정이 끝났어요. 확인된 시간까지 저장됐어요. |
| 측정 중 `closed(unauthorized)`(비밀번호 변경·탈퇴) | 비밀번호 변경이나 탈퇴로 로그인이 끝나 측정을 마쳤어요. 그때까지 저장됐어요. |
| 측정 중 `closed(bad_message)` | 측정을 이어갈 수 없어 마쳤어요. 그때까지 저장됐어요. |
| `closed(limit_reached)` | 한 번에 측정할 수 있는 시간을 넘어 측정을 마쳤어요. |
| `closed(unmeasurable_timeout)` | 자세를 확인할 수 없는 상태가 30분 이어져 측정을 마쳤어요. 그때까지 저장됐어요. |
| `closed(day_changed)` | 자정이 지나 측정을 마쳤어요. 자정 전까지 저장됐어요. 새 측정을 시작해 주세요. |
| 쓰던 카메라가 빠짐 | 쓰던 카메라가 빠져 측정을 마쳤어요. 그때까지의 기록은 저장했어요. |
| 측정 중 카메라 영상 크기가 바뀜 | 카메라 영상 크기가 바뀌어 측정을 마쳤어요. 그때까지의 기록은 저장했어요. |
| 작은 카메라 창을 닫아 끝냄(데스크톱) | 작은 창을 닫아 측정을 끝냈어요. 그때까지의 기록은 저장했어요. |

### 7.2 결과 화면 맨 위 띠

| 상황 | 문구 |
|---|---|
| `closed` 없이 넘어왔고(5초, 또는 kafka 모드 종료 뒤 `stalled` 3초) 서버가 종료를 확인해 주지 않음 | **서버 응답이 늦어 결과를 먼저 보여 드려요** — 사용자 잘못이 아니에요. 측정 기록은 서버에 저장되고 있고, 저장이 확인되면 기록에 자동으로 반영돼요. |

기록은 이 기기의 대기 기록으로 남고 R1(측정 중이 아닐 때 15초마다)로 확인된다. 끝내 확인되지 않는 경우는 [FE 예외 처리 방안](fe-exception-handling-plan.md) 0장.

코드: `LiveSessionPage` `result-note`·`lateResult`, `useLiveSession.ts`, `sessionControl.ts` `WINDOW_END_REASON`.

## 8. 측정 중 안내 (측정 화면 안)

| 상황 | 어디 | 문구 |
|---|---|---|
| 서버 결과가 5초 넘게 없음(`stalled`) | 연결 상태 칸 | 분석이 잠시 멈췄어요. 측정은 계속돼요. |
| 앱이 판정 불가로 본 프레임(어깨가 안 보임·사람 없음) | 상태 제목·안내 | 자세를 확인할 수 없어요 / 얼굴과 어깨가 보이지 않아요. 이 시간은 집계에서 빠져요. |
| 서버가 고개 돌림으로 판정 불가 | 상태 제목·안내 | 자세를 확인할 수 없어요 / 고개를 돌린 동안은 판정하지 않아요. 이 시간은 집계에서 빠져요. |
| 카메라 영상이 1초 넘게 멈춤(`away`) | 상태 제목·설명 | 카메라 영상을 기다리고 있어요 / 인식 중입니다. 3초 후에 측정 재개 버튼을 눌러주세요. |
| 측정 시작 직후 서버 연결 중 | 상태 제목 | 서버에 연결하고 있어요 |
| 소리를 재생하지 못함 | 안내 띠 | 소리를 재생하지 못했습니다. 소리 켜기를 다시 눌러 주세요. |
| 브라우저가 소리를 허락하지 않음 | 안내 띠 | 이 브라우저에서 소리를 켜지 못했습니다. |
| 자정에 서버가 새 세션으로 이음(`session_rollover`) | 안내 띠 | 자정이 지나 새 측정으로 이어졌어요. |

`ack`는 앱이 쓰지 않는다. 이미 닫힌 사건의 `alert`가 늦게 오면 울리지 않는다.

코드: `LiveSessionPage` `headline`·`nudgeText`·`connectionText`, `useLiveSession.ts`.

## 11. 자세 등록 안내 (자세 등록 화면)

| 상황 | 문구 |
|---|---|
| 측정 중에 다시 등록하려 함 | 측정 중에는 기준 자세를 바꿀 수 없어요 / 진행 중인 측정을 마친 뒤 다시 등록해 주세요. |
| 등록한 자세를 불러오지 못함(B2 실패) | 등록한 기준 자세를 불러오지 못했어요 (「다시 불러오기」·「새로 등록」을 고름) |
| 저장 중 | 기준 자세를 저장하고 있어요 / 서버에 저장되면 바로 다음 단계로 넘어가요. |
| 저장 실패 | 기준 자세를 저장하지 못했어요 + 아래 사유 |
| 자세를 알아보기 어려움 | 자세를 알아보기 어려워요 / 얼굴과 양쪽 어깨가 화면 안에 들어오게 앉고, 잠시 움직이지 말아 주세요. |

저장 실패 사유(B1):

| 상황 | 문구 |
|---|---|
| 401·403 | 로그인이 필요해요. 다시 로그인한 뒤 등록해 주세요. |
| 400 | 등록한 자세를 서버가 받지 않았어요. 다시 등록해 주세요. |
| 409 | 다른 화면에서 계정이나 자세가 바뀌었어요. 다시 등록해 주세요. |
| 503 | 서버가 다른 작업을 처리하고 있어요. 잠시 뒤 다시 등록해 주세요. |
| 404·429·5xx | 서버에 자세를 저장하지 못했어요. 잠시 뒤 다시 등록해 주세요. |
| 응답 없음 | 서버에 연결하지 못했어요. 연결을 확인한 뒤 다시 등록해 주세요. |

## 13. 위쪽 안내 한 줄 (앱 위쪽)

사용자가 누른 동작이 막히거나 실패했을 때다. 저장 성공 같은 일반 안내는 뺐다.

| 상황 | 문구 |
|---|---|
| 측정 중 로그아웃 | 측정을 종료하고 결과 저장을 확인한 뒤 로그아웃해 주세요. |
| 서버 확인 전 기록이 있을 때 로그아웃 | 결과 저장을 완료한 뒤 나가 주세요. |
| 계정 변경 처리 중 이동·로그아웃 | 계정 변경을 확인한 뒤 이동해 주세요. / 계정 변경을 확인한 뒤 로그아웃해 주세요. |
| 측정 중 수집 화면으로 이동 | 진행 중인 측정을 마친 뒤 이동해 주세요. |
| 서버 로그아웃 실패 | 서버 로그아웃을 확인하지 못했어요. 연결 후 다시 시도해 주세요. |
| 서버 설정을 못 불러옴(본문 오류 화면이 아닐 때) | 서버 설정을 불러오지 못했어요. 측정 전에 설정 화면을 다시 열어 주세요. |
| 설정 저장 실패 | 설정을 저장하지 못했어요. |
| 측정 시작 전 준비 안 됨 | 카메라 연결과 기준 등록을 완료한 뒤 시작해 주세요. / 기준 자세가 없어요. 자세를 먼저 등록해 주세요. |
| 이전 결과를 확인하는 중 | 이전 결과를 서버에서 확인하고 있어요. 확인 후 새 측정을 시작해 주세요. |
| 이 기기에 결과를 보관하지 못함 | 결과를 이 기기에 보관하지 못했어요. 창을 닫지 말고 저장 공간을 확인해 주세요. / 중간 기록을 보관하지 못했어요. 저장 공간을 확인해 주세요. |
| 서버 확인 전 기록이 손상됨 | 미확인 기록을 읽지 못했어요. 원본을 보존하고 새 측정을 중단합니다. |
| 서버 기록 확인 실패(본문 오류 화면이 아닐 때) | 서버 기록을 확인하지 못했어요. 임시 자료는 유지돼요. |
| 개발자 계정으로 측정 | 개발자 계정은 화면 확인용이에요. 서버 측정은 일반 계정으로 로그인해 주세요. |

서버 확인 전 기록이 있으면 홈에 「서버 저장 확인을 기다리는 기록 n개 · 이 기기에 임시 보관 중」과 「저장 확인 다시 시도」 버튼이 붙는다.

설정 저장(W2) 실패 사유:

| 상황 | 문구 |
|---|---|
| 401·403 | 로그인이 필요해요. 다시 로그인해 주세요. |
| 400 | 설정 값을 확인해 주세요. |
| 409 | 설정을 저장하지 못했어요. 다시 시도해 주세요. |
| 503 | 서버가 다른 작업을 처리하고 있어요. 잠시 뒤 다시 시도해 주세요. |
| 5xx | 서버 설정을 처리하지 못했어요. |
| 응답 없음 | 서버에 연결하지 못했어요. 연결을 확인해 주세요. |

## 14. 창 닫기 확인 (대화상자)

측정 중부터 결과가 나올 때까지 창을 닫으려 하면 묻는다. 닫아도 서버가 끊긴 시점까지 저장한다([ADR 0024](../../decisions/0024-session-ends-on-lost-connection.md)).

| 상황 | 문구 | 버튼 |
|---|---|---|
| 웹: 탭·창 닫기, 새로고침, 다른 주소로 이동 | 브라우저 기본 문구(예: 「사이트에서 나가시겠습니까?」). 앱이 바꿀 수 없다 | 브라우저 기본 |
| 데스크톱: X·Alt+F4([ADR 0017](../../decisions/0017-desktop-app-shell-and-redesign.md) 결정 9) | 측정 중이에요. 정말 닫을까요? / 닫으면 측정이 끝나요. 그때까지의 기록은 서버에 저장돼요. | 닫기 / 계속 측정 |

코드: `useSessionPersistence.ts` `beforeunload`, `electron/main.cjs` `will-prevent-unload`.
