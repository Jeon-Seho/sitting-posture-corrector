# 휴대폰에서 측정 기록 보기

- 상태: planned
- 담당: klaod-tech(FE). BE 요청은 김유진(DB·BE)
- 시작일: 2026-11-10
- 관련 요구사항/ADR: [FE 기능 명세](fe-feature-spec.md)(기록 조회·기간 통계), [ADR 0027](../../decisions/0027-today-records-from-collected-server-results.md)(기록은 R1 서버 기록), [연동 명세](api-ws-spec.md) 3·7장(R1·R1b·T1)

## 문제와 완료 기준

측정은 컴퓨터(웹·데스크톱 앱)에서 하지만, 지난 기록과 통계는 휴대폰에서도 보고 싶다. 기록은 이미 서버에 있다(R1). ADR 0027로 앱이 기록을 기기에 두지 않고 R1에서 받으므로, 휴대폰에서도 로그인만 하면 같은 기록을 볼 수 있는 구조다. 남은 것은 휴대폰 화면과 서버에 없는 조회 API다.

완료 기준:

1. 휴대폰 브라우저(Android Chrome, iOS Safari)에서 로그인하고, 컴퓨터에서 측정한 오늘 기록과 지난 기록·달력·최근 7일·30일 흐름을 볼 수 있다.
2. 폭 360~430px 화면에서 가로 스크롤 없이 읽힌다.
3. 다시 열어도 로그인이 유지된다(refresh 쿠키).
4. 휴대폰에서 측정 화면은 열리지 않거나, 열리면 컴퓨터에서 하라고 안내한다(이번 범위 밖).

## 범위와 제외

- 바꿀 곳: `frontend/src`의 로그인·오늘·기록·달력 화면 배치(`styles/responsive.css`, `styles/records.css`), 휴대폰에서의 메뉴, 측정 메뉴 안내.
- 쓰는 API: A3·A8·A4(로그인·유지), R1(기록). 서버에 생기면 R1b(기록 하나), T1(일별 통계).
- 제외: 휴대폰 카메라로 측정하기, 휴대폰 알림, 앱 스토어 앱. 설정 화면의 판정 기준 바꾸기는 W1·W2로 이미 서버에 있으므로 화면만 맞으면 된다.

## 지금 상태 (2026-11-10 확인)

| 항목 | 지금 | 휴대폰에 필요한 것 |
|---|---|---|
| 기록 데이터 | R1로 서버에서 받아 앱이 집계한다. 기기에 저장하지 않는다 | 그대로 쓴다 |
| 화면 배치 | 가장 좁은 기준이 600·860·960px(`@media`). 휴대폰 폭(360~430px)은 따로 맞추지 않았다 | 좁은 화면 배치 |
| 설치(홈 화면 추가) | `manifest`·서비스 워커가 없다. `viewport` 메타는 있다 | 하기로 하면 추가 |
| 로그인 유지 | 웹(`app.posegood.site` → `api.posegood.site`)은 refresh 쿠키로 된다 | 휴대폰 브라우저에서 확인 필요(특히 iOS Safari) |
| R1b 기록 하나 | 서버에 없다(BE-2, 형식 미정) | 상세 화면을 R1 목록에서 찾으면 없어도 된다 |
| T1 일별 통계 | 서버에 없다(BE-2, 형식 확정). 지금은 R1 전체를 앱이 집계 | 기록이 많아지면 휴대폰에서 R1 전체를 받는 부담이 커져 필요 |

## 정할 것

1. **앱 형태.** 추천: 지금 웹 앱(`app.posegood.site`)을 휴대폰 화면에 맞춘다(반응형). 서버·로그인·기록 코드를 그대로 쓰고 배포도 지금 Vercel 하나다. 홈 화면 추가(PWA `manifest`)는 그 뒤 선택. 별도 앱(React Native 등)은 로그인·기록 코드를 다시 만들어야 하고 이번 범위에 비해 크다.
2. **휴대폰에서 측정.** 추천: 이번에는 하지 않는다. 휴대폰 카메라 각도·성능이 컴퓨터 정면 웹캠과 달라 판정 기준(ADR 0021, 정면 640×480)이 맞는지 따로 봐야 한다.
3. **T1을 기다릴지.** 추천: 기다리지 않고 R1로 먼저 만든다. T1이 생기면 어제까지의 기간 통계만 T1로 바꾼다(ADR 0027 결정 3).

## 작업 단계

- [ ] 정할 것 1~3을 팀과 정한다.
- [ ] 휴대폰 브라우저에서 지금 웹 앱을 열어 로그인 유지·기록 화면이 어떻게 보이는지 확인하고 결과를 이 문서에 적는다.
- [ ] 좁은 화면 배치: 로그인, 메뉴, 오늘, 기록(달력·날짜 상세·최근 흐름), 설정.
- [ ] 휴대폰에서 측정 메뉴는 숨기거나 「측정은 컴퓨터에서 해 주세요」로 안내한다.
- [ ] BE에 T1·R1b 일정 확인(FE 제안서 BE-2).
- [ ] (선택) 홈 화면 추가용 `manifest`·아이콘.
- [ ] `python tools/dev.py check-frontend`, 휴대폰 실기기 확인(Android Chrome, iOS Safari), 결과 기록.
- [ ] 기능 명세(기록 조회·기간 통계·화면 구성)와 연동 명세에 휴대폰 동작을 적는다.
