# 개발자 실험실 `/dev`

> 현재 사이클은 [ADR 0044](../decisions/0044-optional-stretch-cycles.md)를 따른다. 기본은 이탈·복귀 반복이며 스트레칭은 선택한다.

2026-10-26부터 `/dev`는 [동작 관측·리플레이 화면](../decisions/0042-unified-dev-observation-route.md)으로
통일했다.

2026-10-26 시각 디테일은 사용자 제공 건강 앱 이미지를 참고한다. 검정 바탕과 둥근 차콜 카드,
항목별 Phosphor 아이콘·청록/주황/민트/파랑/핑크, 큰 흰색 숫자와 작은 회색 단위로 구분한다.
Pretendard 로컬 폰트와 기존 숫자 볼드를 유지하며 라이트 모드는 밝은 바탕·흰 카드·진한 강조색을 쓴다.
그래프는 기존 최근 10초 관측값과 누락 경계를 보존한다. 점수·가짜 수치·OS 장식은 추가하지 않는다.
관측 도구의 탭은 기본 노출하고 최대 384px로 가운데 정렬한다. 도움말·테마 아이콘은 같은 줄 오른쪽에 두어 별도 제목 행의 공간을 쓰지 않는다. 접기 버튼은 없으며 모바일에서는 아이콘과 제목을
세로로 놓는다. `수치·그래프 / 리플레이 / 비교표` 세 탭을 제공한다. 함께 보기는 최대 1560px
컨테이너에서 왼쪽의 큰 4:3 영상과 오른쪽 300~360px 그래프 1열을 배치한다. 데스크톱은 화면 높이에
맞춰 영상과 목록을 제한하고 오른쪽 패널 안에서만 스크롤한다. 기본 스크롤바는 숨기며 위/아래에
더 볼 내용이 있는 방향의 중앙에 배경 없는 56px 바를 표시한다. 처음은 아래, 중간은 양쪽, 마지막은
위에만 표시하며 넘침이 없으면 모두 숨긴다. 바를 누르면 목록 높이의 70%를 이동한다. 마우스·트랙패드·
키보드 스크롤을 유지하고 버튼 사용 후 초점은 목록으로 옮긴다. 내용/화면 크기 변화와 탭 복귀 시
가장자리를 재계산하고 줄어든 모션에서는 바의 부유 애니메이션을 끈다. 안내는 영상 왼쪽 위, 제어는 아래쪽의
같은 반투명·흐림 배경에 둔다. 시작 버튼에도 이 배경을 적용한다. 확대 토글과 변화율 목록 제목은
제거했다. 제어의 바깥 곡률은 버튼 반경 14px에 여백 9px를 더한 23px로 맞춘다. 상대 z 좌표는 마지막 카드다. 1100px 미만에서는 영상 위·목록 아래, 760px 미만에서는
그래프도 1열로 전환한다. 좁거나 짧은 화면은 자연스러운 페이지 스크롤과 최대 65svh 목록 내부 스크롤을
허용해 제어가 잘리지 않게 한다. 활성 라이브는 상단 고정 묶음으로 보이고 꺼진 영상·리플레이는
고정하지 않는다. 영상·안내·리플레이 트리를 계속 유지하며 입력 해상도와 추론은 바꾸지 않는다.
원시 추정 m와 기준 대비 %의 의미는 구분한다. 상대 z 좌표 카드도 공통 헤더·큰 값·작은 단위로
맞추고 보조 문구는 `기준 {값} m · 모델 추정` 또는 `기준 없음`만 표시한다. 수식과 해석은 도움말에 둔다.
각 지표의 설명은 제목 옆 헤더에서 아래쪽을 맞추며 폭이 좁으면 같은 헤더 안에서 줄바꿈한다.
카드 아이콘은 28px로 통일하고 제목·설명을 묶은 텍스트 영역의 세로 중앙에 정렬한다. 별도 위쪽 오프셋은 사용하지 않는다.

리플레이는 같은 왼쪽 프리뷰 슬롯에서 표시한다. 중앙에는 5초 뒤로 / 재생·일시정지 / 5초 앞으로
아이콘을 배치한다. 포인터 이동·터치로 중앙 제어·타임라인·설정이 함께 나타나고 2초 유휴 뒤 숨는다.
타임라인은 18px 아래에서 위로 260ms에 걸쳐 올라오며 나머지는 200ms 페이드한다.
키보드 초점이 있거나 설정이 열린 동안에는 유지하며 설정을 닫으면 유휴 숨김을 재개한다. 빈 기록의 설정은 항상 노출한다.
5초 이동은 양 끝에 제한하고 재생을 멈춘다. 하단 반투명 박스에는 가운데 시간과 탐색 막대만 두며
18px/24px/20px 여백을 준다. 탐색 막대는 브라우저 기본 테두리를 없애고 4px 트랙·12px 손잡이로 직접 그린다.
다크는 #327cff, 라이트는 #245ce0 블루이며 진행률과 탐색 값은 같은 위치를 사용한다. 모바일은 16px/20px/18px로 줄이고 설정 행과 분리한다.
파일 가져오기·최근 측정 보기·JSON 저장·속도·좌표 보기는 오른쪽 아래 톱니바퀴에서 조작한다.
기록 정보는 설정 끝의 동그라미 느낌표 아이콘으로 연다. 읽기 전용 모달은 재생을 멈추고 출처·프레임 수·
추출기·학습 해석을 보여준다. 닫기/Escape/바깥 클릭으로 닫고 아이콘으로 초점을 복원한다.
Tab 초점은 모달 안에서 순환하며 부모 설정의 Escape 처리와 분리한다. 긴 내용은 공통 부유 막대 스크롤을 쓴다.
최근 측정 보기는 불러온 파일 대신 현재 탭에 남은 가장 최근 측정 전체를 연결한다.
파일 가져오기는 기존 드래그앤드롭 모달을 연다. 속도/좌표 선택은 공통 SelectMenu의 앱 스타일 목록이며,
42px 트리거와 충분한 여백을 둔다. 속도/좌표 버튼의 테두리는 없애고 옵션 목록의 1px 테두리는 유지한다.
목록은 설정 내부 흐름에 배치하여 공통 부유 막대 스크롤로 접근한다.
방향키/Home/End·Enter·Escape를 지원하며 선택/닫기 후 트리거로 초점을 돌린다. Escape는 먼저 선택
목록만 닫는다. 설정은 Escape/바깥 클릭/파일 작업 선택으로 닫는다.
측정 종료 후 기록이 남으면 영상 빈 화면의 안내와 하단 제어를 측정 기록 안내·다시 측정·JSON 다운로드로
바꾼다. 두 버튼 높이는 데스크톱 48px/좁은 화면 42px로 통일한다. 다시 측정은 기존 모드 선택과 자료 보호 확인을 유지하며 다운로드는 현재 기록을 내보낸다.
왼쪽 위 출처/영상 미포함 배지는 설정의 기록 정보로 옮긴다. 오른쪽 위에는 ‘자세 라벨’ 제목 없이 동작·단계만 표시한다.
동작은 현재 프레임에 기록된 안내 동작이며
판정 결과가 아니다. 기록이 없으면 `등록된 자세 없음`을 표시한다. 라벨 배지는 12px/16px 여백을 두고 영상 경계에서 16px 띄운다. 오른쪽에는 라이브와 같은 여섯 카드와
최근 10초 그래프를 항상 표시하며 기록이 없으면 빈 값이다. v1 JSON에 기준 좌표가 없어 기록된 등록 단계와 완료 경계 프레임을
기존 8초 기하 엔진에 순서대로 전달해 표시용 기준을 복원한다. 등록이 불충분한 파일은 변화율을
비워 두며 수행 구간을 기준으로 삼지 않는다. 미래 값·누락 구간을 이어 그리지 않는다. JSON 형식과
안내 표식은 유지하며 재구성 지표는 수행 정답이나 학습 라벨이 아니다.
하나의 ObservationReplay가 재생 상태를 소유하며 화면만 포털로 옮긴다. 라이브 트리는 숨겨도
마운트를 유지한다. 실측 중에는 라이브를 우선하고 경쟁 재생·파일 조작을 막는다. 탭 이탈은 재생을
멈추지만 위치·불러온 파일을 유지한다. 상세한 기록 정보는 아이콘을 눌렀을 때만 모달에 표시한다.

비교표 탭에서는 영상을 숨기고 최대 1100px의 둥근 차콜 카드를 중앙에 배치한다. 주요 다운로드와
빈 값 표기만 기본 노출하고 긴 설명은 `비교표 안내`로 접는다. 행은 줄무늬 없이 얇은 구분선을 쓰고
항목 색상은 그래프와 맞춘다. 영상이 숨겨져도 스트림·안내는 계속되므로 활성 측정의 빨간 종료 버튼을
표 위에 남긴다. 완료한 측정 5초의 중앙값을 자동 반영하며 같은 동작은 최근 완료 회차로 갱신한다.
구간 시작/끝의 기존 500ms 공백 허용 범위와 연속성·2D 품질을 확인하고 중단된 시도는 합치지 않는다.
기존에 직접 담은 값은 보존한다. 기준 자세는 변화율 산출 기준으로만 쓰므로 별도 측정 행은 비워 둔다.
표를 비운 뒤 원본 시계열에서 자동 복원하지 않으며 원본 CSV·리플레이는 유지한다.

탭 사이의 구분선은 제거한다. hover는 배경을 바꾸지 않고 글자/아이콘을 진하게 1.045배 확대한다.
탭 선택 배경은 동일 폭 항목 사이를 420ms 가속·감속 이동하고, 안쪽 면은 가로로 늘며 얇아졌다가
도착 시 조금 부풀고 원래 크기로 돌아온다. 빠른 재선택은 현재 변형에서 새로 시작하고 이전 모션을 취소한다. 패널/버튼 등장과 테마 아이콘·색상은
180~240ms로 전환한다. 안내 패널 높이는 제어 구성이 바뀔 때만 애니메이션 처리하고 프레임·초 갱신에는
재시작하지 않는다. prefers-reduced-motion에서는 CSS와 높이 모션을 모두 끈다. 관측점·그래프 값은 보간하지 않는다.

별도의 `동작 선택` 탭은 제거했다. 안내 진행 중 동작 표식은 현재 단계에 맞춰 자동 선택된다.
시작창의 자동/수동 진행 모드는 유지한다. 라디오 원은 시각적으로 숨기되 네이티브 키보드 선택과
초점 표시는 유지한다. 선택 배경은 라이트 #edf2ff·다크 #202c43, 안내 주요 버튼은 블루와 흰색 700 굵기다.
일시정지/재개 버튼은 활성 측정 동안 고정 폭 슬롯에 항상 두며 준비·등록·수동 대기에는 비활성화한다.
다음 안내는 시간 아래 오른쪽 정렬하고 다음 동작명을 굵게 표시한다.
영상/비교표의 측정 종료는 확인창을 거쳐 실행한다. 취소하면 상태를 유지하고 확인 전에는 측정이 계속된다.
진행/일시정지와 빨간 종료 버튼은 큰 화면의 영상 내부 하단, 좁은 화면의 안내 아래에 함께 둔다. 별도 기준 재등록·상단 CSV 버튼은
없애고 비교표 안 다운로드와 기존 자료 보호 확인창의 다운로드는 유지한다. 카메라 위치를 옮긴 경우
종료 후 다시 시작해 기준을 등록한다. 도움말은 상단 테마 아이콘 왼쪽에 두고 아래로 펼친다.

이 문서 아래는 경로에서 제외된 기존 예측 실험실의 설계 기록이다.

기존 사용자 앱과 별도로 여는 로컬 연구 화면이다. [실험 출력](../../contracts/forecast-experiment.v1.md)을
소비하며 사용자 프로필·기록·서비스 알림·CEP 상태를 만들거나 변경하지 않는다.

## 디자인과 조작

소개 카드 중심 구성을 카메라 작업 공간으로 교체했고, 2026-10-14 피드백에 따라
**준비 중 큰 영상 → 측정 중 작은 영상과 상태 요약**으로 전환한다.
검정 배경과 간결한 제어, 기본 다크 테마를 사용하고 라이트 테마는 수동으로 전환한다.
문양·마케팅 문구·가상 인물 일러스트는 사용하지 않는다. 넓은 화면에서 측정 영상은 높이 270px,
현재 상태·기준 차이·연속 이탈 시간·알림은 옆 카드에 표시한다. 작은 화면은 세로로 배치한다.
「크게 보기/작게 보기」는 동일한 비디오·스트림을 유지한 채 레이아웃만 바꾼다.
영상의 상세 위치 수치, 모델과 규칙 비교, 입력 품질과 이벤트는 기본 접힌 항목으로 제공한다.
2026-10-15부터 카메라 위의 숫자 패널에는 이탈 확인·지속 이탈·최근 1초 실제 알림을 0/1로,
짧은 이탈 후 복귀·누적 알림을 횟수로, 이탈·복귀 경과를 초로 항상 표시한다.
룰과 예측 조합 상태를 나란히 표시하고 화면 이동·어깨폭 변화도 보여 정규화로 사라지는 변화를 확인한다.
원시 관측이 없으면 화면 수치를 숨긴다. 기존 화면 수치와 별도로, 새 고정 영상 보완은 등록 당시 얼굴·어깨의 공통 이동과 영상 어깨폭 축소를 판정에 사용한다. 상대 모양·몸 전체·종합 점수를 나눠 표시한다.
현재 요약과 카메라 상태는 선택한 알림 판단 기준을 따르며 관측 준비/측정 불가를 정상으로 바꾸지 않는다.
첫 요약은 기준 범위 유지 비율·실제 보낸 알림·비교 가능한 시간이다. 그래프는 기준과의 거리만
먼저 보여 주며 「예측 오차 함께 보기」를 선택하면 예측 오차와 한계를 추가한다.
알림 설정·내역은 그래프 아래에 두고 긴 판정 조건은 펼쳐서 읽는다.

- **실시간 실험:** 영상 중앙의 측정 시작 한 번으로 카메라 연결 → 짧은 안내 → 구도 정렬과 안정 확인
  → 유효 관측 8초·최소 65표본 기준 등록 → 측정.
  브라우저 카메라 권한은 최초 요청에서 사용자가 허용한다. 화면 진입만으로 카메라를 켜지 않는다.
- **실험 기록:** 현재 탭에서 종료한 실행을 최대 8개 보관한다. 새로고침하면 사라지며 각 실행을 내려받을 수 있다.
- **실험 설정:** 실행 중 예측 방법·모델·알림 기준을 변경하지 않는다. 변경 후 다음 실행에서 새 기준을 등록한다.
- **합성 데모:** 카메라 없이 명시적인 합성 시계열을 같은 연구 코어에 넣는다. 실제 측정과 별도 표시하고 합산하지 않는다.
  탭이 숨겨지거나 콜백이 늦어지면 측정 불가로 끊고 시나리오 진행을 멈춘다. 복귀 후 남은 동작을
  이어가므로 중단 시간만큼 전체 실행 시간이 길어질 수 있다.

## 카메라 가이드와 효과

얼굴과 어깨의 위치·크기를 구도선으로 안내하고 유효 구도를 약 0.5초 관측하면 자동 등록한다.
개별 관측점의 튐 대신 얼굴·어깨의 전체 구도를 확인한다. 짧은 추적 손실에는 준비 진행률을
잠시 멈추고 이어가며, 실제 구도 이탈이나 지속 손실에는 초기화한다. 등록 중에는 처음 구도의
픽셀 위치에 고정하지 않고 얼굴·어깨와 3D 관측이 유효하면 표본을 더한다. 짧은 누락은 등록을
잠시 멈추며, 오래 끊기거나 영상 크기가 바뀌면 다시 맞춘다.
등록 중 위치·가시성이 깨지면 재정렬하며 등록 완료 뒤에는 의도적인 자세 변화를 허용한다.
구도선은 촬영 준비용이며 정상 자세를 보장하지 않는다. [가이드 결정](../decisions/0026-developer-camera-guidance.md).

실제 영상과 13개 관측점에 같은 좌우 반전과 contain 좌표를 적용한다. 등록 구간의 평균 기준
윤곽을 현재 관측과 겹쳐 보여주며 현재점·변화 벡터·상태 색으로 움직임을 읽는다.
점선은 **등록 당시 화면 위치**다. 화면 좌우/상하 변화는 화면폭/높이 대비 코 위치의 변화이며,
판정에 사용하는 3D 자세 차이와 별도로 표시한다. 3D 입력은 매 관측의 양어깨 중심·폭으로
정규화하므로 몸 전체의 평행 이동과 일정한 크기 변화는 제거된다. 점선에서 떨어져 보이는 것만으로
자세 차이를 확정하지 않는다. `near_reference`는 **자세 차이 · 기준 범위 안**으로 표시한다.
안내 교체, 구도 확보, 기준 수집, 모델/룰 상태 전환에만 애니메이션을 연결하고
`prefers-reduced-motion`에서는 지속 움직임과 큰 전환을 줄인다.

연결 중 취소, 측정 종료, 화면 이탈은 카메라·타이머·관측 구독을 해제한다. 저품질·누락은
`unmeasurable`로 표시하고 기준 등록 또는 연속 판정을 끊는다. 측정 불가를 기준 유지로 채우지 않는다.

## 수치의 의미

기준 근처 비율은 등록 이후 유효하게 관측한 시간 중 기준 근처 상태의 시간 비율이다.
기준 등록·예측 준비·측정 불가·끊긴 구간은 유효 분모에서 제외한다. 0과 자료 없음은 구분한다.
거리·예측 오차는 정규화한 3D 좌표의 그룹 평균 거리이며 정확도·건강 점수·정상 확률이 아니다.
진입 12%/복귀 8%의 연구 임계값에 따른 범위이고 기준과 정확히 같다는 뜻은 아니다.
추이 그래프는 실제 수치 진단만 사용하며 자료가 없으면 빈 상태를 보여 준다.

매 관측을 양어깨의 3D 중심과 어깨폭으로 정규화한 뒤 개인 기준과 각 점의 3D 거리를 구한다.
얼굴 9점·귀 2점·어깨 2점의 그룹별 평균 거리를 다시 같은 비중으로 평균한다.
화면 좌우/상하 이동이나 어깨선 각도는 별도 표시값이며 이 거리 임계값으로 해석하지 않는다.

## 지속 이탈 알림

알림 기준의 기본값은 **관측 범위 + 지속시간**(`rule`)이다. 개인 정상 범위가 있으면 1배 초과 이탈,
2/3배 이하 복귀를 사용하고, 없으면 거리 기준을 사용한다. 실행 전 설정에서 **예측 + 거리·시간**(`predictor`)으로 바꿀 수
있으며 실행 중에는 고정한다. 두 결과의 비교 표시는 계속 유지한다.

| 코어의 연구 조건 | 지속 이탈 후보가 되는 때 |
| --- | --- |
| 거리·시간만 | 기준 거리 12% 이상으로 진입한 이탈이 3초 지속 |
| 예측 + 거리·시간 | 이탈 3초 이상과 낮은 예측 오차 1초 이상을 함께 만족하거나, 이탈이 5초 지속 |
| 지속 이탈 후 복귀 | 거리 8% 이하로 돌아와 3초 유지하면 복귀 완료 |

거리 8% 초과·12% 미만 구간에서는 이미 시작한 이탈의 연속성을 유지하는 히스테리시스를 적용한다.
낮은 오차는 등록 중 대응 예측 잔차가 20개 이상이면 99분위수와 최소값 0.02 중 큰
한계 이하다. 표본이 부족하면 개인 오차 추정 대신 최소값 0.02를 사용한다.
수치의 근거와 연구 경계는 [ADR 0025](../decisions/0025-local-forecast-experiment.md)를 따른다.
이 화면의 알림부는 이 조건을 재판정하지 않고 선택한 코어의 `persistent_deviation_candidate`만 소비한다.

같은 사건은 최초 한 번 알리고, 지속 이탈 후보가 계속 관측되면 마지막 알림에서 60초가 지난 뒤
재알림한다. `recovery_pending` 중 다시 벗어나면 같은 사건으로 유지한다.
`near_reference`가 되면 사건을 종료한다. 저품질·관측 간격 누락도 알림 사건을 끊지만,
이는 정상 복귀가 아니다. 다음에는 새 코어의 지속 이탈 후보를 기다린다.
관측이 연속인데 예측값만 잠시 준비 중이면 알림을 억제한다. 코어가 같은 이탈/복귀 확인 사건을
유지하는 동안 사건과 최대 거리는 보존하므로 준비가 끝났다는 이유로 최초 알림을 다시 만들지 않는다.
등록 전·등록 중·측정 불가·예측 준비 중에는 울리지 않는다.

소리는 기본 꺼짐이다. 사용자가 켠 경우 브라우저 내장 Web Audio로 짧게 재생한다. 소리를 켠 상태라면 측정/합성 데모 시작 클릭에서 준비하고,
사용자가 소리 켜기나 소리 테스트를 누를 때도 준비할 수 있다. 브라우저가 소리를 차단하면
표시로 상태를 알리며 자동으로 재개하지 않는다. 음소거해도 시각 알림·알림 수·기록은 유지한다.
종료·음소거·개발자 경로 이탈 때 대기 중인 소리를 취소하며 OS 알림이나 서비스 알림은 호출하지 않는다.
숫자 표시의 범위와 한계는 [ADR 0033](../decisions/0033-live-decision-numbers.md)을 따른다.

알림 기록에는 알림 시점의 거리, 그 사건에서 관측한 최대 거리, 이탈 지속시간, 예측 오차와 한계를
복사해 남긴다. 이후 움직임이 바뀌어도 과거 알림 값은 바꾸지 않는다. 최근 100개를 시간순으로 보관하고,
전체 실행의 알림 수는 따로 누적한다. 알림 수는 재알림도 포함하므로 지속 이탈 후보 사건 수와 다르다.
합성 데모의 알림은 합성 출처로 표시한다.

### 일시적인 움직임과 스트레칭의 한계

현재 동작을 스트레칭·작업 자세 등으로 분류하는 모델은 없다. LSTM은 300ms 뒤의 좌표를 예측한다.
큰 예측 오차는 예상 밖 움직임이라는 뜻이며 일시적인 스트레칭을 확정하지 않는다.
실제로 기준 범위로 돌아와야 짧은 이탈로 확인할 수 있다. 오래 유지한 스트레칭도 지속 이탈 후보가
되어 알림이 울릴 수 있다. 높은 오차만으로 지속 이탈을 무기한 제외하지 않는 5초 보완 조건의 한계다.

## 모델과 데이터

기본 마지막 위치 유지 예측 및 등속 예측은 학습 가중치 없이 실행한다. LSTM은 유효한
`forecast-weights-v1` 파일이 있을 때만 선택할 수 있다. `/research-model/forecast.json` 자동 읽기 또는
설정의 파일 불러오기를 사용한다. 불러온 모델은 현재 탭 메모리에만 둔다. 누락·HTML 응답·손상된 파일을
학습 모델로 대체하지 않는다. 기존 `/#forecast` 경로는 유지한다.
유효한 로컬 가중치를 발견하면 처음에는 LSTM을 기본 선택한다. 사용자가 선택한 단순 예측이나
실행 중인 실험은 그대로 유지한다. 수동 파일 연결은 다음 실행을 LSTM으로 선택한다.
현재 Mac의 [실제 재학습 및 측정 흐름](../ml/jisung/2026-10-13-mac-dev-lstm-training.md)을 확인한다.

실제 영상·관절 좌표·기준 좌표·모델 가중치를 저장하거나 자동 전송하지 않는다.
사용자가 내보내는 것은 [개발자 진단 export v1](../../contracts/developer-lab-export.v1.md)이다.
실제 사용자의 자세 구분 정확도와 Panoptic↔MediaPipe 입력 호환성은 여전히 미검증이다.

## 구현 경계

`frontend/src/features/developer/`는 UI·카메라 수명·표시 집계, `model/prototype/forecast.ts`는
특징·등록·예측·연구 판정을 소유한다. `developerGuidance.ts`는 연구 화면의 구도 기하를 소유한다.
경로는 `/dev`와 `/dev/`만 선택하며 기존 루트/해시 경로는 유지한다.
개발자 CSS는 `.dev-lab` 안에만 적용하고 라우트를 지연 로딩한다. `/dev`는 인증 관리자 화면이 아니며
서버나 다른 사용자의 데이터에 대한 접근 권한을 제공하지 않는다.

이번 변경의 추가 패키지는 없다. [의존성 기록](developer-lab-dependencies.md)과
[서비스 승격 절차](../../frontend/src/features/developer/README.md)를 별도로 관리한다.

알림 전달 결정과 개발용 재알림 간격의 근거는 [ADR 0027](../decisions/0027-developer-posture-alerts.md)을 따른다.
카메라 안내 영역에도 지속 후보 알림과 현재 거리·시간을 표시해 영상을 보면서 확인할 수 있다.


## 2026-10-14 정상 자세 수집과 현재 판단

`정상 자세 수집`에서 유효 관측 30초와 구간 확인 후 개인 정상 범위를 적용한다.
웹캠 측정과 수집은 서로 배타적이며 이동/중단 시 수집을 종료한다. 영상은 저장하지 않는다.
별도 원본 좌표 다운로드·개인 범위 저장/불러오기만 명시적으로 실행한다.
현재 상태 카드/그래프/알림은 개인 범위가 있으면 경계 대비 배수(1배 진입, 0.67배 복귀),
없으면 기존 어깨폭 대비 거리를 표시한다. 기본 알림은 기준 이탈+지속시간이며 LSTM은 비교 모드다.
예측 보조 준비와 측정 불가를 구분한다. 키포인트 표시만 적응 평활화하고 누락 시 숨긴다.
구현/연구 상태는 [최신 ML 계획](../ml/current-plan.md)을 따른다.


## 등록 영상에 고정한 큰 변화 보완

새 `/dev` 실행은 어깨 정규화 상대 좌표와 함께 등록 당시 영상에 고정한 위치·크기를 비교한다. 몸 전체가 뒤로 물러나 작아지거나 크게 이동하면 상대 모양이 같아도 종합 점수가 올라간다. 작은 흔들림에는 허용폭과 200ms 평활화, 기존 3초 지속·복귀를 적용한다. 큰 이탈은 자동 정상 수집에서 제외한다. 카메라 고정이 전제이며 실제 후방 각도·의도 분류가 아니다. [ADR 0034](../decisions/0034-fixed-image-posture-anchor.md).
후속 영상 v2는 이동 하한 18% 등록 어깨폭·축소 12%로 조정했다. 자동 수집은 종합 0.5배 이내·실측 룰 범위 안·실측 1초 연속을 함께 요구한다. 이전 선별 자료는 보존·재검토 표시하며 학습을 차단한다. [현재 조정](../decisions/0035-posture-and-clean-normal-selection.md).

새 실행의 종합 진입은 사용자 지정0.7배, 복귀는0.7×2/3배다. 숫자·게이지·그래프·설정·내보내기의 실제 경계를 일치시키고 과거1배 결과는 소급하지 않는다. [ADR 0036](../decisions/0036-composite-entry-point-seven.md).

## 관측 스크롤 표시 규칙

`/dev`의 커스텀 세로 스크롤은 정보 목록·도움말·설정 팝업 모두 `ObservationScrollPanel`을 공유한다.
네이티브 바 대신 같은 위/아래 부유 막대를 쓰고 팝업은 막대 전용 여백을 두어 내용을 가리지 않는다.
넘침 없음/숨김/내용 크기 변경을 관찰하며 휠·트랙패드·키보드와 버튼 이동·초점을 유지한다.
OS 기본 선택 메뉴는 이 커스텀 스크롤 대상에 포함하지 않는다. 감소된 모션에서는 부유·탭 이동과 변형을 끈다.
