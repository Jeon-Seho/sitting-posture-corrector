- 대상: 우진(데스크톱 앱 화면·자동 기준 등록·다른 탭 측정 유지)
- 작성: 동욱 요청, Claude 작성 (2026-10-08)
- 기준 코드: `lee_app1`(develop PR #22)
- 관련: [판정 불가 처리](unmeasurable-handling.md)(판정 규칙 전체, DevOps용), [ADR 0012 세션 시간 정책](../decisions/0012-session-timing-policy.md),

판정 불가 처리를 바꾸기로 하면서 우진 담당 화면에 필요한 변경이 두 가지 생겼다(1·2번).

## 1. 자동 기준 등록 전에 어깨 구도 확인 (요청)

### 문제

[useAutoBaseline.ts](../../frontend/src/features/camera/useAutoBaseline.ts)는 얼굴과 양어깨가 0.8초(`AUTO_CALIBRATE_DELAY_MS`) 보이면 보정을 시작하고,
보정이 끝나면 측정을 시작한다. 보정은 판정 가능한 프레임인지만 확인한다([calibration.ts](../../model/prototype/calibration.ts)).
판정 가능 기준은 어깨·코가 화면 가장자리 2% 안쪽에 있고 visibility가 0.65 이상이다([pose.ts `features()`](../../model/prototype/pose.ts)).

그래서 어깨가 화면 아래 끝에 겨우 걸친 상태(예: y = 0.95)에서도 기준이 만들어진다.
구부정해지면 어깨와 머리가 아래로 내려가 y가 0.98을 넘거나 visibility가 떨어지고, 그 프레임은 판정 불가가 된다.
결과적으로 **잡아야 할 무너진 자세가 판정 불가로 빠져서 경고가 울리지 않는다.**
동욱 환경(작은 카메라 화각)에서 실제로 어깨가 보였다 안 보였다를 반복한다.

### 요청하는 동작

- 자동 보정 시작 조건에 구도 확인을 더한다. 양어깨가 화면 아래 끝에서 일정 거리 이상 떨어져 있고, visibility가 충분할 때만 0.8초 대기를 시작한다.
- 조건을 못 채우면 보정을 시작하지 않고 안내한다. 예: "어깨가 화면 아래에 걸려 있어요. 카메라를 조금 올리거나 뒤로 앉아 주세요."
- 수동 "기준 다시 찍기"에도 같은 조건을 쓴다. 보정 중에 조건이 깨지면, 지금처럼 판정 불가 프레임이 나왔을 때와 같이 다시 시작한다.
- 카메라 안내 화면의 사람 맞춤(이전 작업)과 같은 자리에서 보여 주면 자연스럽다.

### 아직 정하지 않은 값

여백 크기(예: 어깨 y ≤ 0.85)와 visibility 기준(예: 0.8)은 **근거가 없어서 아직 정하지 않았다.**
동욱이 디버그 CSV에 어깨·코 visibility 열을 다시 넣고 평소 자세와 구부정한 자세를 찍은 뒤 값을 정해서 알려 준다.
값을 상수 하나로 두면 나중에 숫자만 바꾸면 된다.

## 2. 판정 불가로 자동 멈춤·재개될 때의 화면 표시 (요청)

### 바뀌는 판정 규칙 (동욱이 `lee_app1`에서 구현 예정)

| 상황 | 처리 |
|---|---|
| 판정 불가 3초 미만 | 판정 시계만 멈춘다. 화면은 지금처럼 "판정 불가", 점수 숨김 |
| 판정 불가 3초 연속 | 측정을 **자동 멈춤**. "측정 멈춤 – 어깨가 보이게 앉아 주세요" |
| 멈춘 뒤 0.5초 연속 판정 가능 | **자동 재개**. 버튼을 누를 필요가 없다 |
| 카메라 입력 1.5초 넘게 끊김 | 지금처럼 멈춤, 직접 재개(변경 없음) |

### 우진 화면과 부딪히는 곳

"다른 탭에서도 측정 유지" 때문에, 사용자가 기록 탭이나 설정 탭을 보고 있을 때 자동 멈춤이 걸릴 수 있다.
지금 사이드바는 측정 중이면 점 하나만 보여 준다([AppSidebar.tsx](../../frontend/src/app/AppSidebar.tsx) `nav-live`).
그래서 멈춘 것인지 측정 중인지 구별할 수 없다.

### 요청하는 동작

- 사이드바 측정 표시를 세 가지로 나눈다: **측정 중** / **자동 멈춤(다시 보이면 이어짐)** / **멈춤(직접 재개 필요)**.
  상태 값은 세션 화면 상태에서 받도록 동욱이 함께 열어 둔다.
- Electron 창이 최소화돼 있거나 다른 앱을 보고 있을 때 자동 멈춤을 알릴지는 정해야 한다.
  자동 재개되는 상태라 알림 없이 두는 안과, 자동 멈춤이 오래(예: 30초) 이어지면 한 번 알리는 안이 있다. 우진 의견이 필요하다.

## 3. PR #22로 우진 화면이 바뀐 점 (알림)

- 결과 화면 [SessionResult.tsx](../../frontend/src/features/session/SessionResult.tsx)
  - "저장 다시 시도"는 저장에 실패했거나 확인을 못 받았을 때만 보인다(`saveFailed`).
  - 그 자리에 "측정 데이터 저장" 버튼이 나온다. 로컬 카메라 측정에서만 보이고,
    Kafka 형식 구간 데이터(`.txt`)와 분석용 좌표(`.csv`)를 내려받는다.
- 기본 정상 복귀 시간이 2초 → 3초다. 브라우저 시나리오([scenarios.mjs](../../tools/browser/scenarios.mjs), [accounts.mjs](../../tools/browser/accounts.mjs))의 기대값도 3·3·60으로 바뀌었다.
- 어깨 기울기 기준이 0.13 → 0.03이다([ADR 0019](../decisions/0019-shoulder-tilt-scale.md)). 어깨가 조금만 기울어도 점수가 오른다. 실측 확인 전이다.
