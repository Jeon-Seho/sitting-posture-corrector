# 개인정보 수집 동의 제안서 초안

> 작성: 2026-10-13 · FE · 상태: **초안** · 대상: DB(동의 저장), BE(가입 API), PM(문구 확정)
> 근거: [FE 제안서](fe-server-proposal.md) F12, [ADR 0021](../decisions/0021-app-sends-information-server-judges.md)(좌표 수집 동의는 가입 필수), 아키텍처 v5.1(탈퇴 30일 뒤 삭제 J4), DB V2.1(`user_consent` 보류)
> 한국 개인정보보호법 기준으로 FE가 정리한 안이다. 법률 검토가 아니므로 최종 문구는 지도교수·학교 확인을 거친다.

## 1. 가입 화면 동의 목록

| # | 동의 | 필수/선택 | 거부하면 |
|---|---|---|---|
| C1 | 서비스 이용약관 | 필수 | 가입할 수 없다 |
| C2 | 회원가입 정보 수집·이용 | 필수 | 가입할 수 없다 |
| C3 | 선택 정보(나이·직업) 수집·이용 | 선택 | 불이익 없음. 입력란을 비운다 |
| C4 | 카메라 관절 좌표 수집·이용 | 필수 | 측정을 할 수 없어 가입할 수 없다(로컬 모드 없음, ADR 0021) |
| C5 | 측정 기록 저장 | 필수 | 결과·기록·통계를 보여 줄 수 없어 가입할 수 없다 |
| C6 | 학술·ML 학습용 기록 활용 | 선택 | 불이익 없음. 서비스는 그대로 쓴다 |
| C7 | 만 14세 이상 확인 | 필수 | 가입할 수 없다(법정대리인 동의 절차는 두지 않는다) |
| — | 개인정보 처리방침 | 동의 아님 | 가입 화면과 설정에 링크로 둔다 |

- 필수와 선택을 한 체크박스로 묶지 않는다. 「전체 동의」 버튼은 두되 각 항목을 따로 끌 수 있게 한다.
- C4는 다른 항목과 섞지 않고 따로 받는다. 자세 좌표가 건강 관련 정보로 볼 여지가 있어서다.

## 2. 항목별 고지 내용

동의마다 수집 항목, 목적, 보유 기간, 거부할 권리와 불이익을 적는다.

| # | 수집 항목 | 목적 | 보유 기간 |
|---|---|---|---|
| C2 | 이메일, 비밀번호(단방향 해시), 이름 | 로그인, 계정 관리 | 탈퇴 후 30일 |
| C3 | 나이, 직업 | 사용자 환경별 통계(선택) | 탈퇴 후 30일, 또는 입력란을 지울 때 |
| C4 | 관절 9곳(코·눈·귀·입 양끝·어깨)의 화면 좌표와 시각. **영상·사진은 기기 밖으로 보내지 않는다** | 자세 판정과 교정 알림 | 측정 원본은 탈퇴 후 30일 |
| C5 | 측정 세션, 이탈 사건, 알림 기록, 일별 통계, 기준 자세 | 결과·기록·통계 화면 | 탈퇴 후 30일 |
| C6 | **스켈레톤(관절 좌표와 시각)만**. 계정 정보(이메일·이름·나이·직업)는 붙이지 않는다 | 학술 연구, ML 모델 학습 | **30일**(기준 시점은 3장 ①) |

## 3. 정할 것

| # | 질문 | FE 안 |
|---|---|---|
| ① | C6 보유 기간 30일의 기준 | 수집한 날부터 30일. 그 안에 학습용으로 옮긴 사본은 계정과 분리된 상태로 연구 기간 동안 둔다. 이렇게 할지, 탈퇴 후 30일로 할지 |
| ② | 이미 학습한 모델 | 동의를 철회하거나 30일이 지나도 이미 학습한 모델은 지우지 않는다는 문장을 C6에 넣는다 |
| ③ | IRB 연구 참여 동의 | 논문에 쓰면 학교 IRB 기준의 연구 참여 동의서가 따로 필요한지 확인한다. 필요하면 C6과 합치지 않고 수집 참여자에게만 받는다 |
| ④ | 학습 데이터가 어디서 오나 | 아키텍처 v5.1은 학습을 앱의 CSV 수동 수집으로 하고 HDFS와 잇지 않는다. C6이 서비스 측정 좌표에도 적용되는지, 수집 화면 CSV에만 적용되는지 정한다. 수집 CSV v3에는 참여자 코드·촬영 환경·자기 보고가 함께 있어 "스켈레톤만"과 맞춰야 한다(수집 화면은 다른 담당) |
| ⑤ | 동의 저장 | DB `user_consent`(V2.1 보류)를 살린다. 행: 사용자, 동의 종류(C1~C7), 문서 버전, 동의 여부, 시각. 철회도 새 행으로 남긴다 |
| ⑥ | 철회 | 설정에서 C3·C6을 끌 수 있다. C4·C5 철회는 탈퇴와 같다(측정할 수 없음) |

## 4. API에 미치는 것

- `POST /auth/register`의 `consents`: `[{type: "C1".."C7", version, agreed}]`([API 명세](api-ws-spec.md) 2.2).
- 설정에서 C3·C6 철회: `PUT /consents/{type}` `{agreed: false}`를 더한다(초안).
- 지금 계정 계약 v1의 `consent_version: "service-v1"` 하나는 이것으로 바뀐다.
