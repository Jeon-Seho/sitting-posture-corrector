# 정면 어깨 위 관측의 판정 한계

- 작성: 2026-10-15
- 상태: 수집 전 범위 정의. 실제 구별 성능과 허용 촬영 조건은 아직 검증하지 않았다.
- 관련: [재설계 계획](rebuild-plan.md), [ADR 0038](../decisions/0038-ml-rebuild-scope.md), [실행 계획 0052](../plans/active/0052-ml-rebuild.md).

사용자는 정면에서 어깨 위만 보이는 조건을 목표로 하며, 기준 형태를 유지한 채 몸을 옮기면
원하는 자세 변화를 놓쳤다고 보고했다. 이는 사용자 관찰이며 정량 성능 측정 결과는 아니다.
먼저 무엇을 판정할 수 있는지 정한다. 데이터 양과 LSTM 구조를 정하는 작업은 그다음이다.

## 이번 설계에서 주장하지 않을 것

정면 어깨 위 랜드마크만으로 전신의 정상·비정상, 허리·골반·척추 상태를 판정하지 않는다.
등록 기준은 사용자가 선택한 관측 기준이지 올바른 자세의 정답이 아니다.
등록 때와 비슷하다는 결과도 실제 신체 자세가 적절하다는 뜻이 아니다.

서로 다른 신체 상태가 같은 입력 좌표와 관측 이력을 만들면, 그 입력을 받는 모델은 두 상태를
개별 사례에서 확실히 구분할 수 없다. 학습이 자료의 상관관계를 이용할 수는 있지만,
보이지 않는 상태를 실제로 측정한 것으로 바꿀 수는 없다. 영상의 정보와 모델에 남긴 특징의 정보도 구별한다.

MediaPipe는 영상 좌표와 추정 world 좌표를 출력한다. world의 기준점은 엉덩이 중점이다.
이 출력이 있다는 사실만으로 가려진 몸통이나 깊이를 검증된 실측으로 취급하지 않는다.
이는 [공식 출력 정의](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/web_js#handle_and_display_results)를 바탕으로 한 이번 연구의 해석 제한이다.

엉덩이 중점은 좌표계 원점이며 엉덩이 노출이 z 출력의 필수 조건이라는 뜻은 아니다.
같은 Pose 출력의 코 z와 양어깨 평균 z의 차이에서는 공통 원점이 상쇄된다.
어깨 위 촬영에서 이 상대 깊이가 실제 전방 변화와 대응하는지는 미검증이다. 별도 후보로 확인하되 확정 판정 근거로 삼지 않는다.
Face의 턱 z와 Pose의 어깨 z는 공통 좌표계 확인 없이 직접 빼지 않는다.
후속 거북목 제안과 다른 브랜치의 턱 활용·합성 규칙 확인은 [2026-10-15 기록](jisung/2026-10-15-desktop-ml-scope-and-depth-review.md)에 정리했다.

## 판정 범위

아래의 측정 후보는 가능한 입력의 종류다. 현재 장비에서 안정적으로 검출된다는 성능 주장이 아니다.

| 원하는 결과 | 정면 어깨 위에서의 취급 | 이유와 조건 |
| --- | --- | --- |
| 등록 대비 영상상 머리의 좌우 기울어짐, 머리와 어깨의 상대 위치 변화 | 측정 후보 | 보이는 2D 변화만 표현. 실제 목 관절 각도나 원인을 붙이지 않음 |
| 영상상 어깨선 기울기 변화 | 측정 후보 | 어깨 추적 품질과 카메라 고정 조건 필요. 몸통 전체 기울기로 일반화하지 않음 |
| 얼굴·어깨의 공통 이동, 영상상 어깨폭 확대·축소 | 별도 측정 후보 | 화면 안 배치 변화. 몸·의자·카메라 이동과 회전 등이 섞일 수 있음 |
| 앞쪽으로 목을 뺐는지, 상체 전체가 움직였는지 구별 | 현재 보장 대상에서 제외 | 정면 투영·가림·형태 유지로 모호한 사례가 생김. 앞으로 움직였다는 방향도 확정하지 않음 |
| 허리 굽힘, 골반 위치, 척추 곡률, 전신의 정상 자세 | 대상에서 제외 | 필요한 부위·독립 기준을 관측하지 않음 |
| 잠깐 화면을 읽는 동작과 원치 않는 자세 변화의 의도 구별 | 대상에서 제외 | 같은 관측에 다른 의도가 가능. 지속시간은 알림 정책일 뿐 의도의 정답이 아님 |
| 보이지 않거나 불안정한 점의 상태 | `unmeasurable` | 좋은 자세나 유효한 이탈로 채우지 않음 |

대상에서 제외한 신체 상태와 측정 품질 실패는 다르다. 머리·어깨가 잘 관측되면 지원하는 2D 항목은
측정할 수 있다. 허리가 안 보인다는 이유만으로 그 관측 전체를 `unmeasurable`로 만들지는 않는다.
반대로 지원 항목에서 변화가 없다는 결과를 제외한 신체 상태까지 정상이라고 해석하지 않는다.

## 형태를 유지한 이동이 빠지는 이유

기존 [`liveForecastPoints`](../../model/prototype/forecast.ts)는 매 프레임 어깨 중심을 빼고
현재 어깨폭으로 나눈다. 입력 점 전체에 같은 이동과 양의 배율을 적용하면 정규화된 형태는 같다.
이 입력만으로는 제거된 이동·크기 신호를 LSTM이 복원할 수 없다.

현재 코드는 별도의 [`ImagePostureAnchor`](../../model/prototype/imagePosture.ts)에서
등록 영상 대비 얼굴·어깨의 공통 이동과 어깨폭 축소를 보완한다. 따라서 현재 구현 전체가
모든 이동을 무시한다고 단정하지 않는다. 이 보완도 이동 원인이나 자세의 적절성을 판정하지 못하며,
현재 축소 항목은 확대를 표현하지 않는다.

새 설계는 다음을 별도로 보존하고 검증한다.

1. 형태: 머리·어깨의 상대 위치와 영상상 방향.
2. 배치: 등록 영상 대비 공통 이동, 어깨폭의 확대·축소.
3. 품질: 가시성, 누락, 구도와 추적의 유효성.

배치 변화만으로 나쁜 자세 점수를 만들지 않는다. 큰 변화는 원인을 확인할 수 없는 구도·위치 변화로
표현하는 안부터 검토한다. 움직인 신체를 새 정상으로 자동 등록하지 않는다.
카메라를 실제로 옮긴 경우에는 기존 기준을 계속 쓰지 않고 사용자가 조건을 확인한 뒤 재등록한다.
이 항목은 새 연구 출력 제안이며 현재 서비스 출력 계약이나 화면을 바꾸는 결정이 아니다.

## 0.3초 예측이 했던 일

기존 [ADR 0025](../decisions/0025-local-forecast-experiment.md)의 실험은 과거 좌표로
0.3초 뒤 좌표를 예측한 뒤, 그 시각의 실제 관측과 비교한 오차를 사용한다.
예측값은 미래의 정상·비정상 라벨이 아니다. 오차가 작다는 것은 이 좌표 예측이 잘 맞았다는 뜻이다.
고정된 기준 밖 자세도 잘 예측될 수 있고, 기준 근처의 빠른 움직임은 예측 오차가 클 수 있다.

`ForecastPolicy`의 LSTM 보조 경로는 기준 이탈 3초에 낮은 오차 1초 조건을 추가하고,
이탈 5초에서는 그 조건 없이 확정하는 실험이다. 룰 경로에는 낮은 예측 오차 조건이 없다.
따라서 이 실험의 예측은 조기 경고를 보장하는 기능이 아니라 확정 조건을 보조하는 기능이다.
낮은 오차를 일시 동작과 구분하는 근거로 쓸 수 있는지도 별도 검증이 필요하다.

새 계획에서는 이 미래 회귀를 이어가지 않는다. LSTM 분류기도 필수 후보에서 내린다.
지원할 현상·라벨·단순 측정 기준이 정해지고 시간 이력의 추가 이득을 검증할 이유가 생길 때만 검토한다.

## 팔꿈치를 필수로 할지

팔꿈치 포함을 해결책으로 확정하지 않는다. 팔꿈치는 팔의 추가 기준이며 몸통·골반의 대체 기준이 아니다.
키보드·책상·팔 동작에 따라 달라질 수 있어, 먼저 무엇을 더 구별할지 정해야 한다.

| 촬영 범위 후보 | 추가로 확인할 정보 | 남는 제약 |
| --- | --- | --- |
| 얼굴·양어깨 | 현재 목표 사용 조건을 유지하는 2D 변화 | 숨은 몸통과 깊이 모호성 유지 |
| 팔꿈치까지 | 어깨와 팔의 관계 | 팔 움직임·가림의 영향. 몸통 상태를 직접 보여주지는 않음 |
| 몸통 아래 기준까지 | 보이는 몸통의 축과 상대 위치 | 더 넓은 구도 필요. 정면 한 시점의 깊이·내부 척추 상태를 보장하지 않음 |
| 측면·사선 또는 추가 관측 | 일부 앞뒤 변화가 영상에 드러나는지 확인 | 설치·사용 조건이 달라짐. 유효성은 별도 실험 대상 |

우선안은 어깨 위 조건을 유지하면서 지원 현상을 좁히는 것이다. 팔꿈치 필수화는 보류한다.
몸통이나 앞뒤 자세 판정이 반드시 필요한 요구라면, 관측 범위·시점을 바꿀 수 있는지 먼저 결정한다.
요구와 촬영 제약이 양립하지 않으면 해당 기능을 범위에서 내린다. 학습을 반복해 해결된 것으로 취급하지 않는다.

## 수집 전에 할 확인과 진행 조건

다음 단계는 학습 자료 수집이 아니라, 같은 사람이 직접 보는 짧은 관측 한계 확인이다.
현 단계에서 영상·실제 좌표를 새로 저장하거나 학습할 필요는 없다. 아직 이 확인을 실행하지 않았다.

- 머리·어깨 모양을 비슷하게 유지한 채 가려진 몸통 상태를 바꾸기: 서로 다른 상태가 같은 입력으로 남는지 확인.
- 머리·어깨를 함께 이동하기: 상대 형태와 화면 위치를 각각 확인.
- 카메라 이동·의자 이동·몸의 이동을 비교하기: 현재 입력으로 원인을 구분할 수 있는지 확인.
- 고개 기울임과 고개 돌림·가림을 비교하기: 측정할 현상과 품질 실패를 혼동하는지 확인.
- 팔꿈치가 보이는 조건과 가려지는 조건 비교: 명시한 목표 현상을 더 구별하는 정보가 생기는지 확인.

이는 반례를 찾는 확인이다. 몇 번 구별됐다고 정확도를 계산하거나 타인 일반화를 주장하지 않는다.
결과는 실제 좌표 대신 상황·화면 조건·구분 가능/모호·근거만 기록한다.

본 수집으로 가려면 지원 현상, 제외 상태, 구도·품질 조건, 사람의 라벨 정의, 모호한 경우의 처리를 먼저 고정한다.
`reference/deviation` 라벨도 이 지원 현상의 기준 유지/변화에만 붙이고, 정상/나쁜 자세의 정답으로 쓰지 않는다.
원하는 목표가 보이지 않는 상태에 의존하면 구도 또는 목표를 바꿀 때까지 수집·학습을 진행하지 않는다.
기존 75분 수집안과 모델 탐색 예산은 이 조건을 통과한 뒤 재검토할 참고안이다.
