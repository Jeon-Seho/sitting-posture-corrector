# 2026-10-29 ML·/dev 변경 메모

개인 메모 겸 팀 공지용 요약. 상세는 [ADR 0043](../../decisions/0043-base-deviation-stretch-collection.md),
[재설계 계획 G4](../rebuild-plan.md#출력-점수-3클래스-softmax-2026-10-29-사용자-결정),
[점검 기록](2026-10-29-desktop-replay-training-feasibility.md).

```text
[바뀐 방향]
- 목표: "알림을 보낼 자세인가" 판정
- 라벨: 기준 / 이탈 / 스트레칭 (3클래스 softmax)
- 점수: p(이탈) = collapse_probability  (화면 점수 100 x (1 - p) 그대로)
- n초 지속 판단: 판정 서버의 3초 규칙에 맡김 → LSTM 안 씀
- 머리 내밀기·고개 숙이기·몸통 접근·어깨 올리기 과제는 더 측정 안 함
- 이탈 = 각자 "알림 받아야 한다"고 생각하는 자세, 매번 종류·크기 바꾸기
- 스트레칭 = 앉은 채로만. 서서 하는 스트레칭은 측정 불가로 둠

[/dev 측정 방법 (프로토콜 v4)]
- 한 바퀴: 기준 → 이탈(5초 유지) → 기준 → 앉은 채 스트레칭(8초 유지) → 기준
- 시작 창에서 선택: 수동/자동, 바퀴 수 1 또는 3 (기본 1), 순서 섞기 (기본 켬)
- 1바퀴씩 여러 번 권장. 실행마다 기준 자세 새로 등록됨
- 안내 끝나면 카메라 꺼짐 → JSON 다운로드
- JSON은 저장소 밖이나 data/ 폴더에 (model/temp 는 git 무시 대상 아님, 커밋 주의)

[JSON 변경 (리플레이 v2)]
- 좌표 0~22번 기록: 얼굴·어깨 0~12 + 팔꿈치 13·14, 손목 15·16, 손 17~22
- 팔이 화면 밖이어도 MediaPipe 추정값 + 낮은 visibility 로 기록됨
- 값이 아예 없을 때만 null (0으로 채우지 않음)
- 상단 plan: { rounds, shuffle }
- 예전 13점 v1 파일도 계속 불러올 수 있음

[측정 목표 (6명, 최소 시험용 추정)]
- 1인: 앉기 2회 (카메라 재설치 / 다른 시간대) x 1바퀴 실행 6회
- 1인 약 20분, 전체 약 2시간 (동시 진행 가능)
- 이걸로 보는 것: 처음 보는 사람에게 되는지 (한 명씩 빼고 평가)
- 이걸로 못 보는 것: 평소 작업 중 오알림률, 팀 밖 사용자

[짧은 가림 규칙 (BE 요청, 미구현)]
- 물 마시기·고개 돌림처럼 얼굴만 잠깐 안 보임 → 직전 점수 유지, 타이머만 멈춤
- 2초 넘으면 그때부터 측정 불가
- 스트레칭 중 타이머 처리·한도는 아직 미정

[아직 안 된 것]
- 학습 코드 (새로 작성 예정: JSON 읽기 → 분할 → 특징 → 규칙/softmax → 3초 규칙 재생 평가)
- 서버 계약: 추론 입력은 아직 이전 3특징, 프레임 계약 9점에 팔 없음 → 서비스 적용 전 변경 필요
- /dev 평소 작업(자유 작업) 기록 단계
- 실제 카메라에서 팔 좌표 품질 확인
- z(상대 깊이) 의존도는 부풀었을 수 있음 → 보조 입력 후보로만
```
