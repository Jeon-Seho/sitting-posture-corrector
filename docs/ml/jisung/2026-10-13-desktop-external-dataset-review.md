# 외부 데이터셋 적용 조사

- 확인일·환경: 2026-10-13 · desktop
- 작업 브랜치: `feature/repo-baseline-mediapipe`, 기준 커밋 `8ab1c18`
- 상태: 공식 배포처 조사와 MultiPosture CSV 집계 확인. 모델 학습·성능 검증 없음.
- 제품 목표: 등록한 개인 기준에서 관찰 가능한 얼굴·어깨 변화량. 보편적인 정상 자세 판정이 아니다.
- 입력 방향: MediaPipe Pose Heavy의 원래 인덱스 0~12. 손목 제외, Face Landmarker는 후속 실험.

## 결론

MultiPosture를 단일 프레임 특징 비교의 첫 외부 자료로 검토한다. EYEDIAP은 머리 회전·이동 정답을
활용하는 검증용 후보로 접근 신청을 권한다. 두 자료 모두 우리 서비스의 개인 기준 이탈 정답을
그대로 제공하지 않으므로 자체 기준 등록 및 실제 사용 상황 평가는 남는다.

외부 자세 라벨은 별도 보조 과제로 사용한다. 외부 데이터의 upright 라벨을 우리 사용자의 정상
기준으로 대체하지 않는다. 가입·접근 신청·저자 문의는 이번 조사에서 실행하지 않았다.

## MultiPosture 실제 파일 확인

[공식 API](https://zenodo.org/api/records/14230872)와 공개 CSV를 메모리에서 읽고 집계만 기록했다.
실제 좌표 행·참여자 자료를 로컬 파일이나 Git에 저장하지 않았다.

| 항목 | 확인 결과 |
| --- | --- |
| 파일 | `data.csv`, 9,327,935 bytes |
| 접근·라이선스 | `access_right: open`, `license.id: cc-by-4.0` |
| 실제 행 수 | 4,794 |
| 참여자 수 | 13 |
| 열 수 | 102 = 참여자·상체·하체 라벨 3 + 33포인트 × xyz |
| 얼굴·어깨 열 | 코, 좌우 눈 각각 3, 귀 2, 입 양끝 2, 어깨 2 모두 있음 |
| 상체 라벨 행 수 | TUP 1,615 / TLF 1,897 / TLB 442 / TLL 420 / TLR 420 |
| 시간·프레임·세션 열 | 없음 |
| visibility·presence 열 | 없음 |

배포 설명은 4,800프레임·11개 관절·33입력 차원이라고 적혀 있다. 실제 배포 파일은 위와 달라
설명과 파일을 구분해야 한다. 모델의 11관절 선택과 CSV 전체 33관절의 관계는 원 논문 추가 확인 대상이다.
배포 설명에 따르면 골반 중심 정규화 좌표이므로 현재 영상 정규화 좌표와 직접 합치지 않는다.
좌표 생성 세부 설정, 단위, 카메라 시점, 품질 처리는 아직 재현 확인하지 않았다.

### 사용할 수 있는 방법

1. 얼굴·어깨 13포인트만 선택해 눈/귀/입을 추가했을 때의 특징 구분력을 비교한다.
2. 골반 기준의 전체 위치 정보와 분리되는 어깨 중심 상대 위치·각도·비율부터 조사한다.
   이미지 픽셀 특징과 3D/정규화 좌표 특징은 출처를 분리한다.
3. TUP 대 몸통 기울임을 보조 분류 과제로 삼고 단순 모델부터 비교한다.
4. `subject` 단위로 학습/검증/시험을 나눈다. 행 무작위 분할은 사용하지 않는다.

### 사용할 수 없는 주장

- CSV 행 순서만으로 시간 창이나 속도를 만들 수 없다. 촬영 순서·간격·세션 경계를 먼저 받아야 한다.
- 골반 중심으로 제거된 전체 카메라 이동 성분을 복원할 수 없다. 절대 영상 좌표 변화(A) 검증을 대신하지 못한다.
- 원본 영상이 없어 우리 추출기 설정으로 재추출하거나 정면 어깨 위 크롭 성능을 재현할 수 없다.
- 시험 참여자의 TUP 평가 행을 골라 개인 기준을 만들면 평가 정답을 이용하게 된다.
  기준 실험에는 별도 등록 구간이나 명시적인 외부 적응 규약이 필요하다.
- 몸통 기울임 라벨로 머리 회전의 정답이나 개인 기준 이탈의 정확도를 보고할 수 없다.

CC BY 4.0은 출처 표시 등 조건 아래 상업적 이용도 허용하는 공개 라이선스다.
조건은 [공식 라이선스 설명](https://creativecommons.org/licenses/by/4.0/)을 따른다.

## EYEDIAP과 라벨 부담

[공식 설명](https://www.idiap.ch/en/dataset/eyediap)은 16명·94세션, RGB VGA/HD 영상,
프레임별 `head_pose.txt`, 카메라 보정 정보를 제공한다고 명시한다. 정적인 머리(S)와
회전·이동하는 머리(M) 조건, 모니터 목표(DS/CS)와 공간 목표(FT)를 구분한다.

제안 실험은 원본 RGB에 현재 Pose Heavy를 실행해 13포인트를 추출하고,
기존 머리 자세 정답의 기준 대비 회전량과 우리 특징의 관계를 측정하는 것이다.
머리 회전의 연속 정답이 있으므로 이 실험을 위해 모든 프레임을 수동 분류할 필요는 줄어든다.
하지만 제공 head pose의 좌표계·동기화·추정 품질을 확인해야 하며, 몸통 이탈·정상 자세·알림
정답까지 자동으로 확보되는 것은 아니다. Face Landmarker 도입 없이도 검증할 수 있는 제안이다.

접근 신청은 비상업 연구 목적, 신청자·소속·용도, 상근 서명권자 정보를 준비한다.
현재 [Zenodo 신청 페이지](https://zenodo.org/records/4467455)에 공개된 조건을 우선한다.
학교 과제라면 교수/연구책임자 등 실제 권한자가 서명 조건을 충족하는지 확인한다.
회원가입·로그인만으로 자동 승인이 되지는 않는다. EULA의 상세 조건과 서비스 사용 허용은
접근 승인 과정에서 확인해야 한다.

## 낮은 우선순위·미확인 후보

- BIWI Kinect Head Pose: [원 배포처](https://data.vision.ee.ethz.ch/cvl/gfanelli/head_pose/head_forest.html)
  접속 실패. 머리 회전 벤치마크 후보지만 현재 원 배포의 다운로드·가입·이용 조건은 확정하지 않는다.
- UPNA Head Pose: 원 배포처 접속 실패. 현재 접근 조건을 확인하지 못했다.
- [SitStraightNet](https://github.com/realratchet/SitStraightNet): 논문이 연결한 저장소는 접근 가능하지만,
  확인한 dataset 폴더에는 이미지 예시만 노출된다. 전체 라벨·원본 시퀀스 배포 여부는 미확인이다.
  코드의 MIT 표시를 영상 데이터 사용 허가로 단정하지 않는다.
- 압력 매트·IMU·광섬유 센서 데이터는 우리 RGB 13포인트와 입력이 달라 직접 학습 자료에서 제외한다.

## 다음 단계

MultiPosture의 좌표 정의·촬영 시점과 논문상의 관절 선택을 먼저 확인하고, 필요하면 저자에게
시퀀스/시간/기준 구간의 제공 여부를 문의한다. 문의 발송은 별도 사용자 지시가 필요하다.
EYEDIAP은 사용자가 접근 신청한다. 최종 평가는 자체 데이터의 별도 기준 등록과 실제 작업
중 관찰 구간에서 수행한다. 자체 라벨은 프레임마다 반복 입력하기보다 촬영 구간의 시작/종료와
과제 지시, 소수 검토 구간을 남기는 방식으로 부담을 줄이는 방향을 검토한다.

## LSTM용 시계열 후보 재검토 (같은 날 추가)

사용자 목표는 LSTM으로 개인 기준 대비 변화를 판단하는 것이다. 시간 없는 MultiPosture의
단일 프레임 실험을 주 학습 모델로 대체하지 않는다. 그 별도 실험은
[실제 학습 기록](2026-10-13-desktop-multiposture-training.md)에 남긴다.

| 후보 | 확인한 시계열 근거 | 목표와 남는 차이·접근 |
| --- | --- | --- |
| [EYEDIAP](https://www.idiap.ch/en/dataset/eyediap) | 16명·94세션, RGB 영상, 프레임별 머리 자세·카메라 보정, 정적/회전·이동 조건 | 모니터 사용 조건으로 머리 변화 검증의 우선 후보. 어깨·개인 이탈 정답 없음. 접근 신청/EULA 필요 |
| [ICT-3DHP](https://multicomp.cs.cmu.edu/resources/ict-3d-headpose-database-2/) | Kinect 앞에 앉아 머리를 움직이는 10시퀀스. 모자에 부착한 Polhemus 센서의 머리 자세 정답 | 센서를 착용한 머리 동작 실험이며 실제 업무 자세와 다름. 공식 배포처는 동의서 서명·반송 요청. 승인 절차는 아직 실행하지 않음 |
| [CMU Panoptic 공식 도구](https://github.com/CMU-Perceptual-Computing-Lab/panoptic-toolbox) | 동기화 영상·보정·프레임별 몸/얼굴 포인트를 시퀀스별 다운로드 안내 | 얼굴 데이터 있는 시퀀스와 적합한 정면 카메라를 선별해야 함. 개인 기준/이탈 라벨 없음. 비상업 연구 전용 |
| [DD-Pose 공식 도구](https://github.com/herr-biber/dd-pose) | 운전 상황의 센서 기록·머리 자세와 시나리오별 처리/시각화 도구 | 운전 구도 차이가 커서 낮은 우선순위. 계정 자격·연구용 라이선스·모델의 비연구 서비스 적용 제한 확인 필요 |

영상이 있다는 것과 우리 자세 이탈 정답이 있다는 것을 구분한다. 공개 영상에서 현재 Pose Heavy로
13점을 시간순 추출하는 것은 가능하지만 세션 경계·프레임 시각·품질을 보존해야 한다.
샘플을 내려받아 연속성·얼굴/어깨 가시성·정답 동기화를 확인하기 전에는 LSTM 학습 준비 완료로 쓰지 않는다.

EYEDIAP/ICT-3DHP의 연속 머리 자세 정답은 별도 기준 구간을 정한 뒤 기준 대비 회전을 예측하는
LSTM 회귀 보조 과제에 활용할 수 있다는 제안이다. 이 목표는 정상/비정상 분류나 몸통 이탈의 정답과 다르다.
우리 서비스의 최종 목표는 소규모 자체 기준 등록·일상 동작·지속 이탈 구간으로 확인해야 한다.
기준과 평가 구간을 분리하고 시험 참여자의 이탈 자료로 학습·튜닝하지 않는 규칙은 유지한다.

[HuMoLs](https://groups.inf.ed.ac.uk/vision/DATASETS/HUMOLS/)는 정면 앉은 영상이 있지만,
공식 설명이 얼굴을 합성했고 프레임마다 달라질 수 있다고 명시한다. 얼굴 좌표 변화가 핵심인
현재 연구의 주 학습 자료에서는 제외하는 것을 제안한다.

이번 추가 확인은 공식 문서 조사이며 자료 다운로드·LSTM 학습은 실행하지 않았다.

## 서명·승인 없이 접근하는 대안 재검토

EYEDIAP 접근 부담에 대한 사용자 요청으로 공개 다운로드 후보를 다시 확인했다.
2026-10-13 확인 결과이며 영상 내용·좌표 스키마까지 검증한 결과는 아니다.

- **Panoptic**: 공식 다운로드 스크립트는 로그인·신청 없이 시퀀스별 RGB 영상과
  몸/얼굴 좌표를 제공한다. CMU의 `171204_pose1_sample` HD 카메라 `00_00` 영상에
  HEAD 요청하여 HTTP 200, `video/mp4`, 9,648,349 bytes를 확인했다.
  SNU 미러의 같은 경로는 이번 확인에서 시간 초과했다.
  [공식 도구](https://github.com/CMU-Perceptual-Computing-Lab/panoptic-toolbox)의
  라이선스는 비상업·연구용이다. 샘플의 정면 구도·어깨 가시성과 지속 이탈을 먼저 확인할
  후보로 제안한다. 제공 관절 정의가 MediaPipe 13점과 달라 원본 영상에서 다시 추출해야 한다.
  개인 기준 등록과 기준 대비 자세 이탈의 정답은 제공되지 않는다.
- **MAmI ADL 2025**:
  [공식 배포](https://zenodo.org/records/15642257)는 16명의 주방 일상 활동(세탁·아침 식사)
  다중 시점 영상과 MediaPipe/YOLOv8로 처리한 골격 자료를 제공한다.
  Zenodo API에서 `open`, `cc-by-4.0`, ZIP 14,771,068,307 bytes를 확인했고,
  공개 ZIP에 HEAD 요청하여 HTTP 200을 확인했다. 별도 신청·서명 없이 접근할 수 있다.
  연속 영상 기반 LSTM 입력 처리 실험 후보지만 앉은 정면 업무 자세와 차이가 크다.
  실제 CSV의 시간·관절·품질 열과 좌표 정의는 아직 확인하지 않았다.
  활동 라벨을 개인 기준 자세 이탈 라벨로 바꾸지 않는다.

두 후보 모두 데이터 파일은 다운로드하지 않았고 LSTM 학습도 실행하지 않았다.
공개 시계열로 움직임 표현을 먼저 학습하는 방안은 제안이며, 서비스 판정의 검증에는
자체 기준 등록과 별도 관찰 구간이 필요하다. 같은 추출기의 좌표로 만든 차이를 정답으로
사용하면 규칙을 모사하는 학습이 되므로 독립적인 자세 이탈 정답으로 보고하지 않는다.
