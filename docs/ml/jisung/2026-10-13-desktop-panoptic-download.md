# Panoptic 공개 시계열 다운로드·구조 확인

- 환경: desktop, 2026-10-13
- 브랜치: `feature/repo-baseline-mediapipe`, 기준 커밋 `8ab1c18`
- 사용자 요청: 개인 기준 자세는 이번 외부 데이터 실험에서 제외하고, 공개 자료로 가능한 성능 확인을 준비한다.
- 상태: 실제 다운로드·파일 구조 확인 완료. MediaPipe 추출·LSTM 학습·성능 평가는 미실행.

## 받은 자료

[공식 도구와 이용 조건](https://github.com/CMU-Perceptual-Computing-Lab/panoptic-toolbox)을
기준으로 CMU 공개 배포 서버에서 받았다. 비상업·연구용이며 신청·서명은 요구하지 않았다.
자료는 Git에서 제외되는 `data/external/panoptic/`에만 보관한다.
각 디렉터리의 `source.json`에 출처 URL·실제 크기·SHA-256을 기록했다.

| 시퀀스 | 파일 | 실제 크기 |
| --- | --- | --- |
| `171204_pose1_sample` | HD `00_00` 영상 | 9,648,349 bytes |
| 동일 샘플 | 몸 3D 좌표 TAR | 156,672 bytes |
| 동일 샘플 | 얼굴 3D 좌표 TAR | 793,600 bytes |
| 동일 샘플 | 카메라 보정 JSON | 252,047 bytes |
| `171204_pose1` 원본 | 몸 3D 좌표 TAR | 41,850,880 bytes |
| 동일 원본 | 얼굴 3D 좌표 TAR | 191,621,120 bytes |
| 동일 원본 | 카메라 보정 JSON | 252,047 bytes |

원본 HD `00_00` 영상의 HEAD 응답은 HTTP 200, 3,012,670,026 bytes였다.
이번에는 좌표 시계열과 작은 샘플 영상까지 받았고 3GB 원본 영상은 받지 않았다.

## 실제 파일 확인 결과

- 샘플 영상의 MP4 헤더상 길이: 3.371초. 몸·얼굴 JSON 각각 101프레임(0–100).
- 원본 몸 JSON: 27,561프레임(118–27,678), `univTime` 기준 919.595918초.
  프레임 번호 누락 0, 시간 역전/중복 0.
- 원본 얼굴 JSON: 27,560프레임(118–27,677), 프레임 번호 누락 0.
  몸 자료의 마지막 프레임에는 대응 얼굴 JSON이 없으므로 인덱스로 교집합을 맞춘다.
- 몸은 `joints19`: 19개 관절 × (x,y,z,confidence), 각 사람 레코드의 값 76개.
- 얼굴은 `face70.landmarks`: 70개 포인트 × (x,y,z), 값 210개.
- 몸 track ID는 0–5이며 얼굴에는 -1도 있다. ID를 실제 참여자 식별자와 동일시하지 않는다.
  얼굴 -1과 몸·얼굴 대응을 확인하지 못한 레코드는 참여자 학습 자료로 연결하지 않는다.
- 프레임 파일 존재와 유효한 사람 측정 존재는 다르다. 몸 레코드 26,603개,
  얼굴 레코드 26,003개이며 프레임 전체를 유효 측정으로 처리하지 않는다.
- 검사한 몸 레코드에는 정상/기울임 등의 자세 분류나 센서 머리 각도 정답이 없다.
  다중 카메라 복원 3D 좌표가 제공되는 관측 목표다.

집계 상세는 무시된 데이터 디렉터리의 `audit.json`에 보관한다.

## 이번 실험의 평가 범위

개인 기준 등록·기준 대비 점수는 이번 실험에 넣지 않는다.
현재 자료로 가능한 후보는 과거 좌표 창을 입력으로 다음 프레임/구간의 3D 좌표를 예측하는
LSTM 실험이다. 위치·속도 유지 예측과 같은 단순 비교 방법에 대한 오차 개선을 측정할 수 있다.
이 결과를 자세 분류 정확도로 표현하지 않는다.

서비스와 동일한 Pose Heavy 13포인트 입력의 성능을 확인하려면 원본 RGB 영상이 추가로
필요하다. 제공 COCO19·face70을 MediaPipe 13점과 같은 포인트라고 간주하지 않는다.
원본 RGB 추출과 다중 시점 복원 좌표의 대응을 확인한 뒤 오차를 평가한다.
이는 Face Landmarker 도입 결정이 아니다.

단일 원본 시퀀스의 track 분할만으로 참여자 일반화 성능을 주장할 수 없다.
추가 시퀀스의 실제 참여자 대응을 확인해 참여자 단위 분할 후 창을 만든다.
미측정 구간·품질 부족·시간 단절은 제외하거나 명시적 마스크로 처리한다.

## 검증

다운로드한 7개 파일의 크기·SHA-256 기록 완료. TAR 내부 JSON을 직접 읽어 집계했으며
자료를 저장소 소스로 추가하지 않았다. `git check-ignore`로 로컬 데이터 제외 확인 완료.
문서 검증: `python -X utf8 tools/dev.py check-repo`, `git diff --check`.
코드 변경이 없어 테스트·타입 검사·빌드는 실행하지 않았다.
