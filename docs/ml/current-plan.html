01

범위·지속시간·예측은 서로 다른 역할입니다.

개인 범위

확인한 정상 중심과 폭

수동 30초 구간의 통계량을 맞춥니다. 새 등록 후보와 현재 자세가 학습한 범위 안인지 비교합니다.

거리·시간

얼마나, 얼마나 오래

기준에서 벗어난 거리와 지속시간을 관찰합니다. 프로파일이 없을 때의 기본 판단이며 비교군입니다.

LSTM

300ms 뒤 움직임

30시점 × 39차원에서 미래 좌표를 회귀합니다. 정상/비정상 정답이나 스트레칭 의도를 학습한 분류기가 아닙니다.

정상은 사용자가 확인한 허용 구간입니다.
의학적 정상·건강 점수·척추 곡률을 뜻하지 않습니다. 구부정한 자세도 잘 예측할 수 있으므로 미래 예측 오차만으로 정상 여부를 판단하지 않습니다.
02

자동은 범위를 선택하고, 수동은 구간을 확인합니다.

자동 · 미검토 약라벨

정상자세(자동)

기본 ≤ 6%

0.5%·3%·6% 선택. 기준 등록 뒤 새 유효 관측마다 최대 10Hz로 한 행을 추가합니다. 선별값은 행마다 기록합니다.

수동 · 참여자 확인

정상자세(수동)

유효 30초

준비 3초 뒤 실제 30초·최소 100표본. 사용자가 구간을 확인하며 개인 기준용과 학습 자료용을 구분합니다.

백분율은 기준과의 3D 거리입니다.

현재 어깨폭을 100%로 보고 얼굴 9점·귀 2점·어깨 2점의 평균 점 거리를 같은 비중으로 합칩니다. 픽셀 차이·정상 확률·LSTM 오차와 다릅니다. 6%는 수집 가용성을 위한 개발값이며 검증된 정상 기준이 아닙니다.

확인할 것의미
행 수 + 연속 학습 후보입력 30시점과 약 300ms 뒤 타깃을 담을 약 3.2초 연속 구간이 필요합니다. 후보 수와 최종 학습 창 수는 다릅니다.
탈락 이유범위 밖·낮은 품질·시간 단절 등을 구분합니다. 측정 불가를 정상으로 채우지 않습니다.
구간 경계가림·250ms 초과·일시정지·기준/모델/선별값 변경을 넘는 창은 만들지 않습니다.
보관메모리에서 최대 6,000행. 필요한 원본만 직접 다운로드하며 자동 학습·업로드는 하지 않습니다.

03

다른 자세를 다시 등록해도 정상 중심은 바뀌지 않습니다.

얼굴 중심 · 귀 중심 · 어깨 방향

9축의 중앙값과 변동 폭을 학습합니다. 허용 폭은 절대 중앙편차 q95 × 1.5와 기존 개발 하한 중 큰 값입니다.

점수 = |현재 특징 − 학습한 중심| ÷ 허용 폭의 최댓값

점수 ≤ 1 통과 · > 1 거부. 등록 후보와 측정 모두 학습 중심을 사용합니다. 등록을 다시 했다는 이유로 이탈 자세가 0점이 되지 않습니다.

  1. 유효한 등록 후보 수집

    기존 최소 8초·실제 65표본 조건을 유지합니다. 보간값을 실제 표본으로 세지 않습니다.

  2. 실제 추출 모델 확인

    프로파일과 관측의 알려진 ID가 정확히 같아야 합니다. 출처 미상·다른 모델·손상 자료는 검증 통과로 표시하지 않습니다.

  3. 학습 범위와 비교

    벗어나면 가장 크게 달라진 얼굴/귀/어깨 부위를 안내합니다. 범위로 돌아오면 등록을 다시 시도합니다.

  4. 범위를 고정해 지속시간 관찰

    1 초과 이탈·2/3 이하 복귀 확인. 이탈 자료를 자동으로 학습 중심에 흡수하지 않습니다.

프로파일이 없으면 학습 검증이 없다는 안내와 함께 기존 거리·시간 기준을 사용합니다. 이탈 3초·복귀 3초·재알림 60초는 개발 설정이며 의도적인 긴 스트레칭도 알림 후보가 될 수 있습니다.

04

수집 → 검사 → 학습 → 불러오기.

원본과 결과는 비공개 폴더에 보관합니다. 브라우저는 모델을 자동 교체하거나 실제 학습을 실행하지 않습니다.

수동 v1 / 자동 v1·v2 JSON→파일 hash·참여자 분할 검사→로컬 LSTM→설정에서 model.json 선택

한 사람 pilot 실행 예

저장소 루트, 학습용 Python 환경에서 실행합니다. manifest 형식과 설치 방법은 MediaPipe 학습 안내에 있습니다.

python -m model.analysis.mediapipe_lstm manifest --mode pilot \
  --output "$HOME/posture-private/manifest.json" \
  "$HOME/posture-private/normal-auto.json"

python -m model.analysis.mediapipe_lstm validate \
  --manifest "$HOME/posture-private/manifest.json" --mode pilot

python -m model.analysis.mediapipe_lstm train \
  --manifest "$HOME/posture-private/manifest.json" --mode pilot \
  --output "$HOME/posture-private/run-01" --epochs 25

manifest는 명시한 파일의 실제 모델·참여자·hash로 한 사람 pilot 목록을 새로 만듭니다. 파일명은 내려받은 이름에 맞춰 바꾸세요. validate/prepare는 학습 없는 자료 검사입니다. train은 선택 NumPy/PyTorch 환경의 CPU 학습이며 새 출력 폴더에 model.json·report.json·research-lstm.pt를 만듭니다.

행을 많이 모았다고 바로 학습되는 것은 아닙니다.
원본에서 정규화 값을 다시 계산하고 출처·품질·시각·구간을 확인합니다. 입력만 100ms 격자로 보간하며 미래 정답은 목표 시각 ±50ms의 실제 관측을 사용합니다. 실제 타깃이 없으면 창을 제외합니다.

06

본인 실험과 새로운 사람의 평가는 나눕니다.

PILOT

한 사람의 연결 점검

train만 사용하고 validation/test는 비웁니다. 개인 보정 자료도 허용합니다. 학습 자료 적합·기능 확인이며 새 사용자 성능으로 보고하지 않습니다.

PARTICIPANT HOLDOUT

참여자 단위 분리

train·validation·test가 모두 필요하고 사람은 겹치지 않습니다. 수동 자료는 학습 용도만 사용합니다. 변환기는 train으로, 모델 선택은 validation으로 합니다.

미래 좌표 오차와 자세 판정 정확도도 다릅니다.
LSTM·위치 유지·등속을 같은 창에서 비교합니다. 자동 약라벨은 정상 정답이 아닙니다. 자세 효과를 보려면 별도 기준 유지·일시 이탈·지속 이탈·측정 불가 구간과 시간당 오알림·놓침·감지 지연을 평가해야 합니다.
