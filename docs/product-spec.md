# 제품 범위

근거: [프로젝트 초안](references/posture_ai_project_one_page.md), [논문 초안](references/posture_ai_paper_one_page.md).
이 문서는 초안에서 채택한 개발 범위이며, 모델 성능을 증명하는 자료가 아니다.

추가 근거: [현재 기업연계 계획서](references/current-proposal-review.md). 작성 중 자료로서 아래의 기술·기능 방향에 반영하고,
계약과 실험 설계가 달라지는 부분은 미결정 사항으로 관리한다.

## 사용자 흐름

1. 사용자 1명이 단일 RGB 카메라를 허용한다.
2. 측정 품질을 확인하고 20~30초 동안 개인 기준 자세를 등록한다.
3. 최근 약 3초의 상체 특징으로 기준 대비 변화를 판단한다.
4. 자세 이탈이 설정 시간 동안 지속되면 알림을 제공한다. 기본 최초 알림 3초, 정상 복귀 3초(2026-10-06 개정), 같은 사건 재알림 60초를 사용한다.
5. 일별 기준 유지/이탈 시간과 변화 유형을 확인한다.

현재 계획서는 로그인·사용자별 기록 분리, 측정 일시정지/종료, 주·월별 비교,
붕괴 이벤트 간격·지속시간·알림 후 회복 시간까지 제품 방향을 구체화했다. 세부 수용 기준과 계약은 구현 전에 정의한다.

## 포함 및 제외

포함: 1인 상체 추적, 기준 등록, 정상·지속적 이탈·측정 불가 표시, 지속시간 기반 알림, 일별 통계.
제외: 다중 사용자/카메라, 의료 진단, 척추 곡률 측정, 치료 처방, 복잡한 커뮤니티·게임화.

## 목표와 미결정 사항

- 실시간 10 FPS 이상은 **목표**다. 실제 환경에서 p95 지연과 함께 측정해야 한다.
- MediaPipe 33개 랜드마크를 입력 특징으로 사용하는 방향을 채택한다. 라이브러리 버전은 구현 시 검증·고정한다.
- 현재 기업연계 계획의 모델 방향은 LSTM이다. 기존 논문 구상의 GRU 및 M0~M4 비교군과의 통합 설계는 아직 미정이다.
- 정면/측면/약 45도를 프로토타입으로 비교한 후 하나의 카메라 시점을 고정한다.
- 기준/전방·구부정/좌측/우측 기울임은 후보 라벨이다. 수집 전에 가시성과 분리도를 확인한다.
- 해상도, 거리, 시퀀스 길이, 신뢰도·알림 임계값은 데이터 수집 전에 결정한다.
- 현재 계획의 우선 스택은 React·TypeScript, Spring Boot, Python/LSTM이다. 버전·빌드 도구·통신 계약은 미정이다.
- 특징·분리 추론은 [ADR 0013](decisions/0013-frontend-server-feature-connection.md), 사용자 선택한 MySQL·이메일/비밀번호 계정·저장은 [ADR 0014](decisions/0014-mysql-persistence-and-accounts.md)를 따른다. Compose와 자동 배포 설정은 [ADR 0015](decisions/0015-compose-and-deployment.md)이며 실제 배포 서버는 미정이다.
- 알림 시간 정책은 [ADR 0012](decisions/0012-session-timing-policy.md)로 확정했다. 최초 알림 3초·정상 복귀 3초(2026-10-06 개정)·같은 사건 재알림 60초는 기본값이며 입력 시퀀스 길이와 구분한다. 설정 변경은 다음 새 세션부터 적용한다.

## 확정 시간 정책

휴식 후에는 이전 사건을 중단하고 연속 이탈·복귀 누적을 초기화하여 새로 시작한다.
자리 비움·측정 불가·누락도 연속 판정을 끊으며 해당 시간은 유효 통계에서 제외한다.
중단은 정상 복귀가 아니다. 새 사건은 설정한 지속시간을 채운 뒤 첫 알림을 만들고,
이전 사건의 60초 재알림 간격을 적용하지 않는다. 같은 세션의 휴식 재개와 복구는 기존 설정을 유지한다.
이 정책 합의는 특징·품질 임계값이나 실기기 성능 검증을 완료했다는 뜻이 아니다.

개발 서버 입력은 어깨 너비로 정규화한 세 특징의 현재−시작 기준 변화량과 품질이다.
영상·원본 좌표를 보내지 않으며 기본 로컬 모드에서 명시적으로 선택한다. 서버 사건·통계를 그대로 표시하고
새로고침에는 고정 기준과 미확인 요청을 보존한다. 서버 유실 후 확인된 요약 보관은 종료 성공과 구분한다.
이는 기하학적 규칙 연결이며 학습 모델·해부학적 진단·실제 장치 정확도 검증이 아니다.

## 실패 상태

카메라 거부·연결 끊김, 가림, 낮은 가시성, 프레임 누락은 정상 상태로 표시하지 않는다.
기준 미등록 및 카메라 이동 시 재등록 흐름이 필요하다. 등록 전에는 이탈 알림을 만들지 않는다.
측정 불가 구간을 이탈 지속시간이나 정상 유지시간에 누적하지 않는다.
