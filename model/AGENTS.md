# Model 작업 지도

루트 [AGENTS.md](../AGENTS.md), [연구 프로토콜](../docs/research/protocol.md), [출력 계약](../contracts/README.md)을 따른다.

- 담당: 포즈 어댑터, 측정 품질, 상체 특징, 정규화, 개인 보정, 시계열 추론, 알림 판정, 평가.
- 프레임 무작위 분할을 금지한다. 참여자 분할 후 창을 생성하고 학습/검증으로만 변환기를 맞춘다.
- 시험 참여자의 기준 등록 외 데이터를 보정·학습·튜닝에 사용하지 않는다.
- 측정 불가 구간에는 상태를 추측하지 않는다. 이탈 타이머에 해당 구간을 누적하지 않는다.
- 연구용 코드와 서비스 추론 코드를 분리한다. 화면·DB에 직접 의존하지 않는다.
- 가중치·실제 시퀀스는 외부에 보관한다. 커밋하는 fixture는 합성임을 명시한다.
- 첫 구현 때 합성 시퀀스, 분할 누수, 시각 누락/역전 검증을 루트 게이트에 연결한다.
