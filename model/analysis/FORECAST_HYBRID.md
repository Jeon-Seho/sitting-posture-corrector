# 미래 예측 오차 + 기준 거리 + 지속시간 실험

이 모듈은 **연구용 합성 실험**이다. 서비스/CEP의 알림 정책을 변경하지 않는다.
저장된 실제 Panoptic LSTM 가중치와 명시적인 합성 좌표 10개 시나리오를 사용한다.
실제 사람 분류 정확도와 의료적인 자세 붕괴를 검증하지 않는다.

```powershell
.venv/Scripts/python.exe -m model.analysis.forecast_hybrid --model runs/panoptic/2026-10-13-desktop-lstm-v1/research-lstm.pt --output runs/panoptic/new-hybrid-experiment
.venv/Scripts/python.exe -m unittest discover -s tests -p test_forecast_hybrid.py -v
```

기존 완료 결과를 덮어쓰지 않고 Git 제외 `runs/` 아래에 결과를 기록한다.
신뢰한 연구 체크포인트만 `weights_only=True`로 로드하며 13점 정의·3초 창·0.3초 horizon을 확인한다.
`report.json`에 모델 hash·설정·사례별 사건을,
`explicit-synthetic-traces.json`에 합성 시간·기준 거리·예측 오차·상태를 기록한다.
CI의 unittest discovery가 시간·품질·인과성 테스트를 실행한다.

## 서로 다른 신호의 역할

- 기준 거리: 등록 구간에서 관측한 형상과 얼마나 달라졌는가.
- 예측 오차: 과거에서 예상했던 좌표와 도착한 좌표가 얼마나 다른가.
- 지속시간: 그 차이가 복귀 없이 얼마나 지속됐는가.

예측 오차가 높다는 것은 예상하지 못한 변화다. 일시 동작이라는 정답은 아니다.
일시 동작 확인은 이후 복귀가 관측된 때 가능하다. 예측 오차가 낮아도 기준에서 멀어지지
않으면 지속 이탈 후보가 아니다. 급변 뒤 유지하는 경우도 지속 이탈 후보여야 한다.

예측 기반 이상 탐지의 선행 예로
[Hundman et al. 2018](https://arxiv.org/abs/1802.04431)이 있다.
우주선 계측 연구의 탐지 결과를 자세 데이터에 대한 성능 근거로 사용하지 않는다.

## 인과성과 기준 설정

10Hz 입력에서 시간 t의 예측은 t까지의 최근 30개 관측만 사용한다.
0.3초 뒤 관측이 도착하면 보관한 예측과 비교한다. 미래 관측을 입력 창에 넣지 않는다.
예측 오차는 0.3초 동안의 과거 예측을 현재 관측으로 확인한 값이다.

합성 `reference_hold`의 최초 8초만으로 기준 median 및 predictor별 오차 q99를 계산한다.
오차 임계값 하한은 0.02다. 나머지 시나리오에 맞춰 다시 임계값을 튜닝하지 않는다.
기준 거리·예측 오차는 얼굴9점·귀2점·어깨2점의 그룹별 평균 점거리를 동일 가중치로 합한다.
모두 현재 어깨 중심/너비 정규화 좌표이며 몸 전체 이동을 측정하는 입력이 아니다.
본 서비스에는 기존 ADR0023의 상대·중점·크기 변화를 별도 검증해야 한다.

## 실험 정책과 대조군

모든 값은 이 합성 실험의 설정이며 서비스 임계값으로 확정하지 않는다.

- 기준 거리≥0.12에서 이탈 관찰 시작, ≤0.08에서 기준 근처 복귀. hysteresis 적용.
- 3초 이탈 + 최근 1초간 낮은 예측 오차이면 지속 이탈 후보.
- 예측 오차가 계속 높아도 5초 이탈이면 지속 이탈 후보. 무기한 억제 방지.
- 3초 기준 근처 유지 후 회복 확인. 이미 지속 이탈로 판정한 사건을 일시 동작으로 다시 쓰지 않음.
- 품질 부족은 `unmeasurable`; 누락/시간 단절/품질 부족은 이탈·회복 누적을 끊음.
- 모델 입력 창도 품질·시간 단절을 넘지 않음. 복귀 전에 동작을 일시적이라고 확정하지 않음.

비교 방법:

1. LSTM 예측 + 거리/시간 + 최대 대기시간
2. 마지막 좌표 유지 예측 + 동일 규칙
3. 등속 예측 + 동일 규칙
4. 거리/시간만: 모델 없이 3초 이탈 확인
5. LSTM의 낮은 오차 조건 필수: 최대 대기시간 없이 모델이 판정을 계속 막을 수 있는 대조군

## 해석

합성 시나리오의 작성 의도는 실제 사람의 정답 라벨이 아니다. 학습 자료가 다른 LSTM이
낯선 합성 좌표에서 큰 오차를 보일 수 있으므로 이 실험으로 LSTM 자체를 일반적으로 부정하지 않는다.
장시간 의도적 동작과 자세 이탈은 같은 관측 흐름을 가질 수 있다.
모델 학습에 별도 분류 라벨이 없어도 미래 좌표를 목표로 쓸 수 있지만, 판정 정책의 실제 검증에는
복귀·지속 이탈·의도적 동작을 확인한 별도 구간이 필요하다.
