# 두 단계 개인 기준·자세 실험

2026-11-08. 원본 v8 키포인트와 개인 등록 기준을 쓰는 오프라인 탐색 실험이다. 개인이 선택한
기준은 의학적으로 올바른 자세라는 뜻이 아니다. 서비스·프론트엔드·원본 JSON은 바꾸지 않는다.

## 학습 목표

1. **합성 이동 보정 모델:** 사람별 기준 유지 안내 구간을 사용한다. 화면 세로축에 인위적으로
   추가한 −14.4~+14.4px의 이동량을 랜덤 포레스트 회귀기로 추정한다. 입력은 기존 6개 특징과
   개인 등록의 어깨 폭이다. 원본 기준 창마다 51개 이동 입력을 만들고 가중치 합을 보존한다.
2. **자세 판별 모델:** 개인 기준 대비 6개 특징으로 기준 유지·이탈 안내를 구분하는 랜덤
   포레스트 분류기다. 보정기 출력을 사용할 때의 입력 분포를 학습하도록, 학습 참여자별로 그
   사람과 시험 참여자를 모두 뺀 보정기 예측으로 학습 입력을 만든다. 각 입력은 25배 증강한다.
   기존 분류기 설정·임계값은 이전 내부 참가자 검증 결과를 사용하며 이번 단계에서 다시 고르지 않았다.

두 모델 모두 실제 시험 참여자 한 명을 제외하고 학습하는 과정을 6회 반복한다. 해당 시험 사람의
개인 등록 구간만 기준에 사용한다. 분류기는 같은 분할에서 보정 없이 학습한 비교 모델도 만든다.
모델 출력은 미보정, 보정 후 기존 분류기, 보정 후 재학습한 분류기, 인위적으로 주입한 이동량을
아는 합성 오라클을 나눠 비교한다. 오라클은 실제 사용 가능한 모델이 아니다.

## 결과

입력 이름 기준 6명·20개 파일로 실행했다. 전체 자료 후보 기준 보정 학습은 **기준 창 982개 →
50,082개 합성 입력**, 자세 학습은 **원본 창 1,968개 → 49,200개 입력**이다. 사람을 하나씩 뺀
6회 평가에서 기준·이탈 재현율을 사람별로 평균한 결과다. 정답은 수행 확인 전 안내 라벨이다.

| 합성 이동 | 보정 없는 모델 | 보정 후 재학습한 두 단계 모델 | 기준 안내 구간의 3초 이탈 감지: 전 → 후 |
| --- | ---: | ---: | ---: |
| 없음 | 92.1% | 92.1% | 5/56 → 5/56 |
| 위 14.4px | 92.4% | 92.8% | 5/56 → 5/56 |
| 아래 14.4px | 89.1% | 88.3% | 8/56 → 10/56 |
| 위 28.8px | 92.3% | 93.4% | 6/56 → 4/56 |
| 아래 28.8px | 81.8% | 79.5% | 17/56 → 20/56 |

3초 이탈 감지는 안내된 각 구간을 독립 재생한 결과다. 예를 들어 아래 14.4px에서 유효한 이탈
안내 시도·재시도 65개 중 감지는 보정 전 46개, 두 단계 47개였다. 화면 아래 이동으로 품질
조건에 걸리는 프레임이 늘어 원본의 71개와 시험 대상이 다르다. 표의 전후 비교는 각 행 안에서
같은 유효 창을 사용하며, 행과 행 사이 성능을 동일 분모로 해석하면 안 된다.

참고로 보정 모델만 붙이고 원래 분류기를 재학습하지 않은 비교는 아래 14.4px에서 91.5%, 기준
안내 3초 이탈 감지 5/56이었다. 반면 보정 출력에 맞춰 재학습한 두 단계 모델은 같은 사례에서
88.3%, 10/56이다. 선택된 임계값은 기존 미보정 모델 기준이고 두 단계용으로 재탐색하지 않았다.
같은 6명을 여러 실험에 반복 사용했으므로 이 비교만으로 가장 좋은 구성을 결정하지 않는다.

추가 이동이 없는 기준 안내 창에서 보정기의 평균 절대 출력은 7.2px이었다. 이는 **주입한 이동이
0인 과제**에 대한 값이다. 원본 촬영에 이미 자연스러운 이동이 있었는지 알 수 없으므로 실제
이동량 추정 오차라고 해석할 수 없다. 현재 보정기는 위치가 바뀌지 않은 경우에도 상당한 보정을
가할 수 있어 자동 기준 변경에 사용하지 않는다.

## 해석과 한계

- 기존 v8에는 실제 의자 이동량·카메라 이동량·보정해야 할 기준의 정답이 없다. 학습 목표와
  시험 정답은 **추가로 주입한 2D 세로 이동량**이다. 원본에 이미 있던 이동은 알 수 없다.
- 보정은 6개 특징 중 화면상 어깨 높이 변화량에서만 수행한다. 개인 등록 좌표를 갱신하지 않고,
  2D 이동의 원인·횡방향·깊이·회전·줌을 판별하지 않는다. 실제 의자 보정 모델이 아니다.
- 합성 시 모든 입력 키포인트를 동시에 같은 양 이동시키며 가시성은 변하지 않는다고 가정한다.
  시험 시에는 이동된 프레임의 품질을 다시 검사하고 제외된 구간을 별도로 보고한다.
- 고개 회전 등으로 측정 불가인 입력을 정상 또는 이탈로 채우지 않는다. 현재 v8은 전환과 일상
  작업을 기록하지 않으므로 실제 오알림이나 이탈 발생 지연은 측정하지 못한다.
- 사람이 6명뿐이고 이름 기준 임시 그룹이다. 동일인 확인과 안내 라벨 검토가 필요하다. 이 사람들은
  과거 여러 모델 비교에도 사용돼 최종 독립 검증 자료가 아니다.
- 51배·25배 표본은 수학적 변형이며 신규 참여자·촬영이 아니다. 전체 사람으로 재학습한 후보에는
  별도 독립 시험이 없다. 학습용 보정 범위를 벗어나는 6% 이동은 외삽 스트레스 사례일 뿐이다.
- 회귀기는 학습한 보정 범위를 넘어서는 이동을 안정적으로 표시하지 못한다. 재등록 정책이나
  기준 자동 업데이트는 구현하지 않았다. 자세 점수도 검증된 실제 이탈 확률이 아니다.
- 두 단계 재학습은 보정기만 연결한 첫 결과를 확인한 뒤 추가했다. 이전 실험과 같은 6명을 반복
  관찰한 탐색 비교이므로 선택 편향이 있다. 참가자별 혼동 행렬·재현율은 비공개 보고서에 남겼다.

## 다음 검증

동일 자세를 유지한 의자 이동과 실제 자세 이탈을 구분해 기록한 사례가 우선 필요하다. 작은 이동,
큰 이동, 복귀와 가림을 포함하고 새 사람을 통째로 시험에서 제외한다. 보정 모델의 움직임 추정,
불필요한 보정, 기준 구간의 오감지, 이탈 놓침, 측정 불가와 재등록 요청을 따로 평가한다. 같은
6명의 시험 결과로 반복 튜닝해 수치만 올리는 방식은 피한다.

## 실행

`requirements-training.txt`와 `requirements-trees.txt` 환경 및 기존 파일럿 결과와 비공개
카탈로그가 필요하다. 입력과 기존 보고서의 해시·기존 분류 결과 재현을 검사하고, 새로운 출력
폴더에만 결과를 쓴다.

```powershell
python -m model.analysis.replay_pilot.two_stage `
  --catalog "<private>/catalog.json" `
  --prior-report "<private>/augmentation-50k-run-01/report.json" `
  --output "<private>/two-stage-new"
```

참여자 식별을 확인하기 전 파이프라인 탐색에만 `--allow-unverified-identities`를 추가한다.
`all-data-synthetic-vertical-corrector.joblib`과 `all-data-posture-after-correction.joblib`은
독립 시험을 받지 않은 전체 자료 후보이며, 그 밖의 `P...` 모델은 해당 사람을 뺀 fold 모델이다.
각 단계 모델·원본·카탈로그·보고서는 Git 밖의 비공개 위치에 두고, `joblib` 파일은 신뢰할 수
있는 출처의 파일만 읽는다. 기존 API는 이 6개 특징과 시간 창을 그대로 받을 수 없다.
