# 키포인트 특징 약 5만 건 실험

2026-11-08, 개인 기준 대비 얼굴·어깨 특징으로 만든 오프라인 파일럿이다. 원본 JSON과 프론트엔드는
수정하지 않았다. 데이터의 안내 라벨은 수행 검증을 거친 정답이 아니고, 이름별 참여자가 실제로
서로 다른 사람인지 아직 확인하지 않았다. 모델은 서비스에 연결하지 않았다.

## 증강과 분리

- 좌표 자체를 새로 저장하지 않는다. 기존 1초 창의 6개 특징을 메모리에서 좌우 반전하고,
  기존 실험과 같은 범위의 잘린 정규 잡음을 더한다.
- 원본 창 1,968개로 전체 자료 후보를 학습할 때, 원본을 포함해 25개씩 **49,200개 특징 벡터**를
  만든다. 이전 5개 변형 묶음에 20개를 추가한다. 서로 비슷한 합성 특징이며 실제 사람·촬영을
  25배로 늘린 것이 아니다.
- 사람별 6회 평가에서 시험 사람은 **분할 후 증강·학습·튜닝에서 전부 제외**하고, 그 사람의
  실제 원본 창만 시험한다. 25배 학습에 쓰는 모델 설정·임계값은 각 회차의 학습 참여자만을
  사용한 5배 내부 검증으로 미리 고정하고, 5배·25배에 동일하게 적용했다.
- 원본과 24개 파생 창의 가중치 합을 원래 창의 가중치와 같게 한다. 경계 자세의 라벨이 반전·잡음
  후에도 유지된다는 가정과 잡음의 실제 촬영 적합성은 미검증이다.

## 원본 실제 자료의 비교 결과

각 숫자는 시험 참여자별 balanced accuracy의 평균이다. 5배와 25배는 같은 하이퍼파라미터와
임계값으로 비교했다. 증강 전은 같은 방식의 별도 내부 검증을 거친 원래 모델이다.

| 모델 | 증강 전 | 5배 | 25배 |
| --- | ---: | ---: | ---: |
| 랜덤 포레스트 | 91.1% | 91.6% | 92.1% |
| LightGBM | 88.5% | 89.0% | 88.7% |

시도 단위 점수 중앙값으로 계산한 참여자별 balanced accuracy 평균은 랜덤 포레스트
93.2% → 93.1% → 95.2%, LightGBM 90.3% → 91.3% → 91.3%다.
3초 연속 이탈을 각 안내 구간에서 따로 재생하면 랜덤 포레스트 5배와 25배 모두
이탈 시도·재시도 **55/71 감지**, 기준 구간 **5/56 이탈 감지**였다. 증강 전은 각각
56/71, 7/56이다. 유효 창이 없는 1개 시도·재시도는 분모에서 제외했다.

작은 집단에서 의도적으로 수행한 안내 라벨을 사용했으므로 차이를 확정적 성능 향상으로
해석하지 않는다. 이동·복귀·일상 작업은 자료에 없어 실생활 오알림률이나 실제 발생 시점부터의
지연은 측정할 수 없다. 의자 이동 보정과 재등록은 구현하거나 평가하지 않았다.

## 실행

기존 `requirements-training.txt`, `requirements-trees.txt` 환경과 비공개 카탈로그가 필요하다.
동일인 여부를 확인한 후 저장소 루트에서 실행한다.

```powershell
python -m model.analysis.replay_pilot.augment_50k --catalog "<private>/catalog.json" --output "<private>/augmentation-50k-run-01"
```

신원 확인 전에는 탐색에 한해 `--allow-unverified-identities`를 추가한다. 폴더는 새로 만들어야
하며 원본 파일과 카탈로그의 해시를 실험 전후 검사한다. `report.json`에는 분할·설정·버전·코드와
모델 해시가 있다. 각 fold 모델은 해당 시험 참여자를 빼고 학습했다. `all-data-25x-*` 모델은 전체
사람으로 재학습한 후보이며 별도의 독립 시험을 받지 않았다. 원본·카탈로그·가중치·보고서는 Git 밖의
접근 제한 위치에 둔다. `joblib`은 신뢰할 수 있는 파일만 불러온다.

## 외부 데이터 견적과 보류 사항

- [Multi-view Sitting Posture Dataset](https://github.com/LKW123800/multi-view-sitting-posture-dataset):
  논문은 전체 49,798장과 7가지 자세, 다중 시점을 설명하며, 논문에서 사용한 정면 시점 묶음은
  5,095장이다. [논문](https://pure.hw.ac.uk/ws/portalfiles/portal/151801017/LGCSPNet_posture_management.pdf)
  은 남성 참여자를 언급한다. 정면 이미지를 확보하면 얼굴·어깨 키포인트 추출과 라벨 일치를 먼저
  검사할 수 있다. 현재 공개 저장소는 바이두 공유 링크만 제공하고 이 환경에서는 보안 정책으로
  접근이 차단되어 실제 파일·참여자 ID·라이선스·추출 성공률을 확인하지 못했다. 요청에 따라 자료
  취득은 보류했다. 이미지 5,095장 전부가 독립된 5,095명이라는 뜻은 아니다.
- [MultiPosture](https://zenodo.org/records/14230872): 13명이 다양한 착석 자세를 취한 영상에서
  MediaPipe로 미리 추출한 3D 관절 좌표와 몸통·다리 라벨의 CSV다. 원본 이미지·영상은 없다.
  이전 별도 실험의 실제 행 수는 4,794개였다. 골반 기준 정규화와 우리 2D 좌표·개인 등록 기준의
  차이 때문에 지금의 모델에 자동으로 합칠 수 없다. 과거 시험은 [기존 기록](../../../docs/ml/jisung/2026-10-13-desktop-multiposture-training.md)을 따른다.

이미지 라벨만으로 절대 자세 분류기를 실험하는 방향은 가능하지만 개인 기준 이탈 판정과 다른
목표다. 외부 데이터의 `upright`를 이용해 시험 참여자 기준을 사후에 골라서는 안 된다. 나중에
외부 자료를 쓰면 촬영자·세션 단위로 먼저 분리하고, 얼굴·어깨 가시성 및 라벨별 표본을 확인한다.
정지 이미지에 시간 순서가 없다면 1초 창과 3초 알림 평가를 구성할 수 없다.
