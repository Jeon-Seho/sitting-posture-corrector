# Database 작업 지도

루트 [AGENTS.md](../AGENTS.md)와 [아키텍처](../docs/architecture.md)를 먼저 따른다.

- 담당: 저장 스키마, 마이그레이션, 보존/삭제 규칙. DB 제품은 미정이다.
- 세션 집계와 개인 기준·연구 데이터의 보존 목적을 구분한다.
- 실제 영상·랜드마크·참여자 식별 데이터는 Git에 저장하지 않는다.
- 스키마 변경 시 적용/복구 방법과 데이터 호환성을 문서화한다.
- 첫 구현 때 합성 데이터 기반 마이그레이션 검증을 루트 게이트에 연결한다.
- 운영 데이터 삭제·변경은 개발용 마이그레이션 검증과 구분한다.
